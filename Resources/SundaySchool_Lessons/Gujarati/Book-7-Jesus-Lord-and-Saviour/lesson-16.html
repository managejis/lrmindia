ધનવાન મૂર્ખ શું ભૂલી ગયો

Download Word

હેતુ

બાળકોને શીખવવું કે જીવનમાં સંપત્તિ કરતાં વધુ અગત્યની બાબતો છે.

શાસ્ત્રવાંચન

લૂક 12:15-21

મુખપાઠ કલમ

યોહાન 1:12

પાઠ 15નો મુખપાઠનો કલમ પૂરો કરો. તોપણ જેટલાએ તેનો સ્વીકાર કર્યો, એટલે જેમણે તેના નામ પર વિશ્વાસ કર્યો, તેમને તેણે ઈશ્વરનાં બાળકો થવાનો અધિકાર આપ્યો …

પાઠની રજૂઆત

શરૂઆત

લગભગ દરેકને શ્રીમંત થવું છે! જો તમે શ્રીમંત હો તો તમે શાના માલિક બનવા માગો?

પાઠના મુખ્ય મુદ્દાઓ

1. મોટા ભાગના લોકો જે ભૂલી જાય છે તે એ છે કે મહાન સંપત્તિ સાથે મોટી જવાબદારીઓ આવે છે. ઈસુએ એક ધનવાન માણસ વિશે વાર્તા કહી. સાંભળો અને જુઓ કે તેને તમારી જવાબદારીઓ યાદ રહી કે નહિ.

2. ધનવાન માણસ પાસે ફળદ્રુપ જમીન હતી જેમાં સારો પાક થતો. હકીકતમાં, તેની પાસે જલદી સંગ્રહ કરવાની જગ્યા ખૂટી પડી. ચિત્ર 16 બતાવો. તેણે નક્કી કર્યું કે ઉકેલ એ છે કે વધુ મોટા કોઠારો બાંધવા (12:16-18).

3. ધનવાન માણસે પોતાની સંપત્તિ પોતાની આસપાસના ગરીબો સાથે વહેંચવાનો વિચાર પણ કર્યો નહિ. તેને એટલું પણ સમજાયું નહિ કે તેના આશીર્વાદો ઈશ્વર તરફથી આવ્યા હતા. તેને ફક્ત પોતાની જ પરવા હતી અને પોતાને જ ખુશ કરવા માગતો હતો (12:19).

4. પૈસા બધું ખરીદી શકતા નથી, જેમ ધનવાન માણસને અંતે ખબર પડી. ઈશ્વર, જેમણે ધનવાન માણસને ફળદ્રુપ પાક આપ્યો હતો, તેમણે તેનો પ્રાણ લઈ લીધો. ત્યારે તેની સંપત્તિ તેના કોઈ કામની ન રહી. ધનવાન માણસ ઈશ્વરને ભૂલીને આ જગતની સંપત્તિ અને સુખો માટે જીવવામાં મૂર્ખ હતો (12:20-21).

વાર્તા પ્રત્યે આપણો પ્રતિભાવ

ઈસુ ઇચ્છે છે કે આપણે સમજીએ કે આપણી પાસે જે વસ્તુઓ છે તે આપણા જીવનમાં બીજા સ્થાને હોવી જોઈએ. ઈશ્વર આપણને જે કંઈ આપણી પાસે છે તે બધું આપે છે, તેથી તેમને પ્રથમ સ્થાન મળવું જોઈએ. આપણે સૌપ્રથમ તેમને ખુશ કરવાની ચિંતા કરવી જોઈએ.

આનો અર્થ એ કે આ વાર્તાનો બોધ આપણા સૌ માટે છે, ફક્ત જેમને આપણે શ્રીમંત માનીએ છીએ તેમના માટે જ નહિ. ગરીબ લોકો પણ એટલા લોભી કે ઈર્ષ્યાળુ થઈ શકે છે કે સંપત્તિ તેમના જીવનની સૌથી અગત્યની બાબત બની જાય છે. વાર્તામાં ધનવાન માણસના જીવન કે યોજનાઓમાં ઈશ્વરનું કોઈ સ્થાન ન હતું. જ્યારે આપણે ઈશ્વર પાસેથી મેળવેલું વહેંચીએ છીએ ત્યારે તેમને આનંદ થાય છે. ઈશ્વર આપણને આ જગતમાં જે જોઈએ તે માટે તેમના પર ભરોસો રાખવા કહે છે, કારણ કે તે આપણને કામ કરવાની શક્તિ આપે છે, અને તે આપણને સ્વર્ગમાં સંપત્તિ આપશે (12:15, 21).

પાઠ - 16: ધનવાન મૂર્ખ શું ભૂલી ગયો

શાસ્ત્રવાંચન: લૂક 12:15-21

1. સાચા શબ્દોને ફરતે કુંડાળું કરો

સાચા શબ્દ પર ગોળ કરો:

  • ધનવાન માણસની જમીને (મોટો / નાનો) પાક આપ્યો. 👉 મોટો
  • તેણે (વધુ મોટા / વધુ નાના) કોઠારો બાંધવાનું નક્કી કર્યું. 👉 વધુ મોટા
  • તે (ઈશ્વરને / ખેતીને) ભૂલી ગયો. 👉 ઈશ્વરને

2. વહેંચવું કે રાખવું? વ/રા

જો આપણે વહેંચીએ તો વ અથવા ફક્ત રાખીએ તો રા લખો:

  • હું મારા ભૂખ્યા મિત્રને મારા ખોરાકમાંથી થોડું આપું છું. ( ___ ) 👉 વ
  • હું મારાં રમકડાં સંતાડી દઉં છું જેથી કોઈ તેનો ઉપયોગ ન કરી શકે. ( ___ ) 👉 રા
  • મારી પાસે જે કંઈ છે તે માટે હું ઈશ્વરનો આભાર માનું છું. ( ___ ) 👉 વ

3. હા કે ના?

હા માટે “હા” અથવા ના માટે “ના” લખો:

  • શું ધનવાન માણસે ગરીબોનો વિચાર કર્યો? ( ___ ) 👉 ના
  • શું આપણી પાસે જે કંઈ છે તે બધું ઈશ્વર તરફથી આવ્યું છે? ( ___ ) 👉 હા
  • શું ઈશ્વર વસ્તુઓ કરતાં વધુ અગત્યના છે? ( ___ ) 👉 હા

4. ચર્ચાના પ્રશ્નો

  • ધનવાન માણસ શું ભૂલી ગયો?

નમૂનારૂપ જવાબ: ઈશ્વર, અને બીજાઓ સાથે વહેંચવું.

  • જીવનમાં સૌથી વધુ અગત્યનું શું છે?

નમૂનારૂપ જવાબ: વસ્તુઓ ધરાવવા કરતાં ઈશ્વરને પ્રેમ કરવો અને તેમને ખુશ કરવા.

  • તમે શું વહેંચી શકો?

નમૂનારૂપ જવાબ: ખોરાક, રમકડાં, સમય અને બીજાઓ માટે મદદ.

5. મુખપાઠ કલમ:

યોહાન 1:12 — “તોપણ જેટલાએ તેનો સ્વીકાર કર્યો, એટલે જેમણે તેના નામ પર વિશ્વાસ કર્યો, તેમને તેણે ઈશ્વરનાં બાળકો થવાનો અધિકાર આપ્યો ...”

માથ્થી 6:33 — “પહેલાં તેમના રાજ્યને અને તેમના ન્યાયીપણાને શોધો, એટલે આ બધી વસ્તુઓ પણ તમને આપવામાં આવશે.”

હસ્તકલા 1: કોઠારનું ચિત્ર

સામગ્રી: લાલ કાગળ, પીળી ક્રેયોન, ગુંદર

સૂચનાઓ:

  • લાલ કાગળમાંથી કોઠાર કાપો.
  • સોનેરી અનાજ દોરો.
  • લખો: “ઈશ્વર પ્રથમ.”

પાઠનો મુદ્દો: આપણી પાસે જે કંઈ છે તે બધું ઈશ્વર તરફથી આવે છે.

હસ્તકલા 2: વહેંચવાની થેલી

સામગ્રી: કાગળની થેલી, ક્રેયોન

સૂચનાઓ:

  • થેલીને શણગારો.
  • લખો: “હું વહેંચીશ.”
  • કોઈ માટે નાની ભેટ અંદર મૂકો.

પાઠનો મુદ્દો: જ્યારે આપણે વહેંચીએ છીએ ત્યારે ઈશ્વરને આનંદ થાય છે.

રમત 1: કોઠાર ભરો

રમવાની રીત:

  • બાળકો “કોઠાર” લખેલા ખોખામાં કાગળના ગોળા મૂકે છે.
  • પછી તેમાંથી થોડા “પડોશી” ખોખામાં આપે છે.
  • વહેંચવા વિશે વાત કરો.

પાઠનો મુદ્દો: ઈશ્વર ઇચ્છે છે કે આપણી પાસે જે છે તે આપણે વહેંચીએ.

રમત 2: વહેંચો કે રાખો

રમવાની રીત:

  • રમકડા કે નાસ્તાનું ચિત્ર ઊંચું ઝાલો.
  • બાળકો “વહેંચો!” કહે છે અને વહેંચવાની ક્રિયા કરી બતાવે છે.
  • ચિત્રોની અદલાબદલી કરો.

પાઠનો મુદ્દો: બધું રાખવા કરતાં વહેંચવું વધુ સારું છે.
