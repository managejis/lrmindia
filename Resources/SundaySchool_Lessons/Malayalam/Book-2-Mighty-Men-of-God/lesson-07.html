ഈജിപ്തിലെ അടിമയായ യോസേഫ്

Download Word

അധ്യാപക മാർഗ്ഗദർശി · നോക്കൂ, കേൾക്കൂ, ജീവിക്കൂ – പുസ്തകം 2: ദൈവത്തിന്റെ ശക്തരായ പുരുഷന്മാർ

ലക്ഷ്യം

യോസേഫിന്റെ സാഹചര്യങ്ങൾ എന്തായിരുന്നാലും ദൈവം അവനോടുകൂടെ ഉണ്ടായിരുന്നു എന്ന് കുട്ടികളെ പഠിപ്പിക്കുക. അവന്റെ എല്ലാ ബുദ്ധിമുട്ടുകളിലും ദൈവം അവനെ അനുഗ്രഹിച്ചു.

തിരുവെഴുത്ത് വായന

ഉല്പത്തി 39:1-23

മനഃപാഠ വാക്യം

1 കൊരിന്ത്യർ 10:13

ദൈവം … നിങ്ങളുടെ കഴിവിനപ്പുറം പരീക്ഷിക്കപ്പെടുവാൻ അനുവദിക്കയില്ല.

പാഠം അവതരിപ്പിക്കൽ

തുടക്കം

രണ്ടു കുട്ടികളെക്കുറിച്ച് ഒരു കഥ ഉണ്ടാക്കുക: ഇളയവൻ വീട്ടിൽ എന്തെങ്കിലും പൊട്ടിക്കുകയോ പഞ്ചസാര മോഷ്ടിക്കുകയോ ചെയ്യുന്നു, എന്നാൽ മാതാപിതാക്കൾ മൂത്ത കുട്ടിയെ കുറ്റപ്പെടുത്തി തെറ്റായി ശിക്ഷിക്കുന്നു. തീർച്ചയായും ഇത് വളരെ അന്യായമാണ്.

ഇന്നത്തെ പഠിപ്പിക്കലിലെ പ്രധാന കാര്യങ്ങൾ

1. യോസേഫിന് വളരെ അന്യായമായ ചില കാര്യങ്ങൾ സംഭവിച്ചു. അവ എന്തൊക്കെയായിരുന്നു എന്ന് ക്ലാസ്സിനോട് ചോദിക്കുക (ഉല്പ 37:11, 18-20, 23-24, 28 കാണുക). സഹോദരന്മാർ അവനെ സഞ്ചാരികളായ കച്ചവടക്കാർക്ക് വിറ്റ സമയത്ത് യോസേഫ് ഒരുപക്ഷേ അത്ര ഇഷ്ടപ്പെടാവുന്ന വ്യക്തി ആയിരുന്നില്ല; എങ്കിലും അവരുടെ ശിക്ഷ വളരെ ക്രൂരമായിരുന്നു.

2. ഈജിപ്തിലെ രാജാവിന്റെ ഒരു പ്രധാന ഉദ്യോഗസ്ഥനായ പോത്തീഫറിന് യോസേഫിനെ അടിമയായി വിറ്റു. യോസേഫ് നന്നായി ജോലി ചെയ്ത് വിശ്വസ്ത ദാസനായിത്തീർന്നു. പോത്തീഫറിന്റെ വീട്ടുകാര്യങ്ങളെല്ലാം നോക്കാൻ അവനെ ചുമതലപ്പെടുത്തി. അവന് വലിയ ഉത്തരവാദിത്വം ലഭിച്ചു; അവൻ ചെയ്തതെല്ലാം ദൈവം അനുഗ്രഹിച്ചു (39:1-6).

3. എന്നാൽ യോസേഫിന് കൂടുതൽ കഷ്ടതകൾ വന്നു. പോത്തീഫറിന്റെ ഭാര്യ യോസേഫിനെ സ്വന്തമാക്കാൻ ആഗ്രഹിച്ചു. അവളുടെ പ്രലോഭനങ്ങളെ യോസേഫ് പലപ്പോഴും നിരസിച്ചു (39:7-10).

4. അവളുടെ ആവശ്യങ്ങൾക്ക് വഴങ്ങുന്നതിനു പകരം യോസേഫ് പോത്തീഫറിന്റെ ഭാര്യയുടെ അടുത്തുനിന്ന് ഓടിപ്പോയി. അവൾ അവന്റെ വസ്ത്രത്തിന്റെ ഒരു കഷണം കീറിയെടുത്തു (39:11-15). ചിത്രം 7 കാണിക്കുക.

5. ഈ സംഭവത്തെക്കുറിച്ച് ഭാര്യ പറഞ്ഞ നുണകൾ പോത്തീഫർ വിശ്വസിച്ചു. താൻ ചെയ്യാത്ത ഒരു കാര്യത്തിന് യോസേഫ് ജയിലിലായി (39:16-20).

6. എന്നാൽ ജയിലിൽ പോലും ദൈവം യോസേഫിനോടുകൂടെ ഉണ്ടായിരുന്നു (39:21-23).

കഥയോടുള്ള നമ്മുടെ പ്രതികരണം

ഇത് യോസേഫിനോട് വളരെ അന്യായമായിരുന്നു. നിരപരാധി ആയിരുന്നിട്ടും അവൻ 8-10 വർഷം ജയിലിൽ കഴിഞ്ഞു. എങ്കിലും അവൻ ദൈവത്തിൽ ആശ്രയിക്കുകയും അവിടുത്തെ നിയമങ്ങൾ അനുസരിക്കുകയും ചെയ്തു. ദൈവം എല്ലാം നിയന്ത്രിക്കുന്നു എന്ന് അവൻ വിശ്വസിച്ചു; ദൈവം യോസേഫിനെ അവൻ ചെയ്ത എല്ലാറ്റിലും അനുഗ്രഹിച്ചു. ഒരു ദിവസം ദൈവം നമ്മെയെല്ലാം വിധിക്കുകയും തിന്മ തിരഞ്ഞെടുക്കുന്നവരെ തള്ളിക്കളയുകയും ചെയ്യും. എന്നാൽ തന്നിൽ ആശ്രയിക്കുന്നവർക്ക് തങ്ങളുടെ മുമ്പിൽ വരുന്ന പ്രലോഭനങ്ങളെ ചെറുക്കാനുള്ള ശക്തി ദൈവം നൽകുന്നു. ഇതിനെക്കുറിച്ച് ഇന്നത്തെ മനഃപാഠ വാക്യം എന്താണു പറയുന്നതെന്ന് നോക്കുക.

കാര്യങ്ങൾ ബുദ്ധിമുട്ടാകുമ്പോൾ യോസേഫിന്റെ മാതൃക ഓർക്കുക. ആമുഖമായി പറഞ്ഞ കഥ ക്ലാസ്സിനെ ഓർമ്മിപ്പിക്കുക.

മനഃപാഠ വാക്യം ഹൃദിസ്ഥമാക്കൽ

പാഠം - 7 : ഈജിപ്തിലെ അടിമയായ യോസേഫ്

തിരുവെഴുത്ത് വായന: ഉല്പത്തി 39:1-23

1. ശരിയോ തെറ്റോ

ശരിക്ക് ‘ശ’ എന്നും തെറ്റിന് ‘തെ’ എന്നും എഴുതുക:

  1. യോസേഫ് പോത്തീഫറിനുവേണ്ടി നന്നായി ജോലി ചെയ്തു. ( ___ ) 👉 ശ

  2. യോസേഫ് തെറ്റു ചെയ്യാൻ സമ്മതിച്ചു. ( ___ ) 👉 തെ

  3. യോസേഫ് പ്രലോഭനത്തിൽ നിന്ന് ഓടിപ്പോയി. ( ___ ) 👉 ശ

  4. ദൈവം യോസേഫിനെ ജയിലിൽ തനിച്ചാക്കി. ( ___ ) 👉 തെ

2. ചേരുന്നവ ചേർക്കുക

A B
പോത്തീഫർ യോസേഫിന്റെ യജമാനൻ
പോത്തീഫറിന്റെ ഭാര്യ യോസേഫിനെക്കുറിച്ച് കള്ളം പറഞ്ഞു
യോസേഫ് ദൈവത്തെ വിശ്വസ്തതയോടെ സേവിച്ചു
ദൈവം യോസേഫിനോടുകൂടെ ഉണ്ടായിരുന്നു

ഉത്തരങ്ങൾ:
പോത്തീഫർ → യോസേഫിന്റെ യജമാനൻ
പോത്തീഫറിന്റെ ഭാര്യ → യോസേഫിനെക്കുറിച്ച് കള്ളം പറഞ്ഞു
യോസേഫ് → ദൈവത്തെ വിശ്വസ്തതയോടെ സേവിച്ചു
ദൈവം → യോസേഫിനോടുകൂടെ ഉണ്ടായിരുന്നു

3. പ്രലോഭനത്തോട് അതെ അല്ലെങ്കിൽ ഇല്ല എന്നു പറയുക

ശരിയായ തിരഞ്ഞെടുപ്പ് വട്ടമിടുക:

  1. ഒരു കൂട്ടുകാരൻ “നമുക്ക് മോഷ്ടിക്കാം” എന്നു പറയുമ്പോൾ ഞാൻ (അതെ / ഇല്ല) എന്നു പറയും. 👉 ഇല്ല

  2. ആരെങ്കിലും നുണ പറയാൻ പറഞ്ഞാൽ ഞാൻ (സമ്മതിക്കും / നിരസിക്കും). 👉 നിരസിക്കും

  3. എനിക്ക് പ്രലോഭനം ഉണ്ടാകുമ്പോൾ ഞാൻ (പ്രാർത്ഥിക്കും / വഴങ്ങും). 👉 പ്രാർത്ഥിക്കും

4. ചർച്ചാ ചോദ്യങ്ങൾ

  1. യോസേഫിന് എന്തൊക്കെ അന്യായമായ കാര്യങ്ങൾ സംഭവിച്ചു?

    മാതൃകാ ഉത്തരം: അവനെ അടിമയായി വിൽക്കുകയും താൻ ചെയ്യാത്ത കുറ്റത്തിന് ജയിലിലടയ്ക്കുകയും ചെയ്തു.

  2. യോസേഫ് പ്രലോഭനത്തെ എങ്ങനെ ചെറുത്തു?

    മാതൃകാ ഉത്തരം: അവൻ ഇല്ല എന്നു പറഞ്ഞ് ഓടിപ്പോയി.

  3. തെറ്റിനോട് ഇല്ല എന്നു പറയാൻ നിനക്ക് എന്താണ് സഹായിക്കുന്നത്?

    മാതൃകാ ഉത്തരം: പ്രാർത്ഥിക്കുന്നതും ദൈവവചനം ഓർക്കുന്നതും.

5. മനഃപാഠ വാക്യം:

1 കൊരിന്ത്യർ 10:13 — “ദൈവം നിങ്ങളെ നിങ്ങളുടെ കഴിവിനപ്പുറം പരീക്ഷിക്കപ്പെടുവാൻ അനുവദിക്കയില്ല.”

സങ്കീർത്തനം 119:11 — “ഞാൻ നിനക്കെതിരെ പാപം ചെയ്യാതിരിക്കേണ്ടതിന് നിന്റെ വചനം എന്റെ ഹൃദയത്തിൽ സംഗ്രഹിച്ചിരിക്കുന്നു.”

കരകൗശലം 1: നിർത്തുക എന്ന ചിഹ്നം

സാമഗ്രികൾ: ചുവന്ന കടലാസ്, വെളുത്ത കടലാസ്, ക്രാഫ്റ്റ് സ്റ്റിക്ക്, പശ

നിർദ്ദേശങ്ങൾ:

  1. ഒരു ചുവന്ന വൃത്തം മുറിച്ച് ഒരു വടിയിൽ ഒട്ടിക്കുക.

  2. വെളുത്ത അക്ഷരങ്ങളിൽ “നിർത്തുക” എന്ന് എഴുതുക.

  3. താഴെ എഴുതുക: “തെറ്റിനോട് ഇല്ല എന്നു പറയുക.”

പാഠ സന്ദേശം: പ്രലോഭനത്തെ ചെറുക്കാൻ ദൈവം ശക്തി നൽകുന്നു.

കരകൗശലം 2: ദൈവം എന്നോടുകൂടെ - ജനാല

സാമഗ്രികൾ: കാർഡ്, ക്രയോണുകൾ, കത്രിക

നിർദ്ദേശങ്ങൾ:

  1. മടക്കിയ കാർഡിന്റെ മുൻഭാഗത്ത് ജനാലക്കമ്പികൾ വരയ്ക്കുക.

  2. ഉള്ളിൽ പുഞ്ചിരിക്കുന്ന യോസേഫിനെ വരയ്ക്കുക.

  3. എഴുതുക: “ദൈവം എന്നോടുകൂടെ ഉണ്ട്.”

പാഠ സന്ദേശം: ജയിലിൽ പോലും ദൈവം യോസേഫിനോടുകൂടെ ഉണ്ടായിരുന്നു.

കളി 1: ഇല്ല എന്നു പറയുക!

കളിക്കുന്ന വിധം:

  1. അധ്യാപകൻ ചെയ്യാൻ പാടില്ലാത്ത തെറ്റായ കാര്യങ്ങൾ വിളിച്ചുപറയുന്നു.

  2. എല്ലാ കുട്ടികളും “ഇല്ല!” എന്ന് വിളിച്ചുപറഞ്ഞ് കൈകൾ പിണച്ചുവയ്ക്കുന്നു.

  3. നല്ല കാര്യങ്ങൾക്ക് “അതെ!” എന്ന് വിളിച്ചുപറയുന്നു.

പാഠ സന്ദേശം: പാപത്തോട് ഇല്ല എന്നു പറയാൻ നാം തീരുമാനിക്കണം.

കളി 2: ഓടിപ്പോകുക!

കളിക്കുന്ന വിധം:

  1. ഒരു മൂലയിൽ “പ്രലോഭിപ്പിക്കുന്ന” ഒരു മിഠായി വയ്ക്കുക.

  2. കുട്ടികൾ അതിൽ തൊടാതെ അതിനടുത്തുകൂടി നടന്ന് അകന്നുപോകുന്നു.

  3. യോസേഫ് പ്രലോഭനത്തിൽ നിന്ന് ഓടിപ്പോയതിനെക്കുറിച്ച് സംസാരിക്കുക.

പാഠ സന്ദേശം: യോസേഫ് പാപത്തിൽ നിന്ന് ഓടിപ്പോയി.
