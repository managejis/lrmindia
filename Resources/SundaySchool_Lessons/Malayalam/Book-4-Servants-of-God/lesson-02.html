നൊവൊമിയും രൂത്തും ഇസ്രായേലിലേക്കു മടങ്ങുന്നു

Download Word

അധ്യാപക മാർഗ്ഗദർശി · നോക്കൂ, കേൾക്കൂ, ജീവിക്കൂ – പുസ്തകം 4: ദൈവത്തിന്റെ ദാസന്മാർ

ലക്ഷ്യം

തന്റെ അമ്മായിയമ്മയായ നൊവൊമിയോടുള്ള രൂത്തിന്റെ പ്രതിബദ്ധത സ്നേഹത്തിന്റെയും വിശ്വസ്തതയുടെയും ശ്രേഷ്ഠമായ ഉദാഹരണമാണെന്ന് കുട്ടികളെ കാണിക്കുക.

തിരുവെഴുത്ത് വായന

രൂത്ത് 1:6-22

മനഃപാഠ വാക്യം

സങ്കീർത്തനം 121:2

എന്റെ സഹായം ആകാശവും ഭൂമിയും ഉണ്ടാക്കിയ യഹോവയിങ്കൽനിന്നു വരുന്നു.

പാഠം അവതരിപ്പിക്കൽ

തുടക്കം

അഭയാർത്ഥികളും കുടിയൊഴിപ്പിക്കപ്പെട്ടവരും തങ്ങൾ ആദ്യം വന്ന രാജ്യങ്ങളിലേക്കോ പ്രദേശങ്ങളിലേക്കോ മടങ്ങാൻ കാരണമാകുന്നത് എന്താണെന്ന് ക്ലാസിനോടു ചോദിക്കുക. മടങ്ങിപ്പോകാനുള്ള ഏറ്റവും പ്രധാന കാരണങ്ങൾ അവിടെ വീണ്ടും ഭക്ഷണം ഉണ്ടെന്നതും അത് സുരക്ഷിതമായ സ്ഥലമാണെന്നതുമാണ്.

പാഠത്തിലെ പ്രധാന ആശയങ്ങൾ

1. ചിത്രം 1 കാണിക്കുക. നൊവൊമിയും കുടുംബവും ഇസ്രായേലിലെ ബേത്ലഹേമിൽ നിന്നുള്ള അഭയാർത്ഥികളായിരുന്നു. ഇപ്പോൾ നൊവൊമിയുടെ ഭർത്താവും പുത്രന്മാരും മരിച്ചു; മോവാബ് എന്ന ആ അന്യദേശത്ത് അവൾക്ക് രക്തബന്ധുക്കൾ ആരും ഇല്ലായിരുന്നു. അവളെയും അവളുടെ രണ്ടു അന്യദേശക്കാരായ മരുമക്കളായ ഒർപ്പായെയും രൂത്തിനെയും നോക്കാൻ ആരും ഇല്ലായിരുന്നു. അപ്പോൾ തന്റെ പിതൃദേശമായ ഇസ്രായേലിലെ ക്ഷാമം അവസാനിച്ചുവെന്ന് നൊവൊമി കേട്ടു. അതിനാൽ വീട്ടിലേക്കു മടങ്ങാൻ അവൾ തീരുമാനിച്ചു (1:6).

2. നൊവൊമിയും ഒർപ്പായും രൂത്തും ഒരുമിച്ചു പുറപ്പെട്ടു. പിന്നെ ഒർപ്പായോടും രൂത്തിനോടും മോവാബിലെ അവരുടെ ബന്ധുക്കളുടെ അടുത്തേക്കു മടങ്ങിപ്പോകാനും നൊവൊമിയെ തനിയെ ബേത്ലഹേമിലേക്കു പോകാൻ അനുവദിക്കാനും നൊവൊമി പറഞ്ഞു. അവർ നല്ല മരുമക്കളായിരുന്നു, എന്നാൽ അവർക്ക് വിവാഹം കഴിക്കാൻ നൊവൊമിക്ക് ഇനി പുത്രന്മാർ ഇല്ലായിരുന്നു; അവർ വീണ്ടും സ്വന്തം കുടുംബങ്ങൾ തുടങ്ങേണ്ടിയിരുന്നു. വലിയ ദുഃഖത്തോടെ ഒർപ്പാ അവളെ വിട്ട് തന്റെ സ്വന്തം ജനത്തിലേക്കു മടങ്ങി (1:6-14).

3. എന്നാൽ നൊവൊമിയോടൊപ്പം നിൽക്കാൻ രൂത്ത് അപേക്ഷിച്ചു. അവൾ പറഞ്ഞു: “നിന്നെ വിട്ടുപോകാൻ എന്നെ നിർബന്ധിക്കരുതേ. നീ പോകുന്നിടത്തു ഞാനും പോകും; നീ പാർക്കുന്നിടത്തു ഞാനും പാർക്കും. നിന്റെ ജനം എന്റെ ജനം, നിന്റെ ദൈവം എന്റെ ദൈവം.” അങ്ങനെ രൂത്ത് നൊവൊമിയോടൊപ്പം ഇസ്രായേലിലെ ബേത്ലഹേമിലേക്കു പോയി (1:14-17). ചിത്രം കാണിക്കുക

2. ഒർപ്പാ മോവാബിലേക്കു മടങ്ങുന്നത് ചൂണ്ടിക്കാണിക്കുക.

4. നൊവൊമി രൂത്തിനോടൊപ്പം ബേത്ലഹേമിൽ എത്തിയപ്പോൾ അവിടെയുള്ള എല്ലാവരും അവളെ കണ്ട് ആവേശഭരിതരായി. എന്നാൽ പത്തു വർഷം മുമ്പ് പട്ടണം വിട്ടുപോയ സ്ത്രീ നൊവൊമിയാണെന്ന് ആദ്യം അവർക്ക് ഏതാണ്ട് തിരിച്ചറിയാൻ കഴിഞ്ഞില്ല. ദുഃഖം ഒരുപക്ഷേ അവളുടെ മുഖം മാറ്റിയിരുന്നു. തന്റെ പേരും മാറ്റാൻ അവൾ ആഗ്രഹിച്ചു. നൊവൊമി എന്നാൽ “മനോഹരി” എന്നാണ്. ഇപ്പോൾ “കയ്പ്” എന്നർത്ഥമുള്ള മാറാ എന്നു വിളിക്കപ്പെടാൻ അവൾ ആഗ്രഹിച്ചു.

5. എന്നാൽ വളരെ വിശ്വസ്തയും സഹായിയുമായ മരുമകൾ തന്നോടൊപ്പം താമസിക്കുന്നതിലൂടെ നൊവൊമി അനുഗ്രഹിക്കപ്പെട്ടു. രൂത്ത് അവളോടു പറഞ്ഞത് ഓർക്കുന്നുണ്ടോ? 16-17 വാക്യങ്ങളിലെ രൂത്തിന്റെ വാക്കുകൾ വീണ്ടും വായിക്കുക. വളരെ ദരിദ്രയായ വിധവയായ നൊവൊമിയോടൊപ്പം നിൽക്കാൻ രൂത്ത് സ്വന്തം കുടുംബത്തെയും സ്വന്തം രാജ്യത്തെയും സ്വന്തം മതത്തെയും ഉപേക്ഷിക്കാൻ തയ്യാറായി.

കഥയോടുള്ള നമ്മുടെ പ്രതികരണം

പ്രതിഫലമൊന്നും പ്രതീക്ഷിക്കാതെ നൊവൊമിയോടൊപ്പം ഇരിക്കാൻ രൂത്ത് എല്ലാം ഉപേക്ഷിക്കാൻ തയ്യാറായിരുന്നു. ഈ ആഴ്ച പകരം ഒന്നും പ്രതീക്ഷിക്കാതെ നിങ്ങളുടെ സമൂഹത്തിലെ ആർക്കെങ്കിലും വേണ്ടി എന്തെങ്കിലും ചെയ്യാൻ നിങ്ങൾ ഓരോരുത്തരെയും ഞാൻ വെല്ലുവിളിക്കുന്നു. “മറ്റൊരു രൂത്ത്” ആകാൻ ശ്രമിക്കുക.

മനഃപാഠ വാക്യം ഹൃദിസ്ഥമാക്കൽ

അടുത്ത പാഠത്തിൽ ദൈവം രൂത്തിനെയും നൊവൊമിയെയും പരിപാലിച്ച വിധത്തിൽ ഈ വാക്യത്തിന്റെ ഒരു ഉദാഹരണം നാം കാണും.

പാഠം 1-ലെ മനഃപാഠ വാക്യം അവലോകനം ചെയ്യുക.

പാഠം - 2 : നൊവൊമിയും രൂത്തും ഇസ്രായേലിലേക്കു മടങ്ങുന്നു

തിരുവെഴുത്ത് വായന: രൂത്ത് 1:6-22

1. ശരിയായ ഉത്തരം തിരഞ്ഞെടുക്കുക

a), b) അല്ലെങ്കിൽ c) വട്ടമിടുക:

  1. മോവാബിൽ സ്വന്തം ജനത്തിലേക്ക് തിരിച്ചുപോയത് ആര്?
    a) രൂത്ത് b) ഒർപ്പാ c) നൊവൊമി 👉 b) ഒർപ്പാ

  2. നൊവൊമിയോടൊപ്പം നിന്നത് ആര്?
    a) രൂത്ത് b) ഒർപ്പാ c) ബോവസ് 👉 a) രൂത്ത്

  3. മാറാ എന്നതിന്റെ അർത്ഥം എന്ത്?
    a) മനോഹരി b) കയ്പ് c) സന്തോഷം 👉 b) കയ്പ്

2. വിശ്വസ്തനോ സ്വാർത്ഥനോ? വി/സ്വ

വിശ്വസ്തതയ്ക്ക് ‘വി’ എന്നും സ്വാർത്ഥതയ്ക്ക് ‘സ്വ’ എന്നും എഴുതുക:

  1. ദുഃഖിതനായ ഒരു സുഹൃത്തിനോടൊപ്പം നിൽക്കുന്നു. ( ___ ) 👉 വി

  2. സഹായം വേണ്ട ഒരു സുഹൃത്തിനെ ഉപേക്ഷിക്കുന്നു. ( ___ ) 👉 സ്വ

  3. പ്രതിഫലം ചോദിക്കാതെ ഒരാളെ സഹായിക്കുന്നു. ( ___ ) 👉 വി

  4. സമ്മാനം കിട്ടുമ്പോൾ മാത്രം സഹായിക്കുന്നു. ( ___ ) 👉 സ്വ

3. കഥ ക്രമത്തിലാക്കുക

a) രൂത്ത് പറഞ്ഞു: “നിന്റെ ദൈവം എന്റെ ദൈവം ആയിരിക്കും.”
b) ക്ഷാമം തീർന്നെന്ന് നൊവൊമി കേട്ടു.
c) ബേത്ലഹേമിലെ സ്ത്രീകൾ നൊവൊമിയെ സ്വാഗതം ചെയ്തു.
d) ഒർപ്പാ മോവാബിലേക്കു മടങ്ങിപ്പോയി.

👉 ശരിയായ ക്രമം:

  1. ക്ഷാമം തീർന്നെന്ന് നൊവൊമി കേട്ടു.

  2. ഒർപ്പാ മോവാബിലേക്കു മടങ്ങിപ്പോയി.

  3. രൂത്ത് പറഞ്ഞു: “നിന്റെ ദൈവം എന്റെ ദൈവം ആയിരിക്കും.”

  4. ബേത്ലഹേമിലെ സ്ത്രീകൾ നൊവൊമിയെ സ്വാഗതം ചെയ്തു.

4. ചർച്ചാ ചോദ്യങ്ങൾ

  1. നൊവൊമി ബേത്ലഹേമിലേക്കു വീട്ടിലേക്കു മടങ്ങിയത് എന്തുകൊണ്ട്?

    മാതൃകാ ഉത്തരം: ഇസ്രായേലിൽ വീണ്ടും ഭക്ഷണം ഉണ്ടെന്ന് അവൾ കേട്ടു.

  2. രൂത്ത് നൊവൊമിക്ക് എന്തു വാഗ്ദാനം ചെയ്തു?

    മാതൃകാ ഉത്തരം: നൊവൊമി പോകുന്നിടത്തെല്ലാം പോകാമെന്നും അവളുടെ ദൈവത്തെ അനുഗമിക്കാമെന്നും അവൾ വാഗ്ദാനം ചെയ്തു.

  3. ഈ ആഴ്ച നിങ്ങൾക്ക് ആർക്ക് ഒരു “രൂത്ത്” ആകാൻ കഴിയും?

    മാതൃകാ ഉത്തരം: ഉത്തരങ്ങൾ വ്യത്യസ്തമായിരിക്കും. ഏകാകിയായ ഒരാൾ അല്ലെങ്കിൽ സഹായം വേണ്ട ഒരാൾ.

5. മനഃപാഠ വാക്യം:

കരകൗശലം 1: രണ്ടു നടക്കുന്നവർ കാർഡ്

സാമഗ്രികൾ: മടക്കിയ കാർഡ്, ക്രയോണുകൾ

നിർദ്ദേശങ്ങൾ:

  1. മുൻവശത്ത് ഒരുമിച്ചു നടക്കുന്ന രണ്ടു സ്ത്രീകളെ വരയ്ക്കുക.

  2. ഒരു വഴിക്കും മലകൾക്കും നിറം കൊടുക്കുക.

  3. ഉള്ളിൽ എഴുതുക: “നീ പോകുന്നിടത്തു ഞാനും പോകും.”

  4. ഒരു കൂട്ടുകാരന് കൊടുക്കുക.

പാഠ സന്ദേശം: രൂത്ത് നൊവൊമിയെ സ്നേഹിച്ചു, അവളോടൊപ്പം നിന്നു.

കരകൗശലം 2: സൗഹൃദ വള

സാമഗ്രികൾ: കമ്പിളിനൂൽ അല്ലെങ്കിൽ കടലാസ് സ്ട്രിപ്പുകൾ, ടേപ്പ്

നിർദ്ദേശങ്ങൾ:

  1. മൂന്ന് കമ്പിളിനൂൽ കഷണങ്ങൾ മുറിക്കുക.

  2. അവ ഒരുമിച്ച് പിന്നുക.

  3. അറ്റങ്ങൾ ഒരു കൂട്ടുകാരന്റെ കൈത്തണ്ടയിൽ ടേപ്പ് കൊണ്ട് ഒട്ടിക്കുക.

  4. പറയുക: “ഞാൻ നിന്റെ സുഹൃത്തായിരിക്കും.”

പാഠ സന്ദേശം: യഥാർത്ഥ സുഹൃത്തുക്കൾ പ്രയാസകാലത്ത് അടുത്തു നിൽക്കും.

കളി 1: ഒരുമിച്ച് നടക്കുക

കളിക്കുന്ന വിധം:

  1. കുട്ടികൾ ജോഡികളായി കൈകോർത്തു പിടിക്കുന്നു.

  2. “മലകളിലേക്ക്” (ഒരു കസേര) മുറിയിൽ പതുക്കെ നടക്കുക.

  3. ഒരുമിച്ചു പറയുക: “നീ പോകുന്നിടത്തു ഞാനും പോകും.”

പാഠ സന്ദേശം: രൂത്ത് നൊവൊമിയോടൊപ്പം വഴിമുഴുവൻ നടന്നു.

കളി 2: ദയാപ്രവൃത്തികളുടെ ഓട്ടം

കളിക്കുന്ന വിധം:

  1. രണ്ടു ടീമുകൾ ഉണ്ടാക്കുക.

  2. “ഒരു സഞ്ചി ചുമക്കുക” പോലുള്ള ഒരു ദയാപ്രവൃത്തി വിളിച്ചുപറയുക.

  3. അത് അഭിനയിക്കുന്ന ആദ്യ ടീമിന് ഒരു പോയിന്റ് കിട്ടും.

പാഠ സന്ദേശം: ദയാപ്രവൃത്തികൾ ചെയ്തുകൊണ്ട് നമുക്ക് “മറ്റൊരു രൂത്ത്” ആകാം.
