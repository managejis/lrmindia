ഏലിയാവും സ്വർഗ്ഗത്തിൽ നിന്നുള്ള തീയും

Download Word

അധ്യാപക മാർഗ്ഗദർശി · നോക്കൂ, കേൾക്കൂ, ജീവിക്കൂ – പുസ്തകം 4: ദൈവത്തിന്റെ ദാസന്മാർ

ലക്ഷ്യം

ഏലിയാവ് ബാലിന്റെ പ്രവാചകന്മാരെ തോൽപ്പിക്കുകയും ജീവനുള്ള ദൈവത്തിന്റെ ശക്തി പ്രകടമാക്കുകയും ചെയ്തതെങ്ങനെയെന്ന് കുട്ടികളെ കാണിക്കുക.

തിരുവെഴുത്ത് വായന

1 രാജാക്കന്മാർ 18:16-46

മനഃപാഠ വാക്യം

സങ്കീർത്തനം 121

സങ്കീർത്തനം മുഴുവൻ അവലോകനം ചെയ്യുക.

പാഠം അവതരിപ്പിക്കൽ

തുടക്കം

മത്സരങ്ങളെയും മാറ്റുരയ്ക്കലുകളെയും കുറിച്ച് ക്ലാസ്സിനോടു സംസാരിക്കുക. ഒരു പ്രത്യേക പ്രവർത്തനത്തിൽ ആരാണ് ഏറ്റവും മികച്ചതെന്ന് കണ്ടെത്താൻ ആളുകൾ പങ്കെടുക്കുന്ന പരിപാടികളാണ് ഇവ. ഏതുതരം മത്സരങ്ങളാണ് നിങ്ങൾക്ക് ഇഷ്ടം?

പാഠത്തിലെ പ്രധാന ആശയങ്ങൾ

1. ഏലിയാവിന് ബാലിന്റെ പ്രവാചകന്മാരുമായി ഒരു മത്സരം ഉണ്ടായിരുന്നു. ഇസ്രായേൽ ജനത്തോടും ബാലിന്റെ പ്രവാചകന്മാരോടും കർമ്മേൽ പർവ്വതത്തിൽ ഏലിയാവിനെ കാണാൻ ആഹാബ് രാജാവ് കൽപ്പിച്ചു. ആരാണ് യഥാർത്ഥ ദൈവമെന്നു കാണാൻ അവർക്കൊരു മത്സരം ഉണ്ടായിരിക്കും. ദൈവമോ ബാലോ? (18:20-22).

2. ഏലിയാവ് മത്സരത്തിന്റെ നിയമങ്ങൾ പ്രഖ്യാപിച്ചു. ബാലിന്റെ പ്രവാചകന്മാർ അഥവാ നേതാക്കൾ – എല്ലാം കൂടി 450 പേർ – രണ്ടു കാളകളെ യാഗത്തിനായി ഒരുക്കണം. ദൈവത്തിന്റെ ഏകപ്രവാചകനായ ഏലിയാവ് അതുതന്നെ ചെയ്യും. അവർ യാഗത്തിന്റെ അടിയിൽ തീ കത്തിക്കരുത്; പകരം സ്വർഗ്ഗത്തിൽ നിന്ന് തീ അയയ്ക്കണമെന്ന് അവർ പ്രാർത്ഥിക്കണം. തീകൊണ്ട് ഉത്തരം നൽകുന്നവൻ യഥാർത്ഥ ദൈവം. എല്ലാവരും ഈ നിയമങ്ങൾ സമ്മതിച്ചു (18:22-24).

3. ബാലിനെ ആരാധിക്കുന്നവർ ആദ്യം അവരുടെ യാഗപീഠം പണിതു. അവർ ദിവസം മുഴുവൻ പ്രാർത്ഥിച്ചു, എന്നാൽ തീ വന്നില്ല. ഏലിയാവ് അവരെ പരിഹസിക്കാൻ തുടങ്ങി (18:25-29).

4. വൈകുന്നേരം ഏലിയാവ് തന്നെ നോക്കാൻ എല്ലാവരെയും വിളിച്ചു. തകർക്കപ്പെട്ടിരുന്ന ദൈവത്തിന്റെ യാഗപീഠം അവൻ നന്നാക്കി, യാഗം ഒരുക്കി. അത് കത്താൻ കൂടുതൽ ബുദ്ധിമുട്ടാക്കാൻ അവൻ നാലു വലിയ കുടം വെള്ളം അതിന്മേൽ ഒഴിപ്പിക്കുകയും ചെയ്തു (18:30-35).

5. പിന്നെ ഏലിയാവ് ദൈവത്തോടു പ്രാർത്ഥിച്ചു, യഹോവയാണ് ജീവനുള്ള ദൈവമെന്ന് ജനത്തെ കാണിക്കാൻ സ്വർഗ്ഗത്തിൽ നിന്ന് തീ അയയ്ക്കണമെന്ന് അപേക്ഷിച്ചു. ചിത്രം 22 കാണിക്കുക. യാഗം കിടന്ന കല്ലുകൾ ഉൾപ്പെടെ എല്ലാം ദഹിപ്പിച്ചുകളയുന്ന തീ ദൈവം അയച്ചു. എല്ലാ ജനവും ആർത്തുവിളിച്ചു: “യഹോവ തന്നെ ദൈവം!” ജനത്തോടു നുണ പറഞ്ഞ ബാലിന്റെ പ്രവാചകന്മാരെ എല്ലാം കൊന്നു (18:36-40).

കഥയോടുള്ള നമ്മുടെ പ്രതികരണം

ഏലിയാവ് രാജാവിനും രാജ്ഞിക്കും 450 ബാൽ പ്രവാചകന്മാർക്കും അവിശ്വസ്തരായ ഇസ്രായേല്യർക്കും എതിരെ ഒറ്റയ്ക്കായിരുന്നു. എന്നാൽ അവൻ ജീവനുള്ള ദൈവത്തെ സേവിച്ചു. താൻ ഏക സത്യദൈവത്തെയാണ് സേവിക്കുന്നതെന്നും മറ്റു ദൈവങ്ങൾ ഇല്ലെന്നും അവനറിയാമായിരുന്നു. ഒറ്റയ്ക്കായിരുന്നിട്ടും തിന്മയ്ക്കെതിരെ നിലകൊണ്ട ദൈവത്തിന്റെ ധീരനായ ദാസന്റെ മാതൃകയാണ് ഏലിയാവ്.

ഇന്ന് ചില ക്രിസ്ത്യാനികളെ ദൈവം ഇതിനായി വിളിക്കുകയും സജ്ജരാക്കുകയും ചെയ്യുന്നു. അവർക്കുവേണ്ടിയും നമുക്കുവേണ്ടിയും, നമ്മുടെ ദൈവം ജീവനുള്ള ദൈവമാണെന്ന സത്യത്തിൽ നാം ഉറച്ചുനിൽക്കാൻ പ്രാർത്ഥിക്കാം.

മനഃപാഠ വാക്യം ഹൃദിസ്ഥമാക്കൽ

ഏലിയാവ് സങ്കീർത്തനം 121-ന്റെയും സങ്കീർത്തനം 1-ന്റെയും സത്യം തന്റെ ജീവിതത്തിൽ അനുഭവിച്ചു.

പാഠം - 22 : ഏലിയാവും സ്വർഗ്ഗത്തിൽ നിന്നുള്ള തീയും

തിരുവെഴുത്ത് വായന: 1 രാജാക്കന്മാർ 18:16-46

1. ശരിയായ ഉത്തരം തിരഞ്ഞെടുക്കുക

a), b) അല്ലെങ്കിൽ c) വട്ടമിടുക:

  1. മത്സരം നടന്നത് എവിടെ?
    a) കർമ്മേൽ പർവ്വതം b) യെരൂശലേം c) മോവാബ് 👉 a) കർമ്മേൽ പർവ്വതം

  2. തീകൊണ്ട് ഉത്തരം നൽകിയത് ആര്?
    a) ബാൽ b) ജീവനുള്ള ദൈവം c) ആഹാബ് 👉 b) ജീവനുള്ള ദൈവം

  3. ദൈവത്തിനു വേണ്ടി ഒറ്റയ്ക്കു നിന്നത് ആര്?
    a) ഏലിയാവ് b) ഓബേദ് c) ജോനാഥാൻ 👉 a) ഏലിയാവ്

2. ശരിയോ തെറ്റോ

ശരിക്ക് ‘ശ’ എന്നും തെറ്റിന് ‘തെ’ എന്നും എഴുതുക:

  1. ബാൽ സ്വർഗ്ഗത്തിൽ നിന്ന് തീ അയച്ചു. ( ___ ) 👉 തെ

  2. ഏലിയാവ് ജീവനുള്ള ദൈവത്തിൽ ആശ്രയിച്ചു. ( ___ ) 👉 ശ

  3. ജനം പറഞ്ഞു: “യഹോവ തന്നെ ദൈവം!” ( ___ ) 👉 ശ

3. ധൈര്യമോ ഭയമോ? ധൈ/ഭ

ധൈര്യത്തിന് ‘ധൈ’ എന്നും ഭയത്തിന് ‘ഭ’ എന്നും എഴുതുക:

  1. ശരിയായതിനു വേണ്ടി നിലകൊള്ളുന്നു. ( ___ ) 👉 ധൈ

  2. മറ്റുള്ളവർ തെറ്റു ചെയ്യുമ്പോൾ മിണ്ടാതിരിക്കുന്നു. ( ___ ) 👉 ഭ

  3. സുഹൃത്തുക്കളോടു ദൈവത്തെക്കുറിച്ച് പറയുന്നു. ( ___ ) 👉 ധൈ

4. ചർച്ചാ ചോദ്യങ്ങൾ

  1. ഏലിയാവ് ദൈവത്തോട് എന്തു ചെയ്യാൻ ആവശ്യപ്പെട്ടു?

    മാതൃകാ ഉത്തരം: താനാണ് ദൈവമെന്ന് എല്ലാവരും അറിയാൻ തീ അയയ്ക്കണമെന്ന്.

  2. ജനം എന്തു പഠിച്ചു?

    മാതൃകാ ഉത്തരം: യഹോവയാണ് സത്യവും ജീവനുമുള്ള ദൈവമെന്ന്.

  3. നമുക്ക് ദൈവത്തിനായി എങ്ങനെ ധൈര്യമുള്ളവരാകാം?

    മാതൃകാ ഉത്തരം: പ്രാർത്ഥിച്ചും സത്യം സംസാരിച്ചും.

5. മനഃപാഠ വാക്യം:

സങ്കീർത്തനം 121:1-2 — “ഞാൻ പർവ്വതങ്ങളിലേക്കു കണ്ണു ഉയർത്തുന്നു; എന്റെ സഹായം എവിടെ നിന്നു വരും? എന്റെ സഹായം ആകാശവും ഭൂമിയും ഉണ്ടാക്കിയ യഹോവയിങ്കൽ നിന്നു വരുന്നു.”

കരകൗശലം 1: പർവ്വതവും ജ്വാലയും

സാമഗ്രികൾ: കടലാസ്, ഓറഞ്ചും ചുവപ്പും കടലാസ്, പശ

നിർദ്ദേശങ്ങൾ:

  1. ഒരു പർവ്വതം വരയ്ക്കുക.

  2. ഓറഞ്ചും ചുവപ്പും കടലാസിൽ നിന്ന് ഒരു ജ്വാല മുറിക്കുക.

  3. ജ്വാല യാഗപീഠത്തിൽ ഒട്ടിക്കുക.

  4. എഴുതുക: “യഹോവ ദൈവം.”

പാഠ സന്ദേശം: ദൈവം ഏലിയാവിന്റെ പ്രാർത്ഥനയ്ക്ക് ഉത്തരം നൽകി.

കരകൗശലം 2: ഉറച്ചുനിൽക്കുക ബാനർ

സാമഗ്രികൾ: കടലാസ് സ്ട്രിപ്പ്, ക്രയോണുകൾ

നിർദ്ദേശങ്ങൾ:

  1. എഴുതുക: “യഹോവ, അവൻ ദൈവം!”

  2. നക്ഷത്രങ്ങൾ കൊണ്ട് അലങ്കരിക്കുക.

  3. നിൽക്കാൻ അടിഭാഗം മടക്കുക.

  4. ഒരു സുഹൃത്തിനെ കാണിക്കുക.

പാഠ സന്ദേശം: ഏലിയാവ് ദൈവത്തിനായി തനിച്ചു നിലകൊണ്ടു.

കളി 1: ആരാണ് ദൈവം?

കളിക്കുന്ന വിധം:

  1. രണ്ടു ഗ്രൂപ്പുകൾ: ഒന്ന് “യഹോവ ദൈവം!” എന്ന് ആർപ്പുവിളിക്കുന്നു.

  2. മറ്റേ ഗ്രൂപ്പ് നിശബ്ദമായി ശ്രദ്ധിക്കുന്നു.

  3. പരസ്പരം മാറി ദൈവം യഥാർത്ഥമായിരിക്കുന്നതെങ്ങനെയെന്ന് സംസാരിക്കുക.

പാഠ സന്ദേശം: യഹോവ മാത്രമാണ് ജീവനുള്ള ദൈവം.

കളി 2: ദൈവത്തിനായി എഴുന്നേറ്റുനിൽക്കുക

കളിക്കുന്ന വിധം:

  1. ശരിയും തെറ്റും സംബന്ധിച്ച പ്രസ്താവനകൾ വായിക്കുക.

  2. ചെയ്യുന്നത് ശരിയാണെങ്കിൽ കുട്ടികൾ എഴുന്നേറ്റുനിൽക്കുന്നു.

  3. തെറ്റാണെങ്കിൽ ഇരിക്കുക.

പാഠ സന്ദേശം: ദൈവത്തിന്റെ ദാസന്മാർ ശരിയായതിനു വേണ്ടി നിലകൊള്ളുന്നു.
