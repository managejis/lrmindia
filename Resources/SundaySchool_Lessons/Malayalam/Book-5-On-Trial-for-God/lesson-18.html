സിംഹങ്ങളുടെ ഗുഹയിൽ ദാനീയേൽ

Download Word

അധ്യാപക മാർഗ്ഗദർശി · നോക്കൂ, കേൾക്കൂ, ജീവിക്കൂ – പുസ്തകം 5: ദൈവത്തിനു വേണ്ടി വിചാരണയിൽ

ലക്ഷ്യം

ദാനീയേലിനെപ്പോലെ ആളുകൾക്ക് നമ്മോടു ചെയ്യാവുന്ന ഒന്നിനെയും നാം ഭയപ്പെടേണ്ടതില്ലെന്ന് കുട്ടികളെ കാണിക്കുക. യേശുക്രിസ്തു നമുക്കു നൽകിയ നിത്യജീവൻ ഒരിക്കലും ആർക്കും എടുത്തുകളയാൻ കഴിയില്ല.

തിരുവെഴുത്ത് വായന

ദാനീയേൽ 6:16-18

മനഃപാഠ വാക്യം

പുറപ്പാട് 20:12

(പത്തു കൽപ്പനകൾ) “നിന്റെ ദൈവമായ യഹോവ നിനക്കു തരുന്ന ദേശത്തു നിനക്കു ദീർഘായുസ്സ് ഉണ്ടാകേണ്ടതിന് നിന്റെ അപ്പനെയും അമ്മയെയും ബഹുമാനിക്കുക.”
ശ്രദ്ധിക്കുക: അധ്യായം മുഴുവൻ വായിക്കുന്നതാണ് നല്ലത്. കഴിഞ്ഞയാഴ്ചത്തെ ഓർമ്മവാക്യം അവലോകനം ചെയ്ത് ഈ ആഴ്ച 12-ാം വാക്യം പൂർത്തിയാക്കുക.

പാഠം അവതരിപ്പിക്കൽ

തുടക്കം

നിങ്ങളിൽ ആരെങ്കിലും ഒരു സിംഹത്തെ കണ്ടിട്ടുണ്ടോ, അല്ലെങ്കിൽ കണ്ടിട്ടുള്ള ആരെയെങ്കിലും അറിയുമോ? അവ വളരെ ശക്തിയുള്ള അപകടകാരികളായ മൃഗങ്ങളാണ്. ഒന്നിനെ കണ്ടുമുട്ടിയാൽ നിങ്ങൾക്ക് നല്ല ഒരു ആയുധം വേണ്ടിവരും!

പാഠത്തിലെ പ്രധാന ആശയങ്ങൾ

1. ദാനീയേൽ ഒരു സിംഹത്തെയല്ല, പല സിംഹങ്ങളെയാണ് കണ്ടുമുട്ടാൻ പോകുന്നത്, അതും തികച്ചും നിരായുധനായി! ദാരിയൂസ് രാജാവിന് ഈ കാര്യമെല്ലാം ഇഷ്ടമല്ലായിരുന്നു, എന്നാൽ തന്റെ പുതിയ ഭോഷത്തം നിറഞ്ഞ നിയമത്തിൽ നിന്ന് ഒരു വഴി കണ്ടെത്താൻ അവന് കഴിഞ്ഞില്ല (ദാനീ 6:14-15). ചിത്രം 17 കാണിച്ച് ചോദ്യങ്ങൾ ചോദിച്ച് കഴിഞ്ഞയാഴ്ചത്തെ കഥ ചുരുക്കി അവലോകനം ചെയ്യുക.

2. ദാനീയേലിനെ അറസ്റ്റ് ചെയ്ത് സിംഹങ്ങളുടെ ഗുഹയിൽ എറിഞ്ഞു. രാജാവിന്റെ വിടവാങ്ങൽ ആശംസയും ദാനീയേൽ ഗുഹയ്ക്കുള്ളിൽ തന്നെ നിൽക്കാനുള്ള മുൻകരുതലുകളും രാജാവിന്റെ മോശം രാത്രിയും കുട്ടികളോടു പറയുക (6:16-18).

3. പിറ്റേന്ന് പുലർച്ചയ്ക്ക് ദാരിയൂസ് രാജാവ് സിംഹങ്ങളെ പാർപ്പിച്ചിരുന്ന കുഴിയിലേക്ക് ധൃതിയിൽ ചെന്നു. ദാനീയേലിന്റെ ദൈവത്തിന് അവനെ രക്ഷിക്കാൻ കഴിഞ്ഞോ? രാജാവ് വിളിച്ചപ്പോൾ ദാനീയേൽ എങ്ങനെ മറുപടി പറഞ്ഞുവെന്ന് വിവരിക്കുക. ചിത്രം 18 കാണിക്കുക. ദാനീയേൽ തികച്ചും സുരക്ഷിതനായിരുന്നു (6:19-22)!

4. രാജാവ് അത്യധികം സന്തോഷിച്ചു. ദാനീയേലിനെ വിട്ടയച്ചു, അവനെതിരെ ഗൂഢാലോചന നടത്തിയ ദുഷ്ടന്മാരെ പകരം സിംഹങ്ങൾക്ക് എറിഞ്ഞുകൊടുത്തു (6:23-24).

5. ദൈവം ഈ സംഭവം തന്റെ ശക്തി കാണിക്കാൻ ഉപയോഗിച്ചു, ഫലമായി ദാനീയേൽ ജീവനുള്ള ദൈവത്തെ സേവിക്കുന്നുവെന്ന് ദാരിയൂസ് രാജാവിന് ബോധ്യമായി. ദൈവത്തെക്കുറിച്ചുള്ള അറിവ് ആ വിശാല രാജ്യത്തുടനീളം വ്യാപിച്ചു. 6:26-27 കുട്ടികളെ വായിച്ചു കേൾപ്പിക്കുക.

കഥയോടുള്ള നമ്മുടെ പ്രതികരണം

ആഫ്രിക്കയിലെ ആയിരക്കണക്കിന് ആളുകൾ യുദ്ധം, വിശപ്പ്, രോഗം, ദുരാത്മാക്കൾ, ഏറ്റവുമധികം മരണം എന്നിവയെ ഭയന്ന് ജീവിക്കുന്നു. പലർക്കും വീടുകളും സർവ്വസ്വവും നഷ്ടപ്പെട്ടു, ചിലർക്ക് ഒന്നിലധികം തവണ.

ദാനീയേൽ തന്നെ പരിപാലിക്കാൻ ദൈവത്തിൽ ആശ്രയിച്ചു, ദൈവം അവനെ സിംഹങ്ങളിൽ നിന്ന് രക്ഷിച്ചു. എന്നാൽ ദൈവത്തിന്റെ മറ്റ് വിശ്വസ്ത ദാസന്മാർ മരിക്കാൻ അനുവദിക്കപ്പെട്ടിട്ടുണ്ട്. എബ്രായർ 11:35-40 ലെ പട്ടിക കുട്ടികളെ വായിച്ചു കേൾപ്പിക്കുക.

ഇതുപോലുള്ള ഭയങ്കര പീഡനങ്ങൾ ഇന്നും നടക്കുന്നു. എന്നാൽ ദുഷ്ടന്മാർ ക്രിസ്ത്യാനികളുടെ ജീവൻ എടുത്താലും അവരുടെ പ്രത്യാശയെ കൊല്ലാൻ അവർക്കു കഴിയില്ല. ദൈവപുത്രനായ യേശുക്രിസ്തു നമുക്ക് നിത്യജീവൻ നൽകാൻ വന്നു.

മനഃപാഠ വാക്യം ഹൃദിസ്ഥമാക്കൽ

ഇതുവരെ പഠിച്ച പുറപ്പാട് 20-ലെ എല്ലാ വാക്യങ്ങളും അവലോകനം ചെയ്യുക.

പാഠം - 18 : സിംഹങ്ങളുടെ ഗുഹയിൽ ദാനീയേൽ

തിരുവെഴുത്ത് വായന: ദാനീയേൽ 6:16-18

1. കഥ ക്രമത്തിലാക്കുക

a) രാജാവിന് ഉറങ്ങാൻ കഴിഞ്ഞില്ല.
b) രാജാവ് ജീവനുള്ള ദൈവത്തെ സ്തുതിച്ചു.
c) ദാനീയേലിനെ സിംഹങ്ങളുടെ ഗുഹയിൽ ഇട്ടു.
d) രാവിലെ ദാനീയേലിനെ സുരക്ഷിതനായി കണ്ടു.

👉 ശരിയായ ക്രമം:

  1. ദാനീയേലിനെ സിംഹങ്ങളുടെ ഗുഹയിൽ ഇട്ടു.

  2. രാജാവിന് ഉറങ്ങാൻ കഴിഞ്ഞില്ല.

  3. രാവിലെ ദാനീയേലിനെ സുരക്ഷിതനായി കണ്ടു.

  4. രാജാവ് ജീവനുള്ള ദൈവത്തെ സ്തുതിച്ചു.

2. ശരിയോ തെറ്റോ?

ശരിക്ക് ‘ശ’ എന്നും തെറ്റിന് ‘തെ’ എന്നും എഴുതുക:

  1. ദൈവം സിംഹങ്ങളുടെ വായ് അടച്ചു. ( ___ ) 👉 ശ

  2. ദാനീയേലിന് പരിക്കേറ്റു. ( ___ ) 👉 തെ

  3. രാജാവ് ദാനീയേലിന്റെ ദൈവത്തിൽ വിശ്വസിച്ചു. ( ___ ) 👉 ശ

3. വിട്ടുപോയ അക്ഷരങ്ങൾ

വിട്ടുപോയ അക്ഷരങ്ങൾ പൂരിപ്പിക്കുക:

  1. സിം _ ങ്ങൾ (ഗുഹയിലെ മൃഗങ്ങൾ) ____________ __________ 👉 സിംഹങ്ങൾ

  2. രാ _ വ് (ഗുഹയിലേക്ക് ധൃതിയിൽ ചെന്നവൻ) ____________ __________ 👉 രാജാവ്

  3. ജീ _ ൻ (ദൈവം നമുക്കു നൽകുന്ന നിത്യ ____) ____________ __________ 👉 ജീവൻ

4. ചർച്ചാ ചോദ്യങ്ങൾ

  1. ദൈവം ദാനീയേലിനെ സുരക്ഷിതനായി സൂക്ഷിച്ചത് എങ്ങനെ?

    മാതൃകാ ഉത്തരം: ദൈവം തന്റെ ദൂതനെ അയച്ച് സിംഹങ്ങളുടെ വായ് അടച്ചു.

  2. രാവിലെ രാജാവിന് എന്തു തോന്നി?

    മാതൃകാ ഉത്തരം: ദാനീയേൽ ജീവനോടെ ഇരിക്കുന്നതിൽ അവൻ അത്യധികം സന്തോഷിച്ചു.

  3. ആളുകൾക്ക് നമ്മോടു ചെയ്യാവുന്നതിനെ നാം ഭയപ്പെടേണ്ടാത്തത് എന്തുകൊണ്ട്?

    മാതൃകാ ഉത്തരം: യേശു നമുക്ക് നിത്യജീവൻ നൽകുന്നു.

5. മനഃപാഠ വാക്യം:

പുറപ്പാട് 20:12 — “നിന്റെ ദൈവമായ യഹോവ നിനക്കു തരുന്ന ദേശത്തു നിനക്കു ദീർഘായുസ്സ് ഉണ്ടാകേണ്ടതിന് നിന്റെ അപ്പനെയും അമ്മയെയും ബഹുമാനിക്കുക.”

യെശയ്യാവ് 41:10 — “ഭയപ്പെടേണ്ട, ഞാൻ നിന്നോടുകൂടെ ഉണ്ട്.”

കരകൗശലം 1: സിംഹ മുഖംമൂടി

സാമഗ്രികൾ: കടലാസ് പാത്രം, മഞ്ഞ കമ്പിളി നൂൽ, ക്രയോണുകൾ, ചരട്

നിർദ്ദേശങ്ങൾ:

  1. പാത്രത്തിന് മഞ്ഞ നിറം കൊടുക്കുക.

  2. അരികിൽ ചുറ്റും കമ്പിളി നൂൽ ഒട്ടിക്കുക.

  3. ഒരു സൗഹൃദമുള്ള മുഖം വരയ്ക്കുക.

  4. ചരട് ഘടിപ്പിക്കുക.

പാഠ സന്ദേശം: ദൈവം സിംഹങ്ങളുടെ വായ് അടച്ചു.

കരകൗശലം 2: ദാനീയേലും സിംഹങ്ങളും ചിത്രം

സാമഗ്രികൾ: കടലാസ്, ക്രയോണുകൾ

നിർദ്ദേശങ്ങൾ:

  1. ഒരു വലിയ ഗുഹ വരയ്ക്കുക.

  2. നടുവിൽ ദാനീയേലിനെ വരയ്ക്കുക.

  3. അവന് ചുറ്റും ഉറക്കംതൂങ്ങുന്ന സിംഹങ്ങളെ വരയ്ക്കുക.

  4. എഴുതുക: “ദൈവം രക്ഷിക്കുന്നു.”

പാഠ സന്ദേശം: തന്നിൽ ആശ്രയിക്കുന്നവരെ ദൈവം സംരക്ഷിക്കുന്നു.

കളി 1: ശാന്തരായ സിംഹങ്ങൾ

കളിക്കുന്ന വിധം:

  1. കുട്ടികൾ ശാന്തരായ സിംഹങ്ങളെപ്പോലെ ഇഴയുന്നു.

  2. അധ്യാപകൻ “ദാനീയേൽ!” എന്നു പറയുമ്പോൾ അവർ നിശ്ശബ്ദമായി കിടക്കുന്നു.

  3. പറയുക: “ദൈവം അവയുടെ വായ് അടച്ചു.”

പാഠ സന്ദേശം: ഏതു സിംഹത്തെക്കാളും ദൈവം ശക്തനാണ്.

കളി 2: പ്രഭാത ചോദ്യം

കളിക്കുന്ന വിധം:

  1. ഒരു കുട്ടി രാജാവായി വിളിക്കുന്നു: “ദാനീയേൽ, നീ സുരക്ഷിതനാണോ?”

  2. മറ്റൊരാൾ മറുപടി പറയുന്നു: “ദൈവം എന്നെ രക്ഷിച്ചു!”

  3. വേഷങ്ങൾ മാറുക.

പാഠ സന്ദേശം: തന്നിൽ ആശ്രയിക്കുന്നവരെ ദൈവം വിടുവിക്കുന്നു.
