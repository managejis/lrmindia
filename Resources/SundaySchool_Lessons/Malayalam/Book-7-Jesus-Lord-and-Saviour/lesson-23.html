വീട്ടുടമസ്ഥൻ മടങ്ങിവരുന്നു

Download Word

അധ്യാപക മാർഗ്ഗദർശി · നോക്കൂ, കേൾക്കൂ, ജീവിക്കൂ – പുസ്തകം 7: യേശു കർത്താവും രക്ഷകനും

ലക്ഷ്യം

ക്രിസ്ത്യാനികൾ കർത്താവായ യേശുവിന്റെ മടങ്ങിവരവിനായി കാത്തിരിക്കുമ്പോൾ അവനെ വിശ്വസ്തതയോടെ സേവിക്കണമെന്ന് കുട്ടികൾക്കു കാണിച്ചുകൊടുക്കുക.

തിരുവെഴുത്ത് വായന

ലൂക്കൊസ് 12:35-48

മനഃപാഠ വാക്യം

യോഹന്നാൻ 1:10-14

ഭാഗം പുനരവലോകനം ചെയ്യുക.

പാഠം അവതരിപ്പിക്കൽ

തുടക്കം

അധ്യാപകനെ എവിടേക്കെങ്കിലും വിളിച്ചാൽ സ്കൂളിൽ ക്ലാസ്സ്മുറിയിൽ എന്തു സംഭവിക്കും? ആദ്യം എല്ലാവരും നിശ്ശബ്ദമായി ജോലി ചെയ്തേക്കാം; എന്നാൽ അധ്യാപകൻ തുടർന്നും ഇല്ലാതിരുന്നാൽ ചിലർ സംസാരിക്കാൻ തുടങ്ങും, അത് മറ്റുള്ളവർക്ക് ശ്രദ്ധ കേന്ദ്രീകരിക്കാൻ ബുദ്ധിമുട്ടാക്കും. ഒടുവിൽ അധ്യാപകൻ വരുമ്പോൾ ക്ലാസ്സ് മുഴുവൻ സാധാരണയായി ജോലി നിർത്തി സംസാരിക്കുകയോ കളിക്കുകയോ ചെയ്യും.

പാഠത്തിലെ പ്രധാന ആശയങ്ങൾ

1. ഭൂമിയിലെ തന്റെ കാലത്ത് യേശു തന്റെ ശിഷ്യന്മാരോട് തന്റെ രണ്ടാം വരവിനെക്കുറിച്ചു പറഞ്ഞു. അവൻ മടങ്ങിവരുന്നതുവരെ കാത്തിരിക്കുമ്പോൾ അവന്റെ ശിഷ്യന്മാർ എങ്ങനെ ജീവിക്കണമായിരുന്നു? തന്നെ അനുഗമിക്കാൻ ആഗ്രഹിക്കുന്നവരെ സഹായിക്കാൻ യേശു ഇതിനെക്കുറിച്ച് പല കഥകളും പറഞ്ഞു.

2. ഉദാഹരണത്തിന്, ഒരു വിവാഹത്തിനു പോയ ഒരു മനുഷ്യനെക്കുറിച്ച് അവൻ ഒരു കഥ പറഞ്ഞു. അത്തരം ആഘോഷങ്ങൾ വളരെ വൈകുംവരെ നീണ്ടേക്കാം. എങ്കിലും ആ മനുഷ്യൻ വീട്ടിൽ മടങ്ങിയെത്തിയപ്പോൾ അവന്റെ വേലക്കാർ ഉടൻ വാതിൽ തുറന്നു. അർദ്ധരാത്രി കഴിഞ്ഞിട്ടായാലും വേലക്കാർ തങ്ങളുടെ യജമാനനെ കാത്ത് ഒരുക്കമുള്ളവരായിരുന്നു. യജമാനൻ തങ്ങളിൽ ഇത്രയധികം സംതൃപ്തനായതിൽ അവർ ആഹ്ലാദിച്ചു. വേലക്കാർ തന്റെ സ്വത്ത് ഇത്ര നന്നായി നോക്കിയതിൽ യജമാനൻ അത്രയധികം സന്തോഷിച്ചതുകൊണ്ട് അവൻ അവർക്ക് ഭക്ഷണം വിളമ്പിക്കൊടുത്തു (ലൂക്കൊ 12:35-38)!

3. പിന്നെ ഒരു ജ്ഞാനി കള്ളന്മാരിൽനിന്ന് തന്റെ വീടിനെ എങ്ങനെ കാക്കുന്നുവെന്ന് യേശു വിവരിച്ചു. കള്ളന്മാർ വരുമ്പോൾ മുന്നറിയിപ്പു തരില്ലല്ലോ; അതുകൊണ്ട് അവൻ എല്ലായ്പ്പോഴും ഒരുങ്ങിയിരിക്കുന്നു. യേശു എപ്പോൾ വീണ്ടും വരുമെന്ന് നാമും അറിയുന്നില്ല; അതുകൊണ്ട് നാം എല്ലായ്പ്പോഴും ഒരുങ്ങിയിരിക്കണമെന്ന് ഈ കഥ നമുക്കു മുന്നറിയിപ്പു തരുന്നു (12:39-40).

4. മറ്റു കഥകളിൽ, തന്നെ കാത്തിരിക്കുമ്പോൾ തന്റെ സുഹൃത്തുക്കൾ എന്താണ് ചെയ്യേണ്ടതെന്ന് യേശു കാണിക്കാൻ ആഗ്രഹിച്ചു. അവൻ വിശ്വസ്തനായ ഒരു കാര്യസ്ഥന്റെ പെരുമാറ്റം വിവരിച്ചു. ചിത്രം 23 കാണിക്കുക. തന്റെ അസാന്നിധ്യത്തിൽ തന്റെ വീട്ടുകാര്യങ്ങൾ നന്നായി ക്രമീകരിച്ചിരിക്കുന്നത് യജമാനൻ കണ്ടു; അതിനാൽ കാര്യസ്ഥന് തന്റെ വിശ്വസ്തവും ഉത്തമവുമായ സേവനത്തിന് പ്രതിഫലം കിട്ടി (12:42-44).

5. എന്നാൽ ചുമതലയേല്പിക്കപ്പെട്ടവർ കുടിച്ചു മത്തരായി, യജമാനന്റെ സ്വത്തു പാഴാക്കി, തങ്ങൾ ഉത്തരവാദികളായിരുന്നവരെ ദ്രോഹിച്ചാൽ എന്തു സംഭവിക്കുമെന്നും യേശു വിവരിച്ചു. അവരുടെ ശിക്ഷ കഠിനമായിരിക്കും (12:45-46).

കഥയോടുള്ള നമ്മുടെ പ്രതികരണം

യേശു ഒരു വീട്ടുകാര്യം നോക്കുന്നതിനെക്കുറിച്ചു സംസാരിച്ചപ്പോൾ, അത് നമ്മുടെ ജീവിതത്തിന്റെ ഒരു ചിത്രമായി അവൻ ഉപയോഗിക്കുകയായിരുന്നു. ഒരു വീടിന് പല മുറികളുണ്ട്. ഉദാഹരണത്തിന്, സ്വീകരണമുറി, കിടപ്പുമുറികൾ, അടുക്കള, സംഭരണമുറി — ഇവ ഓരോന്നും നമ്മുടെ ജീവിതത്തിന്റെ ഓരോ ഭാഗം പോലെയാണ്. ഉദാഹരണത്തിന്, അടുക്കളയിലാണ് ധാരാളം ജോലി ചെയ്യപ്പെടുന്നത്. നാം എത്ര നന്നായി ജോലി ചെയ്യുന്നു? നമ്മുടെ ദൈനംദിന ജോലികൾ ചെയ്യുന്ന രീതിയിലൂടെ നമുക്ക് യേശുവിനെ മഹത്ത്വപ്പെടുത്താം. നമ്മുടെ മനസ്സ് സംഭരണമുറികൾ പോലെയാണ്. നാം എന്തിനെക്കുറിച്ച് അല്ലെങ്കിൽ ആരെക്കുറിച്ചാണ് ചിന്തിക്കുന്നത്? മറ്റ് പ്രായോഗിക ഉദാഹരണങ്ങൾ ചിന്തിച്ചെടുക്കാൻ കഴിയുമോ എന്നു നോക്കുക.

കർത്താവ് നമ്മെ എല്ലാവരെയും തന്നെ ബഹുമാനിക്കാൻ സൃഷ്ടിച്ചു, എന്നാൽ അവൻ നമ്മെ പരസ്പരം വ്യത്യസ്തരായി സൃഷ്ടിച്ചു. അവൻ നമുക്ക് വ്യത്യസ്ത ഉത്തരവാദിത്വങ്ങളും കഴിവുകളും തന്നു. അവന്റെ മടങ്ങിവരവിനായി കാത്തിരിക്കാനും അവൻ നമുക്കു തന്നതുകൊണ്ട് നാം എന്തു ചെയ്തുവെന്ന് അവനെ കാണിക്കാൻ ഒരുങ്ങിയിരിക്കാനും നാം ആഗ്രഹിക്കുന്നു.

മനഃപാഠ വാക്യം ഹൃദിസ്ഥമാക്കൽ

പാഠം - 23 : വീട്ടുടമസ്ഥൻ മടങ്ങിവരുന്നു

തിരുവെഴുത്ത് വായന: ലൂക്കൊസ് 12:35-48

1. വാക്യങ്ങൾ പൂർത്തിയാക്കുക

വാക്കുകളുടെ പെട്ടി: യജമാനനെ, ഒരുക്കമുള്ളവരായി, മടങ്ങിവരും

  1. വേലക്കാർ തങ്ങളുടെ ____________ കാത്തിരുന്നു. __________ 👉 യജമാനനെ

  2. അവർ രാത്രി മുഴുവൻ ____________ ഇരുന്നു. __________ 👉 ഒരുക്കമുള്ളവരായി

  3. യേശു ഒരു ദിവസം ____________. __________ 👉 മടങ്ങിവരും

2. ശരിയോ തെറ്റോ? ശ/തെ

ശരിക്ക് ‘ശ’ എന്നും തെറ്റിന് ‘തെ’ എന്നും എഴുതുക:

  1. ഒരുക്കമുള്ളവരായിരുന്നതിന് വേലക്കാർക്കു പ്രതിഫലം കിട്ടി. ( ___ ) 👉 ശ

  2. യേശു എപ്പോൾ മടങ്ങിവരുമെന്ന് നമുക്ക് അറിയാം. ( ___ ) 👉 തെ

  3. കാത്തിരിക്കുമ്പോൾ നാം ദൈവത്തെ സേവിക്കണം. ( ___ ) 👉 ശ

3. ഒരുക്കമോ അല്ലയോ? ഒ/അ

ഒരുക്കമുണ്ടെങ്കിൽ ‘ഒ’ എന്നും ഇല്ലെങ്കിൽ ‘അ’ എന്നും എഴുതുക:

  1. ഞാൻ എന്റെ വീട്ടുജോലികൾ നന്നായി ചെയ്യുന്നു. ( ___ ) 👉 ഒ

  2. ഞാൻ എന്റെ സമയം പാഴാക്കുന്നു. ( ___ ) 👉 അ

  3. ഞാൻ പ്രാർത്ഥിക്കുകയും ബൈബിൾ വായിക്കുകയും ചെയ്യുന്നു. ( ___ ) 👉 ഒ

4. ചർച്ചാ ചോദ്യങ്ങൾ

  1. നാം യേശുവിനായി ഒരുങ്ങിയിരിക്കേണ്ടത് എന്തുകൊണ്ട്?

    മാതൃകാ ഉത്തരം: അവൻ എപ്പോൾ വരുമെന്ന് നമുക്ക് അറിയില്ല.

  2. വിശ്വസ്തനായ ഒരു വേലക്കാരൻ എന്തു ചെയ്യുന്നു?

    മാതൃകാ ഉത്തരം: യജമാനൻ അകലെയായിരിക്കുമ്പോഴും തന്റെ ജോലി നന്നായി ചെയ്യുന്നു.

  3. നാം ഒരുക്കമുള്ളവരാണെന്ന് എങ്ങനെ കാണിക്കാം?

    മാതൃകാ ഉത്തരം: ദിവസവും ദൈവത്തെ അനുസരിച്ചും സേവിച്ചും.

5. മനഃപാഠ വാക്യം:

യോഹന്നാൻ 1:10-11 — “അവൻ ലോകത്തിൽ ഉണ്ടായിരുന്നു; ലോകം അവൻ മുഖാന്തരം ഉളവായി; എങ്കിലും ലോകം അവനെ അറിഞ്ഞില്ല.”

ലൂക്കൊസ് 12:40 — “നിങ്ങളും ഒരുങ്ങിയിരിപ്പിൻ; നിനച്ചിരിക്കാത്ത നാഴികയിൽ മനുഷ്യപുത്രൻ വരും.”

കരകൗശലം 1: വിളക്കിന്റെ ചിത്രം

സാമഗ്രികൾ: കടലാസ്, മഞ്ഞ ക്രയോൺ

നിർദ്ദേശങ്ങൾ:

  1. ഒരു എണ്ണവിളക്ക് വരയ്ക്കുക.

  2. തീനാളത്തിന് മഞ്ഞ നിറം കൊടുക്കുക.

  3. എഴുതുക: “ഒരുങ്ങിയിരിക്കുക.”

പാഠ സന്ദേശം: നാം യേശുവിനായി ഒരുങ്ങിയിരിക്കണം.

കരകൗശലം 2: വീട്ടുജോലികളുടെ പട്ടിക

സാമഗ്രികൾ: കാർഡ്, പെൻസിൽ, ക്രയോണുകൾ

നിർദ്ദേശങ്ങൾ:

  1. വീട്ടിലെ മൂന്നു ജോലികൾ പട്ടികപ്പെടുത്തുക.

  2. നിങ്ങൾ ചെയ്യുന്ന ഓരോ ജോലിയുടെയും അടുത്ത് ഒരു നക്ഷത്രം വരയ്ക്കുക.

  3. അവ വിശ്വസ്തതയോടെ ചെയ്യുക.

പാഠ സന്ദേശം: വിശ്വസ്തമായ ജോലി ദൈവത്തെ പ്രസാദിപ്പിക്കുന്നു.

കളി 1: കാത്തിരുന്നു സേവിക്കൂ

കളിക്കുന്ന വിധം:

  1. ഒരു കുട്ടി “യജമാനൻ” ആയി പുറത്തേക്കു പോകുന്നു.

  2. മറ്റുള്ളവർ നിശ്ശബ്ദമായി മുറി വൃത്തിയാക്കുന്നു.

  3. യജമാനൻ മടങ്ങിവന്ന് അവരെ പ്രശംസിക്കുന്നു.

പാഠ സന്ദേശം: കാത്തിരിക്കുമ്പോൾ നാം നന്നായി ജോലി ചെയ്യുന്നു.

കളി 2: ഒരുക്കത്തിന്റെ സൂചന

കളിക്കുന്ന വിധം:

  1. അധ്യാപകൻ പറയുന്നു, “യജമാനൻ വരുന്നു!”

  2. കുട്ടികൾ വേഗത്തിലും നിശ്ശബ്ദമായും ഇരിക്കുന്നു.

  3. പല പ്രാവശ്യം ആവർത്തിക്കുക.

പാഠ സന്ദേശം: നാം എല്ലായ്പ്പോഴും ഒരുങ്ങിയിരിക്കണം.
