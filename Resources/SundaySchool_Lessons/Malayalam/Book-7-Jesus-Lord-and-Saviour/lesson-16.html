ധനവാനായ ഭോഷൻ മറന്നത്

Download Word

അധ്യാപക മാർഗ്ഗദർശി · നോക്കൂ, കേൾക്കൂ, ജീവിക്കൂ – പുസ്തകം 7: യേശു കർത്താവും രക്ഷകനും

ലക്ഷ്യം

വസ്തുവകകളെക്കാൾ പ്രധാനപ്പെട്ട കാര്യങ്ങൾ ജീവിതത്തിലുണ്ടെന്ന് കുട്ടികളെ പഠിപ്പിക്കുക.

തിരുവെഴുത്ത് വായന

ലൂക്കൊസ് 12:15-21

മനഃപാഠ വാക്യം

യോഹന്നാൻ 1:12

പാഠം 15 ലെ ഓർമ്മവാക്യം പൂർത്തിയാക്കുക. എന്നാൽ അവനെ കൈക്കൊണ്ടവർക്ക്, അവന്റെ നാമത്തിൽ വിശ്വസിക്കുന്നവർക്കെല്ലാം, ദൈവമക്കളാകാൻ അവൻ അധികാരം കൊടുത്തു …

പാഠം അവതരിപ്പിക്കൽ

തുടക്കം

മിക്കവാറും എല്ലാവരും ധനികരാകാൻ ആഗ്രഹിക്കുന്നു! നിങ്ങൾ ധനികനായിരുന്നെങ്കിൽ എന്താണ് സ്വന്തമാക്കാൻ ആഗ്രഹിക്കുക?

പാഠത്തിലെ പ്രധാന ആശയങ്ങൾ

1. മിക്കവരും മറന്നുപോകുന്നത് വലിയ സമ്പത്ത് വലിയ ഉത്തരവാദിത്വങ്ങൾ കൊണ്ടുവരുന്നുവെന്നാണ്. യേശു ഒരു ധനികനെക്കുറിച്ച് ഒരു കഥ പറഞ്ഞു. ശ്രദ്ധിക്കുക; അവൻ തന്റെ ഉത്തരവാദിത്വങ്ങൾ ഓർത്തിരുന്നുവെന്ന് നിങ്ങൾ കരുതുന്നുണ്ടോ എന്നു നോക്കുക.

2. ധനവാന് നല്ല വിളവു നല്കുന്ന ഫലഭൂയിഷ്ഠമായ നിലം ഉണ്ടായിരുന്നു. വാസ്തവത്തിൽ വേഗംതന്നെ അവന്റെ സംഭരണസ്ഥലം തീർന്നുപോയി. ചിത്രം 16 കാണിക്കുക. വലിയ പത്തായങ്ങൾ പണിയുക എന്നതാണ് പരിഹാരമെന്ന് അവൻ തീരുമാനിച്ചു (12:16-18).

3. തന്റെ ചുറ്റുമുള്ള ദരിദ്രരുമായി തന്റെ സമ്പത്തു പങ്കുവയ്ക്കുന്നതിനെക്കുറിച്ച് ധനവാൻ ചിന്തിച്ചില്ല. തന്റെ അനുഗ്രഹങ്ങൾ ദൈവത്തിൽനിന്നാണ് വരുന്നതെന്ന് അവൻ തിരിച്ചറിഞ്ഞതുപോലുമില്ല. അവൻ കരുതിയതും പ്രസാദിപ്പിക്കാൻ ആഗ്രഹിച്ചതും തന്നെത്തന്നെ മാത്രമായിരുന്നു (12:19).

4. പണത്തിന് എല്ലാം വാങ്ങാൻ കഴിയില്ലെന്ന് ധനവാൻ ഒടുവിൽ കണ്ടെത്തി. ധനവാന് ഫലഭൂയിഷ്ഠമായ വിളവു നല്കിയ ദൈവം അവന്റെ ജീവൻ അവനിൽനിന്ന് എടുത്തുകളഞ്ഞു. അപ്പോൾ അവന്റെ വസ്തുവകകൾ അവന് ഒരു പ്രയോജനവുമില്ലായിരുന്നു. ദൈവത്തെ മറന്ന് ഈ ലോകത്തിന്റെ സമ്പത്തിനും സുഖങ്ങൾക്കുംവേണ്ടി ജീവിച്ചതുകൊണ്ട് ധനവാൻ ഭോഷനായിരുന്നു (12:20-21).

കഥയോടുള്ള നമ്മുടെ പ്രതികരണം

നമ്മുടെ സ്വന്തമായ വസ്തുക്കൾ നമ്മുടെ ജീവിതത്തിൽ രണ്ടാം സ്ഥാനത്തായിരിക്കണമെന്ന് നാം മനസ്സിലാക്കണമെന്ന് യേശു ആഗ്രഹിക്കുന്നു. നമുക്കുള്ളതും നമ്മുടെ സ്വന്തമായതുമെല്ലാം ദൈവം തരുന്നതാണ്; അതിനാൽ അവന് ഒന്നാം സ്ഥാനം ലഭിക്കണം. അവനെ പ്രസാദിപ്പിക്കുന്നതിലായിരിക്കണം നമ്മുടെ ഒന്നാമത്തെ ശ്രദ്ധ.

അതായത് ഈ കഥയുടെ പാഠം നാം ധനികരെന്നു കരുതുന്നവർക്കു മാത്രമല്ല, നമുക്കെല്ലാവർക്കും ഉള്ളതാണ്. ദരിദ്രരും അത്യാഗ്രഹികളോ അസൂയക്കാരോ ആയിത്തീർന്ന് വസ്തുവകകൾ തങ്ങളുടെ ജീവിതത്തിലെ ഏറ്റവും പ്രധാന കാര്യമാക്കിയേക്കാം. കഥയിൽ ദൈവത്തിന് ധനവാന്റെ ജീവിതത്തിലോ പദ്ധതികളിലോ സ്ഥാനമില്ലായിരുന്നു. ദൈവത്തിൽനിന്നു ലഭിച്ചതു നാം പങ്കുവയ്ക്കുമ്പോൾ അത് അവനെ പ്രസാദിപ്പിക്കുന്നു. ഈ ലോകത്തിൽ നമുക്ക് ആവശ്യമുള്ളതിനായി തന്നെ ആശ്രയിക്കാൻ ദൈവം നമ്മോടു പറയുന്നു; അവൻ നമുക്ക് അധ്വാനിക്കാനുള്ള ഊർജ്ജം തരുന്നു; സ്വർഗ്ഗത്തിൽ അവൻ നമുക്കു സമ്പത്തു നല്കും (12:15, 21).

മനഃപാഠ വാക്യം ഹൃദിസ്ഥമാക്കൽ

പാഠം - 16 : ധനവാനായ ഭോഷൻ മറന്നത്

തിരുവെഴുത്ത് വായന: ലൂക്കൊസ് 12:15-21

1. ശരിയായ വാക്കുകൾ വട്ടമിടുക

ശരിയായ വാക്ക് വട്ടമിടുക:

  1. ധനവാന്റെ നിലം (വലിയ / ചെറിയ) വിളവു നല്കി. 👉 വലിയ

  2. അവൻ (വലിയ / ചെറിയ) പത്തായങ്ങൾ പണിയാൻ തീരുമാനിച്ചു. 👉 വലിയ

  3. അവൻ (ദൈവത്തെ / കൃഷിയെ) മറന്നു. 👉 ദൈവത്തെ

2. പങ്കുവയ്ക്കുക അല്ലെങ്കിൽ സൂക്ഷിക്കുക? പ/സൂ

പങ്കുവയ്ക്കുന്നെങ്കിൽ ‘പ’ എന്നും സൂക്ഷിച്ചുവയ്ക്കുക മാത്രമെങ്കിൽ ‘സൂ’ എന്നും എഴുതുക:

  1. വിശക്കുന്ന ഒരു കൂട്ടുകാരന് ഞാൻ എന്റെ ഭക്ഷണത്തിൽ കുറച്ചു കൊടുക്കുന്നു. ( ___ ) 👉 പ

  2. ആർക്കും ഉപയോഗിക്കാൻ കഴിയാത്തവിധം ഞാൻ എന്റെ കളിപ്പാട്ടങ്ങൾ ഒളിച്ചുവയ്ക്കുന്നു. ( ___ ) 👉 സൂ

  3. എനിക്കുള്ളതിനെല്ലാം ഞാൻ ദൈവത്തിനു നന്ദി പറയുന്നു. ( ___ ) 👉 പ

3. അതെ അല്ലെങ്കിൽ ഇല്ല

അതെ അല്ലെങ്കിൽ ഇല്ല എന്ന് എഴുതുക:

  1. ധനവാൻ ദരിദ്രരെക്കുറിച്ചു ചിന്തിച്ചോ? ( ___ ) 👉 ഇല്ല

  2. നമുക്കുള്ളതെല്ലാം ദൈവത്തിൽനിന്നു വരുന്നുവോ? ( ___ ) 👉 അതെ

  3. വസ്തുക്കളെക്കാൾ ദൈവം പ്രധാനമാണോ? ( ___ ) 👉 അതെ

4. ചർച്ചാ ചോദ്യങ്ങൾ

  1. ധനവാൻ മറന്നത് എന്താണ്?

    മാതൃകാ ഉത്തരം: ദൈവത്തെയും മറ്റുള്ളവരുമായി പങ്കുവയ്ക്കേണ്ടതിനെയും.

  2. ജീവിതത്തിൽ ഏറ്റവും പ്രധാനം എന്താണ്?

    മാതൃകാ ഉത്തരം: വസ്തുക്കൾ സ്വന്തമാക്കുന്നതിനെക്കാൾ ദൈവത്തെ സ്നേഹിക്കുകയും പ്രസാദിപ്പിക്കുകയും ചെയ്യുന്നത്.

  3. നിങ്ങൾക്ക് എന്തു പങ്കുവയ്ക്കാൻ കഴിയും?

    മാതൃകാ ഉത്തരം: ഭക്ഷണം, കളിപ്പാട്ടങ്ങൾ, സമയം, മറ്റുള്ളവർക്കുള്ള സഹായം.

5. മനഃപാഠ വാക്യം:

യോഹന്നാൻ 1:12 — “എന്നാൽ അവനെ കൈക്കൊണ്ടവർക്ക്, അവന്റെ നാമത്തിൽ വിശ്വസിക്കുന്നവർക്കെല്ലാം, ദൈവമക്കളാകാൻ അവൻ അധികാരം കൊടുത്തു ...”

മത്തായി 6:33 — “മുമ്പെ അവന്റെ രാജ്യവും നീതിയും അന്വേഷിപ്പിൻ; എന്നാൽ ഇവയെല്ലാം നിങ്ങൾക്കു കൂട്ടിക്കിട്ടും.”

കരകൗശലം 1: പത്തായത്തിന്റെ ചിത്രം

സാമഗ്രികൾ: ചുവപ്പ് കടലാസ്, മഞ്ഞ ക്രയോൺ, പശ

നിർദ്ദേശങ്ങൾ:

  1. ചുവപ്പ് കടലാസിൽനിന്ന് ഒരു പത്തായം മുറിച്ചെടുക്കുക.

  2. സ്വർണ്ണനിറമുള്ള ധാന്യം വരയ്ക്കുക.

  3. എഴുതുക: “ദൈവം ഒന്നാമത്.”

പാഠ സന്ദേശം: നമുക്കുള്ളതെല്ലാം ദൈവത്തിൽനിന്നു വരുന്നു.

കരകൗശലം 2: പങ്കുവയ്ക്കലിന്റെ സഞ്ചി

സാമഗ്രികൾ: കടലാസ് സഞ്ചി, ക്രയോണുകൾ

നിർദ്ദേശങ്ങൾ:

  1. സഞ്ചി അലങ്കരിക്കുക.

  2. എഴുതുക: “ഞാൻ പങ്കുവയ്ക്കും.”

  3. മറ്റൊരാൾക്കായി ഒരു ചെറിയ സമ്മാനം അതിൽ ഇടുക.

പാഠ സന്ദേശം: നാം പങ്കുവയ്ക്കുമ്പോൾ അത് ദൈവത്തെ പ്രസാദിപ്പിക്കുന്നു.

കളി 1: പത്തായം നിറയ്ക്കൂ

കളിക്കുന്ന വിധം:

  1. കുട്ടികൾ “പത്തായം” എന്നെഴുതിയ ഒരു പെട്ടിയിൽ കടലാസ് ഉണ്ടകൾ ഇടുന്നു.

  2. പിന്നെ ചിലത് “അയൽക്കാരൻ” എന്ന പെട്ടിക്കു കൊടുക്കുന്നു.

  3. പങ്കുവയ്ക്കലിനെക്കുറിച്ചു സംസാരിക്കുക.

പാഠ സന്ദേശം: നമുക്കുള്ളത് പങ്കുവയ്ക്കണമെന്ന് ദൈവം ആഗ്രഹിക്കുന്നു.

കളി 2: പങ്കുവയ്ക്കണോ സൂക്ഷിക്കണോ

കളിക്കുന്ന വിധം:

  1. ഒരു കളിപ്പാട്ടത്തിന്റെയോ ലഘുഭക്ഷണത്തിന്റെയോ ചിത്രം ഉയർത്തിക്കാണിക്കുക.

  2. കുട്ടികൾ “പങ്കുവയ്ക്കൂ!” എന്നു പറഞ്ഞ് ഒരു പങ്കുവയ്ക്കൽ ചേഷ്ട കാണിക്കുന്നു.

  3. ചിത്രങ്ങൾ പരസ്പരം മാറ്റുക.

പാഠ സന്ദേശം: എല്ലാം സൂക്ഷിച്ചുവയ്ക്കുന്നതിനെക്കാൾ പങ്കുവയ്ക്കുന്നതാണ് നല്ലത്.
