エリシャと神の軍勢

ねらい

神が、超自然的な方法で、エリシャをどのように守られたかを、子どもたちに示す。神は今日も、私たちを守ってくださる。しばしば、思いがけない方法で。

聖書箇所

2列王記 6:8-17

暗唱聖句

出エジプト 20:3

（十戒）「あなたには、わたしのほかに、ほかの神々があってはならない。」

レッスンの進め方

導入

アフリカの子どもたちにとって、兵士はとても身近な存在です。兵士がする、さまざまな仕事について話しましょう。砲兵隊に属して、大砲を撃つ兵士もいます。戦車を運転したり、工兵になったりする兵士もいます。軍隊で最も危険な仕事の一つは、スパイや偵察兵になることです。敵の中にいて、その計画を探り出し、それから味方に報告しなければなりません。

今日の教えの要点

1. シリアとイスラエルは、互いに戦争をしていました。シリアの王は、イスラエルの軍隊に奇襲をかけようと計画するたびに、それが失敗するのが、理解できませんでした。彼は、自分の将校たちを、イスラエルの王のスパイだと責めました（2列王 6:8, 10-11）。

2. シリアの王の将校たちは、自分たちの中にスパイはいないと言いました。イスラエルの人々に警告し続けていたのは、預言者エリシャでした。エリシャは、スパイのように、シリアの王の計画を知っていて、それをイスラエル軍に知らせていたのです。すべてを知っておられ、私たちの心の秘密さえ知っておられる神が、シリアの王の計画を、エリシャに明らかにされたのです（6:9, 12）。

3. すぐに、シリアの王は、エリシャがどこに住んでいるかを、突き止めました。王は、エリシャを捕らえるために、夜のうちに、大きな強い軍隊を送って、町を取り囲ませました（6:13-14）。

4. エリシャのしもべは、翌朝、目をさまして、強力なシリア軍が町を取り囲んでいるのを見て、震え上がりました。「ああ、どうしましょう」と、彼は恐れて主人にたずねました（6:15）。

5. エリシャが、しもべに答えたことばと、しもべの目が開かれるようにというエリシャの祈りを、暗記してください。これらは、力強く、劇的なことばです。子どもたちにくり返すとき、それが伝わるようにしましょう。神は、ご自分の軍勢を送って、エリシャを守っておられたのです！ その軍勢は、あの大きなシリア軍よりも、はるかに強力でした（6:16-17）。

絵3を見せます。

お話への応答

エリシャのしもべは、とても恐れて、自分たちは死ぬのだと思いました。戦争は恐ろしいものです。私たちは、テレビやラジオで、それを聞いたり見たりしてきました。戦時には、家族が離ればなれになり、家や持ち物を失い、人々は飢え、多くの人が死にます。けれども、多くの信者は、しばしば危険や死から、すばらしい救い出しを体験しています。ここで、分かち合える体験談が、あるかもしれません。

神には、私たちを守る御使いの軍勢がおられます。見えないからといって、自分たちの戦う力に頼らなければならないわけではありません。神は、すべてを造られた方であり、すべての力の源です。主イエスは、全世界のすべての悪の力に、勝利されました。いつの日か、神が新しい天と新しい地で、ご自分の支配を打ち立てられるとき、私たちは、その最終的な勝利を、自分の目で見るでしょう（2ペテロ 3:13）。

これまでに学んだ、出エジプト記20章のすべての節を、復習します。

第3課：エリシャと神の軍勢

聖書箇所：2列王記 6:8-17

1. 合うものを結びましょう

A

B

シリアの王

奇襲を計画した

エリシャ

神から計画を知らされていた

しもべ

とてもこわがった

山々

馬と火でいっぱいだった

答え：
シリアの王 → 奇襲を計画した
エリシャ → 神から計画を知らされていた
しもべ → とてもこわがった
山々 → 馬と火でいっぱいだった

2. 正しい答えを選びましょう

a)、b)、c) のどれかに○をつけましょう：

  • エリシャに、王の秘密の計画を告げたのは、だれですか。
    a) スパイ b) 神 c) 鳥 👉 b) 神
  • 軍隊が町を取り囲んだのは、いつですか。
    a) 夜 b) 昼食のとき c) 正午 👉 a) 夜

3. 数えて書きましょう

数字を書きましょう：

  • エリシャは、しもべの目のために、何回祈りましたか。 ____ __________ 👉 1
  • 最後には、エリシャの町のまわりに、いくつの軍勢がありましたか（シリアの軍と、神の軍）。 ____ __________ 👉 2
  • 出エジプト 20:3によれば、私たちは、ほかの神々を何人持つべきですか。 ____ __________ 👉 0

4. 話し合いの質問

  • エリシャは、おびえたしもべに、何と言いましたか。

答えの例：「恐れるな。私たちとともにいる者は、彼らとともにいる者よりも多い。」

  • 神がしもべの目を開かれたとき、しもべは何を見ましたか。

答えの例：エリシャのまわり一面の、火の馬と戦車でいっぱいの山々。

  • 私たちがこわいとき、だれがいっしょにいてくださいますか。

答えの例：神と、神の御使いたちが、ともにいてくださる。

5. 暗唱聖句：

出エジプト記 20:3 ―「あなたには、わたしのほかに、ほかの神々があってはならない。」

詩篇 34:7 ―「主の使いは、主を恐れる者の周りに陣を張り、彼らを助け出される。」

6. 絵に色をぬりましょう：

工作1：御使いの軍勢の絵

材料：紙、クレヨン、綿、のり

手順：

  • 紙に、山々を描きます。
  • 綿で作った御使いを、山にはります。
  • 下のほうに、エリシャとしもべを描きます。
  • 書きましょう：「神さまの軍勢が、私たちとともにいる。」

ひとこと：神の御使いは、見えなくても、私たちを守ってくださいます。

工作2：目が開くしおり

材料：厚紙の細長い切れ、クレヨン、はさみ

手順：

  • 厚紙の細長い紙を切ります。
  • 上のほうに、大きな開いた目を描きます。
  • 書きましょう：「主よ、私の目を開いてください。」
  • 星でかざります。

ひとこと：神は、神が私たちとともにおられることを、見えるようにしてくださいます。

ゲーム1：うしろにいるのはだれ？

遊び方：

  • 一人の子が、壁のほうを向いて立ちます。
  • ほかの子たちは、静かにそのうしろに立ちます。
  • 言います。「見えなくても、私たちはここにいるよ。」神の御使いについて話し合います。

ひとこと：神の助けは、いつも見えるとはかぎりませんが、そこにあります。

ゲーム2：勇気の叫び

遊び方：

  • こわい場面（雷、暗い部屋）を、いくつか読み上げます。
  • 一つずつのあとで、子どもたちは、「神さまがともにいる！」と叫びます。
  • 子どもたちに、自分でも付け加えさせます。

ひとこと：神が守ってくださるので、私たちは恐れる必要はありません。
