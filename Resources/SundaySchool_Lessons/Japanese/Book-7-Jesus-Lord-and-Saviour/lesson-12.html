友人たちに現れるイエス

ねらい

イエスが、弟子たちにどのように現れ、特にペテロに語りかけて、イエスがどなたであり、ご自分を信じるすべての人に何を差し出しておられるかを、みんなに伝える使命を、ペテロに託されたかを、子どもたちに示す。

聖書箇所

ヨハネ 21:1-19

暗唱聖句

新しい聖句はありません

ここまでの箇所を復習します。

レッスンの進め方

導入

自分にできると知っていること、そしておそらく得意なことについて、クラスで話します。例：ヤギやほかの動物の世話、ブリキや針金でおもちゃを作ること、年下の子どもたちの世話、お茶を入れて出すこと。

今日の教えの要点

1. イエスの弟子たちの多くは、漁師でした。それはもともと彼らの仕事で、得意でもありましたが、三年間、イエスについて回っている間は、ほとんどやめていました。今や彼らは、イエスが生きておられることを知っていました。イエスに会ったのです。それでも、彼らはとても混乱していました。これらすべての驚くべき出来事の行き着く先が何なのか、わからなかったのです。そこで、そのうちの七人は、自分たちのよく知っていることを、しようと決めました。彼らは、ガリラヤ湖へ漁に出ました。けれども、彼らは、腕のよい漁師だったのに、一晩中、何も捕れませんでした（21:2-3）。

2. 夜明けに、彼らが知らない一人の男の人が、岸から彼らに呼びかけました。その人が何と言ったか、そして、弟子たちがその指示に従った時に何が起こったかを、クラスに話します（21:4-6）。

3. その時、ヨハネは、岸にいるのがイエスだと気づきました。ヨハネは、自分の名前を使わずに、自分のことを「イエスが愛された弟子」と呼んでいることを、説明します（21:7前半）。ペテロは、すぐにイエスにあいさつしたくてたまりませんでした。イエスは、疲れておなかをすかせた漁師たちのために、岸で食事を用意しておられました。彼らは、奇跡的に捕れた魚を、そこに加えました（21:7後半-14）。絵12を見せます。その日、イエスは、友人たちのために、二つの奇跡を行われました。魚がいないように見えるところで、たくさん魚を捕れるようにされ、そして、彼ら自身が魚を持って来る前から、食事を用意しておられました。

4. 朝食の後、イエスは、ペテロを、特別に話すために、わきに連れて行かれました。イエスがペテロにされた三つの質問、ペテロの答え、そして、イエスがペテロに与えられた使命を、説明します（21:15-19）。イエスが十字架につけられる前の夜、ペテロは三度、イエスを知らないと言いました。今、イエスは、ペテロに、三度、ご自分を愛しているかとたずねられました。ペテロは、答え方によって、自分が本当にイエスを愛していること、そして、イエスの命令を実行したいと思っていることを、示そうとしました。

お話への応答

イエスは、ペテロにたずねられたのと同じ質問を、私たちにもされます。あなたたち一人ひとりが、この質問の前に、自分の名前を入れることができます。たとえば、「ルタ／ジュマ、あなたはわたしを愛しますか」。

もし、あなたがイエスを愛しているなら、イエスは、あなたにも、この命令を与えておられます。「わたしの羊を飼いなさい。」神は、イエス・キリストに従う意志のある人たち一人ひとりのために、働きを計画しておられます（エペソ 2:10）。

第12課：友人たちに現れるイエス

聖書箇所：ヨハネ 21:1-19

1. 数えて書きましょう

数字を書きましょう：

  • 弟子たちは、 ____ 人で、いっしょに漁に出た。 __________ 👉 7
  • 彼らは、一晩中に、魚を ____ 匹捕った。 __________ 👉 0
  • イエスは、ペテロに、「わたしを愛しますか」と ____ 度たずねられた。 __________ 👉 3

2. 文を完成させよう

ことばのはこ：あみ、たきび、朝食

  • イエスは、 ____________ を右側に打つように言われた。 __________ 👉 あみ
  • イエスは、魚を焼く ____________ を用意しておられた。 __________ 👉 たきび
  • イエスは、岸で、彼らに ____________ をくださった。 __________ 👉 朝食

3. 合うものを結ぼう

A

B

ペテロ

「わたしを愛しますか」とたずねられた

ヨハネ

「主だ！」と言った

漁師たち

答え：

ヨハネ → 「主だ！」と言った
漁師たち → 一晩中、何も捕れなかった
イエス → 「わたしの羊を飼いなさい」と言われた

4. 話し合いの質問

  • 弟子たちがイエスに従った時、何が起こりましたか。

答えの例：たくさんの魚が捕れた。

  • イエスは、なぜペテロに、三度、ご自分を愛しているかとたずねられたのですか。

答えの例：ペテロは、三度イエスを知らないと言ったが、イエスは彼を赦された。

  • イエスは、ご自分を愛する人たちに、どんな仕事を与えられますか。

答えの例：ほかの人の世話をして、イエスについて話すこと。

5. 暗唱聖句：

ヨハネ 1:3 ―「すべてのものは、この方によって造られた。造られたもので、この方によらずにできたものは一つもない。」

ヨハネ 21:17 ―「主よ。あなたはすべてをご存じです。私があなたを愛していることを、あなたはよく知っておられます。」

6. 絵に色をぬりましょう：

工作1：魚のあみの絵

材料：紙、ひもまたは毛糸、小さな紙の魚、のり

手順：

  • 紙に、ひもを交差させて、あみをはります。
  • 紙の魚を、切り取ります。
  • 魚を、あみの中にはります。

ひとこと：イエスは、私たちが願う以上のものを、与えてくださいます。

工作2：羊飼いのつえカード

材料：二つ折りの厚紙、茶色の紙、クレヨン

手順：

  • 表に、長い羊飼いのつえを描きます。
  • そのとなりに、小さな子羊に色をぬります。
  • こう書きます：「わたしの羊を飼いなさい。」

ひとこと：イエスは、私たちに、ほかの人を愛し、世話をするようにと、求めておられます。

ゲーム1：あみを投げよう

遊び方：

  • 床に、紙の円（あみ）を置きます。
  • 子どもたちは、ラインのところから、紙の魚を投げ入れます。
  • 捕れた魚を、数えます。

ひとこと：イエスに従うと、祝福がもたらされます。

ゲーム2：わたしを愛しますか

遊び方：

  • 先生が、「（名前）さん、あなたはイエスさまを愛しますか」とたずねます。
  • その子が、「はい、主よ、あなたはご存じです」と言います。
  • それから、クラスが言います：「ほかの人の世話をしなさい。」

ひとこと：イエスを愛するなら、私たちは、ほかの人の世話をします。
