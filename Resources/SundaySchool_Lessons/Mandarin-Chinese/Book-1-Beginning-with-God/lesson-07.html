彩虹——神的应许

目标

教导孩子们：神许下应许，就必信守。

经文阅读

创世记 8:1-22；9:8-12

背诵经文

创世记 8:22

“地还存留的时候，稼穑……就永不停息了。”

讲授课程

起点

和全班谈谈应许。举例说明哪些应许已经遵守了，哪些应许被违背了。

今日教学要点

1. 神向挪亚许下应许：只要他遵照神的计划，为自己一家和神吩咐他从各处聚集的动物造一艘方舟，他和他的家人就必得保全。出示图片 5。挪亚顺服神，他们果然在方舟里得保平安。但陆地上和空中所有其他的生物都死了。出示图片 6。

2. 挪亚、他的家人和动物们被关在方舟里好几个月。神忘记他们了吗？雨停了，过了七个月，方舟停在了山上（7:24 – 8:5）。

3. 在船上过了十一个月后，挪亚放出一只乌鸦，这是一种吃腐肉的大黑鸟（8:5-7）。

4. 然后挪亚放出一只鸽子，起初它飞回来了，因为找不到落脚的地方。描述挪亚怎样从鸽子那里得知外面世界的情况（8:8-12）。

5. 挪亚带着家人和动物进入方舟一年之后，他让所有的生灵都出来。挪亚和他的家人做的第一件事就是敬拜神。他们感谢祂应验了保守他们平安的应许。出示图片 7。他们筑了一座坛，献上祭物。神很喜悦（8:13-19）。

6. 神应许祂再也不用水毁灭地了。祂应许将来总有耕种和收获，四季照常运行。神把彩虹放在天空，作为记号提醒人们，祂必永远信守祂的应许。每当我们看见彩虹，就应当记住：我们可以倚靠神的话。

牢记背诵经文

我们对这个故事的回应

请全班向四周看一看，说出一切属于彩虹颜色的东西。（彩虹的七种颜色是：红、橙、黄、绿、蓝、靛、紫。）让这些东西提醒我们，神总是信守祂的应许。我们可以指望神说到做到。

第 7 课：彩虹——神的应许

经文阅读： 创世记 8:1-22；9:8-12

1. 是或否

写上“是”或“否”：

  • 神在方舟里忘记了挪亚吗？（ ___ ） 👉 否
  • 挪亚放出了乌鸦和鸽子吗？（ ___ ） 👉 是
  • 挪亚出方舟后敬拜神了吗？（ ___ ） 👉 是
  • 神应许不再用洪水毁灭全地了吗？（ ___ ） 👉 是

2. 重排字序

利用提示来帮助你：

  • 虹彩 （天空中的记号）→ __________ 👉 彩虹
  • 鸽子 （一种白色的鸟）→ __________ 👉 鸽子
  • 应许 （神总是遵守它）→ __________ 👉 应许
  • 祭坛 （挪亚为敬拜神而筑的）→ __________ 👉 祭坛

3. 完成句子

词语框：应许、敬拜、彩虹

  • 神把____________放在天空作为记号。 __________ 👉 彩虹
  • 神总是遵守祂的____________。 __________ 👉 应许
  • 挪亚和他的家人筑了一座坛来____________神。 __________ 👉 敬拜

4. 讨论题

  • 洪水之后神应许了什么？

参考答案：祂应许不再用水毁灭地。

  • 挪亚为什么筑坛？

参考答案：为了感谢并敬拜神保守他的家人平安。

  • 我们看见彩虹时应当记住什么？

参考答案：神总是信守祂的应许。

5. 背诵经文：

创世记 8:22 — “地还存留的时候，稼穑、寒暑、夏冬、昼夜，就永不停息了。”

诗篇 145:13 — “耶和华在他一切所应许的话上是信实的。”

手工 1：衔着橄榄叶的鸽子

材料： 白纸、绿纸、剪刀、胶水、蜡笔

步骤：

  • 用白纸剪出一只鸽子的形状。
  • 剪一片小绿叶，粘在鸽子的嘴上。
  • 给眼睛和翅膀涂上颜色。
  • 写上：“神信守祂的应许。”

课程重点： 挪亚从鸽子那里得知了方舟外世界的情况。

手工 2：彩虹飘带环

材料： 纸盘、彩色皱纹纸或丝带、剪刀、胶水

步骤：

  • 把纸盘的中间剪掉，做成一个环。
  • 把七条彩色飘带（红、橙、黄、绿、蓝、靛、紫）粘在环上。
  • 举起来挥一挥，并说：“神总是信守祂的话。”

课程重点： 每当我们看见彩虹，就可以倚靠神的话。

游戏 1：寻找彩虹的颜色

玩法：

  • 孩子们在教室里或室外寻找彩虹每种颜色的东西。
  • 他们说出自己找到的每样东西。
  • 第一个为七种颜色都说出东西的孩子获胜。

课程重点： 神的彩虹提醒我们，祂信守祂的应许。

游戏 2：守约的人

玩法：

  • 对每个孩子许一个诺言，例如：“我答应最后送你一张贴纸。”
  • 在孩子们离开前，信守每一个诺言。
  • 谈谈诺言被遵守或被违背时的感受。

课程重点： 神说到做到。
