耶稣为我们而死

目标

教导孩子们：耶稣来是为了救赎我们。

经文阅读

加拉太书 3:13-14；约翰福音 18:12-14；19:16-37

背诵经文

加拉太书 2:20

我如今在肉身活着，是因信神的儿子而活；祂是爱我，为我舍己。

讲授课程

起点

问问孩子们，他们最珍贵的东西是什么。给他们看你自己的，或告诉他们你的——一样你失去了会非常难过的东西。

今日教学要点

1. 神为了我们，把祂极其宝贵的儿子差到这个世界上来。出示图片 22。通过询问关于这幅图的问题，简要复习第 22 课。神在耶稣基督里成就了祂拯救的应许。

2. 耶稣长大成人。他教导人们神的道路。他行了许多神迹，表明他真是从神而来的。但许多人不肯信他。宗教领袖让兵丁把他逮捕带走了（约 18:12-14）。

3. 神的儿子耶稣被钉十字架处死，这是最残忍的处死方式之一。他们把耶稣放在木制的十字架上，把他的手和脚钉在上面。然后把十字架竖起来，让他挂着，直到死去。在他的朋友们把他的身体从十字架上取下来之前，一个兵丁用矛扎了耶稣的肋旁，要确认他真的死了（约 19:16-17，23-24，31-37）。

4. 出示图片 20。当神试验亚伯拉罕，要他献上以撒作祭物，亚伯拉罕顺服时，神预备了一只羊代替以撒。照样，神预备了耶稣作为神的羔羊，代替我们死。神使亚伯拉罕不必承受献上独生子的悲痛，但神自己却为了我们的缘故，献上了祂的独生子！出示图片 3。亚当和夏娃违背了神，我们说他们犯了罪。我们都是有罪的。神差遣耶稣来救赎我们脱离罪，使我们可以得着赦免，并与祂永远同活。

牢记背诵经文

我们对这个故事的回应

给全班讲一个故事：一个男孩做了一辆漂亮的铁皮小汽车。有一天，他把车弄丢了。几个星期后，他在一家商店里看到了它。他去告诉店主那是他的。店主说他可以拿走，但必须付钱。于是男孩攒钱，把自己的车买了回来。他说，现在这辆车是他双重的所有：他做了它，又买了它。

神造了我们。耶稣使我们与神复和。祂为我们而死，救赎了我们，也就是把我们买回来，归给神。带领孩子们祷告，感谢耶稣为我们所做的一切。

第 23 课：耶稣为我们而死

经文阅读： 加拉太书 3:13-14；约翰福音 18:12-14；19:16-37

1. 完成句子

词语框：羔羊、救赎、爱

  • 耶稣是神的____________。 __________ 👉 羔羊
  • 神差遣耶稣，因为祂____________我们。 __________ 👉 爱
  • 耶稣来____________我们，意思是把我们买回来。 __________ 👉 救赎

2. 当时与现在

A

B

羊

代替以撒

耶稣

代替我们

罪

违背神

救赎

买回

答案：
羊 → 代替以撒
耶稣 → 代替我们
罪 → 违背神
救赎 → 买回

3. 圈出正确的词语

圈出正确的词语：

  • 耶稣（做过 / 没有做过）任何错事。 👉 没有做过
  • 耶稣死在（十字架 / 船）上。 👉 十字架
  • 耶稣的死带给我们（赦免 / 只有悲伤）。 👉 赦免

4. 讨论题

  • 耶稣为什么必须死？

参考答案：为了担当我们罪的刑罚，使我们回到神那里。

  • 耶稣救赎了我们，这是什么意思？

参考答案：祂把我们买回来，归给神。

  • 我们怎样感谢耶稣？

参考答案：藉着祷告、顺服祂，并把祂告诉别人。

5. 背诵经文：

加拉太书 2:20 — “我如今在肉身活着，是因信神的儿子而活；祂是爱我，为我舍己。”

约翰一书 4:19 — “我们爱，因为神先爱我们。”

6. 给图画涂色：

手工 1：十字架拼贴画

材料： 纸、彩色皱纹纸碎片、胶水

步骤：

  • 用纸剪出一个十字架的形状。
  • 把小块的彩色皱纹纸粘在十字架上。
  • 写上：“耶稣为我而死。”

课程重点： 耶稣死了，为要拯救我们脱离罪。

手工 2：感恩的心卡片

材料： 对折的纸、蜡笔、贴纸

步骤：

  • 在封面上画一颗大大的心。
  • 在里面给耶稣写一张感谢的便条。
  • 用贴纸装饰。

课程重点： 我们感谢耶稣爱我们，并为我们舍己。

游戏 1：失而复得

玩法：

  • 藏起一辆玩具车，让一个孩子去找。
  • 找到后，解释说这件玩具被它的主人“买回来”了。
  • 谈谈耶稣怎样把我们买回来。

课程重点： 耶稣救赎了我们，所以我们属于神。

游戏 2：感恩祷告圈

玩法：

  • 围坐成一圈，手拉着手。
  • 每个孩子对耶稣说一句简短的感谢。
  • 最后，大家一起说：“感谢祢，耶稣！”

课程重点： 我们为耶稣所做的一切心存感恩。
