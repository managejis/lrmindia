神差遣祂应许的儿子

目标

教导孩子们：神怎样信守了人类最初悖逆祂时所立的应许——差遣祂自己的儿子来到世上。

经文阅读

加拉太书 4:4-5；马太福音 1:18-25；路加福音 2:8-20

背诵经文

加拉太书 4:4

及至时候满足，神就差遣祂的儿子，为妇人所生……

讲授课程

起点

和全班谈谈等候某件事在合适的时间发生。小孩子常常很难接受看着哥哥姐姐去上学。他们也想去，却不明白对他们来说时候还没到。

今日教学要点

1. 出示图片 2 和 3。亚当和夏娃听从了撒但，不得不离开美丽的伊甸园，那是一个非常悲伤的时刻。但神应许，祂会在合适的时候差遣祂的儿子来拯救人类，并击败撒但（创 3:15）。

2. 出示图片 6。神应许亚伯拉罕有那么多的后裔，多得像数天上的星星一样困难。神的儿子将是亚伯拉罕的后裔（创 12:3）。

3. 时候到了，神就差遣祂的儿子来成就祂拯救的应许。神的儿子以婴孩的身份来到这个世界，由一位名叫马利亚的年轻女子所生。

4. 马利亚已与一位名叫约瑟的好人订了婚。约瑟听说马利亚怀孕了，心里很难过，因为他知道自己不是孩子的父亲。他打算悄悄地解除婚约，但这时一位天使在梦中对他说话。约瑟得知，马利亚怀的是一个非常特别的婴孩。这个婴孩来自神。他是神自己的儿子，是神应许给全人类的救主（太 1:18-25）。

5. 新生儿降生时，消息就传开了，人们就来探望。当马利亚在伯利恒生下她的孩子时，一位天使把这件事告诉了在田野里看守羊群的几个牧羊人。起初，他们非常害怕。描述天使拜访牧羊人的情形（路 2:8-14）。

6. 牧羊人急忙去寻找这个婴孩。出示图片 22。之后，他们把所看见的告诉了每一个人，并且不住地赞美神（路 2:15-20）。

牢记背诵经文

我们对这个故事的回应

给新生婴儿起名是一个非常重要的决定。这个婴孩被称为以马内利，意思是“神与我们同在”。他又被起名叫耶稣，意思是“救主”。神差遣祂的儿子到这个世界上，是为了遵守祂的应许，拯救所有的人脱离他们的罪。耶稣是为我们每一个人而来的——也是为你和我而来的。

第 22 课：神差遣祂应许的儿子

经文阅读： 加拉太书 4:4-5；马太福音 1:18-25；路加福音 2:8-20

1. 连线配对

A

B

亚当和夏娃

神应许了一位救主

亚伯拉罕

多如星辰的子孙

马利亚

耶稣的母亲

牧羊人

天使告诉她关于婴孩的事

答案：
亚当和夏娃 → 神应许了一位救主
亚伯拉罕 → 多如星辰的子孙
马利亚 → 耶稣的母亲
牧羊人 → 天使告诉他们关于婴孩的事

2. 完成句子

词语框：伯利恒、天使、救主

  • 耶稣出生在____________。 __________ 👉 伯利恒
  • 一位____________把好消息告诉了牧羊人。 __________ 👉 天使
  • 耶稣这个名字的意思是“____________”。 __________ 👉 救主

3. 是或否

写上“是”或“否”：

  • 神信守了祂差遣救主的应许吗？（ ___ ） 👉 是
  • 牧羊人赞美神了吗？（ ___ ） 👉 是
  • 耶稣只是为少数人而来吗？（ ___ ） 👉 否

4. 讨论题

  • 神为什么差遣耶稣？

参考答案：照着祂的应许，拯救所有的人脱离他们的罪。

  • 牧羊人见到耶稣之后做了什么？

参考答案：他们告诉了每一个人，并赞美神。

  • 我们怎样把耶稣告诉别人？

参考答案：分享好消息，并显出祂的爱。

5. 背诵经文：

加拉太书 4:4 — “及至时候满足，神就差遣祂的儿子，为妇人所生。”

路加福音 2:11 — “今天在大卫的城里，为你们生了救主，就是主基督。”

6. 给图画涂色：

手工 1：伯利恒之星

材料： 黄纸、剪刀、胶水、闪粉

步骤：

  • 用黄纸剪出一颗大星星。
  • 用闪粉装饰它。
  • 在上面写：“耶稣降生了。”

课程重点： 神在合适的时间差遣耶稣来，信守了祂的应许。

手工 2：牧羊人和羊

材料： 纸、脱脂棉、蜡笔、胶水

步骤：

  • 画一位拿着牧杖的牧羊人。
  • 在他旁边粘上用脱脂棉做的羊。
  • 写上：“牧羊人赞美神。”

课程重点： 牧羊人分享了这好消息。

游戏 1：寻找羊群

玩法：

  • 把纸羊藏在教室各处。
  • 孩子们扮演牧羊人，去寻找走失的羊。
  • 数一数每个孩子找到几只，并说“赞美神！”

课程重点： 牧羊人急忙去找婴孩耶稣。

游戏 2：传递好消息

玩法：

  • 把“耶稣降生了”一个接一个地悄悄传给圈里的下一个孩子。
  • 最后一个孩子大声说出来。
  • 大家一起欢呼。

课程重点： 我们应当把耶稣的好消息告诉别人。
