十二个以色列人窥探应许之地

目标

向孩子们说明：我们要信靠神，不要因为眼见的困难就怀疑祂的能力。

经文阅读

民数记 13:1-2, 17-33；14:20-25

背诵经文

民数记 14:9

“耶和华与我们同在，不要怕他们。”

注：可能的话，请研读民数记第 13 和 14 章全部。

讲授课程

起点

问问全班喜不喜欢坐车。他们大概都会说喜欢，尤其是男孩子。但如果你带一个从没坐过车的三岁小孩坐车，他多半会哭。他可能被发动机的声音吓到，也可能不喜欢车颠簸摇晃。他会想要停车下去。

课程重点

1. 摩西正带领以色列人前往迦南地，那是神应许要赐给他们的地方。他派人去探看那地是什么样子（13:1-2）。

2. 这十二个探子（每个支派一人）奉命要留意那里长什么庄稼、城邑有没有坚固的防御，以及住着什么样的人（13:17-20）。

3. 探子们去了 40 天，然后回来向摩西和百姓报告。他们还带回了一些那里出产的美好果子。一根树枝上只有一串葡萄，就大得要两个人抬（13:23, 25-26）。

4. 出示图片 2。摩西面前拿着大串葡萄、石榴和无花果的两个人，就是约书亚和迦勒。你也可以提到孩子们熟悉的其他水果，比如橙子，它们在迦南（现在叫以色列）长得很大。

十二个探子彼此意见不一。他们都说那地非常好（13:27），但其中十个人害怕迦南的居民。他们报告说那些人又强壮又高大。图中显示了其中三个人：看看他们脸上的恐惧。有一个人正在比划迦南人有多高大（13:28）。

5. 接着，迦勒作了他和约书亚准备好的报告。他们建议摩西立刻进入应许之地（13:30）。于是争论开始了。另外十个探子非常害怕，甚至撒谎说那地不好（13:31-33）。他们只看见这些困难，忘了定睛仰望他们大能的神。百姓听信了这十个缺乏信心的探子。

6. 神知道这些人在迦南建立不起一个坚强、忠心的国家。因此，他们必须在旷野漂流，直到所有不信靠神的成年以色列人都死去。他们的孩子长大后，才会进入应许之地。然而，约书亚和迦勒会存活下来，进入迦南（14:20-24）。

我们对这个故事的回应

请孩子们想一想自己担心或害怕的事。然后鼓励他们把这份害怕告诉神，求祂赐给他们信心和胜过它的能力。留出一小段默祷的时间，让孩子们这样做。

牢记背诵经文

指出这些是迦勒对以色列人说的话。

第 2 课：十二个以色列人窥探应许之地

经文阅读： 民数记 13:1-2, 17-33；14:20-25

1. 把故事按顺序排好

甲）十个人害怕，作了坏报告。
乙）摩西派十二个人去窥探迦南。
丙）约书亚和迦勒说：“神与我们同在。”
丁）他们带回一大串葡萄。

👉 正确顺序：

  • 摩西派十二个人去窥探迦南。
  • 他们带回一大串葡萄。
  • 十个人害怕，作了坏报告。
  • 约书亚和迦勒说：“神与我们同在。”

2. 圈出正确的词

圈出正确的词：

  • 约书亚和迦勒是害怕 / 勇敢的。 👉 勇敢
  • 探子们去了 4 / 40 天。 👉 40
  • 十个人看的是巨人 / 神。 👉 巨人

3. 信靠还是忧虑？ 信/忧

信靠写“信”，忧虑写“忧”：

  • “神比我的难题更强大。”( ___ ) 👉 信
  • “这个难题对神来说太大了。”( ___ ) 👉 忧
  • 把我的害怕告诉神。( ___ ) 👉 信

4. 讨论题

  • 这十二个人在迦南发现了什么？

参考答案：一块美好的土地，有奇妙的水果。

  • 为什么有十个人说他们不能进去？

参考答案：他们看见那些强壮的人，就忘了神的能力。

  • 你觉得害怕的时候可以做什么？

参考答案：告诉神，求祂帮助。

5. 背诵经文：

民数记 14:9 ——“耶和华与我们同在，不要怕他们。”

以赛亚书 41:10 — “你不要害怕，因为我与你同在。”

6. 给图画涂色：

手工 1：一串葡萄

材料： 紫色纸、绿色纸、胶水、剪刀

步骤：

  • 剪出许多紫色的圆片。
  • 把它们粘成一串的样子。
  • 再加上绿色的茎和叶子。
  • 写上：“神与我们同在。”

课程重点： 那地是美好的，神也与他们同在。

手工 2：勇敢探子的望远镜

材料： 两个纸筒、胶带、蜡笔

步骤：

  • 装饰两个纸筒。
  • 用胶带把它们并排粘在一起。
  • 透过它们看一位朋友。
  • 说：“我要信靠神。”

课程重点： 我们要看神的能力，不看我们的恐惧。

游戏 1：找水果

玩法：

  • 把纸做的水果藏在教室各处。
  • 孩子们去探查，把它们找出来。
  • 每个找到的人说：“神是良善的。”

课程重点： 探子们在迦南找到了美好的果子。

游戏 2：大还是小？

玩法：

  • 说出一个大的忧虑，比如黑暗的房间。
  • 全班说：“神更大！”
  • 轮流说出各自的忧虑。

课程重点： 神比我们的恐惧更大。
