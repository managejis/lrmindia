参孙毁灭非利士人

目标

向孩子们说明：转向神永远不嫌晚。然而，意识到自己白白浪费了许多事奉神的机会，是非常令人难过的。

经文阅读

士师记 16:21-30

背诵经文

诗篇 51:1

神啊，求你按你的慈爱怜恤我……

讲授课程

起点

如果你观察一群狗或一群鸡，会发现它们都攻击最弱的那一只。人也常常是这样：他们取笑那些无力还手的人。

课程重点

1. 参孙从前是个非常强壮的人。出示图片 19，简要复习这个故事。他因为不顺服和不敬虔的生活方式，失去了神所赐的力量。现在非利士人把他囚禁起来。

2. 非利士人的首领挖掉了他的眼睛，叫他在磨坊里干活，一圈又一圈地走着推动大磨石（16:21）。

3. 非利士人的首领们为庆祝参孙被击败，举行宴会，向他们的偶像大衮献祭。他们派人把参孙叫来，好取笑他（16:23-27）。

4. 参孙已经明白，神才是他力量真正的来源，所以他转向神，求祂让他再强壮最后一次（16:28）。

5. 神垂听了他的祷告。参孙靠着撑住大衮庙宇屋顶的柱子，把整座建筑拉倒了，里面所有的人都被压死（16:29-30）。出示图片 20。

6. 参孙与非利士人的首领们同归于尽。他因为违背神，浪费了他生命中最大的一部分，也浪费了他宝贵的恩赐。这是非常令人难过的。然而，当他回转归向神时，神并没有弃绝他。

我们对这个故事的回应

参孙一生的故事是对我们的警告。神赐给他一份异常的恩赐，但最终没有给参孙带来喜乐，因为他为自己的目的滥用了它。让我们感谢耶稣基督，祂来为我们指明了胜过悖逆和自私、得享永远胜利的道路。

第 20 课：参孙毁灭非利士人

经文阅读： 士师记 16:21-30

1. 是还是否？ 是/否

是写“是”，否写“否”：

  • 参孙在监里回转归向神了吗？( ___ ) 👉 是
  • 参孙祷告的时候，神拒绝了他吗？( ___ ) 👉 否
  • 参孙浪费了许多事奉神的机会吗？( ___ ) 👉 是

2. 完成句子

词语框：祷告、对不起、怜悯

  • 参孙向神____________，求祂帮助。 __________ 👉 祷告
  • 神向求告祂的人施行____________。 __________ 👉 怜悯
  • 我们做错事时应当说____________。 __________ 👉 对不起

3. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 谁嘲笑软弱无助的人？
    甲）非利士人的首领们 乙）底波拉 丙）基甸 👉 甲）非利士人的首领们
  • 我们从中学到神是怎样的？
    甲）祂放弃我们 乙）转向祂永远不嫌晚 丙）祂行动迟缓 👉 乙）转向祂永远不嫌晚

4. 讨论题

  • 转向神有没有太晚的时候？

参考答案：不会。祂赦免真心悔改的人。

  • 浪费机会为什么令人难过？

参考答案：我们错过了神要我们做的美好的事。

  • 我们怎样帮助软弱的人？

参考答案：善待他们，绝不嘲笑他们。

5. 背诵经文：

诗篇 51:1 ——“神啊，求你按你的慈爱怜恤我，按你丰盛的慈悲涂抹我的过犯。”

诗篇 86:5 — “主啊，祢本为良善，乐意饶恕人，有丰盛的慈爱赐给凡求告祢的人。”

6. 给图画涂色：

手工 1：敞开的门卡

材料： 对折的卡片、蜡笔

步骤：

  • 在正面画一扇门。
  • 里面写上：“神欢迎我。”
  • 装饰这张卡片。

课程重点： 神的门永远敞开。

手工 2：悔改的心

材料： 红色纸、蜡笔、胶水

步骤：

  • 把一颗心剪成两半。
  • 在其中一半上写“对不起”。
  • 把两半粘在一起，并写上：“已蒙赦免。”

课程重点： 神赦免我们，并医治我们的心。

游戏 1：回来吧

玩法：

  • 一个孩子从小组走开。
  • 大家叫：“回来吧！”
  • 那个孩子回来，受到欢迎。

课程重点： 我们转回来的时候，神欢迎我们。

游戏 2：友善还是不友善？

玩法：

  • 读几个简短的例子。
  • 孩子们做出快乐或悲伤的表情。
  • 谈谈善待软弱的人。

课程重点： 我们应当善待每一个人。
