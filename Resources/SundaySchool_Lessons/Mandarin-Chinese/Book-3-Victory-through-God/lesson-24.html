神的精兵

目标

向孩子们说明：神装备每一位基督徒，使他们能胜过邪恶。

经文阅读

以弗所书 6:10-18

背诵经文

以弗所书 6:13

要拿起神所赐的全副军装，好在磨难的日子能抵挡仇敌，……还能站立得住。

讲授课程

起点

住在南苏丹朱巴的每一个人，都见过城里的士兵。孩子们喜欢看他们在操场上列队行进，也喜欢在乐队演奏时跟着跑。

课程重点

1. 圣经里有许多关于士兵的故事。约书亚和基甸都做过士兵，带领以色列人得自由。耶稣呼召我们作主军队里的战士。但我们的盔甲和武器与通常士兵所用的有一点不一样！这是因为基督徒事奉的是和平之君；我们要争战的仇敌是看不见的邪恶势力（6:12-13）。

2. 出示图片 24。这个士兵穿得像耶稣时代的罗马士兵。我们要逐一查看他的每一件盔甲，看看它们对基督徒与邪恶的争战说明了什么（6:16）。

3. 图中的士兵已经准备好面对危险。他腰间系着腰带 ，使整套盔甲都固定在他身上，紧贴着他的身体。图中的腰带很难看出来，因为它被手臂挡住了。请指出来。腰带代表真理。作为基督徒战士，我们所说的话必须真实，我们的行为必须显出我们所说的话是真实的。如果一个士兵或一个基督徒被认为是在假装，在玩假扮的游戏，就没有人会信任他们（6:13-14）。

4. 护心镜 保护心。我们一想到心，就想到爱。基督徒战士爱他们的统帅神，也爱他们的邻舍。这意味着他们愿意行正直的事。 这块护心镜保护他们，不让邪恶的欲望进入他们的心里（6:14）。

5. 士兵必须有一双好鞋。 他要走很多公里的路。基督徒战士无论走到哪里，都必须预备好带着平安的福音。 这会使他们站立稳固；使他们不致滑入邪恶的道路（6:15）。

6. 这个士兵举着一面盾牌 ，保护自己不受敌人的箭伤害。那恶者像射出火箭一样向基督徒射出试探。盾牌代表对神的信心或信靠，它使我们平安（6:16）。

7. 士兵戴着头盔 保护他的头。掌管全身的大脑就在头里面。耶稣借着祂的死，救我们脱离了死亡的权势。就像头盔一样，我们的救恩 保护我们的整个生命，使它不受罪和死亡的侵害。

8. 这个士兵只带着一件武器，而这就是他所需要的，因为它的威力太大了。剑 代表神借着祂的灵和祂的话语 教导我们的。身为基督徒，我们必须阅读并认识圣经；这样我们就能分辨撒但的谎言和神的真理。

我们对这个故事的回应

耶稣基督的跟随者需要穿戴神所预备的军装，使他们能胜过邪恶。

如果教室里有黑板，你可以画出基督徒军装的简单图画，问孩子们每一件代表什么。把答案写在每幅图旁边。

第 24 课：神的精兵

经文阅读： 以弗所书 6:10-18

1. 配对军装

A

B

腰带

真理

盾牌

信心

头盔

救恩

宝剑

神的话语

答案：
腰带 → 真理
盾牌 → 信心
头盔 → 救恩
宝剑 → 神的话语

2. 是还是否？ 是/否

是写“是”，否写“否”：

  • 基督徒战士用枪打仗吗？( ___ ) 👉 否
  • 我们应当读圣经，好认识神的真理吗？( ___ ) 👉 是
  • 神赐给我们军装，使我们站立稳固吗？( ___ ) 👉 是

3. 圈出正确的词语

圈出正确的词：

  • 盾牌代表信心 / 食物。 👉 信心
  • 腰带代表真理 / 睡眠。 👉 真理
  • 我们的鞋使我们预备好传平安 / 战争的福音。 👉 平安

4. 讨论题

  • 谁是我们的仇敌？

参考答案：看不见的邪恶势力。

  • 我们怎样才能站立稳固？

参考答案：信靠神，并使用祂的军装。

  • 你最好的武器是什么？

参考答案：神的话语，圣经。

5. 背诵经文：

以弗所书 6:13 ——“所以，要拿起神所赐的全副军装，好在磨难的日子抵挡仇敌，并且成就了一切，还能站立得住。”

以弗所书 6:10 ——“要靠着主，倚赖祂的大能大力，作刚强的人。”

6. 给图画涂色：

手工 1：纸盾牌

材料： 卡纸、锡纸、蜡笔、细绳

步骤：

  • 用卡纸剪出一面盾牌。
  • 用锡纸把它盖住。
  • 写上：“信心。”
  • 加上细绳。

课程重点： 信心使我们免受邪恶的侵害。

手工 2：军装海报

材料： 大张纸、蜡笔

步骤：

  • 画一个士兵。
  • 标出腰带、盾牌、头盔、鞋和宝剑。
  • 涂上颜色。

课程重点： 神装备每一位基督徒。

游戏 1：给士兵穿军装

玩法：

  • 出示一幅士兵的图画。
  • 孩子们加上每一件军装，并说出它的意思。
  • 一起重复一遍。

课程重点： 神的军装保护我们。

游戏 2：站立稳固

玩法：

  • 双脚分开站立。
  • 一个朋友轻轻地想把你推动。
  • 说：“我与神同站立。”

课程重点： 靠着神的帮助，我们站立稳固。
