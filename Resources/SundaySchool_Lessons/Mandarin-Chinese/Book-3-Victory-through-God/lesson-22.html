耶稣责备行恶的人

目标

向孩子们说明：神不容忍邪恶，因为祂是圣洁的。

经文阅读

马可福音 11:15-18；约翰福音 2:13-22

背诵经文

马可福音 11:17

“‘我的殿必称为万国祷告的殿’……你们倒使它成为‘贼窝’了。”

讲授课程

起点

请全班说说，在教会里会进行哪些活动。他们大概会说唱诗、祷告、讲道之类。我们也在教会里举行庆祝活动，比如复活节和圣诞节。

课程重点

1. 圣殿，也就是神的殿，是犹太人敬拜神的地方。耶稣到了那里，发现那里进行的一些事，与你们刚才说的那些活动很不一样。祂确实看到了唱诗、教导和祷告，但也看到了祂非常不喜悦的事。

2. 在耶稣为我们所有的罪作完全的祭牲、死在十字架上之前，犹太人必须献上牲畜作祭物，来与神和好。这些祭牲是在圣殿院内出售的，造成许多混乱和嘈杂。买牲畜还需要特别的钱，所以普通的钱必须兑换成圣殿的钱。这也是在圣殿区域内进行的。

3. 耶稣看见商人们在欺骗人。他们的价格高得离谱。兑换银钱的人也不诚实、不公平（约 2:14）。

4. 耶稣非常生气，但祂不像参孙那样暴躁。耶稣的怒气是受控制的，也是正当的。出示图片 22。耶稣把不诚实的商人和他们的牲畜都赶了出去（约 2:15-17；可 11:15-17）。

5. 一些犹太人和他们的宗教领袖很生气，质问祂有什么权柄这样做（约 2:18-22；可 11:18）。耶稣是神的儿子。所以祂有权利、有权柄、有能力把邪恶从祂父的家中赶出去。

背诵经文。

注：耶稣在地上的服事期间，曾两次把商人赶出圣殿。第一次是在祂服事的开始；这是约翰福音记载的故事。第二次是在祂被钉十字架前的那一周。这是马可福音记载的故事。

我们对这个故事的回应

神要我们在敬拜祂的时候尊崇祂。我们既可以在欢乐的时候这样做，也可以在严肃的时候这样做。神察看我们的心，看我们所说的、所唱的、所做的是不是出自真心，还是只是在做样子、不诚实。请读诗篇 150 篇。这篇诗就是神要我们在祂的殿里怎样敬拜祂的一个例子。

第 22 课：耶稣责备行恶的人

经文阅读： 马可福音 11:15-18；约翰福音 2:13-22

1. 把故事按顺序排好

甲）祂看见人们在欺骗。
乙）领袖们质问祂。
丙）耶稣去了圣殿。
丁）祂把不诚实的商人赶了出去。

👉 正确顺序：

  • 丙）耶稣去了圣殿。
  • 甲）祂看见人们在欺骗。
  • 丁）祂把不诚实的商人赶了出去。
  • 乙）领袖们质问祂。

2. 诚实还是不诚实？ 诚/欺

诚实写“诚”，不诚实写“欺”：

  • 多收钱。( ___ ) 👉 欺
  • 公平地找零钱。( ___ ) 👉 诚
  • 在教会里全心全意地唱诗。( ___ ) 👉 诚

3. 完成句子

词语框：祷告、圣洁、尊崇

  • 神的殿是____________的殿。 __________ 👉 祷告
  • 神是____________的，不容忍错误。 __________ 👉 圣洁
  • 我们敬拜时要____________神。 __________ 👉 尊崇

4. 讨论题

  • 耶稣为什么不高兴？

参考答案：人们在欺骗，圣殿里又吵闹。

  • 耶稣的怒气与参孙的有什么不同？

参考答案：祂的怒气是受控制的，也是正当的。

  • 我们怎样才能好好敬拜神？

参考答案：用诚实的心，用诗歌和祷告。

5. 背诵经文：

马可福音 11:17 ——“‘我的殿必称为万国祷告的殿’，你们倒使它成为‘贼窝’了。”

诗篇 122:1 ——“人对我说：‘我们往耶和华的殿去。’我就欢喜。”

6. 给图画涂色：

手工 1：祷告的殿

材料： 纸、蜡笔、胶水

步骤：

  • 画一座小教堂。
  • 在里面加上正在祷告的人。
  • 写上：“祷告的殿。”

课程重点： 神的殿是用来敬拜的。

手工 2：诚实硬币徽章

材料： 金色的纸圆片、蜡笔

步骤：

  • 剪出一个金色的圆片。
  • 写上：“要诚实。”
  • 加上一张笑脸。

课程重点： 神要诚实的心。

游戏 1：在教会里要安静

玩法：

  • 孩子们像走进教会一样安静地走进来。
  • 作一个简短的祷告。
  • 坐下，轻声唱诗。

课程重点： 我们尊重神的殿。

游戏 2：公平的商店

玩法：

  • 摆上假装的商品，标上公平的价格。
  • 孩子们诚实地买卖。
  • 为公平欢呼。

课程重点： 神要我们在一切所做的事上诚实。
