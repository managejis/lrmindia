以色列人庆祝并赞美神

目标

向孩子们说明：神从仇敌手中拯救了以色列，以色列人怎样赞美神。

经文阅读

士师记 5:1-31

背诵经文

士师记 5:10-11

在打水之处，有歌唱的声音，要在那里述说耶和华公义的作为，就是祂治理以色列的勇士公义的作为。

讲授课程

起点

人们在水泵或公用水龙头旁等着打水时，常常谈论社区里发生的事。那里是打听消息的地方。

课程重点

1. 对西西拉和他的军队作战之后，以色列人在井边谈论的消息，就是神赐给他们的胜利。背诵经文。

2. 百姓决定举行庆祝，感谢神。他们向神唱诗赞美，演奏乐器，跳舞。出示图片 12。

3. 底波拉和巴拉向神唱了感谢的歌（5:1）。以色列众人都欢喜快乐。他们很高兴有底波拉这样敬畏神的领袖。她对他们来说像母亲一样（5:7-15）。出示图片 9 和 10。

4. 雅亿也受到称赞，因为她在拯救以色列百姓这件事上尽了自己的一份力，尽管她属于另一个部族（5:24-27）。出示图片 11。

5. 百姓赞美并感谢神的大能。是神降下了雨，使西西拉的战车在路上寸步难行（5:2-5, 21）。

我们对这个故事的回应

请孩子们说说基督徒的庆祝与异教徒的庆祝有什么不同。异教徒的庆祝常常以争吵和打斗收场，因为他们靠啤酒和其他含酒精的饮料让人高兴。然而，基督徒的快乐来自心中的喜乐，是唯有神才能赐予的喜乐。

帮助全班编一首歌，歌颂神赐给他们的胜利或恩赐。

第 12 课：以色列人庆祝并赞美神

经文阅读： 士师记 5:1-31

1. 我是谁？

选择：底波拉、巴拉、雅亿

  • 我们一起向神唱了感谢的歌。我们是谁？ __________ 👉 底波拉和巴拉
  • 虽然我属于另一个部族，我还是受到称赞。我是谁？ __________ 👉 雅亿
  • 我对以色列来说像母亲一样。我是谁？ __________ 👉 底波拉

2. 是还是否？ 是/否

是写“是”，否写“否”：

  • 百姓用诗歌感谢神吗？( ___ ) 👉 是
  • 快乐的基督徒需要打架才能庆祝吗？( ___ ) 👉 否
  • 是神降下雨来帮助以色列的吗？( ___ ) 👉 是

3. 圈出正确的词语

圈出正确的词：

  • 人们在井边 / 学校里传递消息。 👉 井边
  • 他们演奏音乐，跳舞 / 睡觉。 👉 跳舞
  • 这首歌赞美神 / 西西拉。 👉 神
  • 我们的喜乐来自我们的心 / 金钱。 👉 心

4. 讨论题

  • 百姓为什么庆祝？

参考答案：神把他们从仇敌手中拯救出来。

  • 基督徒的聚会有什么不同？

参考答案：喜乐来自神，而不是来自打斗。

  • 我们可以为什么感谢神？

参考答案：我们的家人、食物和祂的爱。

5. 背诵经文：

士师记 5:10-11 ——“在打水之处，有歌唱的声音，要在那里述说耶和华公义的作为，就是祂治理以色列的勇士公义的作为。”

诗篇 118:1 ——“你们要称谢耶和华，因祂本为善；祂的慈爱永远长存！”

6. 给图画涂色：

手工 1：铃鼓

材料： 两个纸盘、订书机、豆子或米

步骤：

  • 把豆子放在两个盘子之间。
  • 把边缘订起来。
  • 用蜡笔装饰。

课程重点： 以色列用音乐赞美神。

手工 2：感谢海报

材料： 纸、蜡笔

步骤：

  • 写上：“神啊，谢谢你赐给我……”
  • 画出三样你感谢的东西。
  • 把它涂上鲜艳的颜色。

课程重点： 我们为神的恩赐献上感谢。

游戏 1：赞美诗歌

玩法：

  • 编一首关于神的恩赐的短歌。
  • 一边拍手，一边一起唱。
  • 给每一句配上一个动作。

课程重点： 我们用诗歌赞美神。

游戏 2：传消息

玩法：

  • 对身边的人小声说一件神所做的好事。
  • 在圈里依次传下去。
  • 最后一个孩子大声说出来。

课程重点： 我们分享神所做的事。
