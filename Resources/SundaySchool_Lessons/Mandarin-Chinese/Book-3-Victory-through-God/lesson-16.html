300 人击败大军

目标

向孩子们说明：我们不是靠自己的努力得救，而是靠神的恩典。

经文阅读

士师记 7:8-22

背诵经文

士师记 7:15

“耶和华已经把米甸的军队交在你们手里了。”

讲授课程

起点

问问全班，他们认为军队上战场需要什么装备。例如：需要训练有素的士兵、枪炮、坦克和弹药，还需要无线电与指挥官保持联络。

课程重点

1. 基甸正率领以色列人对抗米甸的大军。他们的人和骆驼多得无人能数（7:12）。基甸只有 300 人，但他有神的引导（7:8-9）。

2. 神鼓励基甸，吩咐他带着仆人普拉，悄悄下到米甸营地，去听他们谈论以色列人说些什么（7:10-11）。

3. 讲述基甸和普拉怎样去偷听米甸士兵说话。他们发现，米甸人非常害怕基甸和他的一小队士兵，因为他们知道神与他们同在（7:13-15）。

4. 基甸听到这些话，受到了鼓舞，但他给他的 300 名士兵下了一些不寻常的命令，也发给他们不寻常的武器。讲述士兵们怎样被分成三队，每队 100 人。除了一把刀，每个士兵还拿到一支号角和一个里面放着火把的瓶子。大家都要看着基甸，他怎么做，他们就怎么做（7:16-18）。

5. 基甸带领他的士兵来到米甸营地。讲述 7:19-20 发生的事。你讲故事的时候，所有孩子都可以把它演出来。大家可以对着自己的手吹气，模仿号角的声音，再拍手代表瓶子打碎。你可以用一支普通的手电筒来照亮，然后大家一起喊：“为耶和华和基甸争战！”

6. 我们刚才制造了很大的声响，但基甸的 300 人制造的声响更大。这声响使米甸人惊慌混乱，有些人开始自相残杀，其余的人则逃跑了（7:21-22）。出示图片 16。以色列得救了，感谢神。

我们对这个故事的回应

茜茜是亚洲某个小镇上一个贫穷家庭的七岁女孩。她喜欢去一个叫“快乐星期三”的圣经班，那里大约有 70 个孩子。有一天，她到那里时天几乎黑了，聚会早已结束。“对不起，我来晚了，”她说，“到了该来的时候，爸爸把我锁在一个房间里。他不喜欢我来这里。但我喜欢听耶稣的事。我为这件事祷告过了。我该怎么办？”带领人和茜茜一起祷告，然后他们决定，她可以改在别的日子来参加聚会。神帮助一个小女孩胜过了看起来比她强大得多的环境。

第 16 课：300 人击败大军

经文阅读： 士师记 7:8-22

1. 把故事按顺序排好

甲）他们吹响号角，打碎瓶子。
乙）基甸听见敌人很害怕。
丙）敌人逃跑了。
丁）士兵们拿到号角和装着火把的瓶子。

👉 正确顺序：

  • 乙）基甸听见敌人很害怕。
  • 丁）士兵们拿到号角和装着火把的瓶子。
  • 甲）他们吹响号角，打碎瓶子。
  • 丙）敌人逃跑了。

2. 我是谁？

选择：基甸、普拉、米甸人

  • 我与基甸一起去了敌营。我是谁？ __________ 👉 普拉
  • 我们吓得逃跑了。我们是谁？ __________ 👉 米甸人
  • 我对我的人说：“看着我，照我的样子做。”我是谁？ __________ 👉 基甸

3. 是还是否？ 是/否

是写“是”，否写“否”：

  • 基甸的人只带着刀剑吗？( ___ ) 👉 否
  • 神赐给他们胜利了吗？( ___ ) 👉 是
  • 一个叫茜茜的女孩继续信靠神吗？( ___ ) 👉 是

4. 讨论题

  • 瓶子里的火把为什么有帮助？

参考答案：它让敌人以为那里有一支庞大的军队。

  • 是谁拯救了以色列？

参考答案：是神，靠着祂的恩典。

  • 茜茜的爸爸把她锁起来的时候，她做了什么？

参考答案：她祷告，并找到了另一个来的办法。

5. 背诵经文：

士师记 7:15 ——“起来吧！耶和华已经把米甸的军队交在你们手里了。”

罗马书 8:31 ——“神若帮助我们，谁能敌挡我们呢？”

6. 给图画涂色：

手工 1：装着火把的瓶子

材料： 透明杯子、黄色纸、胶水

步骤：

  • 用纸剪出一团黄色的火焰。
  • 把它粘在透明杯子里面。
  • 写上：“神赐下光。”

课程重点： 基甸的人把火把拿在瓶子里。

手工 2：号角图

材料： 纸、蜡笔、胶水

步骤：

  • 画一支号角。
  • 把它涂成金色。
  • 在周围添上音符。

课程重点： 神的计划简单却有能力。

游戏 1：呐喊与发光

玩法：

  • 每个人对着自己的手吹气。
  • 为打碎的瓶子拍手。
  • 一起喊：“为耶和华和基甸争战！”

课程重点： 神赐给基甸胜利。

游戏 2：手电筒抓人

玩法：

  • 一个孩子拿着手电筒。
  • 被光照到的孩子就定住不动。
  • 轮流进行。

课程重点： 神的光指明道路。
