基甸毁坏以色列的偶像

目标

向孩子们说明：神远比任何木头或石头做的偶像伟大。我们敬拜的是永生神，而偶像没有能力，是死的。

经文阅读

士师记 6:25-32；以赛亚书 44:9-20

背诵经文

以赛亚书 44:9

制造偶像的尽都虚空，他们所喜爱的都无益处。

讲授课程

起点

请全班说出一些有能力的东西（例如：汽车，或可以用来发电照明的发电机）。然后请他们说出另一些没有能力的东西（例如：石头或一块木头）。

课程重点

1. 我们的神是一切能力的源头，但以色列人忘了这一点。他们也忘了神为拯救他们、使他们战胜仇敌所行的一切奇事。他们开始敬拜用木头或石头雕成的偶像。这些是迦南各部族的神，他们是邻居，也是以色列的仇敌。

2. 神吩咐基甸毁坏这些偶像和它们的敬拜之处。他要用那些石头为神筑一座坛，用那些木头生火，向神献燔祭（6:25-26）。

3. 基甸非常害怕，就带了十个仆人，在夜里没有人看见的时候做这件事。出示图片 14。基甸想顺从神，却怕别人会说什么（6:27）。

4. 城里的人发现他们的神发生了什么事，就非常生气，正如基甸所担心的。他们想杀死他（6:28-30）。

5. 但是基甸的父亲保护了他。他说：“巴力和亚舍拉”（这些偶像的名字）“若真有什么能力，他们自己会惩罚基甸。”当然，什么事也没有发生，因为巴力和亚舍拉不过是木头和石头做的像。它们不是真实、有生命的神（6:31-32）。

我们对这个故事的回应

大约二十年前，肯尼亚凯里奥山谷的几位基督徒为一架飞机修整跑道。他们必须砍倒树木，搬开大石头。他们希望一支基督徒医疗队能来到这个偏僻的地方，既给人们带来基督的福音，也带来医疗帮助。在这个过程中，这些基督徒毁掉了两座被认为神圣而有能力的大蚁丘。

基督徒们知道这些蚁丘里没有真正的能力，所以他们毫不害怕地把它们拆毁了。今天，那个地区有许多基督教会。

第 14 课：基甸毁坏以色列的偶像

经文阅读： 士师记 6:25-32；以赛亚书 44:9-20

1. 找出不同的一个

圈出没有能力的那一个：

  • 汽车 发电机 木偶像 👉 木偶像
  • 神 巴力 耶稣 （圈出偶像）👉 巴力
  • 石头 君王 石偶像 （圈出活的那一个）👉 君王

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 基甸什么时候拆毁了偶像？
    甲）夜里 乙）中午 丙）早餐时 👉 甲）夜里
  • 谁保护了基甸？
    甲）他的父亲 乙）国王 丙）巴拉 👉 甲）他的父亲

3. 活的还是死的？ 活/死

活的写“活”，死的（没有能力）写“死”：

  • 永生神。( ___ ) 👉 活
  • 木头做的偶像。( ___ ) 👉 死
  • 石头做的偶像。( ___ ) 👉 死

4. 讨论题

  • 基甸为什么感到害怕？

参考答案：他以为人们会对他发怒。

  • 基甸把巴力打碎时，巴力怎么了？

参考答案：什么也没有。它只是木头和石头。

  • 我们可以把什么放在首位，来代替偶像？

参考答案：独有神。

5. 背诵经文：

以赛亚书 44:9 ——“制造偶像的尽都虚空，他们所喜爱的都无益处。”

出埃及记 20:3 — “除我以外，你不可有别的神。”

6. 给图画涂色：

手工 1：“独有神”牌子

材料： 卡纸、蜡笔

步骤：

  • 写上：“独有神。”
  • 在上面画一顶明亮的王冠。
  • 把它挂在你的墙上。

课程重点： 神比任何偶像都伟大。

手工 2：破碎的偶像图

材料： 纸、蜡笔、胶水

步骤：

  • 画一座碎成几块的木像。
  • 把碎片分开粘上。
  • 写上：“偶像没有能力。”

课程重点： 偶像不能帮助我们。

游戏 1：有能力还是没能力？

玩法：

  • 举起各种东西的图片。
  • 孩子们喊“有能力！”或“没能力！”
  • 最后喊：“神有一切的能力！”

课程重点： 只有神有真正的能力。

游戏 2：夜里的勇气

玩法：

  • 每个人小声说一句勇敢的话。
  • 轮流说：“即使我害怕，我也要顺从神。”
  • 一起轻轻地拍手。

课程重点： 我们害怕的时候，神帮助我们顺从。
