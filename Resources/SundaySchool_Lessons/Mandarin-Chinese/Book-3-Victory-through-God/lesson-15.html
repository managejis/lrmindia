神让基甸只挑选少数人

目标

向孩子们说明：我们应当信靠神的能力，而不是自己的力量。

经文阅读

士师记 7:1-7

背诵经文

诗篇 98:1

祂的右手和圣臂施行救恩……

讲授课程

起点

问问全班，他们认为一名士兵应该是什么样的。例如：他必须勇敢、训练有素、机警，并服从指挥官。

课程重点

1. 神呼召基甸率领以色列的士兵去对抗他们的仇敌米甸人的庞大军队（7:1）。神吩咐基甸用一种特别的方式挑选他的士兵。

2. 许多以色列人来加入基甸的军队，但神对基甸说：“你的人太多了。如果他们打败了米甸人，就会以为是靠自己的力量得胜。叫所有害怕的人回家去吧。”于是有 22,000 人回家了（7:2-3）。

3. 神又对基甸说：“人还是太多。你带他们下到河边去喝水，我会指示你该挑选谁去打仗”（7:4）。

4. 基甸带着众人到河边喝水。出示图片 15。他们大多数跪下来，像狗一样喝水。只有 300 个人用手捧着水喝。神吩咐基甸，只带这 300 个士兵，去对抗强大的米甸军队（7:5-7）。

我们对这个故事的回应

神只让基甸带 300 个士兵去对抗所有的米甸人，是要使以色列人看见，他们必须倚靠神的能力，而不是自己的力量。这样，他们就会因神拯救了他们而尊崇神，而不会以为自己没有祂也行。神做工不需要许多人，也不需要强壮的人；祂需要的是愿意并顺服的人。

扎伊尔独立不久，爆发了内战。反叛的士兵，称为辛巴，反对基督教。基督徒们很害怕，以为辛巴会杀死他们。教会领袖约安·阿库德里说：“神在这里做工。我们要向辛巴传福音。他们比我们的人更需要。”约安被捕了，有人向他开了六枪，全都没有打中。后来，约安获释，继续传道。扎伊尔的基督教会非但没有消失，反而不断增长。

第 15 课：神让基甸只挑选少数人

经文阅读： 士师记 7:1-7

1. 数一数，写下来

写出数字：

  • 有多少人回家了？ __________ 👉 22,000
  • 神留下了多少人？ __________ 👉 300
  • 有多少人用手捧水喝？ __________ 👉 300

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 神为什么只要少数人？
    甲）好让以色列信靠神 乙）祂喜欢小军队 丙）没有粮食 👉 甲）好让以色列信靠神
  • 他们在河边是怎样喝水的？
    甲）只用杯子 乙）有些人跪下，300 人用手捧水 丙）他们没有喝水 👉 乙）有些人跪下，300 人用手捧水

3. 对还是错？ 对/错

对的写“对”，错的写“错”：

  • 说：“这都是我自己做的！”( ___ ) 👉 错
  • 说：“是神帮助了我。”( ___ ) 👉 对
  • 愿意并且顺服。( ___ ) 👉 对

4. 讨论题

  • 神为什么叫这么多人回家？

参考答案：好让以色列人不能夸口。

  • 神做工需要什么？

参考答案：愿意并且顺服的人。

  • 约安害怕的时候，是什么帮助了他？

参考答案：他信靠神保护他。

5. 背诵经文：

诗篇 98:1 ——“你们要向耶和华唱新歌，因为祂行过奇妙的事；祂的右手和圣臂施行救恩。”

撒迦利亚书 4:6 ——“不是倚靠势力，不是倚靠才能，乃是倚靠我的灵方能成事，这是耶和华说的。”

6. 给图画涂色：

手工 1：300 名士兵图

材料： 纸、蜡笔

步骤：

  • 画许多小士兵。
  • 把大部分划掉。
  • 只留下几个，并写上：“神的方法。”

课程重点： 神用少数人显明祂的能力。

手工 2：水杯提醒

材料： 纸杯、蜡笔

步骤：

  • 装饰一个纸杯。
  • 写上：“信靠神的能力。”
  • 把它留作提醒。

课程重点： 神根据他们喝水的方式挑选人。

游戏 1：挑选少数人

玩法：

  • 让许多孩子排成一队。
  • 通过问一个简单的问题，让大部分孩子“回家”。
  • 留下一小群人来“获胜”。

课程重点： 神不需要许多人也能得胜。

游戏 2：像基甸的人那样喝水

玩法：

  • 假装用手捧水。
  • 喝水时抬头张望。
  • 说：“我为神保持警醒。”

课程重点： 神要我们警醒并顺服。
