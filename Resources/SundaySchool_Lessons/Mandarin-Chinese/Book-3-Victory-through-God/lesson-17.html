大力士参孙

目标

向孩子们说明：神赐给我们所需要的才能，好让我们去做祂要我们做的工作。

经文阅读

士师记 13:1-5, 24-25；14:1-20

背诵经文

士师记 13:24-25

耶和华赐福给他，耶和华的灵开始感动他……

讲授课程

起点

请孩子们描述一个好人是什么样的。他或她的行为如何？可能的回答：勇敢、勤劳、品格坚强。

课程重点

1. 基甸死后，以色列人又一次转离了神。于是神任凭残忍的非利士人统治他们许多年（13:1-5）。有一个叫玛挪亚的以色列人没有孩子。有一天，一位天使告诉玛挪亚的妻子，她将生一个非常特别的儿子，他要拯救以色列脱离非利士人。

2. 他们给儿子起名叫参孙。神的灵使他异常强壮（13:24-25）。他的长头发是一个记号，提醒他：他的力量来自神（13:5）。

3. 参孙长大后，想娶一个非利士女子。这使他的父母很难过，但参孙坚持，他们最后同意了。参孙认为他应该娶一个非利士人，为的是与她的族人争执，借此找到借口，把以色列人从非利士人的统治下解救出来（14:1-4）。

4. 去见那女子的路上，参孙遇见一只狮子。神的能力使参孙异常强壮，他独自杀死了那只狮子，没有任何武器，只用赤手空拳（14:5-6）。出示图片 17。

5. 过了一段时间，参孙在去参加婚礼的路上，发现蜜蜂在死狮子的身体里做了窝。他吃了一些蜜（14:8-9）。

6. 在婚宴上，参孙想起了他一路上看到的事。为了娱乐宾客，他把这件事编成一个谜语。参孙许诺，如果他们能猜出谜底，他就给每人一套新衣服。可是如果他们猜不出来，每个人就都得给他一套新衣服（14:11-14）。

7. 宾客们想不出谜底。他们生气了。“参孙是想骗我们给他买新衣服，”他们说。他们甚至威胁新娘，如果她不帮他们，就要对她不客气（14:15）。讲述他的新妻子怎样从参孙口中套出了谜底（14:16-17）。

8. 宾客们说出正确的谜底时，参孙知道他们一定是从他妻子那里听来的。他非常生气。参孙去了另一座非利士城，杀了三十个人，拿走他们的衣服。他就是这样得到他许诺给宾客的新衣服的（14:18-19）。

我们对这个故事的回应

神给了参孙什么恩赐？是异常强大的力量，他本应该用它来做神的工作。但参孙却用它来自己取乐，并发泄他对非利士人的怒气。这个故事是对我们的警告。神赐给我们才能和恩赐，首先是为了帮助别人，成就祂的旨意。当我们用我们的恩赐来服事神和别人时，它们给我们带来最大的喜乐。

第 17 课：大力士参孙

经文阅读： 士师记 13:1-5, 24-25；14:1-20

1. 完成句子

词语框：头发、灵、强壮

  • 神的____________使参孙强壮。 __________ 👉 灵
  • 参孙的长____________是神给的记号。 __________ 👉 头发
  • 神赐给参孙的恩赐是要他____________。 __________ 👉 强壮

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 谁把一个特别的儿子的事告诉了玛挪亚的妻子？
    甲）一位天使 乙）一位国王 丙）一位邻居 👉 甲）一位天使
  • 参孙在路上遇见了什么？
    甲）一只狮子 乙）一头熊 丙）一只骆驼 👉 甲）一只狮子

3. 为神还是为自己？ 神/己

为神和别人写“神”，只为自己写“己”：

  • 用我的才能帮助别人。( ___ ) 👉 神
  • 炫耀，让自己觉得骄傲。( ___ ) 👉 己
  • 在教会里为神歌唱。( ___ ) 👉 神

4. 讨论题

  • 神为什么赐给参孙力量？

参考答案：为了帮助拯救以色列。

  • 参孙是怎样错误地使用他的恩赐的？

参考答案：他用它来自己取乐和发怒。

  • 神赐给你什么恩赐？

参考答案：我的声音、我的双手或我的善良。

5. 背诵经文：

士师记 13:24-25 ——“孩子长大，耶和华赐福给他。耶和华的灵开始感动他。”

彼得前书 4:10 — “各人要照所得的恩赐彼此服事。”

6. 给图画涂色：

手工 1：狮子面具

材料： 纸盘、黄色毛线或纸、蜡笔

步骤：

  • 在盘子上画一张狮子的脸。
  • 粘上黄色纸条当作鬃毛。
  • 剪出眼洞。

课程重点： 神赐给参孙力量。

手工 2：我的恩赐徽章

材料： 卡纸、蜡笔、细绳

步骤：

  • 画出你擅长的事。
  • 写上：“神赐给我这个恩赐。”
  • 用细绳把它挂起来。

课程重点： 我们用我们的恩赐服事别人。

游戏 1：强壮的帮手

玩法：

  • 孩子们说出自己拥有的一项恩赐。
  • 他们演示怎样友善地使用它。
  • 为每个人欢呼。

课程重点： 我们用我们的恩赐服事神。

游戏 2：猜谜时间

玩法：

  • 讲一个简单的谜语。
  • 孩子们猜谜底。
  • 谈谈参孙的谜语怎样以愤怒收场。

课程重点： 我们应当明智而友善地玩乐。
