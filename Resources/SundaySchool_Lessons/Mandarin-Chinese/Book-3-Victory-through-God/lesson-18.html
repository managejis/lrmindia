参孙与燃烧的狐狸

目标

向孩子们说明：我们不可用自己的计划取代神的计划。

经文阅读

士师记 15:1-8

背诵经文

雅各书 1:19

人人都要快快地听，慢慢地说，慢慢地动怒……

讲授课程

起点

课程一开始，先演一出你事先准备好的小短剧。两个孩子都说同一支笔或同一本练习本是自己的。他们都说是自己的。争吵开始了，接着说起了气话，最后打了起来。

课程重点

1. 婚礼本应是欢乐的庆典，但参孙的婚礼以大怒收场，他丢下新娘走了。过了一段时间，参孙回去接她，可是那时她父亲已经把她给了男傧相（15:1-2）。

2. 这使参孙非常愤怒，他对非利士人进行了可怕的报复。他抓了 300 只狐狸，把它们尾巴对尾巴两只两只地绑在一起。然后他在尾巴上绑上燃烧的火把，把狐狸放进非利士人的田里。他们所有的庄稼都被烧光了（15:3-5）。出示图片 18。

3. 这时轮到非利士人大怒了。他们向参孙的妻子和她的父亲报了仇，但参孙回来，杀了更多的非利士人，向他们报复（15:6-8）。

我们对这个故事的回应

这个故事讲的是愤怒和报复。报复解决问题了吗？没有。事实上，它使问题和暴力更加严重。回到开头的短剧。打架解决了那本书或那支笔是谁的这个问题吗？没有，它只会制造更多的问题。愤怒不会带来明智的决定。我们需要求神帮助我们控制怒气，转而聆听祂的声音。背诵经文告诉我们该怎么做。

第 18 课：参孙与燃烧的狐狸

经文阅读： 士师记 15:1-8

1. 对还是错？ 对/错

对的写“对”，错的写“错”：

  • 生气并报复。( ___ ) 👉 错
  • 先听后说。( ___ ) 👉 对
  • 求神帮助我保持冷静。( ___ ) 👉 对

2. 圈出正确的词语

圈出正确的词：

  • 报复使问题变好 / 变坏。 👉 变坏
  • 我们应当快快地听 / 喊叫。 👉 听
  • 愤怒会 / 不会带来明智的选择。 👉 不会

3. 按顺序排列这个故事

甲）参孙非常愤怒。
乙）参孙回去接他的新娘。
丙）问题越来越大。
丁）她父亲已经把她给了别人。

👉 正确顺序：

  • 乙）参孙回去接他的新娘。
  • 丁）她父亲已经把她给了别人。
  • 甲）参孙非常愤怒。
  • 丙）问题越来越大。

4. 讨论题

  • 为那支笔打架解决问题了吗？

参考答案：没有。它使事情更糟。

  • 我们感到生气时可以怎么做？

参考答案：停下来，祷告，平静地交谈。

  • 这节经文教导我们怎么做？

参考答案：先听，慢慢地说，也慢慢地动怒。

5. 背诵经文：

雅各书 1:19 ——“我亲爱的弟兄们，这是你们所知道的。但人人都要快快地听，慢慢地说，慢慢地动怒。”

箴言 15:1 ——“回答柔和，使怒消退；言语暴戾，触动怒气。”

6. 给图画涂色：

手工 1：冷静瓶

材料： 塑料瓶、水、闪粉、瓶盖

步骤：

  • 把瓶子装满水。
  • 加入闪粉，盖上瓶盖。
  • 摇一摇，看闪粉慢慢沉下来。

课程重点： 我们可以平静下来，聆听神。

手工 2：耳朵和嘴巴卡

材料： 卡纸、蜡笔

步骤：

  • 画大大的耳朵和小小的嘴巴。
  • 写上：“快快地听。”
  • 把它涂上漂亮的颜色。

课程重点： 我们多听少说。

游戏 1：数到五

玩法：

  • 读一个孩子心里烦躁的故事。
  • 全班慢慢数到五再回答。
  • 谈谈好的选择。

课程重点： 生气时，我们先停下来想一想。

游戏 2：聆听的耳朵

玩法：

  • 对一个孩子小声说一句简短的话。
  • 在圈里小心地传下去。
  • 比较第一句和最后一句。

课程重点： 好好聆听帮助我们避免犯错。
