参孙失去了他异常的力量

目标

向孩子们说明：参孙因为没有把神赐给他的恩赐用在神所定的目的上，就失去了这恩赐。

经文阅读

士师记 16:4-20

背诵经文

箴言 14:16

智慧人惧怕，远离恶事；愚妄人却狂傲自恃。

讲授课程

起点

如果有人一直问你一个你不想回答的问题，你也许会假装没听见，或者干脆走开。如果那人问个没完，你可能会烦得受不了，最后为了让他住口，就把答案告诉他了。

课程重点

1. 大家都在问同一个问题：“参孙那异常的力量是从哪里来的？”参孙爱上了一个名叫大利拉的女人。她也一直问参孙这个问题：“你的大力是从哪里来的？”（16:4, 6）。

2. 大利拉对参孙不忠心。非利士人的首领们答应给她钱，要她探出参孙的秘密，好知道怎样夺去他的力量（16:5）。

3. 大利拉第一次问参孙这个问题时，他告诉她，用七条新的弓弦就能捆住他。大利拉把他捆起来，然后喊叫说：“参孙哪，非利士人来捉你了！”参孙轻易就挣断了弓弦，自由地走了。非利士人很失望（16:6-9）。

4. 用同样的方式继续讲故事，讲述参孙对大利拉的问题所作的接下来两个回答：用新绳子捆绑他（16:10-12），以及把他的头发牢牢地缠在织布机上（织布用的一种沉重的机器；16:13-14）。什么也捆不住参孙；他力量的秘密在别处。

5. 大利拉对参孙的假话越来越恼怒，而参孙对她没完没了的追问也越来越厌烦。为了让她闭嘴，他把真相告诉了她。他的长头发是神所赐力量的记号（16:15-17）。

6. 用你自己的话讲述接下来发生的事。参孙睡在大利拉腿上的时候，有一个人来剪掉了他的头发。出示图片 19。这一次，非利士人来捉他的时候，参孙没能逃脱。他们把他关进了监牢（16:18-20）。

我们对这个故事的回应

参孙没有用神赐给他的力量来荣耀神或做神的工作。假如有人得到一张 100 元的钞票，却把它撕了丢掉，你会非常吃惊，因为本来可以好好利用的礼物被浪费了。这就是参孙对他那异常力量的恩赐所做的事。他把它浪费在自己自私的目的上，而没有好好使用。神看见参孙怎样滥用他的力量，就把它收回了。

参孙没有听从神的声音，而是任凭自己被暴躁的脾气支配。

第 19 课：参孙失去了他异常的力量

经文阅读： 士师记 16:4-20

1. 我是谁？

选择：参孙、大利拉、非利士人

  • 我一直追问参孙的秘密。我是谁？ __________ 👉 大利拉
  • 我们答应给钱，要她找出这个秘密。我们是谁？ __________ 👉 非利士人
  • 为了不再被追问，我说出了真相。我是谁？ __________ 👉 参孙

2. 对还是错？ 对/错

对的写“对”，错的写“错”：

  • 参孙的头发是神所赐恩赐的记号。( ___ ) 👉 对
  • 七条新弓弦可以捆住参孙。( ___ ) 👉 错
  • 参孙滥用他的力量时，神夺去了他的力量。( ___ ) 👉 对

3. 重新排列字

把字重新排成正确的词：

  • 力 能 （神赐给参孙的）__________ 👉 能力
  • 发 头 （他恩赐的记号）__________ 👉 头发
  • 人 愚 （不智慧的人）__________ 👉 愚人

4. 讨论题

  • 浪费恩赐为什么令人难过？

参考答案：一份好的恩赐没有用在它的目的上。

  • 参孙为什么说出他的秘密？

参考答案：他厌烦了一再被追问。

  • 什么能帮助我们明智地选择？

参考答案：聆听神，并敬畏祂。

5. 背诵经文：

箴言 14:16 ——“智慧人惧怕，远离恶事；愚妄人却狂傲自恃。”

诗篇 119:11 — “我将祢的话藏在心里，免得我得罪祢。”

6. 给图画涂色：

手工 1：力量书签

材料： 卡纸条、蜡笔

步骤：

  • 画一条强壮的手臂。
  • 写上：“神赐下力量。”
  • 装饰边缘。

课程重点： 我们的力量来自神。

手工 2：礼物盒图

材料： 纸、丝带、蜡笔

步骤：

  • 画一个系着蝴蝶结的礼物盒。
  • 在里面写上神赐给你的一项恩赐。
  • 把它涂上鲜艳的颜色。

课程重点： 我们好好使用神的恩赐。

游戏 1：好好使用

玩法：

  • 举起一样东西，比如一支铅笔。
  • 孩子们说它应该怎样使用。
  • 谈谈滥用恩赐。

课程重点： 恩赐是要好好使用的。

游戏 2：温和地说不

玩法：

  • 假装一个朋友一直要你做错事。
  • 孩子们练习说一句友善而坚定的“不”。
  • 为勇敢的回答鼓掌。

课程重点： 我们可以对错误的事说不。
