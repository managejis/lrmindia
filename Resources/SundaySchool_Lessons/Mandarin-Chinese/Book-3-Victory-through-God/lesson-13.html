基甸与耶和华的使者

目标

向孩子们说明：神呼召基甸这个年轻而不起眼的人来拯救祂的百姓。

经文阅读

士师记 6:1-23

背诵经文

哥林多后书 12:9

“我的恩典够你用的，因为我的能力是在人的软弱上显得完全。”

讲授课程

起点

和全班谈谈家里不同成员的地位和重要性。人常常因为所处的地位而显得重要。许多人认为长子的地位重要。在有些文化里，年纪最大的人受到最大的尊敬。

课程重点

1. 整个以色列的情况都很糟。百姓已经忘了底波拉教导他们的一切关于神的事。现在又过了几年，他们再次被另一个仇敌，米甸人，征服了；米甸人抢夺他们，让他们的日子非常艰难。用你自己的话说出士师记 6:16。

2. 后来，以色列人转向神，呼求祂的帮助。神的回应是呼召并栽培一位领袖，来拯救他们脱离仇敌。这个年轻人基甸，在神呼召他的时候，正在打麦子（把谷粒从秸秆上打下来）。他是在酒榨里做这件事，而不是在露天的地方，因为他怕仇敌夺走他的收成（6:11）。

3. 忽然，耶和华的使者向基甸显现，对他说：“大能的勇士啊，你去救以色列人脱离你仇敌米甸人的手”（参 6:12-14）。

4. 基甸很惊讶。“我怎么能救以色列呢？我算不得什么。我在自己家里都没有地位，更不用说在整个以色列人的眼中了。”从某种意义上说，基甸是对的。他确实是一个弱小而不起眼的部族里最不重要的成员之一。圣洁的使者回答说，他能做到，因为神会与他同在（6:15-16）。

5. 基甸想确定这个信息真的是出于神，就去预备一份食物作为供物。耶和华对基甸很有耐心，答应等基甸预备好供物（6:17-19）。

6. 基甸把食物献给使者，使者用他手里的杖碰了一下。供物就烧起火来！出示图片 13。然后使者就不见了。基甸不再需要别的证据，就知道这个信息是出于神的（6:20-24）。

我们对这个故事的回应

神常常拣选不重要或软弱的人来做祂的工。当平凡的人倚靠神的能力而不是自己的力量行事时，他们就能做大事。我们可以从非洲教会领袖身上看到这样的例子：

1. 西利瓦努斯·瓦尼靠给人做家仆挣钱，才供得起上小学。神带领他成为乌干达教会的大主教。

2. 安加波扎·埃采阿是个孤儿。神带领他成为扎伊尔非洲内陆教会（CECA）的会长。

3. 彼得·穆阿卢科牧师出身于一个拜偶像的家庭，曾是一名石匠。神带领他成为一名宣教士，到肯尼亚的图尔卡纳人和苏丹的塔波萨人中去。

第 13 课：基甸与耶和华的使者

经文阅读： 士师记 6:1-23

1. 对还是错？ 对/错

对的写“对”，错的写“错”：

  • 基甸正在酒榨里干活。( ___ ) 👉 对
  • 基甸认为自己很重要。( ___ ) 👉 错
  • 使者说：“神必与你同在。”( ___ ) 👉 对

2. 配对

A

B

米甸人

夺走以色列的收成

基甸

藏起他的粮食

天使

称他为勇士

供物

烧起火来

答案：
米甸人 → 夺走以色列的收成
基甸 → 藏起他的粮食
使者 → 称他为勇士
供物 → 烧起火来

3. 完成句子

词语框：软弱、能力、最小

  • 基甸是他家里____________的。 __________ 👉 最小
  • 神的____________在人的软弱上显得完全。 __________ 👉 能力
  • 神常常拣选看起来____________的人。 __________ 👉 软弱

4. 讨论题

  • 基甸为什么藏他的麦子？

参考答案：他怕仇敌偷走它。

  • 神为什么拣选基甸？

参考答案：神能使用信靠祂的平凡人。

  • 即使你很渺小，你也能为神做什么？

参考答案：祷告、帮助别人，并讲说耶稣。

5. 背诵经文：

哥林多后书 12:9 ——“我的恩典够你用的，因为我的能力是在人的软弱上显得完全。”

士师记 6:16 ——“耶和华对他说：‘我与你同在。’”

手工 1：基甸的酒榨

材料： 棕色纸、蜡笔、胶水

步骤：

  • 画一个大大的酒榨坑。
  • 再加上一个正在打麦子的小人。
  • 写上：“神与我同在。”

课程重点： 神发现基甸躲藏着，却称他为勇士。

手工 2：天使使者

材料： 白纸、剪刀、蜡笔

步骤：

  • 剪出一个有翅膀的天使。
  • 给它的脸涂上颜色。
  • 写上：“神与你同在。”

课程重点： 神的使者给了基甸勇气。

游戏 1：最小的被拣选

玩法：

  • 让孩子们按从最矮到最高排队。
  • 挑最矮的孩子来带领拍手。
  • 说：“神使用渺小的人。”

课程重点： 神拣选软弱的人去做大事。

游戏 2：藏粮食

玩法：

  • 把纸做的粮食藏在教室里。
  • 孩子们把它找出来。
  • 说：“我们信靠神保守我们平安。”

课程重点： 我们感到害怕时，神帮助我们。
