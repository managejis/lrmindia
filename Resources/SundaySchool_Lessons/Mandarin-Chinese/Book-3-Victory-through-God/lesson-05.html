艾城之战

目标

向孩子们说明：倚靠自己的力量和智慧而不倚靠神，会带来失败。

经文阅读

约书亚记 7:1-13

背诵经文

箴言 3:5

你要专心仰赖主，不可倚靠自己的聪明……

讲授课程

起点

一个妇人想把一个大水罐顶在头上时，会请别人帮她抬起来。她自己一个人抬到那个位置太重了。如果她硬要自己做，很可能会洒出许多水。

课程重点

1. 约书亚派了一些以色列人去窥探艾城和周围的乡村（7:2）。

2. 这些探子回来向约书亚报告时说，攻取艾城太容易了，只需要派少数士兵去作战就够了（7:3）。他们没有求问神的指示。他们倚靠自己的力量和智慧。

3. 讲述艾城之战发生了什么事。艾城的居民击败了以色列人，他们害怕起来，就逃跑了（7:4-5）。出示图片 5。看，以色列人正被艾城的士兵追赶逃跑！介绍本周的背诵经文。以色列人没有信靠神。他们倚靠的是自己对艾城所探得情况的理解。

4. 约书亚和以色列的其他领袖因这次失败非常难过。他们向神哭诉自己的苦情。这地所有的仇敌现在会怎么看他们呢？他们会嘲笑他们。他们会击败以色列人，还会说以色列的神其实并不强大（7:6-9）。

5. 神对约书亚和以色列百姓感到失望。他们打败仗的原因，是倚靠了自己的力量。他们忘了战胜耶利哥完全是神的功劳，不是他们自己聪明。正因如此，他们才敢不求问神的旨意就去攻打艾城。回到开头的故事：妇人想独自把一个沉重的水罐抬到头上，结果水洒了。

此外，以色列人违背了神的指示，从耶利哥取了一些东西归自己，尽管一切都属于耶和华（7:1, 10-12）。现在不要讲亚干的故事。我们下一课再讲。

6. 约书亚必须告诉以色列人，要预备自己向神认罪，承认他们的悖逆。只有在他们与神的关系得到修复之后，才能击败艾城（7:13）。

牢记背诵经文

我们对这个故事的回应

人喝了脏水就会生病。我们违背神，就会陷在罪里，无法胜过自己的难题。人生最重要的事，就是与神有稳固的关系，这意味着我们必须遵行祂的指示，并信靠祂。

第 5 课：艾城之战

经文阅读： 约书亚记 7:1-13

1. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 约书亚派谁去窥探艾城？
    甲）几个人 乙）摩西 丙）祭司们 👉 甲）几个人
  • 探子们怎样说艾城？
    甲）它太强大了 乙）它很容易，派少数人去就行 丙）我们不可去 👉 乙）它很容易，派少数人去就行
  • 以色列忘了做什么？
    甲）吃饭 乙）求问神 丙）睡觉 👉 乙）求问神

2. 我是谁？

选择：约书亚、艾城、以色列的士兵

  • 我们从艾城的人面前逃跑了。我们是谁？ __________ 👉 以色列的士兵
  • 我是一座打赢了战争的小城。我是谁？ __________ 👉 艾城
  • 战败之后，我向神哭诉。我是谁？ __________ 👉 约书亚

3. 自己的方法还是神的方法？ 己/神

自己的方法写“己”，神的方法写“神”：

  • 不祷告就作决定。( ___ ) 👉 己
  • 做大事之前先求问神。( ___ ) 👉 神
  • 倚靠自己的聪明。( ___ ) 👉 己

4. 讨论题

  • 以色列为什么在艾城失败？

参考答案：他们倚靠自己，没有求问神。

  • 我们只倚靠自己时会发生什么？

参考答案：我们常常失败，就像那个洒了水的妇人。

  • 谁能帮助我们背负沉重的担子？

参考答案：神，祂随时愿意帮助我们。

5. 背诵经文：

箴言 3:5 — “你要专心仰赖主，不可倚靠自己的聪明。”

诗篇 56:3 — “我惧怕的时候要依靠你。”

6. 给图画涂色：

手工 1：水罐图

材料： 棕色纸、蓝色纸、胶水、蜡笔

步骤：

  • 用棕色纸剪出一个罐子的形状。
  • 在里面粘上蓝色纸做的“水”。
  • 写上：“求神帮助。”

课程重点： 有些担子太重，一个人背不动。

手工 2：信靠牌

材料： 卡纸、蜡笔、细绳

步骤：

  • 把卡纸剪成一块牌子。
  • 写上：“要倚靠耶和华。”
  • 用一颗心装饰。
  • 用细绳把它挂起来。

课程重点： 我们倚靠神，不倚靠自己。

游戏 1：太重了

玩法：

  • 把一本很轻的书放在一个孩子的头上。
  • 先让他自己试，再让一个朋友帮忙。
  • 说：“我们需要神的帮助。”

课程重点： 做大事我们需要神的帮助。

游戏 2：先求问

玩法：

  • 给孩子们一些小任务。
  • 每次开始前，他们先说：“主啊，求你帮助我。”
  • 然后再去做这个任务。

课程重点： 我们行动之前先求问神。
