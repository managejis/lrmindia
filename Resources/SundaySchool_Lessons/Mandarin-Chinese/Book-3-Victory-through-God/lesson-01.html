约书亚大战亚玛力人

目标

向孩子们说明：祷告是得胜的道路。

经文阅读

出埃及记 17:8-16

背诵经文

路加福音 18:1

耶稣设一个比喻，是要人……常常祷告，不可灰心。

讲授课程

起点

给全班讲讲你做某件事极其困难的经历。你必须努力很长时间才成功。你可以用一辆发动不起来的车做例子。我把钥匙在点火开关里转了好几次，发动机还是不响。接着我用力踩油门，还是没有用。最后，几个朋友来推车，发动机才发动起来。

如果孩子们不熟悉汽车，可以另举一个例子，比如点煤油炉或挖树桩，就是你遇到过比平常更多困难的事。

课程重点

1. 摩西的工作非常艰难。他要带领从埃及逃出来的以色列人穿过旷野，前往神应许给他们的地方。他们面对许多难题。有许多部落想要消灭以色列人。其中一个部落叫亚玛力人（8 节）。

2. 摩西吩咐他的副手约书亚，挑选一些以色列人出去，与这个凶猛的部落作战（9 节）。

3. 约书亚和他的少数人在作战的时候，摩西为他们祷告（10 节）。如今我们祷告多半是低下头，但摩西是向神伸出双臂。那是他求神帮助的方式。

4. 只要摩西举起双手祷告，以色列人就得胜。可是战事持续了很久，摩西的手臂累了。于是摩西的同伴亚伦和户珥扶着他的手，把它举起来（11-12 节）。

5. 出示图片 1。通过讨论图片并询问图中各人是谁，简要复习这个故事。重点：以色列人战胜了一个强大凶猛的部落，因为他们的力量在于祷告。

牢记背诵经文

我们对这个故事的回应

乔治·穆勒成为基督徒之后，开始每天为他的五位朋友祷告。过了 18 个月，其中一位成了基督徒。乔治感谢神，继续每天为其余四位祷告。五年后，第二位朋友成了基督徒。现在还剩三位。乔治继续祷告，六年后，第三位也归主了。乔治为他天天祷告了将近 13 年！第四位朋友在乔治为他祷告了 34 年之后成为基督徒。第五位，也是最后一位朋友，是在乔治去世之后才归主的。乔治·穆勒从来没有放弃为他的朋友祷告。

第 1 课：约书亚大战亚玛力人

经文阅读： 出埃及记 17:8-16

1. 我是谁？

选择：摩西、约书亚、亚伦和户珥

  • 我带领战士们作战。我是谁？ __________ 👉 约书亚
  • 我向神伸出双臂祷告。我是谁？ __________ 👉 摩西
  • 我们扶住摩西疲累的手臂。我们是谁？ __________ 👉 亚伦和户珥

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 以色列人在与谁作战？
    甲）亚玛力人 乙）埃及人 丙）米甸人 👉 甲）亚玛力人
  • 什么使以色列得胜？
    甲）大刀大剑 乙）祷告 丙）快马 👉 乙）祷告

3. 坚持祷告还是放弃？ 坚/弃

坚持祷告，写“坚”；放弃，写“弃”：

  • 一次又一次地向神求助。( ___ ) 👉 坚
  • 说：“我不做了，太难了。”( ___ ) 👉 弃
  • 朋友帮助我祷告。( ___ ) 👉 坚

4. 讨论题

  • 摩西的手臂为什么会累？

参考答案：他把手举了很长很长时间。

  • 亚伦和户珥是怎样帮助他的？

参考答案：他们扶住他的手，让他可以继续祷告。

  • 谁可以帮助你坚持祷告？

参考答案：我的家人、我的老师和我的基督徒朋友。

5. 背诵经文：

路加福音 18:1 ——“耶稣设一个比喻，是要门徒常常祷告，不可灰心。”

帖撒罗尼迦前书 5:17 ——“要不住地祷告。”

6. 给图画涂色：

手工 1：祷告的双手图

材料： 纸、蜡笔、剪刀、胶水

步骤：

  • 把你的双手描在纸上，剪下来。
  • 像摩西的手一样，把它们向上粘在一张新纸上。
  • 写上：“常常祷告。”

课程重点： 祷告是得胜的道路。

手工 2：祷告提醒书签

材料： 长卡纸条、蜡笔、细绳

步骤：

  • 剪一条长长的卡纸条。
  • 在上面画三只小手。
  • 写上：“不可灰心。”
  • 在顶端系上细绳。

课程重点： 我们不断祷告，不灰心。

游戏 1：举起来！

玩法：

  • 两个孩子尽可能久地举着手臂。
  • 然后两个朋友帮忙把他们的手臂扶稳。
  • 谈谈有人帮助时是多么轻松。

课程重点： 朋友可以帮助我们坚持祷告。

游戏 2：祷告链

玩法：

  • 围坐成一圈。
  • 每个孩子说出一件要祷告的事。
  • 全班一起说：“主啊，求你垂听我们的祷告。”

课程重点： 我们常常祷告，从不灰心。
