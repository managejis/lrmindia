以色列人过约旦河进入迦南

目标

向孩子们说明：神期望我们凭信心踏出一步，好让祂靠着自己的能力帮助我们胜过困难。

经文阅读

约书亚记 3:1-7

背诵经文

希伯来书 11:1

信就是所望之事的实底，是未见之事的确据。

讲授课程

起点

如果你去别人家里，主人端上一种你从没吃过的陌生食物，你只能相信厨师做的是好东西。即使大家都说这食物好吃，你也得自己尝一尝才能确定。如果你嘴上说相信他们，却不肯把食物放进嘴里，你就无法确定它的味道好不好。这件事谁也不能替你做。

课程重点

1. 自从摩西派十二个探子进入应许之地，已经过了四十年。这时摩西已经去世。约书亚是新的领袖，他带领百姓来到应许之地的边界，就是约旦河（3:1）。

2. 所有的以色列人要怎样过河呢？河水正泛滥，水流湍急，又没有桥。他们带着许多孩子和牲畜。这是个大难题。神告诉约书亚，他们要怎样胜过这个巨大的难题（3:7）。

3. 以色列的祭司有一个特别的木柜，叫作约柜，或耶和华的柜。里面放着神赐给摩西的、刻有生活准则的石版（出 25:20-21）。祭司必须把约柜抬进河里。他们的脚一碰到水边，耶和华就要为他们开出一条路来，让他们过去（3:9-13）。

4. 虽然河水正涨满，祭司们还是必须踏进水里。他们不能只站在河岸上；他们必须凭信心踏出一步，水才会停止流动。他们遵行了神的指示之后，拦阻才从他们面前挪开。请描述所发生的事（3:14-17）。

5. 出示图片 3。祭司们站在约旦河中间，抬着约柜。穿黄色衣服的是约书亚，他站在河边，所有的百姓都平安地过河。

我们对这个故事的回应

给全班举一些我们可能需要凭信心踏出一步的例子。

例如，当你的家搬家时，你很可能要换学校。那时你需要相信神会赐给你新的好朋友，也相信新老师在你不懂学校里的事情时会对你和善。

第 3 课：以色列人过约旦河进入迦南

经文阅读： 约书亚记 3:1-7

1. 完成句子

词语框：约柜、约旦河、约书亚

  • 以色列的新领袖是____________。 __________ 👉 约书亚
  • 他们必须渡过的河是____________。 __________ 👉 约旦河
  • 祭司们抬着____________。 __________ 👉 约柜

2. 配对

A

B

河

涨满泛滥

祭司们

踏进水里

河水

停止流动

百姓

在干地上走过

答案：
河 → 涨满泛滥
祭司们 → 踏进水里
河水 → 停止流动
百姓 → 在干地上走过

3. 是还是否？ 是/否

是写“是”，否写“否”：

  • 祭司们先踏进水里吗？( ___ ) 👉 是
  • 水在他们踏进去之前就停了吗？( ___ ) 👉 否
  • 神帮助祂的百姓过河了吗？( ___ ) 👉 是

4. 讨论题

  • 为什么过河是个难题？

参考答案：河水泛滥，又没有桥。

  • 祭司们必须先做什么？

参考答案：凭信心踏进水里。

  • 我们什么时候可能需要凭信心踏出一步？

参考答案：当我们转学或结交新朋友的时候。

5. 背诵经文：

希伯来书 11:1 ——“信就是所望之事的实底，是未见之事的确据。”

哥林多后书 5:7 ——“因为我们行事为人是凭着信心，不是凭着眼见。”

6. 给图画涂色：

手工 1：过河图

材料： 蓝色纸条、棕色纸、胶水

步骤：

  • 把蓝色纸条横着粘在一张纸上，当作河。
  • 在中间留出一条棕色的路。
  • 在路上画出走过的人。

课程重点： 他们顺服的时候，神就开了一条路。

手工 2：约柜模型

材料： 小盒子、金色纸、胶水

步骤：

  • 用金色纸把盒子包起来。
  • 在顶上加上两个纸做的天使。
  • 写上：“神与我们同在。”

课程重点： 约柜表明神与祂的百姓同在。

游戏 1：踏脚石

玩法：

  • 把纸做的“石头”摆在地板上。
  • 每个孩子从一块石头踏到另一块石头。
  • 每踏一块石头就说：“我信靠神。”

课程重点： 我们凭信心踏出一步。

游戏 2：信任之行

玩法：

  • 两人一组，并排站着。
  • 一个孩子慢慢走，同伴用语言轻轻地引导。
  • 交换角色，然后谈谈信任帮助者的感受。

课程重点： 我们信靠神带领我们。
