耶稣从死里复活

目标

向孩子们说明：耶稣胜过了死亡，今天是活着的。

经文阅读

马太福音 28:16-20

背诵经文

以弗所书 1:22

又将万有服在祂的脚下，使祂为教会作万有之首……

讲授课程

起点

问问全班，我们怎样称呼一个部落、一个省、一个国家的领导人。他们不需要说出这些人的真名，只需要说出他们的职位（例如：酋长、省长、总统）。

课程重点

1. 神已经立耶稣为教会的头。背诵经文。神为什么这样做呢？今天的图片会帮助我们明白。

2. 出示图片 23。图中耶稣正在耶路撒冷城外的一座山上对祂的门徒说话。指出图中的耶路撒冷。耶稣虽然没有做错任何事，却被判处死刑。祂被钉死在两个罪犯中间的十字架上。指出图中的十字架。神的儿子耶稣，任凭自己被处死（太 27:33-44）。

3. 但是死亡拘禁不住永生神的儿子。耶稣从死里复活了。祂战胜了死亡。祂永远不会再死。指出图中空坟墓和旁边那块大石头。

4. 耶稣把祂的门徒召集在一起，对他们说：“天上地下所有的权柄都赐给我了。”祂吩咐祂的门徒出去，把活着的耶稣基督告诉万人，好叫他们也跟随祂、敬拜祂。耶稣应许要常与他们同在。祂应许他们胜过罪恶和邪恶的势力。耶稣的这些话也是对我们说的！

我们对这个故事的回应

扎伊尔成为独立国家之前，殖民政府的一些成员试图限制基督新教的传播。约安·阿库德里在那个时期是一位有才干、很有名气的教会领袖。政府逮捕了他，好把他调到别的地方去，让他给他们少添些麻烦。“这对我没什么，”约安对他们说，“这福音不只是给卡夸人的，而是给我们全国各地的人的！”处理这个案子的政府官员被约安的见证深深打动，就把他释放了。

取自 《阿库德里》 作者：彼得·布拉施勒

第 23 课：耶稣从死里复活

经文阅读： 马太福音 28:16-20

1. 我是谁？

选择：耶稣、门徒、石头

  • 我从坟墓口滚开了。我是谁？ __________ 👉 石头
  • 我从死里复活了。我是谁？ __________ 👉 耶稣
  • 有人吩咐我们去告诉所有的人。我们是谁？ __________ 👉 门徒

2. 对还是错？ 对/错

对的写“对”，错的写“错”：

  • 耶稣今天是活着的。( ___ ) 👉 对
  • 死亡可以永远拘禁耶稣。( ___ ) 👉 错
  • 耶稣应许要常与我们同在。( ___ ) 👉 对

3. 连线配对

A

B

十字架

耶稣死的地方

空坟墓

耶稣是活的

门徒

奉命去分享这个消息

教会

耶稣是它的头

答案：
十字架 → 耶稣死的地方
空坟墓 → 耶稣是活的
门徒 → 奉命去分享这个消息
教会 → 耶稣是它的头

4. 讨论题

  • 空坟墓告诉我们什么？

参考答案：耶稣复活了，战胜了死亡。

  • 谁是教会的头？

参考答案：耶稣基督。

  • 耶稣吩咐祂的跟随者做什么？

参考答案：去把祂的事告诉所有的人。

5. 背诵经文：

以弗所书 1:22 ——“又将万有服在祂的脚下，使祂为教会作万有之首。”

马太福音 28:20 ——“我就常与你们同在，直到世界的末了。”

6. 给图画涂色：

手工 1：空坟墓场景

材料： 灰色纸、棕色纸、胶水

步骤：

  • 用棕色纸剪出一座坟墓。
  • 在旁边粘上一块灰色的石头。
  • 写上：“祂复活了。”

课程重点： 耶稣是活的。

手工 2：复活节十字架

材料： 两根手工小棍、胶水、花

步骤：

  • 把小棍粘成一个十字架。
  • 加上纸做的花。
  • 写上：“耶稣是活的。”

课程重点： 耶稣胜过了死亡。

游戏 1：祂是活的！

玩法：

  • 孩子们蹲下去。
  • 你说“耶稣是活的！”时，他们跳起来欢呼。
  • 重复几次。

课程重点： 耶稣是活的。

游戏 2：去告诉人

玩法：

  • 给每个孩子一张信息卡。
  • 他们走到一位朋友面前说：“耶稣是活的。”
  • 交换卡片。

课程重点： 我们把耶稣的事告诉别人。
