耶稣进入耶路撒冷

目标

向孩子们说明：万王之王耶稣怎样进入耶路撒冷。我们可以期待祂的国有一天降临在地上。

经文阅读

马太福音 21:1-11；以赛亚书 11:1-9

背诵经文

诗篇 1:6

……因为耶和华知道义人的道路……

讲授课程

起点

家庭很重要。我们很快就认识自己家里的成员。随着长大，我们也会听到家族的历史和祖先从前住在哪里。

课程重点

1. 大卫是以色列最伟大的王。神告诉他，只要他的子孙忠心作神的仆人，他的家就会继续统治以色列（历代志上 28:7）。

2. 大卫死后大约一千年，一位名叫马利亚的年轻女子生了一个婴孩。她的丈夫约瑟是大卫王的后裔。神拣选了大卫的家，作为祂自己的儿子——万王之王耶稣基督——的人间家庭。

3. 耶稣在地上的日子，教导祂的门徒关于神的国（马太福音称之为天国）。许多人期待耶稣在耶路撒冷作王，像大卫一样统治全以色列，并赶走统治他们的所有外邦人。

4. 有一天，耶稣进入耶路撒冷，受到百姓的欢迎，但祂骑的是一头驴。伟大的世上君王骑骆驼或马。驴是用来驮货物的，不是用来载重要人物的。今天，国家总统和重要的领袖坐的是大而气派的汽车，而不是廉价的小车或自行车！耶稣是有史以来侍奉神的最伟大的一位，但祂却是谦卑的。祂不用财物来显示祂的权能。祂差两个门徒去牵一头驴来，好让祂骑进城（马太福音 21:1-2）。

5. 门徒受吩咐，如果有人问他们在做什么，就说这驴是他们的主要用的。这些事要应验神的先知许多年前所预言的（21:3-6）。

6. 群众聚集起来迎接耶稣，喊着说：“和散那归于大卫的子孙！奉主名来的是应当称颂的！赞美神！”（21:7-11）。

出示图片 20。

孩子们可以把故事的这一部分演出来——有的挥动树枝，有的把衣服铺在地上让驴走过。大家可以唱一首赞美的歌，欢迎地上万王之王。

我们对这个故事的回应

耶路撒冷的百姓并不真正明白耶稣所说的国。祂要我们成为祂国度的一分子，成为祂家里的人，作神的儿女（约翰福音 1:12）。

有一天，耶稣要作为全地的王再来。祂要建立一个和平的国（以赛亚书 11:1-9）。只有属于神家的人，才能在那美好的国度里有一席之地。

第 20 课：耶稣进入耶路撒冷

经文阅读： 马太福音 21:1-11；以赛亚书 11:1-9

1. 连线配对

A

B

驴

把耶稣驮进城

棕树枝

被群众挥动

和散那

赞美的呼喊

耶稣

万王之王

答案：
驴 → 把耶稣驮进城
棕树枝 → 被群众挥动
和散那 → 赞美的呼喊
耶稣 → 万王之王

2. 对或错

对的写“对”，错的写“错”：

  • 耶稣骑的是马。( ___ ) 👉 错
  • 百姓赞美耶稣。( ___ ) 👉 对
  • 耶稣出自大卫的家。( ___ ) 👉 对
  • 耶稣表明了祂是谦卑的。( ___ ) 👉 对

3. 圈出正确的词语

圈出正确的选择：

  • 耶稣是（众王 / 驴子）之王。 👉 众王
  • 耶稣进入了（耶路撒冷 / 摩押）城。 👉 耶路撒冷
  • 耶稣要建立一个（和平 / 战争）的国。 👉 和平

4. 讨论题

  • 耶稣为什么骑驴？

参考答案：祂是谦卑的，是带着和平而来的。

  • 群众喊了什么？

参考答案：和散那归于大卫的子孙！

  • 今天我们怎样欢迎耶稣？

参考答案：赞美祂并顺服祂。

5. 背诵经文：

诗篇 1:6 ——“因为耶和华知道义人的道路；恶人的道路却必灭亡。”

马太福音 21:9 ——“和散那归于大卫的子孙！”

手工 1：棕树枝

材料： 绿色纸、胶带、小棍

步骤：

  • 用绿色纸剪出一片长长的叶子形状。
  • 沿着两边剪出细缝。
  • 用胶带把它粘在小棍上。
  • 为耶稣挥动它。

课程重点： 群众挥动树枝，欢迎他们的王。

手工 2：驴子手偶

材料： 纸袋、灰色纸、胶水、蜡笔

步骤：

  • 用灰色纸剪出驴的耳朵。
  • 把耳朵粘在纸袋上。
  • 画上眼睛和鼻子。
  • 用它来讲这个故事。

课程重点： 耶稣作为谦卑的王，骑着驴子。

游戏 1：欢迎游行

玩法：

  • 孩子们挥动纸做的树枝。
  • 一个孩子像驴一样走路。
  • 大家一起唱“和散那！”

课程重点： 我们喜乐地欢迎耶稣。

游戏 2：王还是仆人？

玩法：

  • 说一句关于耶稣的话。
  • 如果这句话显出谦卑，孩子们就站起来。
  • 谈谈耶稣为什么既是王又是仆人。

课程重点： 耶稣是谦卑的王。
