哈拿向神祷告

目标

向孩子们说明：哈拿在没有人理解她的烦恼和悲伤时，怎样在祷告中得到安慰。

经文阅读

撒母耳记上 1:1-20

背诵经文

诗篇 121:7

耶和华要保护你，免受一切的灾害；祂要保护你的性命……

讲授课程

起点

请全班说出一些使夫妻在家庭生活中不快乐的事。建议：有时钱不够用，或者因酗酒而引起问题，或者夫妻不能生育孩子。

课程重点

1. 有一个叫哈拿的女人，非常爱她的丈夫以利加拿。他也爱她。然而，哈拿因为没有孩子而不快乐。这使她非常痛苦（1:1-2, 5）。

2. 以利加拿的第二个妻子毗尼拿，惹哈拿烦恼，使她痛苦。她为哈拿没有孩子这件事过分地讥讽她，使哈拿吃不下饭（1:6-7）。

3. 每年，这一家人都要到示罗的神殿去敬拜。他们带着牲畜作祭物献给神。哈拿总觉得这个时候最难熬。因为神没有赐给她孩子，她献给神的祭物比毗尼拿的少（1:3-4, 8）。

4. 有一年，哈拿非常难过，就离开了家人的宴席，到圣殿去，在祷告中向神倾诉她的悲伤。哈拿接着向神许了一个愿：如果祂赐给她一个儿子，她就把他献给神（1:9-11）。

5. 大祭司以利看着哈拿祷告。出示图片 7。她痛哭流涕，嘴唇不停地动，迫切地祷告，但因为以利听不到她的话，就以为她喝醉了。他很生气，因为她以这样不体面的状态来到耶和华的殿。以利犯了多么令人难过的错误啊（1:12-14）！

6. 哈拿纠正了他这个可怕的误会，以利就为她祝福（1:15-17）。

7. 神垂听了哈拿的祷告，赐给她一个儿子。她给他起名叫撒母耳，意思是“神听见”，因为哈拿曾向耶和华求这个儿子（1:19-20）。

我们对这个故事的回应

哈拿是神的又一位仆人，给我们留下了一个值得效法的好榜样。当她痛苦、没有人理解或能帮助她的时候，她向神倾诉她的烦恼（1:15）。神总是在那里垂听我们。

哈拿祷告之后，心里平安了。她不再悲伤，又能吃饭了（1:18）。我们应当像哈拿那样做，在信靠耶和华中得到安慰。

牢记背诵经文

神在哈拿遭遇困难的时候安慰了她。

复习孩子们到目前为止学过的诗篇 121 篇的经文。

第 7 课：哈拿向神祷告

经文阅读： 撒母耳记上 1:1-20

1. 我是谁？

选择：哈拿、以利、撒母耳

  • 我在神的殿里恳切祷告。我是谁？ __________ 👉 哈拿
  • 我是为哈拿祝福的祭司。我是谁？ __________ 👉 以利
  • 我的名字的意思是“神听见”。我是谁？ __________ 👉 撒母耳

2. 祷告还是忧虑？ 祷/忧

祷告写“祷”，忧虑写“忧”：

  • 难过的时候告诉神。( ___ ) 👉 祷
  • 哭泣，却不告诉任何人。( ___ ) 👉 忧
  • 感谢神垂听。( ___ ) 👉 祷

3. 缺少的字

填上缺少的字：

  • 哈拿去了神的圣 _ 。 __________ 👉 殿
  • 她向神作出了承 _ 。 __________ 👉 诺
  • 神赐给她一个儿 _ 。 __________ 👉 子

4. 讨论题

  • 哈拿为什么难过？

参考答案：她没有孩子，又有人对她不友善。

  • 哈拿怎样处理她的悲伤？

参考答案：她在祷告中向神倾诉。

  • 你今天可以告诉神什么？

参考答案：答案各不相同。

5. 背诵经文：

诗篇 121:7 ——“耶和华要保护你，免受一切的灾害；祂要保护你的性命。”

彼得前书 5:7 ——“你们要将一切的忧虑卸给神，因为祂顾念你们。”

手工 1：祷告的双手

材料： 纸、铅笔、蜡笔、剪刀

步骤：

  • 把你的双手描下来。
  • 把它们剪下来。
  • 把它们像祷告的手一样合拢折起。
  • 写上：“神垂听我。”

课程重点： 我们祷告时，神垂听。

手工 2：祷告罐

材料： 纸杯、纸条、蜡笔

步骤：

  • 装饰纸杯。
  • 在一张纸条上写下一件要祷告的事。
  • 把它折起来，放进杯子里。
  • 每天为它祷告。

课程重点： 我们可以把一切告诉神。

游戏 1：悄悄的祷告

玩法：

  • 大家安静地坐着。
  • 每个孩子悄悄对神说一件事。
  • 最后一起说“阿们”。

课程重点： 神连安静的祷告也垂听。

游戏 2：聆听的耳朵

玩法：

  • 一位带领人小声说一个词。
  • 孩子们重复他们听到的。
  • 谈谈以利没有听到哈拿的话，但神听到了。

课程重点： 即使人们误解我们，神也垂听。
