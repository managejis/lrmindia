大卫与巨人歌利亚

目标

向孩子们说明：在似乎不可能的时候，神怎样帮助祂的仆人大卫击败了一个巨人。

经文阅读

撒母耳记上 17:1-54

背诵经文

诗篇 1:3

他要像一棵树栽在溪水旁……

讲授课程

起点

你们知道，不同的人长到不同的高度。有些人长得很高，有些人仍然很矮。给我比一比你见过的最高的人有多高。给全班看一根玉米秆或一根大约三米长的棍子。你们见过有这么高的人吗？

课程重点

1. 歌利亚和这根棍子一样高，当然，还要宽得多。他是个巨人。他属于非利士人的部落，当时他们正与以色列交战。每天他都向以色列人挑战，要他们来与他打。但所有的士兵都怕他怕得要命（17:1-11）。

2. 讲述大卫的父亲怎样派他去军营探望他的哥哥们，给他们带些食物。大卫听见了歌利亚向以色列和他们的神发出的挑战，也看见扫罗王的人是多么害怕。他不明白，他们为什么这么怕这个不认识永生神的人。他知道，即使是庞大的巨人，在神的能力面前也毫无力量（17:17-25）。

3. 大卫的大哥想叫他住口。最后扫罗王听说这个年轻人愿意去与巨人作战，就派人把大卫叫来。扫罗认为大卫对歌利亚没有任何胜算，因为歌利亚是个身经百战的勇士。但大卫告诉王，他信靠神。再次出示图片 13。神怎样帮助他保护自己的羊不受野兽的伤害，神也要怎样帮助他保护自己的子民不受那个巨人的伤害（17:26-37）。

4. 扫罗把自己的盔甲给大卫穿上保护他，但它太大太重了。于是大卫只是走到溪边，为他的甩石器挑选了五块石头（17:38-40）。

5. 出示图片 14。看看歌利亚和大卫的不同——在身材、盔甲和武器方面。最重要的是，歌利亚是在与永生神作战，而大卫是祂的仆人（17:45）。

6. 歌利亚看到以色列只派一个年轻人来与他作战，而且没有盔甲，也没有像样的武器，非常生气！大卫告诉歌利亚，他是永生、得胜之神的仆人（17:41-47）。

7. 告诉全班，大卫怎样用他甩石器里的一块石头战胜了歌利亚。非利士人看到巨人死了，就逃跑了。以色列人赢得了这场战争，大卫保留了歌利亚的剑（17:48-54）。

我们对这个故事的回应

我们常常害怕那些看起来很大或很有力量的东西。歌利亚没有使大卫害怕，尽管他身材高大，看起来那么有力量。大卫靠着神的能力行事，战胜了歌利亚。神也已经把同样的能力赐给我们，祂的仆人，让我们胜过邪恶的攻击和试探（林前 10:13）。

复习孩子们到目前为止学过的诗篇 1 篇的经文。

第 14 课：大卫与巨人歌利亚

经文阅读： 撒母耳记上 17:1-54

1. 连线配对

A

B

歌利亚

一个庞大的非利士巨人

大卫

信靠永生神

五块石头

被捡起来放进甩石器

扫罗的盔甲

太大太重

答案：
歌利亚 → 一个庞大的非利士巨人
大卫 → 信靠永生神
五块石头 → 被捡起来放进甩石器
扫罗的盔甲 → 太大太重

2. 勇敢还是害怕？ 勇/怕

勇敢地信靠写“勇”，害怕写“怕”：

  • 事情看起来太大的时候，信靠神。( ___ ) 👉 勇
  • 因为害怕而躲起来。( ___ ) 👉 怕
  • 说：“神会帮助我。”( ___ ) 👉 勇

3. 完成句子

词语框：神、石头、巨人

  • 歌利亚是一个庞大的____________。 __________ 👉 巨人
  • 大卫捡起五块光滑的____________。 __________ 👉 石头
  • 大卫得胜，是因为____________帮助他。 __________ 👉 神

4. 讨论题

  • 大卫为什么不怕歌利亚？

参考答案：他信靠神会帮助他。

  • 有哪些大事使我们害怕？

参考答案：答案各不相同。

  • 我们害怕的时候可以做什么？

参考答案：祷告，并信靠神。

5. 背诵经文：

诗篇 1:3 ——“他要像一棵树栽在溪水旁，按时候结果子，叶子也不枯干。凡他所做的尽都顺利。”

诗篇 56:3 — “我惧怕的时候要依靠你。”

手工 1：五块光滑的石头

材料： 纸、蜡笔、胶水、卡纸

步骤：

  • 用纸剪出五个圆形。
  • 把它们涂成灰色。
  • 在每一块上写一件神帮助你的事。
  • 把它们粘在一张卡纸上。

课程重点： 神帮助我们解决大大小小的难题。

手工 2：大卫的牧羊袋

材料： 纸袋、蜡笔、细绳

步骤：

  • 装饰一个小纸袋。
  • 给它系上一根绳子当提手。
  • 在正面画五块石头。
  • 写上：“神更大。”

课程重点： 大卫信靠神，胜过信靠盔甲或武器。

游戏 1：巨人的步子

玩法：

  • 带领人迈“巨人”的大步。
  • 孩子们向带领人迈“小”步。
  • 他们到达时喊“神更伟大！”

课程重点： 神的能力比任何巨人都大。

游戏 2：推倒塔

玩法：

  • 把纸杯叠成一座高高的“巨人”塔。
  • 孩子们轮流向纸杯投掷一个软纸球。
  • 每次都说“神帮助我”。

课程重点： 大卫依靠神，而不是依靠自己的力量。
