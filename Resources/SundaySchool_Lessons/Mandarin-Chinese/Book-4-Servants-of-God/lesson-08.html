孩童撒母耳在神的殿里

目标

向孩子们说明：即使是年幼的孩子也能事奉神。

经文阅读

撒母耳记上 1:21-28；2:18-20, 26；3:1-21

背诵经文

诗篇 121:8

你出你入，耶和华要保护你，从今时直到永远。

讲授课程

起点

谈谈孩子们怎样在家里帮忙。让全班说说他们在家里是怎样努力帮忙的。小孩子在学会走路之前，就会试着模仿他们的父母。

课程重点

1. 出示图片 7。通过向孩子们简短提问，复习上周关于哈拿的祷告和撒母耳出生的课程。撒母耳这个名字的意思是“神听见”。你们还记得为什么吗？提醒他们哈拿对神所许的愿（1:11）。

2. 撒母耳还是个刚断奶的小男孩时，哈拿就把他带到示罗神殿的大祭司以利那里。她是在履行自己的诺言，把他的一生奉献给神。撒母耳虽然还很年幼，却要在圣殿里协助事奉神（1:24-28）。

3. 每年，哈拿和以利加拿都去看望撒母耳，给他带来新衣服。年幼的撒母耳正学习作神的仆人，他也知道神与他同在。他大概帮助以利保持圣殿的清洁，给灯添油，传递信息，学习唱诗篇和敬拜时用的其他诗歌。他会做今天孩子们在家里做的许多事。人们对年幼的撒母耳评价很好（2:18-20, 26）。

4. 那时，以色列有许多人并不真诚地敬拜神。神不再对以色列人说话，因为他们不肯听（3:1）。然而，撒母耳正在学习做一个不同的人。

5. 有一天晚上，以利那时几乎已经失明，已经睡下了，撒母耳正在圣殿里的约柜前守着灯。这是圣殿里最神圣的地方，因为约柜里面放着神赐给摩西的诫命。约柜也是神同在的象征。忽然，撒母耳听见有声音叫他的名字。用你自己的话讲述第 4 节和第 5 节发生的事（3:1-5）。

6. 讲述神第二次、第三次呼唤撒母耳，以及以利的指示的故事。出示图片 8。如果你把这一幕演出来，轮流扮演每个角色，这就会成为一个非常生动的故事（3:6-10）。

7. 虽然撒母耳只是个孩子，神却有一些非常令人难过又严肃的消息要告诉他。以利的儿子们，他们也是祭司，却不顺服。他们不是神的好仆人。耶和华要审判他们（2:11-15）。

此后，神多次对撒母耳说话。撒母耳成了一位伟大的先知和他百姓的领袖（3:19-21）。

我们对这个故事的回应

撒母耳在很小的时候就开始事奉神——也许比你们中的一些人还小。他做日常的工作，不只是为了让以利喜悦，主要是为了事奉神、尊荣神。他学会了聆听神。他是今天孩子们可以效法的榜样。

牢记背诵经文

复习孩子们到目前为止学过的诗篇 121 篇的经文。

你们注意到了吗？这篇诗篇对我们到目前为止谈到的所有人都是真实的——路得、马利亚、哈拿和撒母耳。

第 8 课：孩童撒母耳在神的殿里

经文阅读： 撒母耳记上 1:21-28；2:18-20, 26；3:1-21

1. 把故事按顺序排好

甲）他跑到以利那里，以利说：“我没有叫你。”
乙）哈拿把撒母耳带到以利那里。
丙）撒母耳说：“主啊，请说。”
丁）撒母耳在夜里听见一个声音。

👉 正确顺序：

  • 哈拿把撒母耳带到以利那里。
  • 撒母耳在夜里听见一个声音。
  • 他跑到以利那里，以利说：“我没有叫你。”
  • 撒母耳说：“主啊，请说。”

2. 是还是否？

是写“是”，否写“否”：

  • 撒母耳开始事奉神的时候是成年人吗？( ___ ) 👉 否
  • 撒母耳在神的殿里帮忙吗？( ___ ) 👉 是
  • 神对撒母耳说话了吗？( ___ ) 👉 是

3. 圈出帮手

圈出正确的选择：

  • 我在家里帮忙的方式是（收拾整齐 / 弄得乱七八糟）。 👉 收拾整齐
  • 我事奉神的方式是（聆听 / 不理）祂。 👉 聆听
  • 我做我的工作是为了（让神喜悦 / 偷懒）。 👉 让神喜悦

4. 讨论题

  • 撒母耳小时候是怎样事奉神的？

参考答案：他保持圣殿清洁，帮助以利，并聆听神。

  • 神呼唤撒母耳多少次，他才明白？

参考答案：三次。

  • 你在家里怎样事奉神？

参考答案：通过帮忙、善待别人和顺从。

5. 背诵经文：

诗篇 121:8 ——“你出你入，耶和华要保护你，从今时直到永远。”

撒母耳记上 3:10 ——“请说，仆人敬听。”

6. 给图画涂色：

手工 1：撒母耳的小灯

材料： 纸杯、黄色纸、胶水

步骤：

  • 装饰纸杯。
  • 用黄色纸剪出一团火焰。
  • 把火焰粘在杯子里面。
  • 写上：“我在这里。”

课程重点： 撒母耳在神的殿里让灯一直亮着。

手工 2：帮忙的手图表

材料： 纸、蜡笔

步骤：

  • 把你的手描下来。
  • 在每个手指上写一件你在家里做的事。
  • 给手涂上颜色。
  • 拿给你的父母看。

课程重点： 即使是孩子，也能借着帮忙事奉神。

游戏 1：谁叫了我？

玩法：

  • 一个孩子闭着眼睛坐着。
  • 另一个孩子轻轻叫他的名字。
  • 他猜是谁叫的。

课程重点： 撒母耳必须仔细聆听，才能听见神。

游戏 2：小帮手

玩法：

  • 把扫地或搬东西之类的工作演出来。
  • 其他孩子猜是什么工作。
  • 每个人说说为什么帮忙是好事。

课程重点： 撒母耳年幼时就在神的殿里帮忙。
