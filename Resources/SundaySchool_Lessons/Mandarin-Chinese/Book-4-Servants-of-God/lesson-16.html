大卫饶了扫罗的命

目标

向孩子们说明：虽然扫罗王一直想杀大卫，大卫却怎样饶了扫罗王的命。

经文阅读

撒母耳记上 26:1-25

背诵经文

诗篇 1:3（完整的第 3 节）

他要像一棵树栽在溪水旁，按时候结果子，叶子也不枯干。凡他所做的尽都顺利。

讲授课程

起点

问问全班，人们对待自己不喜欢的人是怎样的。仇恨会导致争斗和死亡。

课程重点

1. 大卫有一个凶猛的仇敌。他就是扫罗王。出示图片 15。一边指着图片向全班提问，一边简要复习上一课。因为嫉妒大卫，扫罗多次想杀他，所以大卫不得不躲藏起来。如果情况反过来，大卫能把扫罗掌握在手中，他会怎么做呢？

下面的故事告诉我们答案。

2. 有一天，使者来告诉扫罗王大卫藏在哪里。扫罗立刻带上 3,000 名最精锐的士兵（只为抓一个人！），出去捉拿他。但大卫也有探子，他和他的跟随者看着扫罗和他的军队安营扎寨（26:1-5）。

3. 夜里，大卫和他的朋友亚比筛悄悄溜进营地，一直走到扫罗王睡觉的地方。他所有的守卫也都睡着了！大卫的仇敌扫罗终于落在他的手中了。亚比筛劝大卫让他利用这个机会杀死扫罗（26:6-8）。

4. 但大卫阻止了亚比筛杀扫罗。他说，神已经立扫罗作以色列的王，时候一到，神就会除掉扫罗。大卫知道，神的计划和时间是完美的，即使我们并不总是明白神做事的方式。出示图片 16。大卫反而从扫罗头旁边拿走了扫罗的矛和水壶，来证明他曾经到过那里，如果他想杀扫罗，是可以杀的（26:9-12）。

5. 当他们离营地有了安全的距离，大卫向他们喊话。这时他们才醒来。他告诉他们他和亚比筛做了什么。他把矛和水壶举在空中，让他们看看他们是多么差劲的守卫（26:13-16）。

6. 扫罗王也听出了大卫的声音。大卫问扫罗，为什么一直想杀他。扫罗意识到大卫是多么容易就能杀了他，就答应不再想杀大卫。扫罗和他的军队回家去了（26:17-25）。

我们对这个故事的回应

大卫把扫罗掌握在手中时的反应，与亚比筛的非常不同。大卫觉得自己不能杀扫罗王，尽管扫罗多次想杀他。王意识到这一点时，他对大卫的态度就改变了。大卫怎么能够做到这一点呢？他是一个合耶和华心意的人（13:14），神的灵也降在大卫身上（16:13）。

你怎样对待你不喜欢的人，或曾经想要伤害你的人？耶稣吩咐事奉祂的人，要做与世人相反的事：饶恕。许多年后，保罗给年轻的基督徒教会一些关于这件事的有益指示。这些在今天仍然是很好的劝告。给他们读罗马书 12:17-21。

第 16 课：大卫饶了扫罗的命

经文阅读： 撒母耳记上 26:1-25

1. 我是谁？

选择：大卫、亚比筛、扫罗

  • 我选择饶恕，而不是伤害。我是谁？ __________ 👉 大卫
  • 我是追赶大卫的王。我是谁？ __________ 👉 扫罗
  • 我是想要报仇的大卫的朋友。我是谁？ __________ 👉 亚比筛

2. 善良还是粗鲁？ 善/粗

善良写“善”，粗鲁写“粗”：

  • 饶恕对我刻薄的人。( ___ ) 👉 善
  • 以不善回报不善。( ___ ) 👉 粗
  • 为惹我生气的人祷告。( ___ ) 👉 善

3. 对还是错

对的写“对”，错的写“错”：

  • 大卫拿走了扫罗的矛和水壶。( ___ ) 👉 对
  • 大卫想要报仇。( ___ ) 👉 错
  • 扫罗答应不再追赶大卫。( ___ ) 👉 对

4. 讨论题

  • 大卫做了什么，向扫罗表明他是善良的？

参考答案：他饶了扫罗，并把扫罗的矛和水壶给他看。

  • 大卫为什么没有报仇？

参考答案：神拣选了扫罗作王，大卫信靠神的时间。

  • 我们怎样对待不友善的人？

参考答案：用饶恕和善意。

5. 背诵经文：

诗篇 1:3 ——“他要像一棵树栽在溪水旁，按时候结果子，叶子也不枯干。凡他所做的尽都顺利。”

罗马书 12:21 ——“务要以善胜恶。”

6. 给图画涂色：

手工 1：饶恕卡

材料： 对折的卡片、蜡笔

步骤：

  • 在正面画一颗心。
  • 里面写上：“我饶恕你。”
  • 加上小花。
  • 把它送给某个人。

课程重点： 神的仆人像大卫一样饶恕人。

手工 2：水壶

材料： 纸杯、蜡笔

步骤：

  • 把杯子装饰成水壶的样子。
  • 画出波浪形的水纹。
  • 写上：“善待别人。”
  • 把它留作提醒。

课程重点： 大卫选择善良，而不是报仇。

游戏 1：道歉与饶恕

玩法：

  • 两个孩子演一场小小的争吵。
  • 一个说对不起，另一个饶恕。
  • 全班说“神喜悦”。

课程重点： 我们饶恕，是因为神饶恕了我们。

游戏 2：善意的话轮换

玩法：

  • 围坐成一圈。
  • 说一句别人可能会说的不友善的话，比如“我不喜欢你”。
  • 下一个孩子用一句亲切的话来回答。

课程重点： 大卫以善意回应不善。
