以利亚和从天上降下的火

目标

向孩子们说明：以利亚怎样击败了巴力的先知，并显明了永生神的大能。

经文阅读

列王纪上 18:16-46

背诵经文

诗篇 121 篇

复习整篇诗篇。

讲授课程

起点

和全班谈谈比赛和竞赛。在这些活动中，人们参加比赛，要看看谁在某项活动上最出色。你喜欢哪一类比赛？

课程重点

1. 以利亚与巴力的先知比赛。亚哈王命令以色列百姓和巴力的先知到迦密山去见以利亚。他们要比一比，看谁才是真神。是神，还是巴力？（18:20-22）。

2. 以利亚宣布了比赛的规则。巴力的先知，也就是祭司们——一共四百五十人——要预备两头公牛作祭物。以利亚是神唯一的先知，他也同样预备。他们不可在祭物下面点火；相反，他们要祷告，求火从天上降下。那用火回应的，就是真神。大家都同意这些规则（18:22-24）。

3. 巴力的信徒先筑好他们的祭坛。他们整天祷告，但火没有降下。以利亚开始嘲笑他们（18:25-29）。

4. 傍晚，以利亚叫大家来看他。他修复了那已经被拆毁的神的祭坛，并预备好祭物。他甚至叫人把四大桶水倒在祭物上，使它更难燃烧（18:30-35）。

5. 然后，以利亚向神祷告，求祂降下火来，好让百姓知道耶和华是永生的神。出示图片 22。神降下火来，烧尽了一切，连放祭物的石头也烧了。众百姓都喊着说：“耶和华是神！耶和华是神！”那些对百姓说谎的巴力先知，全都被杀了（18:36-40）。

我们对这个故事的回应

以利亚一个人，对抗王和王后、四百五十个巴力的先知，以及不忠心的以色列人。但他侍奉的是永生的神。他知道自己侍奉的是独一的真神，没有别的神。以利亚是我们的榜样，他是一位勇敢的神的仆人，即使孤身一人，也站出来反对邪恶。

今天，有些基督徒蒙神呼召并装备去这样做。让我们为他们，也为我们自己祷告，愿我们持守这真理：我们的神是永生的神。

牢记背诵经文

以利亚在他的生命中经历了诗篇 121 篇和诗篇 1 篇的真理。

第 22 课：以利亚和从天上降下的火

经文阅读： 列王纪上 18:16-46

1. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 比赛在哪里举行？
    甲）迦密山 乙）耶路撒冷 丙）摩押 👉 甲）迦密山
  • 谁用火回应？
    甲）巴力 乙）永生神 丙）亚哈 👉 乙）永生神
  • 谁独自为神站立？
    甲）以利亚 乙）俄备得 丙）约拿单 👉 甲）以利亚

2. 对或错

对的写“对”，错的写“错”：

  • 巴力从天上降下火。( ___ ) 👉 错
  • 以利亚信靠永生的神。( ___ ) 👉 对
  • 百姓说：“耶和华，祂是神！”( ___ ) 👉 对

3. 勇敢还是害怕？ 勇/怕

勇敢写“勇”，害怕写“怕”：

  • 为正义挺身而出。( ___ ) 👉 勇
  • 别人做错事时保持沉默。( ___ ) 👉 怕
  • 把神告诉朋友。( ___ ) 👉 勇

4. 讨论题

  • 以利亚求神做什么？

参考答案：求祂降下火来，好让每个人都知道祂是神。

  • 百姓学到了什么？

参考答案：耶和华是真实而永生的神。

  • 我们怎样才能为神勇敢？

参考答案：借着祷告和说出真理。

5. 背诵经文：

诗篇 121:1-2 ——“我要向山举目；我的帮助从何而来？我的帮助从造天地的耶和华而来。”

列王纪上 18:39 ——“耶和华，祂是神！”

6. 给图画涂色：

手工 1：山和火焰

材料： 纸、橙色和红色的纸、胶水

步骤：

  • 画一座山。
  • 用橙色和红色的纸剪出火焰。
  • 把火焰粘在祭坛上。
  • 写上：“耶和华是神。”

课程重点： 神垂听了以利亚的祷告。

手工 2：昂首站立的旗子

材料： 纸条、蜡笔

步骤：

  • 写上：“耶和华，祂是神！”
  • 用星星装饰。
  • 把底部折起来，让它立住。
  • 拿给朋友看。

课程重点： 以利亚独自为神站立。

游戏 1：谁是神？

玩法：

  • 分成两组：一组欢呼“耶和华是神！”
  • 另一组安静地听。
  • 交换角色，谈谈神是怎样真实的。

课程重点： 只有耶和华是永生的神。

游戏 2：为神站出来

玩法：

  • 读一些关于对与错的句子。
  • 如果这件事是应该做的，孩子们就站起来。
  • 如果是错的，就坐下。

课程重点： 神的仆人为正义站出来。
