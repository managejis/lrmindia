拿俄米和路得回到以色列

目标

向孩子们说明：路得对她的婆婆拿俄米的委身，是爱与忠诚的杰出榜样。

经文阅读

路得记 1:6-22

背诵经文

诗篇 121:2

我的帮助从造天地的耶和华而来。

讲授课程

起点

问问全班，有哪些原因会使难民和流离失所的人返回他们原来的国家或地区。返回的最重要原因是那里又有了粮食，又成了安全的地方。

课程重点

1. 出示图片 1。拿俄米和她的家人是从以色列的伯利恒逃出来的难民。现在拿俄米的丈夫和儿子都死了，在摩押这个外国，她没有任何血亲。没有人照顾她和她的两个外国儿媳俄珥巴和路得。后来拿俄米听说她祖国以色列的饥荒结束了。于是她决定回家（1:6）。

2. 拿俄米、俄珥巴和路得一同出发。后来拿俄米叫俄珥巴和路得回到摩押她们的亲人那里去，让她一个人回伯利恒。她们一直是好儿媳，但拿俄米已经没有儿子可以给她们作丈夫了，她们需要重新组建自己的家庭。俄珥巴非常悲伤地离开了她，回到了自己的族人那里（1:6-14）。

3. 但是路得恳求留在拿俄米身边。她说：“不要催我离开你。你往哪里去，我也往哪里去；你在哪里住，我也在哪里住。你的民就是我的民，你的神就是我的神。”于是路得陪着拿俄米来到以色列的伯利恒（1:14-17）。出示图片

2. 指出回摩押去的俄珥巴。

4. 拿俄米和路得一到伯利恒，那里所有的人都很激动。可是起初，他们几乎认不出拿俄米就是十年前离开这座城的那个女人。悲伤很可能改变了她的面容。她还想改名字。拿俄米的意思是“甘甜”。现在她想被称为玛拉，意思是“苦”。

5. 但拿俄米得到了祝福，因为有一位非常忠心又乐于帮助人的儿媳与她同住。还记得路得对她说了什么吗？再读一遍路得在第 16-17 节所说的话。路得愿意离开自己的家人、自己的国家和自己的宗教，留在拿俄米身边，而拿俄米是一个非常贫穷的寡妇。

我们对这个故事的回应

路得愿意放下一切，与拿俄米在一起，不期望任何回报。这个星期，我要挑战你们每一个人：为你所在社区里的某个人做一件事，不要期望任何回报。试着成为“另一个路得”。

牢记背诵经文

在下一课里，我们将看到神怎样照顾路得和拿俄米，这就是这节经文的一个例子。

复习第 1 课的背诵经文。

第 2 课：拿俄米和路得回到以色列

经文阅读： 路得记 1:6-22

1. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 谁回到了摩押她自己的族人那里？
    甲）路得 乙）俄珥巴 丙）拿俄米 👉 乙）俄珥巴
  • 谁留在拿俄米身边？
    甲）路得 乙）俄珥巴 丙）波阿斯 👉 甲）路得
  • 玛拉是什么意思？
    甲）甘甜 乙）苦 丙）喜乐 👉 乙）苦

2. 忠诚还是自私？ 忠/私

忠诚写“忠”，自私写“私”：

  • 陪伴一位难过的朋友。( ___ ) 👉 忠
  • 离开一位需要帮助的朋友。( ___ ) 👉 私
  • 帮助别人，不求回报。( ___ ) 👉 忠
  • 只有得到奖品才帮助人。( ___ ) 👉 私

3. 按顺序排列这个故事

甲）路得说：“你的神就是我的神。”
乙）拿俄米听说饥荒结束了。
丙）伯利恒的妇女们欢迎拿俄米。
丁）俄珥巴回摩押去了。

👉 正确顺序：

  • 乙）拿俄米听说饥荒结束了。
  • 丁）俄珥巴回摩押去了。
  • 甲）路得说：“你的神就是我的神。”
  • 丙）伯利恒的妇女们欢迎拿俄米。

4. 讨论题

  • 拿俄米为什么回伯利恒？

参考答案：她听说以色列又有粮食了。

  • 路得向拿俄米许了什么诺？

参考答案：她答应无论拿俄米去哪里，她都跟着去，并跟从拿俄米的神。

  • 这个星期你可以做谁的“路得”？

参考答案：答案各不相同。某个孤单的人，或某个需要帮助的人。

5. 背诵经文：

诗篇 121:2 ——“我的帮助从造天地的耶和华而来。”

约翰福音 15:12 ——“你们要彼此相爱，像我爱你们一样。”

6. 给图画涂色：

手工 1：同行二人卡

材料： 对折的卡片、蜡笔

步骤：

  • 在正面画两个并肩行走的女人。
  • 给道路和山涂上颜色。
  • 里面写上：“你往哪里去，我也往哪里去。”
  • 把它送给一位朋友。

课程重点： 路得爱拿俄米，并留在她身边。

手工 2：友谊手链

材料： 毛线或纸条、胶带

步骤：

  • 剪三条毛线。
  • 把它们编在一起。
  • 用胶带把两端固定在朋友的手腕上。
  • 说：“我要做你的朋友。”

课程重点： 真正的朋友在艰难的时候也会留在身边。

游戏 1：一起走

玩法：

  • 孩子们两人一组，手拉着手。
  • 慢慢地在教室里走向“山”（一把椅子）。
  • 一起说：“你往哪里去，我也往哪里去。”

课程重点： 路得一路陪着拿俄米走。

游戏 2：善行竞赛

玩法：

  • 分成两个队。
  • 喊出一件善事，比如“提一个包”。
  • 最先把它演出来的队得一分。

课程重点： 我们可以做善事，成为“另一个路得”。
