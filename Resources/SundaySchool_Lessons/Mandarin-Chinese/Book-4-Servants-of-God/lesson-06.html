马利亚和神的使者

目标

向孩子们说明：一位名叫马利亚的年轻女子，怎样成为神顺服并蒙福的仆人。

经文阅读

路加福音 1:26-38

背诵经文

诗篇 121:6

白日，太阳必不伤你；夜间，月亮必不害你。

讲授课程

起点

一位年轻女子订婚或许配人之后，有许多事要准备，尤其是婚期临近的时候。会有各种人来帮忙。让孩子们说说他们看到自己的家人是怎样做的。

课程重点

1. 马利亚许配给一个叫约瑟的人，这时有一位非常令人惊讶的访客来到她面前。

2. 马利亚在家里，忽然天使加百列，一位从神那里来的使者，出现在她面前。加百列的问安非常重要：他告诉马利亚，神与她同在（1:26-28）。出示图片 6。

3. 起初马利亚非常害怕，但加百列安慰了她。他说，神要用一种非常特别的方式赐福给她（1:29-30）。

4. 加百列给马利亚带来的信息是：她将成为神的儿子耶稣基督在人间的母亲。神曾应许犹太人，弥赛亚，就是救主，要从大卫的家系降生。许多年轻的犹太女子大概都在想，神会不会拣选她们作弥赛亚的母亲（1:31-33）。

5. 马利亚问天使，神要怎样成就这事，因为她是处女，还没有出嫁。这并不是说她怀疑神的计划。加百列告诉她，这确实将是一个神迹：是神的圣灵的能力要成就这事（1:34-35, 37）。

6. 马利亚接受了神为她所定的计划，尽管这事非常特别，大多数人都不会相信她。她说她是神乐意顺服的仆人（1:38）。

我们对这个故事的回应

马利亚和路得一样，接受了神为她生命所定的计划。她满心欢喜地把自己交在神的手中。读路加福音 1:46-49。神拣选了她去做祂要成就的一件事，而她是神顺服的仆人。

神也要我们全心全意地事奉祂。这是一个极大的特权。这也是祂创造我们的目的。顺服是路得和马利亚得福的道路，对我们今天也依然如此。

牢记背诵经文

整篇诗篇 121 篇显明，神保护事奉祂的人。复习前面几节经文。

第 6 课：马利亚和神的使者

经文阅读： 路加福音 1:26-38

1. 我是谁？

选择：加百列、马利亚、约瑟

  • 我是从神那里来的天使。我是谁？ __________ 👉 加百列
  • 我与马利亚订了婚。我是谁？ __________ 👉 约瑟
  • 我说：“我是主的仆人。”我是谁？ __________ 👉 马利亚

2. 对或错

对的写“对”，错的写“错”：

  • 马利亚起初很害怕。( ___ ) 👉 对
  • 这婴孩要叫耶稣。( ___ ) 👉 对
  • 马利亚对神的计划说了不。( ___ ) 👉 错

3. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 天使告诉马利亚神是怎样的？
    甲）祂生气了 乙）祂与她同在 丙）祂离得很远 👉 乙）祂与她同在
  • 耶稣是谁的儿子？
    甲）神的儿子 乙）国王的儿子 丙）农夫的儿子 👉 甲）神的儿子

4. 讨论题

  • 加百列是怎样帮助马利亚不那么害怕的？

参考答案：他告诉她，神与她同在。

  • 马利亚为什么对神说“是”？

参考答案：她信靠神，也愿意事奉祂。

  • 我们怎样才能对神说“是”？

参考答案：顺从祂，做正确的事。

5. 背诵经文：

诗篇 121:6 ——“白日，太阳必不伤你；夜间，月亮必不害你。”

路加福音 1:38 ——“‘我是主的仆人，’马利亚回答说。”

手工 1：天使加百列

材料： 纸、脱脂棉、胶水、蜡笔

步骤：

  • 在纸上画一个天使。
  • 把棉花粘在翅膀上。
  • 给长袍涂上颜色。
  • 写上：“神与你同在。”

课程重点： 加百列把神的信息带给马利亚。

手工 2：仆人之心

材料： 红纸、剪刀、蜡笔

步骤：

  • 把纸对折。
  • 剪出一个心形。
  • 写上：“我是主的仆人。”
  • 用小星星装饰。

课程重点： 马利亚以乐意的心事奉神。

游戏 1：传话

玩法：

  • 沿着队伍悄悄传一句简短的话。
  • 最后一个孩子大声说出来。
  • 把它与最初的那句话比较。

课程重点： 加百列的信息正是神要马利亚听到的。

游戏 2：是，主啊！

玩法：

  • 喊出一些好的任务，比如“帮妈妈”或“分享”。
  • 孩子们跳起来说：“是，主啊！”
  • 遇到不友善的事，他们就坐着不动。

课程重点： 神的仆人对好的事说“是”。
