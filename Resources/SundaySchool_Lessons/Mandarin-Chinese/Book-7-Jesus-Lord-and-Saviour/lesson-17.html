乞丐和富人

目标

教导孩子们：我们在今生所做的选择，决定我们在来世的地位。

经文阅读

路加福音 16:19-31

背诵经文

约翰福音 1:13

[神的]儿女不是从血统生的，不是从人的意愿生的，也不是从丈夫的意思生的，乃是从神生的。

注：这是一节很长的经文，但又很难分开，所以让全班用两次聚会来学习它。

讲授课程

起点

如果你可以自由选择，你想过什么样的生活？

课程重点

1. 耶稣讲了一个关于另一个富人的故事，他完全按照自己想要的方式生活。描述他所选择的生活（路 16:19）。

2. 拉撒路是一个非常穷的人，他必须在这个富人的庄园门口讨饭为生。他的生活很悲惨（16:20-21）。出示图片 17。这个富人一点也不关心可怜的拉撒路，尽管他有很多东西可以分享。

3. 拉撒路死的时候，对他来说一切都改变了。他在来世的生活很美好；他在天上得到了一个尊荣的位置，在亚伯拉罕的怀里。提醒孩子们亚伯拉罕是谁。他是犹太人的祖先（创 12:2），圣经称他为神的朋友（雅 2:23）。这个富人也死了，他的境况同样发生了巨大的变化。他发现自己在地狱里，遭受着可怕的痛苦（16:22-23）。

4. 描述这个富人怎样呼喊求助，以及他得到的回答（16:23-26）。他在世上的时候不愿帮助任何人，现在没有人能够帮助他。他被切断了一切的善意和关怀。

5. 直到那时，这个富人才开始想到别人。他拼命地想警告他的兄弟们，他们很可能也像他一样漫不经心地生活着（16:27-28）。耶稣要我们从这个故事中学到，神的信息是清楚的，对所有愿意听的人都是可得的。对于那些对神封闭了心思的人，即使有一位从坟墓另一边来的使者，也不能使他们听（16:29-31）。

我们对这个故事的回应

父母和其他大人常常警告孩子们小心危险的东西，例如：“别碰那个锅！它刚从火上拿下来，还很烫。”作为老师，你应该能举出更多的例子。有时候，我们对他们的警告充耳不闻，结果白白受苦。

耶稣用这个故事要警告我们，我们在这个世界上选择怎样生活，会影响我们在来世的地位。如果我们不向神的受造之物显出爱和怜悯，我们怎能指望从我们的造物主那里得到爱和怜悯呢？所以，我们不仅要尽可能地行善；我们也永远不要以牙还牙地回报别人对我们的残忍或不友善。

神渴望奖赏我们，因为祂爱我们，只要给我们好的。爱神，并分享祂赐给我们的，这就是祂要我们生活的方式。这是最好的选择。

第 17 课：乞丐和富人

经文阅读： 路加福音 16:19-31

1. 对还是错？

对的写“对”，错的写“错”：

  • 拉撒路是个贫穷的乞丐。( ___ ) 👉 对
  • 这个富人和拉撒路分享他的食物。( ___ ) 👉 错
  • 拉撒路去天上和亚伯拉罕在一起。( ___ ) 👉 对

2. 配对

A

B

富人

只为自己而活

拉撒路

又穷又病

亚伯拉罕

是神的朋友

哥哥们

需要听神的话

答案：
富人 → 只为自己而活
拉撒路 → 又穷又病
亚伯拉罕 → 是神的朋友
那些兄弟 → 需要听神的话

3. 善良还是粗鲁？ 善/粗

善良写“善”，粗鲁写“粗”：

  • 我帮助一位贫穷的邻居。( ___ ) 👉 善
  • 我不理会一个饥饿的人。( ___ ) 👉 粗
  • 我分享我的午餐。( ___ ) 👉 善

4. 讨论题

  • 这个富人怎样对待拉撒路？

参考答案：他一点也没有帮助他。

  • 这个故事警告我们什么？

参考答案：我们现在怎样生活很重要，所以我们应该善良，并听神的话。

  • 我们怎样帮助有需要的人？

参考答案：分享食物、衣服和友谊。

5. 背诵经文：

约翰福音 1:13 ——“……[神的]儿女不是从血统生的，不是从人的意愿生的，也不是从丈夫的意思生的，乃是从神生的。”

约翰一书 3:18 ——“小子们哪，我们相爱，不要只在言语和舌头上，总要在行为和诚实上。”

手工 1：助人之手

材料： 纸、蜡笔、剪刀

步骤：

  • 在纸上描出你的两只手。
  • 把它们剪下来。
  • 写上：“我要帮助别人。”

课程重点： 神要我们爱有需要的人。

手工 2：善行杯

材料： 纸杯、纸条、蜡笔

步骤：

  • 装饰一个杯子。
  • 把要做的善事写在纸条上。
  • 把纸条放进杯子里，每天抽一张。

课程重点： 我们的选择显明我们对神的爱。

游戏 1：善还是不善？

玩法：

  • 老师说出一个行为；孩子们认为是善就站起来，不善就坐下。
  • 讨论其中几个。
  • 称赞那些善的选择。

课程重点： 我们应该每天都选择善良。

游戏 2：送出去

玩法：

  • 每个孩子都有一枚纸“硬币”。
  • 他们把它送给没有的人。
  • 数一数，直到每个人都有一些。

课程重点： 分享使每个人都得益。
