两个人来到神面前

目标

向孩子们显明：神要我们怎样祷告来到祂面前。

经文阅读

路加福音 18:9-14

背诵经文

没有新的背诵经文

复习到目前为止学过的经文段落。

讲授课程

起点

从全班同学中选三个人，准备一个小短剧作为课程的开始。一个孩子扮演店主，另外两个扮演顾客。顾客要轮流到店里买东西。第一个顾客必须态度傲慢无礼，第二个则必须彬彬有礼。让全班清楚地看到，谁得到了店主更好的服务。

课程重点

1. 耶稣讲了一个故事，说到两个人，他们的行为也截然不同。两个人都到圣殿里去祷告。一个是法利赛人，意思是他是一位宗教领袖，受人尊敬。另一个是税吏。在耶稣的时代，这个职业常常使人成为被抛弃的人。税吏们为令人憎恨的罗马政府工作，这已经够糟糕的了，而且他们往往不诚实，让人们交比应交的更多的税（路 18:10）。

2. 法利赛人站在人人都能看见他的地方。他的祷告全是说他多么好，又多么庆幸自己比别人强，那些人贪婪、不诚实或不道德。他当然不像那边那个邪恶的税吏。他夸耀自己为神所做的一切好事。虽然神的律法只要求人一年禁食一次（不吃东西），他却每周禁食两次（18:11-12）。法利赛人听起来好像根本不需要神，好像神应该感谢他这么了不起，而不是反过来！

3. 税吏的祷告和他的态度很不一样。他知道自己是个罪人，来到至圣的神面前。他谦卑地求神帮助他、拯救他（18:13）。出示图片 19。再一次指出这两个人的不同之处。

4. 耶稣告诉听祂讲话的人，神垂听并回答了税吏的祷告。他回家去的时候，罪得了赦免，与神的关系也恢复了。法利赛人回家去的时候，只带着他的骄傲（18:14）。

我们对这个故事的回应

校长走进你们学校的教室时，你们的表现是怎样的？给孩子们时间回答。我们在他面前不骄傲，也不自夸。如果我们那样表现，他会认为我们从来不需要他的帮助或领导。

我们可以说，神像是我们的首领，尽管祂实际上远不止于此。祂也是我们的创造主和慈爱的父亲。但我们是不顺服祂的罪人，所以我们和祂说话的时候，首先需要求神饶恕。只有我们之间的一切都摆正了，神才会听我们要说的其他事。

骄傲的人信靠自己和自己的能力，而不是信靠神，就像乃缦在得医治之前那样。如有必要，提醒孩子们乃缦的故事。神不会帮助那些认为自己不需要帮助的人（18:9, 14）。

第 19 课：两个人来到神面前

经文阅读： 路加福音 18:9-14

1. 我是谁？

从中选择：法利赛人、税吏、神

  • 我夸耀自己多么好。我是谁？ __________ 👉 法利赛人
  • 我说：“神啊，开恩可怜我这个罪人！”我是谁？ __________ 👉 税吏
  • 我垂听谦卑人的祷告。我是谁？ __________ 👉 神

2. 骄傲还是谦卑？ 骄/谦

骄傲写“骄”，谦卑写“谦”：

  • 我向神说对不起。( ___ ) 👉 谦
  • 我认为我比别人强。( ___ ) 👉 骄
  • 我求神帮助我。( ___ ) 👉 谦

3. 圈出正确的词语

圈出正确的词：

  • 法利赛人（骄傲地 / 安静地）站着。 👉 骄傲地
  • 税吏（低头 / 抬头）并且难过。 👉 低头
  • 他回家去，（得了赦免 / 带着怒气）。 👉 得了赦免

4. 讨论题

  • 法利赛人的祷告有什么问题？

参考答案：他自夸，没有求帮助。

  • 神为什么垂听税吏？

参考答案：他谦卑而诚实。

  • 我们应该怎样祷告来到神面前？

参考答案：谦卑地、说对不起，并信靠祂。

5. 背诵经文：

约翰福音 1:5 ——“光照在黑暗里，黑暗却不接受光。”

雅各书 4:6 ——“神阻挡骄傲的人，赐恩给谦卑的人。”

6. 给图画涂色：

手工 1：谦卑祷告之手

材料： 纸、蜡笔

步骤：

  • 描出祷告的双手，并剪下来。
  • 写上：“神啊，求你帮助我。”
  • 给手涂上颜色。

课程重点： 神垂听谦卑的祷告。

手工 2：两个人的图画

材料： 纸、蜡笔

步骤：

  • 画两个人在祷告。
  • 让一个人站得挺直，一个人深深地鞠躬。
  • 写上：“神垂听谦卑的人。”

课程重点： 神爱谦卑的人。

游戏 1：骄傲和有礼貌

玩法：

  • 两个孩子在一家假想的商店里表演骄傲和有礼貌。
  • 全班判断谁受到了更好的对待。
  • 谈谈谦卑。

课程重点： 谦卑使神喜悦。

游戏 2：先说对不起

玩法：

  • 老师读一些关于做错事的小故事。
  • 孩子们说：“神啊，求你饶恕我。”
  • 最后做一个安静的祷告。

课程重点： 我们应该先求饶恕。
