耶稣死在十字架上

目标

向孩子们显明：耶稣甘心情愿让人把祂钉十字架。祂背负我们的罪担而死，为要带领我们与神相交。

经文阅读

约翰福音 18:1-40；19:1-30

背诵经文

约翰福音 1:8

他不是那光，乃是要为光作见证。

注：这段阅读比平常长，课程里不会全部讲到，但你要把这两章完整地读一遍，好让孩子们能跟上所发生的事。

讲授课程

起点

告诉我，你们要背很重的东西的时候，会想出什么不同的办法？给全班时间回答。你们当中有些女孩今天早些时候也许用头顶着一桶桶水回家。收割的时候，人们顶着一大捆一大捆的草或谷物，几乎看不到下面的人！

当我们背着沉重的负担或重担时，我们都能看到、感觉到压在我们身上的重量。我们背着的还有另一种看不见的重担。那就是我们罪的重担。我们不能明白神是谁，也不能明白祂有多爱我们，因为罪的重担挡在中间，压着我们。前几课已经显明，耶稣就是神自己，是神完美的儿子。只有祂能把这罪的重担从我们身上挪去，从而释放我们去服事神，享受祂自由的生命。

课程重点

1. 耶稣事先告诉了祂的朋友们祂将要死。他们不明白祂在说什么，但知道犹太宗教领袖们想要杀祂（11:55-57）。耶稣在耶路撒冷和祂的门徒们一起守逾越节。晚上，祂到城外不远的一个园子里去祷告。就在那里，祂自己的一个门徒犹大，带着宗教领袖们派来的武装士兵和差役，来拘捕耶稣（18:1-3）。

2. 耶稣的举动不像一般被捕的人。祂没有反抗，也没有设法逃跑。描述耶稣怎样告诉士兵们祂是谁，以及祂怎样任凭他们拘捕。情形正好相反：害怕的倒是士兵们（18:4-8）！耶稣的亲密朋友西门·彼得也很害怕，但他想保护耶稣。他身上带着一把剑，就用了出来。描述耶稣所说的和所做的（约 18:10-11；路 22:49-51）。

3. 整整一夜，大祭司和宗教领袖们审问耶稣。这场审判是不合法的。第一，它是在夜里进行的；第二，他们拿不出任何证人，能证明耶稣做过或教导过任何错误的事（18:19-24）。

4. 早晨，他们把耶稣带到罗马总督本丢·彼拉多那里，只有他才能下令处死人（18:28-31）。然而，彼拉多找不出耶稣有任何罪。他提出要释放耶稣，但犹太人和他们的宗教领袖却选择释放巴拉巴，一个强盗和杀人犯，而不是耶稣（18:38-40）。

5. 彼拉多明知耶稣是无辜的，却允许他的士兵虐待祂。他希望这样能使犹太人满意，这样他就不必让耶稣被处死了。彼拉多意识到耶稣不是个普通人，但他太害怕犹太领袖了，就把耶稣交给他们去钉十字架（19:1-16）。

6. 耶稣被钉在两个强盗中间的十字架上，有士兵看守。出示图片 10。耶稣知道祂在地上所要做的一切都已经成就了，就死了（19:17-18, 28-30）。

我们对这个故事的回应

这个故事里的每个人都背着一副重担——他或她罪的重担。想一想犹大，最后撇下耶稣一个人的门徒们，说自己连耶稣都不认识的彼得，犹太人和他们的宗教领袖，本丢·彼拉多和他的士兵。耶稣在十字架上把每个人的罪担都担在祂自己身上。

祂的死向我们显明，尽管我们是罪人，神却多么爱我们，也显明神多么希望我们回报祂的爱。

第 10 课：耶稣死在十字架上

经文阅读： 约翰福音 18:1-40；19:1-30

1. 对还是错？

对的写“对”，错的写“错”：

  • 耶稣选择为我们走上十字架。( ___ ) 👉 对
  • 彼拉多找到了惩罚耶稣的好理由。( ___ ) 👉 错
  • 耶稣把我们的罪担在祂自己身上。( ___ ) 👉 对

2. 完成句子

词语框：罪、爱、十字架

  • 耶稣死在____________上。 __________ 👉 十字架
  • 祂背负了我们的____________的重担。 __________ 👉 罪
  • 祂的死显明神伟大的____________。 __________ 👉 爱

3. 圈出正确的词语

圈出正确的词：

  • 耶稣到园子里去（祷告 / 玩耍）。 👉 祷告
  • 耶稣在任何错事上都是（有罪的 / 清白的）。 👉 清白的
  • 耶稣死，使我们能够（得赦免 / 失丧）。 👉 得赦免

4. 讨论题

  • 耶稣为什么死在十字架上？

参考答案：为了背负我们的罪，带我们回到神那里。

  • 耶稣是被迫去死的吗？

参考答案：不是，祂允许这样，因为祂爱我们。

  • 我们怎样向耶稣说谢谢？

参考答案：爱祂，顺服祂，并把祂告诉别人。

5. 背诵经文：

约翰福音 1:8 ——“他不是那光，乃是要为光作见证。”

罗马书 5:8 ——“惟有基督在我们还作罪人的时候为我们死，神的爱就在此向我们显明了。”

6. 给图画涂色：

手工 1：十字架卡片

材料： 对折的卡纸、两根棕色纸条、胶水、蜡笔

步骤：

  • 把两根纸条在封面上粘成一个十字架。
  • 在中间画一颗心。
  • 在里面写上：“耶稣爱我。”

课程重点： 耶稣死，是因为祂爱我们。

手工 2：得赦免的心

材料： 红纸做的心、纸团、一个小袋子、胶水

步骤：

  • 把“错事”写在纸团上，并放进袋子里。
  • 感受一下这个袋子有多重。
  • 把它们拿出来，粘上一颗写着下面这句话的心：“已经赦免了！”

课程重点： 耶稣挪去我们罪的重担。

游戏 1：沉重的袋子

玩法：

  • 在一个小袋子里装满纸团。
  • 让孩子们背着它走几步。
  • 一起说：“耶稣背负了我的重担。”

课程重点： 耶稣背负了我们的罪，使我们得自由。

游戏 2：感谢圈

玩法：

  • 围成一圈安静地坐着。
  • 每个孩子说一句简短的“耶稣，感谢你……”。
  • 最后安静地说“阿们”。

课程重点： 我们感谢耶稣伟大的爱。
