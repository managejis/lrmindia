复活的耶稣教导两个朋友

目标

向孩子们显明：复活的耶稣怎样向祂的两个朋友显现，并从旧约圣经里把关于祂自己的一切教导他们。

经文阅读

路加福音 24:13-35

背诵经文

约翰福音 1:10

祂在世界，世界也是借着祂造的，世界却不认识祂。

讲授课程

起点

当你要走很长的路，比如从一个村子走到另一个村子，有人和你作伴是好事。有人可以说话，路程就好像变短了。

课程重点

1. 耶稣的两个朋友从耶路撒冷城走向以马忤斯村，路程大约有 11 公里。在耶稣被钉十字架后的那个星期日下午，他们一路走，一路谈论所发生的一切。这时有一个陌生人赶上了他们，和他们同行。那就是耶稣自己，可是他们没有认出祂！祂问他们在谈论什么（路 24:13-17）。

2. 他们很惊讶，这个陌生人那个星期一直在耶路撒冷，竟然不知道那些使全城都在议论的可怕的事件。告诉全班他们是怎样回答耶稣的（24:18-24）。他们非常悲伤，也很困惑。

3. 出示图片 13。耶稣提醒这两个朋友，摩西和其他先知曾写下，神的儿子，也就是他们所称的基督或弥赛亚，来到这个世界的时候，要受苦并且死。在剩下的路上，祂又教导他们更多关于复活和神的国降临的事（24:25-27）。

4. 他们到了以马忤斯，两个朋友劝这位陌生人留下来和他们一起吃饭。耶稣拿起饼来祝谢的时候，他们终于认出了这位陌生人到底是谁。就在那一刻，耶稣离开了他们（24:28-32）。

5. 两个朋友高兴极了，立刻一路走回耶路撒冷，去告诉其他门徒！那时一定已经天黑了。其他门徒也有奇妙的消息要告诉他们，说他们看见耶稣又活了（24:33-35）。

我们对这个故事的回应

那两个门徒听耶稣解释刚刚发生的可怕事件背后的好消息，该是多么美妙啊。耶稣要我们做的正是这样：把祂的故事告诉我们遇到的那些不认识祂是救主的人。

40 年来，欧洲的阿尔巴尼亚一直对福音关闭。甚至不允许任何人相信神是活的。邻国的一位牧师把圣经的一些部分放进塑料瓶里，扔进海中。他祷告，愿海流把它们冲到阿尔巴尼亚的海岸上。阿尔巴尼亚的情况改变以后，这位牧师亲自去那里传福音。他遇见一个人，这个人捡到了其中一个装满圣经话语的瓶子。那人告诉牧师，他读了那些经文，这使他想要成为耶稣的跟随者！

第 13 课：复活的耶稣教导两个朋友

经文阅读： 路加福音 24:13-35

1. 是还是否？

是写“是”，否写“否”：

  • 两个朋友走向以马忤斯吗？( ___ ) 👉 是
  • 起初他们知道这个陌生人是耶稣吗？( ___ ) 👉 否
  • 耶稣向他们讲解圣经吗？( ___ ) 👉 是

2. 把故事按顺序排好

甲）他们回去告诉其他人。
乙）一个陌生人在路上加入了他们。
丙）两个朋友走向以马忤斯。
丁）耶稣擘开饼，他们就认出了祂。

👉 正确顺序：

  • 丙）两个朋友走向以马忤斯。
  • 乙）一个陌生人在路上加入了他们。
  • 丁）耶稣擘开饼，他们就认出了祂。
  • 甲）他们回去告诉其他人。

3. 缺少的字

填上缺少的字：

  • 以马 _ 斯（那个村子） __________ 👉 以马忤斯
  • 面 _（耶稣擘开的） __________ 👉 面包
  • 圣 _（神的话） __________ 👉 圣经

4. 讨论题

  • 你认为他们为什么没有认出耶稣？

参考答案：神使他们的眼睛不能认出祂，直到合适的时刻。

  • 两个朋友见到耶稣之后做了什么？

参考答案：他们赶紧回去告诉其他人。

  • 这个星期你可以把耶稣告诉谁？

参考答案：一个朋友、一个邻居或一位家人。

5. 背诵经文：

约翰福音 1:10 ——“祂在世界，世界也是借着祂造的，世界却不认识祂。”

路加福音 24:32 ——“在路上与我们说话、给我们讲解圣经的时候，我们的心岂不是火热的吗？”

6. 给图画涂色：

手工 1：以马忤斯之路图画

材料： 纸、棕色和绿色蜡笔

步骤：

  • 画一条长路。
  • 画两个朋友在走路。
  • 再加上第三个人影：耶稣。

课程重点： 即使我们看不见耶稣，祂也与我们同行。

手工 2：圣经书签

材料： 卡纸条、蜡笔

步骤：

  • 剪一条长长的卡纸条。
  • 画一颗心和一本书。
  • 写上：“主啊，求你开我的眼睛。”

课程重点： 耶稣用圣经教导我们。

游戏 1：旅程步行

玩法：

  • 标出一条 20 步长的路。
  • 孩子们两人一组走这条路，说出耶稣做过的一件事。
  • 到了终点说：“祂活了！”

课程重点： 我们一起走路的时候，谈论耶稣是好的。

游戏 2：陌生人是谁？

玩法：

  • 一个孩子戴着帽子或围巾。
  • 其他孩子猜是谁。
  • 说：“直到耶稣擘开饼，他们才认出祂。”

课程重点： 即使我们看不见，耶稣也与我们同在。
