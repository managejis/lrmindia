耶稣医治一个瞎子

目标

教导孩子们：耶稣作为世界的光，显明了祂神圣的能力。

经文阅读

约翰福音 9:1-41

背诵经文

约翰福音 1:6-7

有一个人，是从神那里差来的，名叫约翰。这人来，为要作见证，就是为光作见证……

注：这个故事不会教导所有的细节，但如果你把整个故事读给全班听会更好。

讲授课程

起点

玩一个简短的蒙眼捉人游戏。如果班级很大，就选大约 12 个孩子参加。让一个人蒙上眼睛，其他人围成一圈站在他或她周围。让蒙眼的人试着抓住某个人。抓住的时候，他或她可以摸一摸那个人，并猜是谁。

课程重点

1. 瞎眼的人生活要困难得多。有一天，耶稣遇见一个生来就瞎眼的人。这比后来在人生中失明还要困难，因为如果你从来没有看见过任何东西，你就不记得事物是什么样子。更糟的是，每个人都认为他的瞎眼是对某种罪的惩罚（9:1-2）。

2. 耶稣说，这个人生来瞎眼是有特别的目的。是要让每个人都看见神的能力医治了他，也是要向人们显明，耶稣是作为光来到这黑暗的世界上的（9:3-5）。描述耶稣怎样医治那个人。出示图片 8。那人顺从耶稣的指示，回到家里的时候已经不再瞎眼了（9:6-7）。

3. 在这个故事里，还有其他的人也是瞎的。他们不是肉身上的瞎眼，因为他们的眼睛能看见。然而，他们在灵里是瞎的，因为他们拒绝相信耶稣就是神。他们拒绝信靠祂。

那个从前瞎眼的人的邻居们觉得很难相信他们所看见的，尽管他们的眼睛一点毛病也没有！他们向他询问关于耶稣的事（9:8-12）。

还有法利赛人，他们是重要的犹太宗教领袖，也是灵里的瞎子。他们很生气，因为耶稣在安息日医治了那个人，而安息日是谁也不该做任何工作的日子。他们瞎到这种地步，甚至认为耶稣行了那个神迹就是个罪人！然而，那个得了医治的人知道自己曾经是肉身瞎眼，而且是耶稣使他看见的，他就把这件事告诉了那些宗教领袖（9:13-17, 24-34）。强调约翰福音 9:25。连那个得了医治之人的父母也是灵里的瞎子。他们是那么害怕有权势的宗教领袖，似乎连他们的儿子得了医治也不欢喜（9:18-23）！

4. 耶稣去找那个得了医治的人，并和他说话。给全班读 9:35-37。他现在不仅有了肉身的视力，也有了灵里的视力，因为他相信耶稣是从父神那里来的。这就是第 35 节中“人子”这个名字的意思。那个从前瞎眼的人就敬拜了耶稣（9:38-39）。

我们对这个故事的回应

如果你是瞎的，你就看不见光。大家都闭上眼睛。你们现在是在黑暗中，但这并不意味着光已经走了。你们只是看不见它。

耶稣是我们属灵的光。祂来是要把光带到这黑暗的世界。我们需要属灵的光才能信祂；这样我们才能看见神的道路，并行走在其中。

牢记背诵经文

施洗约翰是父神差来宣告耶稣，这世界的光，将要来临的那一位。

第 8 课：耶稣医治一个瞎子

经文阅读： 约翰福音 9:1-41

1. 圈出正确的词

圈出正确的词：

  • 这个人生来就（瞎 / 聋）。 👉 瞎
  • 耶稣是世界的（光 / 门）。 👉 光
  • 得了医治的人说：“我从前是瞎眼的，如今（能看见 / 能跑）了！” 👉 能看见

2. 配对

A

B

那个瞎子

在池子里洗了，就看见了

邻居们

不能相信

法利赛人

在灵里是瞎的

耶稣

世界的光

答案：
那个瞎子 → 在池子里洗了，就看见了
邻居们 → 不能相信
法利赛人 → 在灵里是瞎的
耶稣 → 世界的光

3. 是还是否？

是写“是”，否写“否”：

  • 耶稣使那个人痊愈了吗？( ___ ) 👉 是
  • 那个人敬拜耶稣了吗？( ___ ) 👉 是
  • 我们每天都需要耶稣的光吗？( ___ ) 👉 是

4. 讨论题

  • 耶稣是世界的光是什么意思？

参考答案：祂向我们显明神的道路，并除去黑暗。

  • 在这个故事里，谁以另一种方式瞎眼？

参考答案：不肯信耶稣的领袖们。

  • 得了医治的人告诉我们耶稣的什么？

参考答案：耶稣真的医治了他，他现在信了。

5. 背诵经文：

约翰福音 1:6-7 ——“有一个人，是从神那里差来的，名叫约翰。这人来，为要作见证，就是为光作见证……”

约翰福音 9:25 ——“有一件事我知道，从前我是瞎眼的，如今能看见了。”

6. 给图画涂色：

手工 1：世界之光的蜡烛

材料： 黄纸和橙纸、一个纸筒、胶水

步骤：

  • 用白纸把纸筒包起来。
  • 用黄纸和橙纸剪一朵火焰。
  • 把火焰粘在上面。
  • 写上：“耶稣是光。”

课程重点： 耶稣是给我们指路的光。

手工 2：睁开眼睛卡片

材料： 对折的纸、蜡笔

步骤：

  • 在封面上画一双大大的、快乐的眼睛。
  • 在里面写上：“现在我看见了！”
  • 给卡片涂上颜色，并分享给别人。

课程重点： 耶稣开我们的眼睛，使我们认识祂。

游戏 1：闭上眼睛

玩法：

  • 所有人闭上眼睛十秒钟。
  • 睁开眼睛，谈谈光怎样帮助我们。
  • 说：“耶稣是我们的光！”

课程重点： 耶稣的光帮助我们看见神的道路。

游戏 2：找到光

玩法：

  • 在房间里藏一支小手电筒或一张黄色卡片。
  • 孩子们去找；老师说“近了”或“远了”。
  • 找到的时候，大家一起说：“耶稣是光！”

课程重点： 我们寻找耶稣，就找到了光。
