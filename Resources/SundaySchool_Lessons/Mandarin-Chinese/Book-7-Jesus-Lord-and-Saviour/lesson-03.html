耶稣对尼哥底母说话

目标

让孩子们看到，耶稣怎样用祂的教导显明祂是神的儿子。

经文阅读

约翰福音 3:1-17；民数记 21:4-9

背诵经文

约翰福音 1:2

[这道]太初与神同在。

讲授课程

起点

假设你想拜访某个人，却不想让别人看见你。你会怎么做？给孩子们时间回答。你可能会用一件大衣或一条毛巾把自己遮起来，或者选择在漆黑的夜里出去。

课程重点

1. 一天夜里，一位名叫尼哥底母的犹太重要宗教领袖来拜访耶稣。他是偷偷来的，因为他不想让别的宗教领袖知道他在做什么。他们恨耶稣，但尼哥底母有些问题想要问。从耶稣所说的和所做的，尼哥底母看出耶稣是从神那里来的。然而，耶稣并不是犹太人所期待的神的使者的那种样子（3:1-2）。

2. 耶稣告诉尼哥底母，要进入神的国，他必须重生。尼哥底母自然认为这是不可能的！出示图片 3。在这里的角落里你们可以看到一位母亲和一个孩子；这幅图代表肉身的出生（3:3-4）。

3. 耶稣解释说，祂讲的是灵里的重生。每一个得着永生的人，都为自己的罪悔改了，罪已经被洗去。然后神把祂的灵作为礼物赐给那个人，使他或她从灵而生。这就是“第二次出生”（3:5-7）。正如我们不能控制风的运行，我们也无法掌控自己的得救；它是神所赐的礼物（3:8）。

4. 尼哥底母觉得这一切都很难明白，尽管他是一位重要的宗教教师！耶稣说：“我对你们说地上的事，你们尚且不信，若说天上的事，怎能信呢？除了从天上降下、仍旧在天的人子，没有人升过天”（3:9-13）。

5. 耶稣是有史以来最好的教师。祂知道用比喻——用语言描绘的图画——来解释最有效。耶稣在这里提到的蛇的故事，讲在第 2 册第 20 课。出示配套的图片，简要复习民数记 21:4-9 的故事会很有用。耶稣将要被举起来钉在十字架上，就像铜蛇在旷野里被举起来一样。接受耶稣是得救的唯一途径，就像在旷野里，仰望铜蛇是被蛇咬后活命的唯一办法（3:14-17）。

我们对这个故事的回应

耶稣请尼哥底母信靠祂。耶稣也请我们信靠祂，接受祂所赐的救恩的礼物。

大声朗读约翰福音 3:16。或者，如果全班已经把它作为背诵经文学过了，就让孩子们把它说出来。

第 3 课：耶稣对尼哥底母说话

经文阅读： 约翰福音 3:1-17；民数记 21:4-9

1. 对还是错？

对的写“对”，错的写“错”：

  • 尼哥底母夜里来见耶稣。( ___ ) 👉 对
  • 尼哥底母是个农夫。( ___ ) 👉 错
  • 耶稣说我们必须重生。( ___ ) 👉 对

2. 我是谁？

从中选择：尼哥底母、耶稣、风

  • 我是一个有许多问题的宗教领袖。我是谁？ __________ 👉 尼哥底母
  • 你看不见我，却能听见我吹的声音。我是谁？ __________ 👉 风
  • 我将被举起来，使人得着生命。我是谁？ __________ 👉 耶稣

3. 缺少的字

填上缺少的字：

  • 重 _（新的生命） __________ 👉 重生
  • 永 _（神所赐的礼物） __________ 👉 永生
  • 救 _（耶稣是我们的……） __________ 👉 救主

4. 讨论题

  • 尼哥底母为什么夜里来？

参考答案：他不想让别的领袖看见他。

  • 重生是什么意思？

参考答案：我们信靠耶稣的时候，神借着祂的灵赐给我们新生命。

  • 谁可以信靠耶稣并得着永生？

参考答案：每一个信祂的人。

5. 背诵经文：

约翰福音 1:2 ——“这道太初与神同在。”

约翰福音 3:36 ——“信子的人有永生。”

6. 给图画涂色：

手工 1：杆子上的蛇

材料： 棕色纸条、一根小棍或吸管、胶水、蜡笔

步骤：

  • 把一条长纸条涂成蛇的样子。
  • 把它缠绕在小棍上。
  • 写上：“仰望就得生。”

课程重点： 耶稣被举起来，使凡信靠祂的人都能永远活着。

手工 2：风车

材料： 方形纸、剪刀、大头针、带橡皮的铅笔

步骤：

  • 把一张方形纸从四个角剪向中心。
  • 把每隔一个的角折向中心。
  • 用大头针把它固定在铅笔上，然后对着它吹气。

课程重点： 我们看不见风，却能看见风所做的；神的灵就是这样运行的。

游戏 1：夜里的访客

玩法：

  • 一个孩子扮作“尼哥底母”，踮着脚走到老师的桌子前。
  • 老师问：“你为什么来？”
  • 孩子问一个关于耶稣的问题；全班帮助回答。

课程重点： 耶稣欢迎每一个带着问题来的人。

游戏 2：风吹

玩法：

  • 老师说：“风吹到每一个……的人”（有兄弟、喜欢吃米饭等等）。
  • 那些孩子互换座位。
  • 说：我们看不见风，但风是真实的，就像神的灵一样。

课程重点： 神的灵是真实的，尽管我们看不见祂。
