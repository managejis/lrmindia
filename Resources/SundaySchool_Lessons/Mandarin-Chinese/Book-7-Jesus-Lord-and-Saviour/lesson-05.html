池边的病人

目标

向孩子们显明：神的儿子耶稣与父神同等。祂能施行神圣的能力。

经文阅读

约翰福音 5:1-18

背诵经文

约翰福音 1:4

[道]里面……有生命，这生命就是人的光。

讲授课程

起点

你有没有试过做一件事，结果发现非常困难，不得不试好几次？也许你差一点就放弃了？举一个具体的例子，比如小孩子常常觉得系鞋带很难。

课程重点

1. 耶稣遇见一个几乎已经放弃了的人。描述这个人怎样病了 30 年，以及他为什么几乎对痊愈不抱希望了（5:2-5）。出示图片 5。耶稣用一个问题向他发出挑战（5:6）。

2. 那人告诉耶稣，他确实想要痊愈，但是他没有朋友帮助他。耶稣的回答，是命令这个不能走路的病人起来。他就起来了（5:7-9上）！

3. 然而，有些宗教领袖对耶稣很生气，因为祂在安息日医治了那个人，而安息日是犹太人停下一切工作来敬拜神的日子。这些生气的犹太领袖找不到耶稣，就拦住那个得了医治的人盘问。他真的不知道是谁医治了他（5:9下-13）。

4. 后来，耶稣果然又遇见了他。这时，那个得了医治的人才明白，既然已经遇见了神的儿子，他的整个生命都需要改变。耶稣再次找到他的时候，他正在圣殿里；也许他是在为自己得了医治而感谢神（5:14）。

我们对这个故事的回应

犹太领袖们继续对耶稣非常生气，因为他们不能接受，父的作为和子耶稣的作为没有分别（5:16-18）。

神是至高的主宰。祂总是知道什么时候是做成某件事的合适时机。祂的计划里没有不合时宜的时间。

让我们赞美父神，在时候刚刚好的时候差遣祂的儿子耶稣基督到世上来。如果有时间，回顾第 1 课关于神的计划的内容。

也许有某种渴望，你相信是神放在你心里的，却还没有得到满足。不要放弃；神会按照祂完美的时间施展祂的能力。

第 5 课：池边的病人

经文阅读： 约翰福音 5:1-18

1. 数一数，写下来

写出数字：

  • 耶稣在池边医治了 ____ 个人。 __________ 👉 1
  • 耶稣吩咐他起来，拿起他的褥子，____。 __________ 👉 走
  • 耶稣和父是 ____ 位神。 __________ 👉 一

2. 配对

A

B

那个病人

没有人帮助他

耶稣

吩咐他起来

领袖们

为安息日的事生气了

褥子

他把它拿起来，走了

答案：
那个病人 → 没有人帮助他
耶稣 → 吩咐他起来
领袖们 → 为安息日的事生气了
褥子 → 他把它拿起来，走了

3. 信靠还是放弃？ 信/弃

我们信靠神的时间写“信”，放弃写“弃”：

  • 我等候神，并不断祷告。( ___ ) 👉 信
  • 我说：“神永远不会帮助我。”( ___ ) 👉 弃
  • 我知道神的时间永远是对的。( ___ ) 👉 信

4. 讨论题

  • 你认为那个人为什么几乎放弃了？

参考答案：他病了很长时间，也没有人帮助他。

  • 耶稣说话的时候，那个人做了什么？

参考答案：他起来，拿起褥子走了。

  • 神的回答似乎很慢的时候，我们可以做什么？

参考答案：继续信靠神，因为祂的时间是完美的。

5. 背诵经文：

约翰福音 1:4 ——“生命在祂里头，这生命就是人的光。”

传道书 3:11 ——“神造万物，各按其时成为美好。”

手工 1：卷起来的褥子

材料： 纸条、细绳、蜡笔

步骤：

  • 把纸条编在一起或粘在一起，做成一张小褥子。
  • 把它卷起来，用细绳系好。
  • 写上：“耶稣使我痊愈。”

课程重点： 耶稣有医治我们、使我们更新的能力。

手工 2：神的时间之钟

材料： 纸盘、卡纸做的指针、大头针

步骤：

  • 在盘子上写上数字。
  • 在中间固定两根卡纸指针。
  • 写上：“神的时间是最好的。”

课程重点： 神总是知道合适的时间。

游戏 1：拿起你的褥子

玩法：

  • 给每个孩子在地上放一块小布。
  • 一听到“耶稣说：起来！”，孩子们就拿起布站起来。
  • 一听到“坐下”，他们又坐下；称赞听得最认真的孩子。

课程重点： 耶稣的话有能力；我们应该顺服祂。

游戏 2：等待游戏

玩法：

  • 每个孩子手里拿着一粒小小的纸“种子”。
  • 闭上眼睛慢慢数到十，再睁开。
  • 谈谈等待是多么难，以及神的时间是最好的。

课程重点： 等候神是值得的。
