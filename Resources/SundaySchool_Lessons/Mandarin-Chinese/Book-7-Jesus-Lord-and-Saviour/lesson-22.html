照顾受伤的陌生人

目标

向孩子们显明：我们相信并顺从神的话，就会改变我们对待其他每一个人的生活方式和行为。

经文阅读

路加福音 10:25-37

背诵经文

复习约翰福音 1:1-9

讲授课程

起点

有时候人们会问一些很难回答的问题，是我们不知道怎样回答的问题。有时候我们知道答案，却不想说出来。例如，如果孩子们放学晚回家，妈妈可能会问他们去了哪里。有时候他们不想告诉她。

课程重点

1. 人们问耶稣许多问题。有时候他们问一个问题，只是为了为难祂。宗教领袖们总是在想方设法试探祂。不过，这从来没有奏效。耶稣向大家显明，这些人中许多人不是好领袖，所以他们对祂很生气。

2. 一个非常熟悉宗教律法的人问耶稣，他怎样才能得着永生。当然，像他这样有学问的人，早就知道圣经里所提供的答案了：爱主，并且爱邻舍。他想用来难住耶稣的难题是：谁是我的邻舍？（路 10:25-29）。

3. 耶稣给他讲了一个故事，不仅向他显明了谁是他的邻舍，还显明了他应当怎样爱邻舍。这可能是一个真实的故事。用你自己的话讲 10:30-35 的故事。祭司和利未人是宗教官员，他们是不允许触碰尸体的。如果那个受伤的人真的死了，碰他就会使他们不洁净，因而在一段时间内不能履行他们的宗教职责。耶稣的意思是，乐于助人的行为比正式的宗教职责更重要。

4. 解释说，停下来帮助那个受伤的人的撒玛利亚人，属于一个被犹太人鄙视和憎恨的种族。出示图片 22。请注意，撒玛利亚人的帮助是慷慨的。他不只是做了一些急救。他仔细地清洗并处理了伤口。然后他把那个人带到一个可以得到照顾的地方，并付了他住宿的费用。他甚至答应回来看看那个人怎么样了，如果还欠更多的钱，他会补上。撒玛利亚人付出的时间、金钱和关怀，和人们对一位朋友或亲人所期待的一样多，而且是对一个通常是他仇敌的人！

5. 然后耶稣问那位精通律法的人：“你想，这三个人哪一个是落在强盗手中的人的邻舍呢？”那个人知道答案，也明白了这个信息，但即使这样，他还是说不出“撒玛利亚人”这个词（10:36-37）！耶稣期待我们向任何有需要的人表示爱和关怀。祂自己就是这样做的（罗 5:8）。

我们对这个故事的回应

这是一个很适合表演的故事。可以按照耶稣所讲的来表演，也可以改编成现代的场景。祭司和利未人必须换成通常会被期待提供帮助的人。撒玛利亚人则是某个被部族仇恨或种族偏见所针对的人。

第 22 课：照顾受伤的陌生人

经文阅读： 路加福音 10:25-37

1. 我是谁？

从中选择：撒玛利亚人、祭司、强盗

  • 我帮助了那个受伤的人，并为他的照顾付了钱。我是谁？ __________ 👉 撒玛利亚人
  • 我从另一边绕过去了。我是谁？ __________ 👉 祭司
  • 我们在路上伤害了那个人。我们是谁？ __________ 👉 强盗

2. 把故事按顺序排好

甲）他把他带到客店，并付了钱。
乙）一个人在路上受了伤。
丙）撒玛利亚人停下来帮助他。
丁）一个祭司和一个利未人从旁边经过。

👉 正确顺序：

  • 乙）一个人在路上受了伤。
  • 丁）一个祭司和一个利未人从旁边经过。
  • 丙）撒玛利亚人停下来帮助他。
  • 甲）他把他带到客店，并付了钱。

3. 是还是否？

是写“是”，否写“否”：

  • 耶稣吩咐我们爱邻舍吗？( ___ ) 👉 是
  • 我们的邻舍只是我们的朋友吗？( ___ ) 👉 否
  • 我们应该帮助和我们不同的人吗？( ___ ) 👉 是

4. 讨论题

  • 谁是真正的邻舍？

参考答案：帮助人的撒玛利亚人。

  • 这个故事为什么出人意料？

参考答案：帮助人的人来自犹太人不喜欢的一个群体。

  • 这个星期你可以怎样帮助某个人？

参考答案：分享、帮助，或说友善的话。

5. 背诵经文：

约翰福音 1:8-9 ——“他不是那光，乃是要为光作见证。那照亮每一个人的真光，正要来到世上。”

路加福音 10:27 ——“爱邻舍如同自己。”

6. 给图画涂色：

手工 1：急救箱

材料： 小盒子、绷带条、红色蜡笔

步骤：

  • 用一个红十字装饰盒子。
  • 在里面放一条绷带。
  • 写上：“我要帮助。”

课程重点： 我们帮助有需要的人。

手工 2：邻舍卡片

材料： 对折的纸、蜡笔

步骤：

  • 画两个人在握手。
  • 写上：“你是我的邻舍。”
  • 把它送给某个人。

课程重点： 每个人都是我们的邻舍。

游戏 1：助人之手

玩法：

  • 用一个玩偶当受伤的人，把这个故事表演出来。
  • 轮流扮演撒玛利亚人。
  • 说：“我要帮助。”

课程重点： 我们甚至帮助那些与我们不同的人。

游戏 2：邻舍圈

玩法：

  • 站成一个圈。
  • 对你左边的孩子说一句友善的话。
  • 依次往下继续。

课程重点： 友善的话语帮助邻舍。
