耶稣在水面上行走

目标

教导孩子们：耶稣怎样向祂的门徒显明祂有神的能力。

经文阅读

约翰福音 6:16-21

背诵经文

没有新的背诵经文

复习到目前为止学过的经文段落。

讲授课程

起点

和全班谈谈人们用来做工的强大机器。也许他们见过平地机、起飞的大型运输机或正在作业的坦克。这些机器的力量那么大，看起来相当吓人！除非你是机械师或工程师，否则你并不真正明白那些力量是从哪里来的。你只是看见这力量能做什么。

课程重点

1. 耶稣是一切能力的源头，因为祂就是神自己。祂在世上的时候，限制了祂神圣的能力。在某些时候，祂用特别的能力作为，教导人们一些关于神的事。

2. 耶稣只用两条鱼和五个饼喂饱了 5 000 人，显出祂神圣的能力之后，祂吩咐门徒们回去，自己却独自走开，向父神祷告。门徒们上了船，驶向湖面。他们还在等耶稣回到他们这里的时候，风暴突然来了（6:16-18）。

3. 描述门徒们看见耶稣在水面上向他们走来时有多么惊恐。出示图片 7。耶稣神迹般的能力使他们害怕。他们不明白（6:19）。

4. 耶稣的话立刻安慰了他们。他们接祂上了船，立刻就离开了风暴，到了目的地（6:20-21）！

我们对这个故事的回应

门徒们看见了耶稣令人敬畏的能力，就害怕了，但祂的话除去了他们的恐惧，他们就被带到了安全的地方。耶稣有能力改变我们的生命，除去我们的恐惧，尽管祂并不总是除去我们所处的危险。扎伊尔有一位将近 90 岁的牧师，经历过战争、饥荒和监禁等许多危险，他常常说：“主是我的帮助者。”他知道这是真的，因为他亲身经历过。

第 7 课：耶稣在水面上行走

经文阅读： 约翰福音 6:16-21

1. 把故事按顺序排好

甲）耶稣说：“不要怕。”
乙）耶稣上山去祷告。
丙）风暴来了，他们看见耶稣在水面上。
丁）门徒们坐船渡过湖面。

👉 正确顺序：

  • 乙）耶稣上山去祷告。
  • 丁）门徒们坐船渡过湖面。
  • 丙）风暴来了，他们看见耶稣在水面上。
  • 甲）耶稣说：“不要怕。”

2. 完成句子

词语框：风暴、害怕、船

  • 门徒们在一条____________上。 __________ 👉 船
  • 一阵强劲的____________刮过湖面。 __________ 👉 风暴
  • 耶稣说：“不要____________。” __________ 👉 害怕

3. 勇敢还是害怕？ 勇/怕

我们信靠耶稣写“勇”，感到害怕写“怕”：

  • 我记得耶稣在黑暗中与我同在。( ___ ) 👉 勇
  • 我认为耶稣已经忘记我了。( ___ ) 👉 怕
  • 我害怕的时候就祷告。( ___ ) 👉 勇

4. 讨论题

  • 门徒们为什么害怕？

参考答案：有一场风暴，他们看见耶稣在水面上行走。

  • 耶稣对他们说了什么？

参考答案：“是我，不要怕！”

  • 你觉得害怕的时候可以做什么？

参考答案：祷告，并记住耶稣与我们同在。

5. 背诵经文：

约翰福音 1:1-2 ——“太初有道，道与神同在，道就是神。这道太初与神同在。”

约翰福音 6:20 ——“是我，不要怕！”

6. 给图画涂色：

手工 1：波浪上的船

材料： 纸、蓝色蜡笔、卡纸、胶水

步骤：

  • 折一只小纸船。
  • 在卡纸上涂出蓝色的波浪。
  • 把船粘在浪花上。
  • 写上：“耶稣与我同在。”

课程重点： 无论遇到什么风暴，耶稣都与我们同在。

手工 2：平静的海瓶

材料： 小瓶子、水、蓝色颜料、一点亮片

步骤：

  • 把瓶子装满水。
  • 加入蓝色颜料和亮片。
  • 盖上盖子摇一摇，然后看着它慢慢沉淀下来。

课程重点： 耶稣有带来平静的能力。

游戏 1：风暴中的海

玩法：

  • 孩子们坐在用绳子或胶带围成的“船”里。
  • 老师说：“风暴来了！”他们就轻轻地摇晃。
  • 老师说“耶稣来了！”的时候，大家都安静平稳地坐着。

课程重点： 耶稣的话除去我们的恐惧。

游戏 2：不要惧怕

玩法：

  • 说出一件可怕的事（黑暗、雷声、狗）。
  • 每说一件，全班就喊：“耶稣与我同在！”
  • 最后做一个简短的祷告。

课程重点： 我们害怕的时候可以信靠耶稣。
