耶稣降生在伯利恒

目标

向孩子们显明：差遣祂的儿子耶稣基督来到这个世界，好让祂向我们显明神真正是怎样的，这是父神的计划。

经文阅读

约翰福音 1:1-14；路加福音 2:1-20

背诵经文

约翰福音 1:1

太初有道，道与神同在……

注：在这一系列的课程中，全班将背诵约翰福音 1:1-14，这段经文见证耶稣是神的儿子。这些课程取自路加福音和约翰福音。

讲授课程

起点

谈谈做计划。你得为你的旅程做计划。雨季出门不好，因为会陷进泥里。你得计划好路线，否则旅程可能会花更长的时间。我们事先计划好，一切就会顺利得多，否则事情就会乱七八糟。

课程重点

1. 父神是一位卓越的计划者。祂计划了整个世界和一切受造之物！祂还使这个世界持续存在。

2. 时候到了，神选择差遣祂的儿子耶稣基督，作为一个人类的婴孩来到这个世界。人们那么容易忘记神，所以我们的天父决定差遣祂的儿子到我们中间来，好让祂向我们显明神真正是怎样的。

3. 耶稣大约在 2 000 年前，生在以色列地的一个马厩里。祂的母亲马利亚是个童女（她从来没有和男人同房）。这意味着耶稣的父亲是独一的真神。这就是为什么耶稣也被称为“神的儿子”。

4. 讲路加福音 2:1-7 的故事：马利亚和约瑟怎样前往伯利恒，耶稣就在那里降生。

5. 天使告诉牧羊人，他们的救主降生了。祂是神的儿子，是主基督。向孩子们解释，基督的意思是“救主”。神天上的天使诗班庆祝这件事（2:8-14）。

6. 牧羊人急忙赶往伯利恒。出示图片 1。他们把所看见的事告诉遇到的每一个人。人们都很惊奇（2:15-20）。

7. 然而，耶稣在以人类婴孩的身份降生到这个世界之前，就已经存在了。祂在时间开始之前，在创造的时候，就与神同在。这就是今天的背诵经文所告诉我们的。

我们对这个故事的回应

在非洲，人们常常有好几个名字。这些名字是出于特别的原因起的。耶稣也有不止一个名字，每个名字都有特别的含义。耶稣来到这个世界，从罪和死亡中拯救我们，是父神的旨意。“救主”这个名字说的就是耶稣的这一点。祂借着祂的话语和行动向我们显明神是怎样的——好让我们爱父、顺服父，正如子所做的那样。

牢记背诵经文

指出这里对耶稣用了另一个名字：“道”。圣经称耶稣为“道”，是因为祂执行父的计划，并把父的信息带给祂的子民。

第 1 课：耶稣降生在伯利恒

经文阅读： 约翰福音 1:1-14；路加福音 2:1-20

1. 把故事按顺序排好

甲）天使把好消息告诉牧羊人。
乙）马利亚和约瑟前往伯利恒。
丙）牧羊人急忙去看那婴孩。
丁）耶稣降生在马厩里。

👉 正确顺序：

  • 乙）马利亚和约瑟前往伯利恒。
  • 丁）耶稣降生在马厩里。
  • 甲）天使把好消息告诉牧羊人。
  • 丙）牧羊人急忙去看那婴孩。

2. 我是谁？

从中选择：马利亚、天使、牧羊人

  • 我说：“救主降生了！”我是谁？ __________ 👉 天使
  • 我是婴孩耶稣的母亲。我是谁？ __________ 👉 马利亚
  • 我看管羊群，并急忙赶往伯利恒。我是谁？ __________ 👉 牧羊人

3. 是还是否？

是写“是”，否写“否”：

  • 神计划差遣耶稣吗？( ___ ) 👉 是
  • 耶稣生在一座大宫殿里吗？( ___ ) 👉 否
  • 耶稣是神的儿子吗？( ___ ) 👉 是

4. 讨论题

  • 神为什么差遣耶稣到世上来？

参考答案：为了拯救我们，并向我们显明神真正是怎样的。

  • 耶稣降生在哪里？

参考答案：在伯利恒的一个马厩里。

  • 我们怎样才能像牧羊人那样传讲这好消息？

参考答案：告诉朋友和家人，耶稣是我们的救主。

5. 背诵经文：

约翰福音 1:1 ——“太初有道，道与神同在……”

路加福音 2:11 ——“今天在大卫的城里，为你们生了救主，就是主基督。”

6. 给图画涂色：

手工 1：伯利恒之星

材料： 黄色卡纸、剪刀、胶水、细绳、蜡笔

步骤：

  • 用黄色卡纸剪出一颗大星星。
  • 用蜡笔装饰它。
  • 写上：“耶稣降生了！”
  • 在顶上系一根细绳，把它挂起来。

课程重点： 神计划在恰当的时候差遣耶稣，我们的救主。

手工 2：马厩场景

材料： 棕色纸、小卡片、蜡笔、胶水

步骤：

  • 把棕色纸折成一个小马厩。
  • 在卡片上画马利亚、约瑟和婴孩耶稣。
  • 把他们立在马厩里面。

课程重点： 耶稣作为一个小婴孩来到我们身边。

游戏 1：牧羊人赶路

玩法：

  • 画一条起跑线和一条“伯利恒”线。
  • 喊“开始！”，牧羊人就快步（不许跑）走向伯利恒。
  • 到了线上，每个孩子低声说：“耶稣降生了！”

课程重点： 牧羊人急忙去看耶稣，并告诉了每一个人。

游戏 2：传消息

玩法：

  • 围坐成一圈。
  • 对你旁边的人低声说“耶稣是我们的救主”。
  • 最后一个孩子大声说出来。

课程重点： 神的好消息是让每个人分享的。
