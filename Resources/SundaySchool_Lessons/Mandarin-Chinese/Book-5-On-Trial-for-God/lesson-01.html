乃缦拜访以利沙

目标

向孩子们说明：我们不能倚靠自己的重要地位来到神面前。

经文阅读

列王纪下 5:1-12

背诵经文

出埃及记 20:1-2

神吩咐这一切的话，说：“我是耶和华你的神……”

注：在这一系列的课程中，孩子们将学习十诫（出埃及记 20:1-17）。

讲授课程

起点

人们为自己的国家感到自豪。例如，如果你来自澳大利亚，你会因为知道它是世界上最大的岛屿而自豪。想一想有哪些事使你为自己的国家感到自豪。

课程重点

1. 乃缦为自己的国家叙利亚感到非常自豪。那是一个重要的国家，有一座美丽的首都大马士革，还有一些美丽的河流使土地肥沃。他也为自己作叙利亚军队的元帅而非常自豪，这支军队打过许多胜仗。乃缦自豪的是，叙利亚王很看重他（列王纪下 5:1上）。

2. 但有一件事乃缦并不自豪。他患了大麻风。在那个时代，这种皮肤病没有医治的方法，即使在叙利亚这样先进富裕的国家也没有（5:1下）。

3. 乃缦的妻子有一个使女，来自邻近贫穷的以色列国。她被认为是乃缦家中最不重要的成员之一，但她知道她的主人在哪里可以得到帮助。她告诉她的女主人，有一位以色列的神的先知能医治大麻风（5:2-3）。

4. 乃缦的妻子把这事告诉他时，他就向叙利亚王告假，前往以色列去拜访这位先知。他带了许多贵重的礼物（叙利亚是个富国，乃缦又是个重要人物）。他还带了一封王亲笔写的信，信上说明乃缦是谁，并吩咐收信的人医治他的好臣仆乃缦（5:4-6）。

5. 然而，骄傲的乃缦元帅去求助的人找错了。他和他的王认为他应该去见以色列王，而不是什么先知。以色列王读了那封信，就非常忧愁，因为他无法医治乃缦的大麻风。他怕如果得罪了叙利亚王，叙利亚人就有借口再次攻打以色列（5:7）。

6. 神的先知以利沙听说了所发生的事，就吩咐以色列王把乃缦送到他简陋的家里来。以利沙才是靠着神的能力能医治乃缦的人（5:8）。

7. 出示图片 1。请指出乃缦看起来多么生气。先知以利沙选择不接见乃缦，也不收他的任何礼物。他只是差他的仆人出去见这位重要的元帅，带去了一些听起来像开玩笑的指示：乃缦要在约旦河里洗七次。这位骄傲的叙利亚军人看不起以色列这个小国，并为以利沙简单的建议和缺乏敬意而感到受了冒犯。他怒气冲冲地拒绝照这些指示去做……他的大麻风仍然没有好（5:9-12）。

我们对这个故事的回应

先知以利沙为什么不像人们所预料的那样，带着极大的尊敬欢迎乃缦？

他为什么只差一个仆人，把这些看起来很荒唐的指示带给这位重要人物？

以利沙要让乃缦看到，他重要的国家、他的财富和他的地位，在以色列的神面前算不得什么。只有当乃缦不再倚靠自己的能力和权势时，神才会医治他。他的骄傲拦阻了他领受神的祝福。

我们有时太骄傲于自己能做的事，这会拦阻我们领受神的祝福。

在下一课中，我们将看到乃缦怎样学到了这个真理。

第 1 课：乃缦拜访以利沙

经文阅读： 列王纪下 5:1-12

1. 我是谁？

从中选择：乃缦、以利沙、使女

  • 我是叙利亚军队的元帅，但我患了大麻风。我是谁？ __________ 👉 乃缦
  • 我告诉我的女主人，以色列有一位先知。我是谁？ __________ 👉 使女
  • 我差我的仆人去告诉乃缦在约旦河里洗。我是谁？ __________ 👉 以利沙

2. 是还是否？

对的写“是”，不对的写“否”：

  • 乃缦为他的国家和他的工作感到自豪吗？( ___ ) 👉 是
  • 乃缦先去见以色列王吗？( ___ ) 👉 是
  • 乃缦对以利沙的建议感到高兴吗？( ___ ) 👉 否

3. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 乃缦要在约旦河里洗几次？
    甲）三次 乙）七次 丙）十次 👉 乙）七次
  • 什么拦阻乃缦领受神的祝福？
    甲）他的骄傲 乙）他的马 丙）他的饥饿 👉 甲）他的骄傲

4. 讨论题

  • 你认为乃缦为什么生气？

参考答案：他很骄傲，期望以利沙把他当作重要人物对待。

  • 以利沙为什么差一个仆人，而不亲自出来？

参考答案：祂要乃缦明白，他的财富和地位在神面前算不得什么。

  • 骄傲会拦阻我们做什么？

参考答案：它会拦阻我们听从神，也拦阻我们领受祂的祝福。

5. 背诵经文：

出埃及记 20:1-2 ——“神吩咐这一切的话，说：‘我是耶和华你的神，曾把你从埃及地、从为奴之家领出来。’”

箴言 16:18 ——“骄傲在败坏以先，狂心在跌倒之前。”

6. 给图画涂色：

手工 1：乃缦的战车

材料： 纸、蜡笔、剪刀、胶水、一个小盒子

步骤：

  • 在纸上画一辆战车和一匹马，并把它们剪下来。
  • 把它们涂上鲜艳的颜色，像元帅的战车一样。
  • 把战车粘在盒子上。
  • 写上：“神比我的骄傲更大。”

课程重点： 我们的地位和财富不能使神动心。

手工 2：约旦河图画

材料： 蓝色纸、棕色纸、胶水、蜡笔

步骤：

  • 把蓝色纸撕成一条弯弯曲曲的河。
  • 把它粘在棕色纸上。
  • 画上乃缦站在河边。
  • 写上：“听从并顺服。”

课程重点： 神的方法看起来也许简单，但那是正确的方法。

游戏 1：骄傲地走，谦卑地走

玩法：

  • 让孩子们像骄傲的重要人物一样走过房间。
  • 然后让他们像谦卑的仆人一样走。
  • 问问哪一种走法会使神喜悦。

课程重点： 神喜悦谦卑的心。

游戏 2：传话

玩法：

  • 让孩子们排成一排，把一句简短的话轻声传给下一个孩子。
  • 最后一个孩子大声说出来。
  • 谈谈使女的话怎样帮助了乃缦。

课程重点： 即使是最小的人，也能帮助别人找到神。
