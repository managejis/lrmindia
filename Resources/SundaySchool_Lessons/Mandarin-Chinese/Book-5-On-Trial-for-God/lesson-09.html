约拿在尼尼微

目标

向孩子们说明：神饶恕那些悔改并归向祂得救的人。

经文阅读

约拿书 3:1-10；马太福音 12:40-41

背诵经文

出埃及记 20:7

（十诫）“不可妄称耶和华你神的名；因为妄称耶和华名的，耶和华必不以他为无罪。”

注：复习上周的背诵经文，并在本周完成第 7 节。

讲授课程

起点

播种的季节来临时，农夫们都在寻找下雨的迹象。雨停了之后，太阳可能烈得把种子或小苗晒死。有时雨又来了，农夫们就再播种一些。他们得到了第二次机会，也能得到收成。

课程重点

1. 神第二次要约拿去向尼尼微人传道。这一次约拿去了（约拿书 3:1-3）。

2. 约拿警告那座庞大而邪恶的城里的人要转回归向神，否则四十天后他们的城就要被毁灭（3:4）。

3. 约拿从神那里带来的信息对尼尼微人产生了极大的影响。他们相信了先知对他们说的话，并为自己所做的恶感到悔恨。王带领他的百姓改变行为。他们脱下华丽的衣服，禁食，好使他们能专心向神祷告（3:5-9）。出示图片 9。左边的约拿站着，向悔改的尼尼微人传道。

4. 神看见百姓悔恨，并且改变了他们的行为，而不只是改变了衣服。所以神没有因他们所做的恶惩罚他们（3:10）。悔改的意思不仅是为你所做的事难过，还要改变你的生活方式，不再回到你从前的恶行中去。

我们对这个故事的回应

我们有时就像尼尼微人。我们忘记神和祂的诫命，违背主。我们所能做的，只有悔改，并呼求神向我们施怜悯。

耶稣预言祂将要死，并在坟墓的黑暗里度过三天时，祂用了约拿的例子，约拿曾在鱼肚子的黑暗里度过三天（马太福音 12:40）。尼尼微人是我们的榜样。像他们一样，我们应当受惩罚。我们需要转向神，并感谢神赐下耶稣，祂借着死和复活，为我们带来了永生。祂就是马太福音 12:41 所说的“比约拿更大的”。

如果你在外面玩得身上很脏，你可以只换衣服，但除非你也洗了身体，你还是不干净。同样，要有真正的悔改，你需要告诉神你很抱歉，并改变你的生活方式。一旦你经历了神在耶稣基督里向你显明的爱，你就会想要讨祂喜悦，并转身离弃邪恶（哥林多后书 5:17）。

牢记背诵经文

尼尼微人改变了，并想要遵守神的诫命。他们明白了这节经文的警告，并认真地对待它。

复习到目前为止所学的出埃及记 20 章的所有经文。

第 9 课：约拿在尼尼微

经文阅读： 约拿书 3:1-10；马太福音 12:40-41

1. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 约拿说尼尼微还剩多少天？
    甲）4 乙）14 丙）40 👉 丙）40
  • 尼尼微人做了什么？
    甲）他们说对不起，并改变了 乙）他们嘲笑 丙）他们逃跑了 👉 甲）他们说对不起，并改变了
  • 谁是“比约拿更大的”？
    甲）王 乙）耶稣 丙）以利沙 👉 乙）耶稣

2. 圈出正确的词语

圈出正确的词：

  • 神给了约拿（第一次 / 第二次）机会。 👉 第二次
  • 悔改的意思是说对不起并（改变 / 躲藏）。 👉 改变
  • 神（惩罚了 / 饶恕了）尼尼微。 👉 饶恕了

3. 是还是否？

对的写“是”，不对的写“否”：

  • 约拿第二次顺服神了吗？( ___ ) 👉 是
  • 我们真心悔改时，神会饶恕吗？( ___ ) 👉 是
  • 换衣服就足以使内心洁净吗？( ___ ) 👉 否

4. 讨论题

  • 尼尼微王和他的百姓做了什么？

参考答案：他们停止了错误的行为，并向神祷告。

  • 他们悔改时，神怎样对待他们？

参考答案：祂施行怜悯，没有惩罚他们。

  • 我们做错了事时应该怎么做？

参考答案：向神说对不起，并改变我们的行为。

5. 背诵经文：

出埃及记 20:7 ——“不可妄称耶和华你神的名；因为妄称耶和华名的，耶和华必不以他为无罪。”

约翰一书 1:9 ——“我们若认自己的罪，神是信实的，是公义的，必要赦免我们的罪。”

6. 给图画涂色：

手工 1：道歉和改变卡

材料： 对折的纸、蜡笔

步骤：

  • 在封面上画一张悲伤的脸。
  • 里面画一张快乐的脸。
  • 写上：“我很抱歉。我会改变。”

课程重点： 悔改就是说对不起并且改变。

手工 2：尼尼微城墙

材料： 棕色的纸、剪刀、胶水、蜡笔

步骤：

  • 用棕色纸剪出砖块的形状。
  • 把它们粘起来，形成一道墙。
  • 在里面画上正在祷告的人。
  • 写上：“神饶恕了尼尼微。”

课程重点： 神饶恕那些转向祂的人。

游戏 1：转过身来

玩法：

  • 孩子们朝一个方向走。
  • 老师说“悔改！”时，他们就转身朝另一个方向走。
  • 谈谈为神改变方向。

课程重点： 悔改就是转向神。

游戏 2：第二次机会

玩法：

  • 给每个孩子一个球，投进篮子里。
  • 如果没投中，他们可以再试一次。
  • 谈谈神赐的第二次机会。

课程重点： 我们悔改时，神再给我们一次机会。
