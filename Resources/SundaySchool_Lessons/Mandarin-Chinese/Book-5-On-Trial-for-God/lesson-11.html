末底改拒绝不忠

目标

向孩子们说明：末底改怎样在外邦之地，即使面临极大的压力，仍然忠于神的诫命。

经文阅读

以斯帖记 3:1-15；4:1-17

背诵经文

出埃及记 20:8

（十诫）“当记念安息日，守为圣日。”

讲授课程

起点

想一想有重要人物来访问你们教会或城镇的时候。每个人总是想讨他们喜欢，给他们提供最舒适的住处，用最好的食物招待他们。这些来访的人中有一些非常和蔼可亲，但另一些可能非常骄傲。

课程重点

1. 亚哈随鲁王任命了一位新的宰相，名叫哈曼。哈曼走过的时候，王命令所有的人都要向他下拜，表示尊敬（以斯帖记 3:1-2上）。这使他非常骄傲。故事的这一部分可以演出来，由班上一位同学扮演哈曼，其余的人在他或她走过时向他下拜。

2. 王的臣仆当中，只有一个人拒绝向别人下拜。那就是末底改。为什么呢？对犹太人来说，向某人下拜就意味着你在敬拜他或她。让全班一起背诵第二条和第三条诫命（出埃及记 20:3-5上）。末底改拒绝向他下拜，使哈曼非常愤怒（3:2下-5）。出示图片 11。班上同学也可以把故事的这一部分演出来。

3. 哈曼决意向末底改报仇。他对王说，王所统治的民族中有一族人不遵守国家的法律。哈曼想要王允许他毁灭这整个民族。他甚至答应，只要王准许，他就给王一大笔钱。亚哈随鲁王什么也没问，就答应了（3:6, 8-11）。

4. 哈曼下了命令，叫人在全国各处宣告，在某一天，所有的犹太人都要被杀。王不知道他的王后以斯帖就属于这个民族（3:12-15）。

5. 末底改惊恐万分。他穿着显出悲哀的衣服走来走去。以斯帖王后听说了这事，就送新衣服给他。他不肯接受，并请她去见亚哈随鲁王，为她族人的性命恳求（4:1-8）。

6. 以斯帖回信说明，如果有人没有被召就进去见王，就会被处死。唯一的例外是王向那人伸出他的权杖，表示要留那人的性命（4:9-11）。出示图片 10。指出王手里的权杖。这根金杖是王权柄的象征。

7. 末底改回答，提醒以斯帖，她也是犹太人。虽然她是王后，住在王宫里，她仍然会与她的族人一同被杀。但他又说，也许神把她安置在这个位置，正是为了能够帮助祂的子民（4:12-14）。

8. 以斯帖答应去见王，但她请犹太人帮助她。在这之前的三天，他们要禁食祷告，求亚哈随鲁王接纳她，留她的性命（4:15-17）。

我们对这个故事的回应

末底改即使在非常危险的时候，仍然忠于神。他知道神比所有反对他的势力都更大。

在非洲的某个国家，有人向一位教会领袖施压，要他否认对基督的信仰。军队闯进他的圣经学院搜捕他时，他躲在一条盖着树叶的深沟里，躲了整整一夜。

士兵们从沟上走过，没有发现他。神把他隐藏起来，使他免受伤害，他又活了许多年，讲述他天父的看顾和保护。

你相信神关心你吗？

第 11 课：末底改拒绝不忠

经文阅读： 以斯帖记 3:1-15；4:1-17

1. 连线配对

A

B

哈曼

想要每个人向他下拜

末底改

只向神下拜

以斯帖

答应去见王

金权杖

表明她的性命被留下了

答案：
哈曼 → 想要每个人向他下拜
末底改 → 只向神下拜
以斯帖 → 答应去见王
金权杖 → 表明她的性命被留下了

2. 完成句子

词语框：祷告、下拜、忠心

  • 末底改对神____________。 __________ 👉 忠心
  • 他不肯向哈曼____________。 __________ 👉 下拜
  • 犹太人为以斯帖禁食并____________。 __________ 👉 祷告

3. 对还是错？

对的写“对”，错的写“错”：

  • 只敬拜神，即使很难。( ___ ) 👉 对
  • 即使是错的，也照别人说的去做。( ___ ) 👉 错
  • 请别人为我祷告。( ___ ) 👉 对

4. 讨论题

  • 末底改为什么不向哈曼下拜？

参考答案：下拜就像是敬拜他，而他只敬拜神。

  • 末底改请以斯帖做什么？

参考答案：去见王，为她的族人恳求。

  • 什么时候做对的事很难？

参考答案：当朋友或别人要我们做错事的时候。

5. 背诵经文：

出埃及记 20:8 ——“当记念安息日，守为圣日。”

使徒行传 5:29 ——“顺从神，不顺从人，是应当的。”

手工 1：只向神下拜海报

材料： 纸、蜡笔

步骤：

  • 画上昂首站立的末底改。
  • 画上哈曼和其他下拜的人。
  • 写上：“我只敬拜神。”

课程重点： 我们只敬拜神。

手工 2：金权杖

材料： 纸筒、金色纸、胶水、星星贴纸

步骤：

  • 用金色纸把纸筒包起来。
  • 在顶部粘上一颗星星。
  • 在侧面写上：“神拯救。”

课程重点： 神看顾以斯帖和她的族人。

游戏 1：昂首站立

玩法：

  • 老师念出要尊敬的人的名字时，大家都站着。
  • 老师说“神”时，大家都跪下。
  • 谈谈只用敬拜来尊崇神。

课程重点： 唯有神配得我们的敬拜。

游戏 2：为以斯帖祷告

玩法：

  • 孩子们围成一圈坐下。
  • 每人为一个需要勇气的人说一句简短的祷告。
  • 最后一起说“阿们”。

课程重点： 我们可以为别人祷告。
