尼希米在大王面前

目标

向孩子们说明：神怎样应允了尼希米的祷告。

经文阅读

尼希米记 1:1-11；2:1-9

背诵经文

出埃及记 20:13

（十诫）“不可杀人。”

讲授课程

起点

你有没有试过把消息藏在心里？如果是好消息，你得小心，不要让喜悦在脸上或行为上显露出来。坏消息要藏在心里就困难得多。

课程重点

1. 尼希米听到了一个非常坏的消息。他是一个信靠神的犹太人。他是在但以理之后一段时间，在巴比伦作奴隶。有人给尼希米带来消息，说他祖先的京城耶路撒冷成了一片废墟，住在那里的人正经历极大的艰难（尼希米记 1:1-3）。

2. 尼希米把他的忧伤带到神面前，祷告。他敬拜神，并提醒神祂对以色列的应许。他承认他的百姓的罪，他们背弃了神。最后，他求神帮助他，得到强大的亚达薛西王的协助。尼希米这样祷告了好几个月（1:4-11）。

3. 尼希米是那位外邦王所信任的仆人。他的工作是在王喝酒之前先尝一尝，以防酒里有毒。在王面前，谁也不许面带愁容。出示图片 19，并描述尼希米怎样走近王（2:1-4上）。

4. 尼希米回答亚达薛西王的问话之前，先默默向神祷告。他已准备好他的请求：请求准许他去耶路撒冷，并请求建筑材料。在他之前花在祷告上的时间里，尼希米已经作了周详的计划。于是神应允了尼希米的祷告，亚达薛西准了他的请求。王还派了士兵同去，在路上保护尼希米（2:4下-9）。

我们对这个故事的回应

你们当中有些人可能是六岁。一群美国基督徒已经为非洲的桑达维人祷告了这么久，求他们能听到神的话语。神应允了他们的祷告——那里建立了一间小教会。最先相信的人当中有一位中年男子。他来到宣教士的家，拿出两本小小的基督教小册子，他已经读了一个月了。他说：“我守着这两本小书已经两个月了，读了又读。我和我的妻子谈过这些书。现在我来到这里，是要得救。”（资料来源：AIM International。）

神垂听并应允了尼希米的祷告。神今天仍然垂听并应允祷告。

第 19 课：尼希米在大王面前

经文阅读： 尼希米记 1:1-11；2:1-9

1. 我是谁？

从中选择：尼希米、亚达薛西、神

  • 我尝王的酒，并为耶路撒冷忧伤。我是谁？ __________ 👉 尼希米
  • 我是准许尼希米前去的王。我是谁？ __________ 👉 亚达薛西
  • 我应允了尼希米的祷告。我是谁？ __________ 👉 神

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 尼希米听到了什么坏消息？
    甲）耶路撒冷成了废墟 乙）王病了 丙）一条船失踪了 👉 甲）耶路撒冷成了废墟
  • 尼希米对王说话之前做了什么？
    甲）他逃跑了 乙）他默默祷告 丙）他唱歌 👉 乙）他默默祷告

3. 对还是错？

对的写“对”，错的写“错”：

  • 把我的忧伤带到神面前祷告。( ___ ) 👉 对
  • 祷告之后制定一个好的计划。( ___ ) 👉 对
  • 以为神没有垂听我。( ___ ) 👉 错

4. 讨论题

  • 尼希米听到坏消息时做了什么？

参考答案：他向神祷告了好几个月。

  • 王给了尼希米什么？

参考答案：准许他前去、建筑材料，以及保护他的士兵。

  • 神垂听并应允我们的祷告吗？

参考答案：会，以祂自己的方式和时间。

5. 背诵经文：

出埃及记 20:13 ——“不可杀人。”

马太福音 7:7 ——“你们祈求，就给你们；寻找，就寻见。”

6. 给图画涂色：

手工 1：祷告日志

材料： 对折的纸、订书机或细绳、蜡笔

步骤：

  • 把纸折成一本小册子。
  • 在封面上写上：“我的祷告”。
  • 在里面画上一件要为之祷告的事。

课程重点： 我们祷告时，神垂听。

手工 2：废墟之城图画

材料： 纸、蜡笔、棕色纸

步骤：

  • 用棕色纸画出残破的城墙。
  • 加上正在祷告的尼希米。
  • 写上：“主啊，求你帮助我们。”

课程重点： 尼希米把他的忧伤带到神面前。

游戏 1：传祷告

玩法：

  • 孩子们排成一队站着。
  • 每人为一个朋友轻声说一句简短的祷告。
  • 最后一个人大声说“阿们”。

课程重点： 我们可以为别人祷告。

游戏 2：笑脸，哭脸

玩法：

  • 老师读一段故事。
  • 孩子们做出快乐或悲伤的表情。
  • 然后一起为悲伤的部分祷告。

课程重点： 神关心我们的感受。
