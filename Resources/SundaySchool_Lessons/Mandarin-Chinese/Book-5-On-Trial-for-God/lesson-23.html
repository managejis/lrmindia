耶稣至死忠心

目标

向孩子们说明：这些大信心人物的故事怎样指向神的儿子耶稣，祂至死忠心。

经文阅读

马太福音 27:27-56；罗马书 5:8-10

背诵经文

出埃及记 20:17

（十诫）“不可贪恋人的房屋；也不可贪恋人的妻子、仆婢、牛驴，并他一切所有的。”

讲授课程

起点

如果你在一座城里走一走，会看到一些告示，告诉你各种东西在哪里，比如教会或办公楼。有时这些告示做成箭头的形状，指向某个特定地方的方向。

课程重点

1. 这本书里的课程，讲的是信心的伟大男女：以利沙、约拿、以斯帖、但以理和他的三个朋友，以及尼希米。由于人类的罪，他们都必须克服巨大的困难和问题。他们都指向神。以利沙和约拿是先知。他们的工作是教导人认识神，并向他们指明认识神的道路。但人很容易忘记神和祂的诫命。还记得以斯拉向百姓宣读神的律法时，他们多么难过和羞愧吗？

2. 最后，时候到了，神差遣了祂的独生子耶稣基督，来向我们显明神是怎样的。耶稣自己就是神。祂来到这个世界，是要向我们显示怎样生活，好让别人在我们的生命中看见神。神多次救以利沙和但以理脱离死亡，但耶稣自己却愿意为我们而死。

3. 耶稣被捕，被判处死在十字架上，这是一种非常残酷而缓慢的死法。他们说耶稣所犯的罪，是自称为犹太人的王。因此，罗马总督的士兵给耶稣穿上王的衣服，嘲弄祂，打祂。还记得第 21 课中，犹太人的仇敌在他们重建城墙时嘲笑他们吗？耶稣本可以制止那些嘲弄祂的人，但祂没有（马太福音 27:27-31）。

4. 耶稣挂在十字架上，拒绝喝那能减轻痛苦的酒。祂正在为我们的罪承受全部的刑罚。围观的人嘲弄耶稣。他们说，如果祂真是神的儿子，就应该从十字架上救自己下来，证明给他们看。他们不明白，耶稣留在那里，是因为祂爱我们，并要我们所有的人都得救（马太福音 27:34, 37-43；罗马书 5:6-9）。

5. 正午的时候，遍地都黑暗了。太阳变黑，因为神的儿子正在为世人而死（马太福音 27:45）。下午三点，耶稣死了。祂是甘心舍去自己的生命。人在死的时候通常是虚弱的，但请注意，圣经说耶稣在那一刻大声喊叫（27:46-50）。耶稣死的时候，耶路撒冷城里发生了许多奇怪的事（27:51-52）。

6. 在那里看守的士兵都非常害怕。至少有一个人意识到，耶稣不是一个普通的人。出示图片 23。那位罗马士兵承认说：“祂真是神的儿子！”（27:54）。

7. 当然，耶稣现在不再挂在十字架上了。祂真的死了，但祂从死里复活了。在耶稣回到父那里之前，有许多见证人看见了祂（28:1-20）。

我们对这个故事的回应

耶稣死的时候，有许多人从旁边走过，或站着观看。让我们想一想有谁在那里。那些嘲笑祂的士兵，其他嘲弄祂的人，还有人群中那些因耶稣没有行神迹、从十字架上下来而失望的人。然而，有一个士兵最后相信了耶稣真是神的儿子。

借着祂在十字架上的牺牲，耶稣为我们的罪带来了饶恕。我们可以从神的仇敌，变成神的朋友。向孩子们读罗马书 5:7-11。这是多么奇妙的改变！来，让我们为此感谢神。

第 23 课：耶稣至死忠心

经文阅读： 马太福音 27:27-56；罗马书 5:8-10

1. 我是谁？

从中选择：耶稣、一位罗马士兵、以利沙

  • 我爱你们到为你们而死。我是谁？ __________ 👉 耶稣
  • 我看见所发生的事，就说：“祂真是神的儿子！”我是谁？ __________ 👉 一位罗马士兵
  • 我是一位先知，把人指向神。我是谁？ __________ 👉 以利沙

2. 是还是否？

对的写“是”，不对的写“否”：

  • 耶稣死是为了饶恕我们的罪吗？( ___ ) 👉 是
  • 耶稣仍然是死的吗？( ___ ) 👉 否
  • 我们能成为神的朋友吗？( ___ ) 👉 是

3. 完成句子

词语框：爱、复活、罪

  • 耶稣为我们的____________而死。 __________ 👉 罪
  • 耶稣从死里____________了。 __________ 👉 复活
  • 祂这样做，是因为祂极大的____________。 __________ 👉 爱

4. 讨论题

  • 耶稣为什么留在十字架上？

参考答案：因为祂爱我们，并要拯救我们。

  • 耶稣死后，那位士兵说了什么？

参考答案：“祂真是神的儿子！”

  • 今天我们可以对耶稣说什么？

参考答案：谢谢你为我而死。

5. 背诵经文：

出埃及记 20:17 ——“不可贪恋人的房屋，也不可贪恋人一切所有的。”

罗马书 5:8 ——“惟有基督在我们还作罪人的时候为我们死，神的爱就在此向我们显明了。”

6. 给图画涂色：

手工 1：十字架卡片

材料： 对折的卡纸、蜡笔、棕色纸

步骤：

  • 把两条棕色纸条粘成一个十字架。
  • 写上：“耶稣爱我。”
  • 用花朵装饰卡片。

课程重点： 耶稣爱我们，爱到为我们而死。

手工 2：空坟墓的场景

材料： 灰色纸、胶水、蜡笔、一块石头形状的纸

步骤：

  • 在灰色纸上画一座坟墓。
  • 在旁边粘上一块石头。
  • 写上：“祂复活了！”

课程重点： 耶稣从死里复活了。

游戏 1：感谢耶稣圈

玩法：

  • 孩子们围成一圈坐下。
  • 每人说一件他们为之感谢耶稣的事。
  • 最后唱一首感谢的歌。

课程重点： 我们为耶稣的爱感谢祂。

游戏 2：指路的箭头

玩法：

  • 做一些写着“耶稣”的箭头路标。
  • 把它们藏在房间各处。
  • 孩子们跟着它们找到一幅耶稣的图画。

课程重点： 所有这些故事都指向耶稣。
