四个麻风病人成了报好消息的人

目标

向孩子们说明：神赐下拯救时，我们需要把它分享给别人。

经文阅读

列王纪下 7:3-20

背诵经文

出埃及记 20:5

（十诫）“不可跪拜那些（别的神），也不可侍奉它，因为我耶和华你的神是忌邪的神，恨我的，我必追讨他的罪，自父及子，直到三四代……”

注：复习上周的背诵经文，并在本周完成第 5 节。

讲授课程

起点

人们得到好消息时会怎样？给孩子们时间回答。他们会四处奔跑，赶快把消息告诉他们能找到的每一个人。你可以用一出小短剧来演示。找三四个人来演，事先要练习！

课程重点

1. 今天的故事讲的是四个人，他们把一个好消息分享给别人。不过，故事一开始，他们还处在悲惨之中。他们患了大麻风，而大麻风病人不许与别人接触，因为这病传染得非常快。在撒玛利亚被围困期间，这些人被关在城外。出示图片 5，并用它来复习第 5 课的故事。麻风病人商量这件事，最后决定不如到叙利亚人的营里去讨饭（列王纪下 7:3-4）。他们出发时是傍晚。

2. 与此同时，叙利亚人听见一阵巨大的响声，好像有一支大军来了。这使他们非常害怕，就逃跑了，把一切都丢在后面。神使强大的叙利亚军队落荒而逃（7:6-7）！

3. 四个麻风病人到了营里，发现一个人也没有。他们惊讶极了。出示图片 6。描述他们怎样从一个帐棚走到另一个帐棚，想拿什么就拿什么（7:5, 8）。

4. 然后，这四个麻风病人忽然想起城里撒玛利亚仍在挨饿的所有人。他们知道，必须把叙利亚人已经离开的好消息告诉城里的人。虽然是夜里，他们还是赶紧回到撒玛利亚，向守城门的人喊出这个消息，守门的人又把好消息传开了（7:9-10）。

5. 王甚至起床来听报告，但他以为这是叙利亚人的诡计，要骗百姓离开安全的城墙。他派了几个人去查看发生了什么事。他们发现，四个麻风病人的话是真的（7:12-15）。

6. 不久，撒玛利亚的百姓就以极低的价钱出售从叙利亚营里得来的食物，正如神借着以利沙所应许的。参看第 5 课。神照着祂自己的计划拯救了以色列（7:16）。

7. 但是，王那不信的军官，正如以利沙所预言的，没有活着分享这喜乐。参看第 5 课。挨饿的百姓涌向食物时，他被踩死了（7:17-20）。

我们对这个故事的回应

非洲的一座城曾经严重缺乏食物，飞机把一包包粮食空投给人们。一位年老的妇人走出城外，走了好几公里去捡柴火。这样做很危险，因为那里有地雷。忽然，她看见一大堆粮食。她简直不敢相信自己的眼睛。她环顾四周，看是不是有人在跟她开玩笑，但这只是一些没有落在空投区的粮食。她赶紧回到城里，尽量多背了一些粮食。

她走到哪里，就把她找到的东西给人们看。大家都分享了这份好运，并赞美神供应他们。

我们可以信靠神。祂必按着

祂的计划供应，正如撒玛利亚的百姓和非洲这座城的百姓所发现的。

神完美而完全的供应，是借着祂儿子

耶稣基督的牺牲，拯救人脱离罪（罗马书 5:8）。这是我们真该与遇见的每一个人分享的好消息！

第 6 课：四个麻风病人成了报好消息的人

经文阅读： 列王纪下 7:3-20

1. 把故事按顺序排好

甲）他们到叙利亚人的营里，发现营里空了。
乙）他们把好消息告诉了守门的人。
丙）四个患大麻风的人坐在城门外。
丁）他们想起了撒玛利亚挨饿的人。

👉 正确顺序：

  • 丙）四个患大麻风的人坐在城门外。
  • 甲）他们到叙利亚人的营里，发现营里空了。
  • 丁）他们想起了撒玛利亚挨饿的人。
  • 乙）他们把好消息告诉了守门的人。

2. 是还是否？

对的写“是”，不对的写“否”：

  • 这些人把食物和消息留给了自己吗？( ___ ) 👉 否
  • 是神使叙利亚人逃跑的吗？( ___ ) 👉 是
  • 王立刻相信了这个消息吗？( ___ ) 👉 否

3. 数一数，写下来

写出数字：

  • 有几个患大麻风的人发现了空营？ ____ __________ 👉 4
  • 多少公斤粮食只卖一个银币？ ____ __________ 👉 3
  • 以利沙说食物在多少小时之内会变便宜？ ____ __________ 👉 24

4. 讨论题

  • 这四个人为什么回到城里去？

参考答案：他们知道挨饿的人需要听到这个好消息。

  • 撒玛利亚的食物价格发生了什么变化？

参考答案：食物变得丰富而便宜，正如神借着以利沙所应许的。

  • 我们能分享的最好的好消息是什么？

参考答案：耶稣为拯救我们脱离罪而死。

5. 背诵经文：

出埃及记 20:5 ——“不可跪拜它们，也不可侍奉它们，因为我耶和华你的神是忌邪的神。”

马可福音 16:15 ——“你们往普天下去，传福音给万民听。”

6. 给图画涂色：

手工 1：好消息卷轴

材料： 纸、铅笔或小棍、蜡笔、细绳

步骤：

  • 把一张纸卷在小棍上。
  • 展开后写上：“好消息！”
  • 画一个空帐棚和一座欢乐的城。
  • 用细绳系起来。

课程重点： 我们应当把好消息与每个人分享。

手工 2：传话的扩音筒

材料： 卡纸、蜡笔、胶带

步骤：

  • 把卡纸卷成圆锥形，用胶带粘住。
  • 用鲜艳的颜色装饰。
  • 写上：“耶稣拯救！”

课程重点： 我们可以把耶稣告诉别人。

游戏 1：跑去告诉

玩法：

  • 在房间的一端放一张写着喜乐信息的卡片。
  • 一个孩子走过去，读了卡片，再走回来告诉其他孩子。
  • 轮流用不同的信息。

课程重点： 好消息是要用来分享的。

游戏 2：寻找空帐棚

玩法：

  • 在房间里到处藏一些剪出来的小面包。
  • 孩子们找到它们，把它们送到一个“城”的篮子里。
  • 说：“神供应我们所有的人！”

课程重点： 神供应，我们把祂所赐的分享出去。
