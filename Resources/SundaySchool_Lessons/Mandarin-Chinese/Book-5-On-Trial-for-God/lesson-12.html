以斯帖的筵席

目标

向孩子们说明：神怎样垂听祂子民的祷告。

经文阅读

以斯帖记 5:1-14；7:1-10；9:1-4

背诵经文

出埃及记 20:9-10

（十诫）“六日要劳碌作你一切的工，但第七日是向耶和华你神当守的安息日；这一日你无论何工都不可作……”

讲授课程

起点

你真正害怕的时候是什么感觉？建议的回答：嘴巴发干，觉得肚子里好像有一个大疙瘩，膝盖甚至可能在打战。

课程重点

1. 以斯帖王后要做一件非常危险的事，但所有的犹太人都在为她祷告。她必须去见王，尽管王没有召她。正如我们上次所看到的，这可能意味着她要死，除非王向她伸出金权杖（以斯帖记 4:16）。

2. 描述以斯帖怎样把自己打扮得美美的，去见亚哈随鲁王。王果然向她伸出了权杖；事实上，他见到她非常高兴（5:1-3）！出示图片 10。

3. 以斯帖很有智慧，没有把她的大难题告诉王。她只是邀请王和他的宰相哈曼，去赴她为他们预备的筵席。王立刻答应了（5:4-5）。他们吃喝尽兴之后，以斯帖请他们第二天晚上再来（5:6-8）。

4. 哈曼受邀与王和王后一同赴宴，感到非常自豪。他到处夸耀。但他想起末底改，虽然他自己那么重要，末底改仍然不肯向他下拜，他的喜乐就变成了愤怒。于是哈曼和他的家人树起一座特别的绞架，高如城墙，等到杀所有犹太人的那一天来到，就把末底改吊在上面（5:9-14）。

5. 在第二次筵席上，王又问：“以斯帖王后，你要什么？你要求什么，就是国的一半也必赐给你。”

下面的经文，以斯帖记 7:1-6，非常富有戏剧性。把对话的话语背下来，由人扮演亚哈随鲁王和以斯帖王后，把它演出来。提醒全班，以斯帖是犹太人。她是在为她族人的性命，也为自己的性命恳求。出示图片 12。

6. 王听到哈曼的恶计，非常愤怒。他意识到哈曼欺骗了他。哈曼被吊在他为末底改所造的绞架上，犹太人就得救了（7:7, 9-10；9:1-4）。神在以斯帖艰难的任务中与她同在，并垂听了祂子民的祷告。今天，犹太人仍有一个特别的节日，来纪念以斯帖王后顺服和勇敢的行动（9:26-28）。

我们对这个故事的回应

“神插手拯救南非”——这是一家报纸的标题，当时南非纳塔尔省的两万五千人在一个体育场聚会，举行耶稣和平大会，为政府选举祷告。当这数以千计的人祷告时，敌对的部落和政治领袖之间举行了一次会谈。他们的祷告蒙了应允，选举平安进行，所有的团体都有代表参加。神保护了南非的人民免于内战。

神今天仍然垂听并应允祷告。

牢记背诵经文

背诵到目前为止学过的所有诫命。

第 12 课：以斯帖的筵席

经文阅读： 以斯帖记 5:1-14；7:1-10；9:1-4

1. 把故事按顺序排好

甲）王知道了真相，犹太人得救了。
乙）犹太人为以斯帖禁食祷告。
丙）以斯帖邀请王和哈曼赴宴。
丁）以斯帖去见王。

👉 正确顺序：

  • 乙）犹太人为以斯帖禁食祷告。
  • 丁）以斯帖去见王。
  • 丙）以斯帖邀请王和哈曼赴宴。
  • 甲）王知道了真相，犹太人得救了。

2. 是还是否？

对的写“是”，不对的写“否”：

  • 王向以斯帖伸出金权杖了吗？( ___ ) 👉 是
  • 神垂听了百姓的祷告吗？( ___ ) 👉 是
  • 以斯帖在第一次筵席上把她的难题告诉王了吗？( ___ ) 👉 否

3. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 以斯帖为王预备了什么？
    甲）一场筵席 乙）一首歌 丙）一条船 👉 甲）一场筵席
  • 谁拯救了犹太人？
    甲）哈曼 乙）神 丙）卫兵 👉 乙）神

4. 讨论题

  • 以斯帖的任务为什么危险？

参考答案：她没有被召就去见王。

  • 神是怎样回应百姓的祷告的？

参考答案：祂保护犹太人平安，并向王显明真相。

  • 我们害怕的时候可以做什么？

参考答案：祷告，并信靠神。

5. 背诵经文：

出埃及记 20:9-10 ——“六日要劳碌作你一切的工，但第七日是向耶和华你神当守的安息日。”

诗篇 120:1 ——“我在急难中求告耶和华，祂就应允我。”

6. 给图画涂色：

手工 1：筵席桌图画

材料： 纸、蜡笔、彩色纸、胶水

步骤：

  • 画一张长桌子。
  • 剪出盘子和水果。
  • 把它们粘在桌子上。
  • 写上：“神垂听祷告。”

课程重点： 神垂听并应允祂子民的祷告。

手工 2：祷告之心

材料： 红色纸、剪刀、蜡笔、细绳

步骤：

  • 剪一颗大大的心。
  • 写上你要为之祷告的一件事。
  • 打一个孔，系上细绳。

课程重点： 我们可以为身处危险的人祷告。

游戏 1：膝盖打战

玩法：

  • 问：“我们害怕的时候是什么感觉？”
  • 孩子们假装害怕，然后深吸一口气，说：“神与我同在。”
  • 重复一遍。

课程重点： 我们害怕的时候，神赐给我们勇气。

游戏 2：蒙应允的祷告

玩法：

  • 孩子们说出神已经应允的祷告。
  • 每说一个，就拍三下手。
  • 一起感谢神。

课程重点： 神今天仍然应允祷告。
