约拿逃避神

目标

向孩子们说明：无论我们到哪里，都不会超出神的看顾和保护之外。

经文阅读

约拿书 1:1-10

背诵经文

出埃及记 20:6

（十诫）“爱我、守我诫命的，我必向他们发慈爱，直到千代。”

讲授课程

起点

描述孩子们听到父母叫他们去做不想做的事时，常常会跑去躲起来。

课程重点

1. 约拿是一位像以利沙一样的先知，但他试图逃避神交给他的任务。神命令约拿到尼尼微去，向那里的人传道。他们非常邪恶（约拿书 1:2）。尼尼微人也是以色列的仇敌。约拿不愿看见那些邪恶的人得救。他不是怕他们会伤害他；他是怕他们会悔改，而他却希望神惩罚他们。

2. 约拿以为，只要离开自己的国家（以色列），就能躲开神。所以他上了一条船，往与尼尼微相反的方向去（1:3）。出示图片 7。

3. 但是船一到海上，神就刮起了一场大风暴。每个人都吓坏了。描述他们做了什么（1:4-5上）。

4. 船长发现约拿在船舱底下睡着了！船长想知道：他为什么不祷告，不设法帮忙救这条船呢（1:5下-6）？

5. 水手们抽签，发现约拿是这场风暴的原因（1:7）。从他对水手们提问的回答，我们看到约拿心里知道，神是天地的主宰（1:9）。然而，从他的行为上却看不出来。约拿充满了勇气，尽管这勇气用错了地方（1:10）。在下一课中，我们将看到神用何等奇妙的方式拯救约拿。

我们对这个故事的回应

现在你们要听圣经里的一首诗篇。我要你们仔细听，神说祂与我们同在的所有不同的地方。听完以后，我要问你们记得多少个。给全班朗读诗篇 139:1-12。如果有两个朗读得好的人，每人轮流读一节，效果会非常好。把这首诗篇读两遍。如果有黑板或类似的工具，把全班的答案列成一张清单。

现在让我们祷告，感谢神无论我们去到哪里，祂都与我们同在。

牢记背诵经文

约拿不愿意借着顺服神的诫命来表明他对神的爱。

复习到目前为止所学的出埃及记 20 章的所有经文。

第 7 课：约拿逃避神

经文阅读： 约拿书 1:1-16

1. 我是谁？

从中选择：约拿、船长、神

  • 我吩咐约拿到尼尼微去。我是谁？ __________ 👉 神
  • 我叫醒了约拿，请他祷告。我是谁？ __________ 👉 船长
  • 我坐上一条走错方向的船逃跑了。我是谁？ __________ 👉 约拿

2. 对还是错？

对的写“对”，错的写“错”：

  • 神说“去”的时候却逃跑。( ___ ) 👉 错
  • 说对不起，并照神所要求的去做。( ___ ) 👉 对
  • 别人需要帮助的时候却在睡觉。( ___ ) 👉 错

3. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 神在海上降下了什么？
    甲）大风暴 乙）雪 丙）浓雾 👉 甲）大风暴
  • 约拿被吩咐去哪里？
    甲）埃及 乙）尼尼微 丙）巴比伦 👉 乙）尼尼微

4. 讨论题

  • 约拿为什么不想去尼尼微？

参考答案：他不想让那里邪恶的人得到饶恕。

  • 我们能躲开神吗？

参考答案：不能。神无论在哪里都与我们同在。

  • 我们对神说“不”会怎样？

参考答案：我们会陷入麻烦，并失去祂所赐的平安。

5. 背诵经文：

出埃及记 20:6 ——“爱我、守我诫命的，我必向他们发慈爱，直到千代。”

诗篇 139:7 ——“我往哪里去躲避你的灵？我往哪里逃避你的面？”

6. 给图画涂色：

手工 1：风暴中的船

材料： 蓝色纸、棕色纸、剪刀、胶水、蜡笔

步骤：

  • 用棕色纸剪出一条船。
  • 把蓝色纸撕成浪花。
  • 把船粘在浪花上。
  • 写上：“神无所不在。”

课程重点： 我们不能逃离神。

手工 2：两条路的路牌

材料： 卡纸、蜡笔、小棍、胶带

步骤：

  • 画一个指向尼尼微的箭头和另一个指向他施的箭头。
  • 把正确的那个涂成绿色。
  • 用胶带把卡片粘在小棍上。

课程重点： 顺服神永远是正确的方向。

游戏 1：摇晃的船

玩法：

  • 孩子们围成一圈坐下，扮作“水手”，像在波浪上一样轻轻摇摆。
  • 老师说“平静！”时，大家就坐着不动。
  • 谈谈是谁平息了风浪。

课程重点： 神掌管天气和大海。

游戏 2：对的路，错的路

玩法：

  • 喊“尼尼微！”，孩子们就向右走一步。
  • 喊“他施！”，他们就必须站着不动。
  • 加快速度再做一遍。

课程重点： 我们应当顺服神，不要逃跑。
