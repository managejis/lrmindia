但以理和他的朋友们保持忠心

目标

向孩子们说明：神怎样尊重那些忠心尊崇祂的人的信心。

经文阅读

但以理书 1:1-21

背诵经文

出埃及记 20:10

（十诫）“第七日是向耶和华你神当守的安息日；这一日你无论何工都不可作，你和你的儿女、仆婢、牲畜，并你城里寄居的客旅，也是如此。”

讲授课程

起点

悲哀却真实的是，今天有许多人，尤其是孩子，是奴隶。战争常常带来奴役。和全班谈谈什么是奴隶制。奴隶被人拥有，常常被带离他们的家人和祖国。他们一无所有，没有收入，而且常常受到极其残酷的对待。

课程重点

1. 但以理和他的三个朋友是奴隶。他们还是少年的时候，在战争中被掳，从以色列的家乡被带到了巴比伦（就是现在的伊朗和伊拉克一带）（但以理书 1:1-2）。

2. 巴比伦王尼布甲尼撒下令，从好人家，甚至从王室中，挑选相貌英俊、聪明的犹太少年，加以训练，作他的臣仆。他吩咐他的宫廷官员好好照顾他们，让他们吃与王一样的食物，并给他们良好的教育（1:3-7）。

3. 巴比伦王的食物是好的，但吃以前先要献给偶像。但以理和他的朋友们想要尊崇永生的神，继续遵守祂的诫命，所以他们拒绝吃王的食物。出示图片 13。描述但以理怎样先去见王的太监长，他愿意帮助他们，却又太害怕。太监长就是图中站在女仆后面、面带忧愁的那个人（1:8-10）。

4. 然后，但以理带着一个计划去见看守他们的卫兵。他请求让他和他的朋友们十天内只吃蔬菜、只喝水。然后拿他们与别的吃王的食物的奴隶少年比较，看谁看起来最健康（1:11-14）。

5. 神奖赏了但以理和他的朋友们的信靠，因为十天之后，他们比所有别的青年更强壮。三年的训练完成后，他们比巴比伦任何人都更健康、更有智慧（1:15-21）。

我们对这个故事的回应

埃里克·利迪尔是一位年轻的苏格兰运动员。在 1924 年的奥运会上，他发现大家都以为他会赢的那场一百米赛跑，竟安排在星期天举行。作为基督徒，他相信那样做就违背了神的诫命，所以他拒绝参赛。每个人都非常失望。

埃里克说，他宁可去跑四百米，尽管他并没有真正为这个项目训练过，这也不是他的强项。他走上跑道的时候，有人递给他一张纸条，上面写着：“尊重我的，我必重看他——撒母耳记上 2:30。”埃里克·利迪尔尊重神的诫命，那天神也尊重埃里克的见证。他赢了那场比赛！

神对今天忠心为祂作见证的人是信实的，正如几百年前祂尊重但以理和他朋友们的信心一样。

牢记背诵经文

埃里克·利迪尔选择对这条诫命保持忠心。

背诵到目前为止学过的所有诫命。

第 13 课：但以理和他的朋友们保持忠心

经文阅读： 但以理书 1:1-21

1. 我是谁？

从中选择：但以理、尼布甲尼撒、卫兵

  • 我是巴比伦王。我是谁？ __________ 👉 尼布甲尼撒
  • 我请求只吃蔬菜、只喝水。我是谁？ __________ 👉 但以理
  • 我看守但以理和他的朋友们，并试验了这个办法。我是谁？ __________ 👉 卫兵

2. 对还是错？

对的写“对”，错的写“错”：

  • 但以理和他的朋友们来自以色列。( ___ ) 👉 对
  • 王的食物是献给偶像的。( ___ ) 👉 对
  • 十天之后，他们看起来更虚弱了。( ___ ) 👉 错

3. 数一数，写下来

写出数字：

  • 但以理有几个朋友？ ____ __________ 👉 3
  • 试验持续了几天？ ____ __________ 👉 10
  • 训练持续了几年？ ____ __________ 👉 3

4. 讨论题

  • 但以理为什么不吃王的食物？

参考答案：那食物是献给偶像的，而他想要尊崇神。

  • 神是怎样奖赏但以理和他的朋友们的？

参考答案：他们比所有别的人更健康、更有智慧。

  • 什么时候做神要我们做的事很难？

参考答案：当别人都在做不同的事的时候。

5. 背诵经文：

出埃及记 20:10 ——“但第七日是向耶和华你神当守的安息日；这一日你无论何工都不可作。”

撒母耳记上 2:30 ——“尊重我的，我必重看他。”

6. 给图画涂色：

手工 1：蔬菜盘

材料： 纸盘、彩色纸、胶水、蜡笔

步骤：

  • 用纸剪出胡萝卜、豌豆和番茄。
  • 把它们粘在盘子上。
  • 写上：“但以理选择了神。”

课程重点： 神尊重那些尊崇祂的人。

手工 2：忠心四人图

材料： 纸、蜡笔

步骤：

  • 画四个站在一起的男孩。
  • 给他们的衣服涂上颜色。
  • 写上：“对神忠心。”

课程重点： 但以理和他的朋友们一起保持忠心。

游戏 1：好好选择

玩法：

  • 出示健康食物和糖果的图片。
  • 孩子们指向健康的食物，并说：“但以理的选择！”
  • 谈谈怎样做选择。

课程重点： 我们可以像但以理一样做出好的选择。

游戏 2：与朋友站在一起

玩法：

  • 四个孩子站在一起。
  • 老师提出一个错误的选择，这四个孩子就说：“不，谢谢！”
  • 交换小组。

课程重点： 朋友们可以互相帮助行正确的事。
