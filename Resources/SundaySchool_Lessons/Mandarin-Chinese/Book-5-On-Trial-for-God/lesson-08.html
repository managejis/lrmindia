约拿和大鱼

目标

向孩子们说明：即使在我们所能想象的最可怕的地方，神也与我们同在。

经文阅读

约拿书 1:10 – 2:10

背诵经文

出埃及记 20:7

（十诫）“不可妄称耶和华你神的名……”

注：最好把约拿书第 1 章全部读一遍，以复习完整的故事。

讲授课程

起点

出示图片 7，并用提问的方式复习第 7 课的故事。

建议的问题：

1. 匆匆赶向那条船的人是谁？约拿书 1:3。

2. 他匆匆要离开的是谁？约拿书 1:3。

3. 他为什么要逃避神？约拿书 1:2-3。

4. 那条船发生了什么事？约拿书 1:4。

5. 别人都在拼命努力设法救船的时候，约拿在做什么？约拿书 1:6。

课程重点

1. 水手们不认识永生的神，敬拜偶像，听说约拿竟想逃避神，都非常惊讶（约拿书 1:10）。他们想知道怎样才能使风浪平静下来（1:11）。

2. 约拿说，他们必须把他抛到海里。水手们不愿意这样做。他们甚至试着把船划近岸边。但风浪越来越大，于是他们求神不要因约拿的死而归罪于他们，就把他抛到海里去了。他们知道他在那汹涌的水里不可能活下来（1:12-16）。

3. 但是约拿没有死。出示图片 8。神安排了一条大鱼把约拿吞了（1:17）。

4. 在鱼肚子里一定是个可怕的地方。有少数人有过和约拿一样的经历，并活着讲述这件事。约拿做了他唯一能做的事。他向神祷告。他知道神与他同在，即使在那条鱼的肚子里（2:1）。

5. 在祷告中，约拿承认神与他同在，并且听他的祷告（2:2）。他曾以为自己已经使自己落到神的帮助以外，但现在他真正知道，他无法把神从他的生命中隔绝出去（2:3-4）。在祷告的结尾，约拿赞美神，并承诺要顺服祂（2:9）。

6. 过了三天，那条鱼把约拿吐在干地上（2:10）。

我们对这个故事的回应

在过去几年里，各个年龄的人都作见证说，在极大的恐惧和苦难的时候——当他们逃避战争、住在难民营或身陷监狱的时候——神与他们同在。我们从世界各地的人那里听到这样的见证，从非洲到北爱尔兰，再到曾被称为南斯拉夫的地区。

向全班朗读上面第 5 点所提到的约拿祷告的部分：约拿书 2:2-4, 9。也许你们当中有人愿意讲一讲一段特别艰难和危险的时期，并说说他或她是怎样被提醒神的同在的。

牢记背诵经文

复习到目前为止所学的出埃及记 20 章的所有经文。

第 8 课：约拿和大鱼

经文阅读： 约拿书 1:11-17；2:1-10

1. 连线配对

A

B

水手们

向永生的神祷告

大鱼

吞了约拿

约拿

在鱼肚子里祷告

三天

在鱼肚子里的时间

答案：
水手们 → 向永生的神祷告
大鱼 → 吞了约拿
约拿 → 在鱼肚子里祷告
三天 → 在鱼肚子里的时间

2. 缺失的字

填上缺少的字：

  • 大 _ （神安排的） __________ 👉 大鱼
  • 祷 _ （约拿做的事） __________ 👉 祷告
  • 干 _ （约拿被吐在这里） __________ 👉 干地

3. 对还是错？

对的写“对”，错的写“错”：

  • 神在鱼肚子里与约拿同在。( ___ ) 👉 对
  • 约拿说他会顺服神。( ___ ) 👉 对
  • 神没有听约拿的祷告。( ___ ) 👉 错

4. 讨论题

  • 神为什么安排那条大鱼？

参考答案：为了拯救约拿，并再给他一次机会。

  • 约拿在遭遇困难时做了什么？

参考答案：他向神祷告。

  • 你什么时候觉得神与你同在？

参考答案：接受任何答案，例如我害怕或生病的时候。

5. 背诵经文：

出埃及记 20:7 ——“不可妄称耶和华你神的名。”

诗篇 46:1 — “神是我们的避难所，是我们的力量，是我们在患难中随时的帮助。”

6. 给图画涂色：

手工 1：鱼书签

材料： 橙色纸、剪刀、蜡笔、胶水

步骤：

  • 剪出一个大鱼的形状。
  • 画上眼睛和鳞片。
  • 剪一道缝，把一个小小的约拿人形塞进去。
  • 写上：“神与我同在。”

课程重点： 神与约拿同在，即使在鱼肚子里。

手工 2：祷告的浪花

材料： 蓝色纸条、剪刀、胶水、蜡笔

步骤：

  • 把蓝色纸条粘起来，做成浪花。
  • 在中间画上正在祷告的约拿。
  • 写上：“我要呼求神。”

课程重点： 我们在任何地方都可以向神祷告。

游戏 1：吞下这个词

玩法：

  • 老师说一个圣经里的词，孩子重复一遍。
  • 如果这个词与约拿有关，孩子就像鱼一样张开双臂。
  • 如果无关，就站着不动。

课程重点： 我们记住约拿的故事。

游戏 2：传祷告

玩法：

  • 孩子们围成一圈坐下，传一个软球。
  • 拿到球的人说一句简短的感谢祷告。
  • 一直传下去，直到每个人都祷告过。

课程重点： 神垂听每一个祷告。
