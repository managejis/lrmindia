神的儿女

目标

向孩子们显明：耶稣愿意每个人都来到祂面前，像小孩子一样信靠祂。

经文阅读

马可福音 10:13-16; 9:33-37

背诵经文

马可福音 10:14

“让小孩子到我这里来，不要禁止他们，因为在神国的，正是这样的人。”

注：教导这节经文时要解释，“神的国”的意思是“神掌权的地方”。

讲授课程

起点

谈谈家里来了客人时，人们希望孩子怎样表现。他们应该问候客人，然后走开。大人不希望孩子们打扰客人。

课程重点

1. 耶稣正向那些来听祂的人讲论重要的事。这时有些母亲带着孩子来到耶稣面前，好让祂为他们祝福。

2. 门徒不想让他们的老师受到打扰，也不想让讨论被打断。他们设法不让母亲和孩子们靠近耶稣。

3. 耶稣注意到发生的事，就制止了门徒。祂叫孩子们到祂这里来，特别关爱他们，并为他们祝福（10:16）。

4. 出示图片 7 并讨论。你有没有注意到耶稣对孩子们多么有兴趣？祂愿意和他们在一起！祂倾听他们。祂希望他们信靠祂。

牢记背诵经文

我们对这个故事的回应

举一个小孩子必须信靠大人的例子，例如第一次上学或去医院。在这样的情况下，孩子们不知道也不明白将要发生什么。他们只是跟着带他们去的大人走，因为他们信任那个人。耶稣希望我们像这样信靠祂、爱祂，无论我们多大年纪。这就是为什么骄傲的人永远不能成为耶稣的跟随者。我们需要像婴孩信任母亲会给他们食物、保护他们、照顾他们那样信靠祂。

第 7 课：神的儿女

经文阅读： 马可福音 10:13-16; 9:33-37

1. 对或错

写“对”或“错”：

  • 母亲们带着孩子来到耶稣面前。( ___ ) 👉 对
  • 门徒很高兴看见孩子们。( ___ ) 👉 错
  • 耶稣为孩子们祝福。( ___ ) 👉 对

2. 我是谁？

写出答案：

  • 我们设法不让孩子们靠近耶稣。我们是谁？ __________ 👉 门徒
  • 我说：“让小孩子到我这里来。”我是谁？ __________ 👉 耶稣
  • 我们带着孩子来，好让耶稣为他们祝福。我们是谁？ __________ 👉 母亲们

3. 重新排列字

写出正确的词：

  • 任 信（相信某人） → __________ 👉 信任
  • 福 祝（对某人说好话） → __________ 👉 祝福
  • 童 孩（小小的人） → __________ 👉 孩童

4. 讨论题

  • 耶稣对孩子们有什么感觉？

参考答案：祂爱他们，愿意和他们在一起。

  • 你信靠谁来照顾你？

参考答案：答案各不相同，例如父母或老师。

  • 我们怎样才能信靠耶稣？

参考答案：相信祂爱我们，并照祂所说的去做。

5. 背诵经文：

马可福音 10:14 ——“让小孩子到我这里来，不要禁止他们，因为在神国的，正是这样的人。”

约翰一书 3:1 ——“你看父赐给我们是何等的爱，使我们得称为神的儿女！”

6. 给图画涂色：

手工 1：耶稣和我

材料： 纸、蜡笔、胶水、卡纸

步骤：

  • 在一张小纸上画你自己。
  • 在一张大纸上画张开双臂的耶稣。
  • 把两张都粘在一张卡片上，并写上：“耶稣爱我。”

课程重点： 耶稣欢迎每一个孩子。

手工 2：手印祝福

材料： 彩色纸、颜料或蜡笔

步骤：

  • 在纸上描出你的手，然后剪下来。
  • 把它涂上鲜艳的颜色。
  • 写上：“耶稣祝福我。”

课程重点： 耶稣祝福来到祂面前的孩子。

游戏 1：到耶稣这里来

玩法：

  • 一个孩子在房间的一端扮演“耶稣”。
  • 其他孩子一个一个走向祂，祂用拥抱或握手欢迎他们。
  • 轮流扮演“耶稣”。

课程重点： 耶稣呼召我们来到祂面前。

游戏 2：信任之行

玩法：

  • 孩子们两人一组，手拉着手。
  • 一个孩子在同伴的带领下慢慢地走。
  • 谈谈信任是什么感觉。

课程重点： 我们信靠耶稣，就像孩子信靠慈爱的父母。
