神的世界里的邪恶

目标

教导孩子们：基督徒要站稳，因为他们与不敬虔的人和邪恶的势力共处在这个世界上。有一天，神公义的统治将被建立，一切邪恶都将被消灭。

经文阅读

马太福音 13:24-30, 36-43

背诵经文

以赛亚书 32:1

看哪，必有一王凭公义行政，必有首领凭公平掌权。

讲授课程

起点

阿里玛住在城里。有一天，她去和住在乡下的亲戚一起度假。她和他们一起到田里去除草。在城里，她连一个花园也没有，所以她不知道哪些是杂草，哪些是好的植物。她的姨妈看着她在做的事，喊道：“哎呀，停下，停下，阿里玛！你把好的植物和杂草一起拔掉了！”

课程重点

1. 耶稣讲了一个关于好植物和坏植物的故事。一个人在他的田里撒了好种子。夜里，他的仇敌来了，在好种子中间撒了稗子（马太福音 13:24-25）。出示图片 6。

好种子和稗子都长起来了（13:26）。他们看见了稗子，这人的仆人就来问他的意见。田主叫他们不要管这块田，等到收割的时候。庄稼成熟的时候，他们就很容易看出哪些是稗子，哪些是可以当食物的麦子（13:27-30）。

2. 耶稣的门徒来问祂，这个故事是什么意思。描述故事中的各种东西所代表的是什么（13:37-39）。

注：故事中的稗子是一种植物，在快要收割之前，它长得和好麦子非常相像。但麦子可以吃，这种稗子却有毒。

3. 耶稣要祂的跟随者记住，我们生活在一个有人违背神、有人跟随恶者的世界里。基督徒无论在哪里遇到邪恶，都必须站稳。我们可以盼望耶稣公义的统治开始、一切邪恶被消灭的那一天。

牢记背诵经文

我们对这个故事的回应

有许多故事讲述苏丹的基督徒，在该国目前所经历的艰难中，面对邪恶坚定不移。找一个讲给全班听。

第 6 课：神的世界里的邪恶

经文阅读： 马太福音 13:24-30, 36-43

1. 完成句子

词语框：稗子、麦子、收割

  • 农夫撒了好种子，长成了____________。 __________ 👉 麦子
  • 仇敌在麦子中间撒了____________。 __________ 👉 稗子
  • 它们在____________的时候被分开。 __________ 👉 收割

2. 好还是坏？ 好/坏

好的写“好”，坏的写“坏”：

  • 说实话。( ___ ) 👉 好
  • 拿不属于我的东西。( ___ ) 👉 坏
  • 帮助一个伤心的朋友。( ___ ) 👉 好
  • 对一个新来的孩子不友善。( ___ ) 👉 坏

3. 按顺序排列这个故事

甲）两样一起长大。
乙）一个人撒了好种子。
丙）收割的时候它们被分开。
丁）一个仇敌在夜里撒了稗子。

👉 正确顺序：

  • 乙）一个人撒了好种子。
  • 丁）一个仇敌在夜里撒了稗子。
  • 甲）两样一起长大。
  • 丙）收割的时候它们被分开。

4. 讨论题

  • 仆人们为什么不立刻把稗子拔掉？

参考答案：他们可能会把好的植物也一起拔掉。

  • 故事的最后谁得胜？

参考答案：神和跟随祂的人。

  • 别人做错事的时候，我们怎样才能站稳？

参考答案：借着祷告，并做正确的事。

5. 背诵经文：

以赛亚书 32:1 ——“看哪，必有一王凭公义行政，必有首领凭公平掌权。”

约翰一书 4:4 ——“那在你们里面的，比那在世界上的更大。”

手工 1：麦子和稗子

材料： 绿色和黄色的纸、胶水、卡纸

步骤：

  • 把高高的黄色麦秆粘在卡纸上。
  • 在它们中间粘上几棵小小的绿色稗子。
  • 写上：“神要在收割的时候审判。”

课程重点： 现在好的和坏的一起生长，但神要使万事都归于正。

手工 2：闪亮的王冠

材料： 金色纸、剪刀、胶带、蜡笔

步骤：

  • 剪一条长长的金色纸条。
  • 用各种形状装饰它，并画一个十字架。
  • 把两端用胶带粘起来，使它适合头的大小。

课程重点： 有一天，耶稣要作王，以公义掌权。

游戏 1：找出稗子

玩法：

  • 把绿色纸做的“植物”和几棵棕色的“稗子”散放在地板上。
  • 孩子们只捡起稗子，不捡植物。
  • 谈谈我们为什么必须小心。

课程重点： 神知道其中的区别，祂要在适当的时候审判。

游戏 2：站稳

玩法：

  • 孩子们像树一样双脚分开站着。
  • 老师说出不好的选择，孩子们说：“不！”并站稳。
  • 遇到好的选择，他们就欢呼：“是！”

课程重点： 基督徒站稳，抵挡邪恶。
