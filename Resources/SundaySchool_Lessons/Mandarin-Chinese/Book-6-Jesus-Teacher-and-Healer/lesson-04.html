以谦卑代替报复

目标

向孩子们说明：耶稣基督的跟随者不应报仇，而应把审判交给神，因为我们没有一个人是无可指责的。

经文阅读

马太福音 5:38-42；路加福音 6:27-36；撒母耳记上 24:1-22。

背诵经文

马太福音 6:15

“你们不饶恕人的过犯，你们的天父也必不饶恕你们的过犯。”

讲授课程

起点

你见过有人从后面推别人一把吗？通常会发生什么？第一个人会使另一个人失去平衡，也许会摔倒。如果有人以某种方式伤害我们，我们大多数人都想报复他们——常常用更糟的方式。如果有两个孩子在全班面前把这演出来，会很醒目。要小心，不要让任何人受伤！

课程重点

1. 耶稣的教导大不相同。

出示图片 4。耶稣举了一个士兵欺负一个人的例子。他打了那个人，还抢走了他的外衣。那个人该怎么办？耶稣说，他不应该还手打那个士兵。他不但不打士兵，还要把自己的衬衣也给他！耶稣教导说，祂的跟随者要总是设法使情况变得更好。比如挑起一场打斗来报仇，只会使事情更糟。这是基督的方式，与世界的行事方式大不相同！

讨论马太福音 5:38-41 中的例子。

注：伤害别人的人，应当按国家的法律受到惩罚。但是很多时候，犯错的人没有被抓到，或者被追究责任的是错的人。神是唯一可靠的审判者。我们应当把惩罚别人的事交给神，并小心不要自己犯罪。

牢记背诵经文

2. 讲大卫在洞里发现扫罗的故事（撒母耳记上 24:1-22）。大卫本可以报仇，但他没有。他知道这是在神的手中。大卫知道，他自己是靠神的恩典而活，不是靠自己的义。

我们对这个故事的回应

我们很难遵行耶稣的这个教导！但是报仇是罪；它意味着我们以为自己可以审判，好像我们自己就是神一样。

这里有一个真实的故事，讲的是一个顺服耶稣的人：他因为是基督徒而被关进监狱，受到非常恶劣的对待。他的牢房小得连坐下都不行，只给他吃咸的米饭。当局烧了他的圣经。他最终被释放后，一名警察一直监视着他的家。令这名警察惊讶的是，这位从前的囚犯待他很好，还给了他一本圣经读。那名警察信主了。

第 4 课：以谦卑代替报复

经文阅读： 马太福音 5:38-42；路加福音 6:27-36；撒母耳记上 24:1-22

1. 报复还是饶恕？ 报/恕

报复写“报”，饶恕写“恕”：

  • 有人推我，所以我推得更用力。( ___ ) 👉 报
  • 有人对我不友善，所以我对他说话和气。( ___ ) 👉 恕
  • 我把审判交给神。( ___ ) 👉 恕
  • 我把伤害我的人的坏话告诉每一个人。( ___ ) 👉 报

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 大卫发现谁在洞里睡着了？
    甲）扫罗王 乙）歌利亚 丙）以利亚 👉 甲）扫罗王
  • 大卫对扫罗做了什么？
    甲）他伤害了他 乙）他没有伤害他 丙）他逃跑了 👉 乙）他没有伤害他
  • 谁是最好的审判者？
    甲）我 乙）我的朋友 丙）神 👉 丙）神

3. 是或否

写上“是”或“否”：

  • 耶稣说我们应该打架，使事情更糟吗？( ___ ) 👉 否
  • 耶稣教导我们要善待伤害我们的人吗？( ___ ) 👉 是
  • 报复会使问题变得更大吗？( ___ ) 👉 是

4. 讨论题

  • 有人伤害许多人时，他们想做什么？

参考答案：他们想要反过来伤害那个人。

  • 耶稣教导我们反而要做什么？

参考答案：要仁慈、饶恕，并把审判交给神。

  • 大卫为什么没有伤害扫罗？

参考答案：他信靠神作审判者。

5. 背诵经文：

马太福音 6:15 ——“你们不饶恕人的过犯，你们的天父也必不饶恕你们的过犯。”

罗马书 12:21 ——“不可为恶所胜，反要以善胜恶。”

6. 给图画涂色：

手工 1：善良的双手

材料： 纸、铅笔、剪刀、蜡笔

步骤：

  • 把你的双手描在纸上，剪下来。
  • 在每只手上写一件你可以做的善事。
  • 把这些手贴在一张卡片上。

课程重点： 我们可以用善意回应伤害。

手工 2：和平鸽

材料： 白纸、剪刀、蜡笔、细绳

步骤：

  • 把白纸折起来，剪出一只带翅膀的鸽子形状。
  • 给眼睛涂上颜色，并在一只翅膀上写上“和平”。
  • 系上细绳，把它挂起来。

课程重点： 耶稣的跟随者选择和平，而不是报复。

游戏 1：洞里的故事

玩法：

  • 两个孩子把故事演出来：大卫悄悄地发现扫罗，然后走开。
  • 全班说：“大卫没有报仇！”
  • 换演员，再讲一遍。

课程重点： 大卫把审判交给神。

游戏 2：善意的回答

玩法：

  • 老师说一句不友善的话，比如“你真慢！”
  • 一个孩子用善意的话回答。
  • 大家为最友善的回答鼓掌。

课程重点： 温柔的回答能平息争吵。
