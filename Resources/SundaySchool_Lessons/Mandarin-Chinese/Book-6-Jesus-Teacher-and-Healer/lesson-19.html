女人终于得了医治

目标

教导孩子们：耶稣知道我们心中的渴望，即使我们向别人隐藏，祂也关心我们。

经文阅读

马可福音 5:25-34

背诵经文

诗篇 44:21

神……晓得人心里的隐秘……

讲授课程

起点

谈谈秘密。一个人可能有一个秘密（隐藏）的地方，用来放别人都不知道的东西。另一个例子是考试里将要问的问题，事先必须保密。

课程重点

1. 有一个女人病得很重。她已经受了 12 年的苦。尽管许多医生都试过，却没有一个医生能帮助她。她为了寻求医治，花光了所有的钱（5:25-26）。更糟的是，她的病使她不被信奉犹太教的人所接纳。别人的家里不欢迎她。她甚至不被允许和其余的信徒一起敬拜神。

2. 后来，这个女人听说了耶稣。她来到祂面前，就是按着她所听到的去行。她悄悄地、羞怯地来，因为她知道人群中的人不会愿意她靠近他们。所以她想暗暗地得医治。她对耶稣有极大的信心。她相信祂的能力是那么大，只要摸一摸祂衣服的衣角，她就会痊愈（5:27-28）。出示图片 19。

3. 这女人真的摸到了耶稣，立刻就痊愈了。耶稣感觉到了；祂知道这是一个需要帮助的人特别的触摸。祂问是谁摸了祂（5:29-30）。门徒们认为这个问题很傻。祂像往常一样被一群人围着，每个人都在推推搡搡，想要挤到祂跟前（5:31）。几乎任何人都有可能摸了祂！

4. 然而，耶稣一直在找那个人。女人知道她暗暗得医治的事被发现了，就在所有人面前来到耶稣跟前（5:32-33）。

5. 耶稣温柔地对她说话。祂称赞她对祂的信心。祂告诉她，她可以确信，从此以后她会健康。祂向她问候说：“平平安安地回去吧，”意思就是说：“你再也没有什么可害怕的了”（5:34）。

牢记背诵经文

我们对这个故事的回应

这个女人偷偷地摸耶稣的时候得了医治，但当她站出来对耶稣说话的时候，她就把她得医治的神迹与大家分享了。当她公开地分享耶稣为她所做的事，她的信心就更坚固了。比起悄悄地离开，她得到了更多的喜乐和平安。

当我们把耶稣为我们所做的事告诉别人，我们对祂的信心和对祂的爱就会更加增长。

第 19 课：女人终于得了医治

经文阅读： 马可福音 5:25-34

1. 数一数，写下来

写出答案：

  • 这个女人病了 ____ 年。 __________ 👉 12
  • 她摸了耶稣衣服的____________。 __________ 👉 衣角
  • 耶稣对她说：“____________地回去吧。” __________ 👉 平平安安

2. 是或否

写上“是”或“否”：

  • 医生们治好了这个女人吗？( ___ ) 👉 否
  • 耶稣知道有人摸了祂吗？( ___ ) 👉 是
  • 这个女人对耶稣有信心吗？( ___ ) 👉 是

3. 重新排列字

写出正确的词：

  • 心 信（相信耶稣） → __________ 👉 信心
  • 愈 痊（得了医治） → __________ 👉 痊愈
  • 密 秘（隐藏的事） → __________ 👉 秘密

4. 讨论题

  • 这个女人为什么悄悄地来？

参考答案：她很害羞，而且人们不欢迎她。

  • 耶稣对她说了什么？

参考答案：她的信心医治了她，要平平安安地回去。

  • 把耶稣为我们所做的事告诉别人为什么是好的？

参考答案：这使我们的信心更坚固。

5. 背诵经文：

诗篇 44:21 ——“神岂不鉴察这事吗？因为祂晓得人心里的隐秘。”

彼得前书 5:7 ——“你们要将一切的忧虑卸给神，因为祂顾念你们。”

6. 给图画涂色：

手工 1：衣角

材料： 布或纸、胶水、卡纸、蜡笔

步骤：

  • 在卡纸上画一个穿长袍的人。
  • 粘上一条布，当作衣角。
  • 写上：“我摸到了耶稣。”

课程重点： 我们向祂伸手的时候，耶稣知道。

手工 2：信心之心

材料： 粉红色卡纸、蜡笔、剪刀

步骤：

  • 用卡纸剪一个心形。
  • 画一只伸向它的小手。
  • 写上：“耶稣知道我的心。”

课程重点： 耶稣关心我们秘密的需要。

游戏 1：谁摸了我？

玩法：

  • 一个孩子闭着眼睛站着。
  • 另一个孩子轻轻拍一下他的肩膀。
  • 第一个孩子猜是谁，然后他们交换。

课程重点： 耶稣总是知道是谁在向祂伸手。

游戏 2：秘密分享

玩法：

  • 围坐成一圈。
  • 每个孩子说出耶稣为他们做的一件好事。
  • 大家一起说：“感谢你，耶稣！”

课程重点： 分享耶稣所做的事，使我们的信心更坚固。
