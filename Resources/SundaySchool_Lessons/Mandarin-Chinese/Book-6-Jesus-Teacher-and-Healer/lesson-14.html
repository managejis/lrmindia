耶稣呼召祂的门徒

目标

向孩子们显明：耶稣呼召了一些人来帮助祂。今天祂仍然需要帮手。

经文阅读

马可福音 1:14-20

背诵经文

马可福音 1:17

耶稣对他们说：“来跟从我，我要叫你们得人如得鱼一样。”

讲授课程

起点

说说你做过的一些自己一个人做不了的工作。你需要别人来帮你。

课程重点

1. 耶稣在世上的时候非常忙碌，因为祂有一项伟大的使命。祂呼召了一些人来帮助祂。祂想教导他们认识神，我们的天父，好让他们转过来再教导别人。

2. 讲一讲，有一天，耶稣沿着加利利海边走，看见一些人在捕鱼。就像沿着尼罗河的河岸行走一样。

3. 出示图片 14。耶稣看见西门和他的兄弟安得烈在用网捕鱼。耶稣对他们说：“来跟从我，我要叫你们得人如得鱼一样。”把这句话重复几遍，因为它是背诵经文。重复两三遍之后，让孩子们跟你一起说。

解释耶稣的意思：祂要西门和安得烈跟从祂，向祂学习。这样，他们就能教导别人来跟从耶稣。

4. 在图片里指出约翰和雅各正在补网。解释这两兄弟在耶稣呼召他们的时候做了什么（1:19-20）。

牢记背诵经文

我们对这个故事的回应

耶稣今天仍然需要帮手。如果我们顺服并跟从祂，我们就成为祂的帮手，也就是门徒。我们怎样才能把祂的信息带给别人，来帮助祂？让孩子们提一些建议。例如：带一个朋友来主日学。

注：这个故事很短，很适合表演。你可以把孩子们分成小组，让每个小组表演这个故事，这样每个人都可以参与。他们可以把背诵经文作为他们“戏”的一部分来说。

第 14 课：耶稣呼召祂的门徒

经文阅读： 马可福音 1:14-20

1. 连线配对

A

B

西门和安得烈

在捕鱼

雅各和约翰

在补网

答案：
西门和安得烈 → 在捕鱼
雅各和约翰 → 在补网
耶稣 → 呼召他们跟从
“得人如得鱼” → 把人带到神面前

2. 数一数，写下来

写出答案：

  • 在这个故事里，耶稣呼召了 ____ 个渔夫。 __________ 👉 四
  • 他们撇下了他们的____________，跟从了祂。 __________ 👉 网
  • 耶稣沿着____________海边走。 __________ 👉 加利利

3. 是或否

写上“是”或“否”：

  • 西门和安得烈跟从了耶稣吗？( ___ ) 👉 是
  • 今天耶稣仍然需要帮手吗？( ___ ) 👉 是
  • 只有大人才能帮助耶稣吗？( ___ ) 👉 否

4. 讨论题

  • 耶稣要渔夫们做什么？

参考答案：跟从祂，向祂学习。

  • “得人如得鱼”是什么意思？

参考答案：带人来跟从耶稣。

  • 这个星期你怎样帮助耶稣？

参考答案：邀请一个朋友来主日学。

5. 背诵经文：

马可福音 1:17 ——“耶稣对他们说：‘来跟从我，我要叫你们得人如得鱼一样。’”

以赛亚书 6:8 ——“我在这里，请差遣我！”

手工 1：渔网

材料： 细绳或毛线、小卡纸鱼、胶带

步骤：

  • 把几段细绳交叉放在卡纸上，做一张简单的网。
  • 用卡纸剪出小鱼并涂上颜色。
  • 用胶带把鱼粘在网里。

课程重点： 耶稣呼召我们把别人带到祂面前。

手工 2：鱼挂饰

材料： 彩色纸、细绳、一根小棍

步骤：

  • 剪出三条纸鱼。
  • 把每条鱼系在一根绳子上。
  • 把它们挂在小棍上。

课程重点： 我们可以跟从耶稣，并把祂告诉别人。

游戏 1：跟我来

玩法：

  • 一个孩子扮演“耶稣”，在房间里走动。
  • 其他孩子排成一队跟着，模仿祂的动作。
  • 每分钟换一个领头的。

课程重点： 无论祂带领我们到哪里，我们都跟从祂。

游戏 2：表演这个故事

玩法：

  • 把全班分成几个小组。
  • 每个小组表演耶稣呼召渔夫的故事。
  • 最后一起说背诵经文。

课程重点： 每个人都可以作耶稣的帮手。
