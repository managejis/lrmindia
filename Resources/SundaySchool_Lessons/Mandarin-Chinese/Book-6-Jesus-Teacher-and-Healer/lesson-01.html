耶稣，我们的老师

目标

向孩子们说明：耶稣在世行走的时候，是一位伟大的老师，祂的话语和故事今天仍然可以教导我们。

经文阅读

马太福音 5:1；6:24-34；马可福音 1:21-22；6:1-3

背诵经文

马可福音 1:22

祂教训他们，正像有权柄的人……

讲授课程

起点

告诉孩子们你在学校里遇到的一位好老师。说说你为什么喜欢他或她。可能的原因：他/她很公平，把课讲得有趣。你有最喜欢的老师吗？

课程重点

1. 耶稣是一位伟大的老师。出示图片 1。有一天，祂走上山坡一小段，好让人们能清楚地看见祂。那天祂教导了几百人。这幅图只画出了其中的几个人。和全班一起讨论图画的细节。你看，有各种年龄的人。有些人看起来像是受过教育的人。这一位也许是宗教领袖。看看他们脸上的表情。

2. 在别的时候，耶稣在会堂里教导人。会堂是犹太教信徒聚集敬拜神的地方。讲马可福音 6:1-3 的故事。这件事发生在耶稣长大的那座城。那里的人从祂小时候就认识祂。他们很惊讶，耶稣讲论神的时候，所知道的比他们有学问的宗教教师多得多。耶稣带着权柄讲论神和祂的国。

牢记背诵经文

3. 耶稣用讲故事的方式教导人。每个人都爱听故事。在接下来的几周里，我们要听一些耶稣讲的、作为教训的故事。

4. 耶稣还用人们每天看到的周围的事物，来解释神的事。让我给你们举个例子：看这朵花；看它的颜色和美丽。指着图中的花。如果可能，带一朵花到课堂上来。从前，以色列有一位非常富有又聪明的王，名叫所罗门。他穿着最美丽的衣服，是用昂贵的彩色布料做的。但是，耶稣教导我们，野地里的花比所罗门穿上王袍的时候还要美丽。神对田野里的花尚且这样费心，把它们照顾得这样好，祂就一定会照顾祂的儿女。

我们对这个故事的回应

我要你们每一个人，试着找一朵野花或几片叶子，把它放在你家里你会注意到的地方。这个星期，你看着那朵花或那些叶子的时候，让它提醒你耶稣所教导的。这也会给你一个机会，在家里的其他人问起它的时候，向他们作见证。

第 1 课：耶稣，我们的老师

经文阅读： 马太福音 5:1；6:24-34；马可福音 1:21-22；6:1-3

1. 我是谁？

写出答案：

  • 我是一位非常富有的王。耶稣说野地里的花比我的衣服更美丽。我是谁？ __________ 👉 所罗门
  • 我是犹太人聚集敬拜神的地方。我是什么？ __________ 👉 会堂
  • 我是在山上教导群众的那一位。我是谁？ __________ 👉 耶稣

2. 是或否

写上“是”或“否”：

  • 耶稣只教导了少数几个人吗？( ___ ) 👉 否
  • 耶稣用花来教导神的看顾吗？( ___ ) 👉 是
  • 耶稣带着权柄教导吗？( ___ ) 👉 是

3. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 耶稣在哪里教导那一大群人？
    甲）山上 乙）船上 丙）旷野里 👉 甲）山上
  • 耶稣常常讲什么来教导人？
    甲）笑话 乙）故事 丙）谜语 👉 乙）故事
  • 谁照顾花朵？
    甲）神 乙）所罗门 丙）没有人 👉 甲）神

4. 讨论题

  • 你最喜欢的老师是谁？为什么？

参考答案：答案各不相同，例如：她很友善，把课讲得有趣。

  • 人们为什么听耶稣的话？

参考答案：祂带着权柄说话，讲的故事每个人都能明白。

  • 一朵花能提醒我们什么？

参考答案：神照顾我们。

5. 背诵经文：

马可福音 1:22 ——“耶稣教训他们，正像有权柄的人，不像文士。”

诗篇 119:105 ——“你的话是我脚前的灯，是我路上的光。”

6. 给图画涂色：

手工 1：花的提醒

材料： 彩色纸、蜡笔、胶水、卡纸、一根绿色小棍或吸管

步骤：

  • 用彩色纸剪出花瓣和一个圆形的花心。
  • 把它们粘在卡纸上，做成一朵花。
  • 在花茎上写上：“神照顾我。”

课程重点： 耶稣用花来教导我们，神照顾我们。

手工 2：山坡图画

材料： 绿色纸、棕色纸、蜡笔、胶水

步骤：

  • 在一张纸上粘一座大大的绿色山坡。
  • 画许多小人坐在山坡上。
  • 在山顶画上正在教导的耶稣。

课程重点： 耶稣教导了许多人，祂的话语今天仍然教导我们。

游戏 1：老师说

玩法：

  • 一个孩子当老师，发出简单的指令，比如“拍两次手”。
  • 只有老师说“耶稣说”的时候，全班才照着做。
  • 每一轮之后换一位老师。

课程重点： 我们要仔细听好老师的话。

游戏 2：故事圈

玩法：

  • 围坐成一圈。
  • 老师开始讲一个关于花或小鸟的简短故事。
  • 每个孩子加一句，并说说它教导了关于神的什么。

课程重点： 耶稣用日常的事物教导我们认识神。
