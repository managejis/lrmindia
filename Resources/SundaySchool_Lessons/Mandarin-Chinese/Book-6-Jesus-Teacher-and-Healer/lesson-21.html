外邦人的信心

目标

教导孩子们：耶稣爱各个部族、各个种族的人。祂愿意我们所有的人都信靠祂，从邪恶的权势中得释放。

经文阅读

马可福音 7:25-30

背诵经文

约翰福音 10:16

“我另外有羊，不是这圈里的……他们也要听我的声音……”

讲授课程

起点

如果有一个来自别的部族的人搬来，住在你家隔壁的院子里，会怎么样？他们说不同的语言，吃不同的食物，或者用不同的方法做饭，有不同的习俗。我们常常不信任他们，因为我们不认识、不了解他们。

课程重点

1. 有一次，一个外邦女人来见耶稣。她不是犹太人。犹太人把所有不属于他们民族的人都叫作外邦人。

这个女人非常担心，因为她的女儿被污灵附着。她恳求耶稣帮助她（可 7:25-26）。

2. 耶稣用一个故事回答了她的请求。给全班读 7:27。耶稣的意思是，祂是来帮助犹太人（故事里的孩子们）的。属于他们的东西不能给别人（故事里的狗；犹太人常常把别的民族的人叫作狗，因为他们看不起他们）。

耶稣是在说，如果祂在帮助犹太人之前先帮助外邦人，就像在孩子们之前先喂狗一样！

3. 但这个女人不肯这么轻易就被打发走。“主啊，是的，”她回答说，“但是狗在桌子底下也吃孩子们的碎渣儿”（7:28）。

出示图片 21。你们注意到图片里的狗了吗？左边的那个人很可能就是耶稣所住的那座房子的主人（7:24）。

4. 耶稣奖赏了这个外邦女人对祂的信心和信靠。祂告诉她，她回到家就会发现她的小女儿已经好了（7:29-30）。

耶稣爱各个部族、各个民族的人。祂愿意全世界的每个人都信靠祂，从邪恶的权势中得释放。

牢记背诵经文

我们对这个故事的回应

我们知道耶稣爱世界上所有部族的人。那么，对于来到我们附近居住的另一个部族的人，我们应该怎样对待他们？帮助全班想出各种不同的办法，帮助外来的人融入社区。当我们与别人分享耶稣的爱，我们就是在做神的工作。

第 21 课：外邦人的信心

经文阅读： 马可福音 7:25-30

1. 我是谁？

写出答案：

  • 我不是犹太人，但我恳求耶稣帮助我的女儿。我是谁？ __________ 👉 那个外邦女人
  • 我因为污灵而生病。我是谁？ __________ 👉 那个女人的女儿
  • 我奖赏了这个女人的信心。我是谁？ __________ 👉 耶稣

2. 善良还是粗鲁？ 善/粗

善良写“善”，粗鲁写“粗”：

  • 我邀请来自另一个部族的新孩子来玩。( ___ ) 👉 善
  • 我嘲笑新来的孩子说话的样子。( ___ ) 👉 粗
  • 我和邻居分享我的食物。( ___ ) 👉 善

3. 完成句子

词语框：碎渣儿、所有、信心

  • 耶稣爱____________部族的人。 __________ 👉 所有
  • 这个女人说，连狗也吃____________。 __________ 👉 碎渣儿
  • 耶稣称赞她的____________。 __________ 👉 信心

4. 讨论题

  • 这个女人怎样显明她的信心？

参考答案：她不断地求耶稣，并信靠祂。

  • 耶稣对所有的部族有什么感觉？

参考答案：祂爱他们所有的人。

  • 你怎样欢迎一个新来的人？

参考答案：问候他，并一起玩。

5. 背诵经文：

约翰福音 10:16 ——“我另外有羊，不是这圈里的……他们也要听我的声音。”

约翰福音 3:16 ——“神爱世人，甚至将祂的独生子赐给他们。”

6. 给图画涂色：

手工 1：世界各地的朋友

材料： 纸、蜡笔、胶水

步骤：

  • 画一些穿着不同衣服、手拉着手的孩子。
  • 把他们涂上许多种颜色。
  • 写上：“耶稣爱所有的人。”

课程重点： 耶稣爱每个部族、每个民族的人。

手工 2：欢迎卡片

材料： 卡纸、蜡笔、贴纸

步骤：

  • 把卡纸对折。
  • 在正面画一个笑脸。
  • 在里面写上：“欢迎！耶稣爱你。”

课程重点： 我们像耶稣一样欢迎别人。

游戏 1：问候一圈

玩法：

  • 孩子们用不同的语言或不同的方式互相问候。
  • 对每个新朋友说“欢迎！”
  • 谈谈被欢迎是什么感觉。

课程重点： 我们应该善待每一个人。

游戏 2：桌子底下的碎渣儿

玩法：

  • 在桌子底下撒一些小小的纸“碎渣儿”。
  • 孩子们把它们收集到篮子里。
  • 解释说，即使是从耶稣那里来的小小碎渣儿，也是一种祝福。

课程重点： 耶稣的爱足够大，足够每一个人。
