银子的比喻

目标

教导孩子们：我们怎样才能为耶稣再来做好准备。

经文阅读

马太福音 25:14-30

背诵经文

马太福音 25:21

“好，你这又良善又忠心的仆人……你一直忠心……可以进来享受你主人的快乐！”

讲授课程

起点

问孩子们他们擅长什么，最喜欢做什么。给他们时间回答。告诉他们你喜欢做什么。

课程重点

1. 有一天，耶稣讲了一个故事，说到一个人出远门之前，给他的仆人们分派了一些事。用你自己的话讲述 25:14-15 的事，说说钱是怎样分的。在那个时候，没有纸币，只有硬币。一“袋”银子是一笔数目不小的钱。

2. 讲一讲第一个仆人怎样运用交托给他的钱，赚了一倍（25:16）。也许他在他的街坊邻里开了一个小生意。

3. 对第二个仆人重复这样的讲述（25:17）。

4. 第三个仆人把钱埋了起来。他没有好好利用它（25:18）。

5. 过了很久，主人回来了。他对前两个仆人很满意，就奖赏了他们（25:19-23）。

6. 第三个仆人把所得到的原数交还，并为自己没有使用它而找借口（25:24-25）。出示图片 12。主人对那个懒惰的仆人很生气，因为他对所得到的什么也没做。那仆人连起初拥有的一点点也失去了（25:26-28）。

牢记背诵经文

我们对这个故事的回应

解释说，耶稣就像故事里的主人，我们是仆人。祂回天上去了，却给我们留下了工作要做，也留下了做这工作的能力。我们得到的不像比喻里的那样是钱。我们每个人都有神给我们的恩赐或才能。我们必须好好运用这些才能。

让我们想一想，课程一开始我问你们擅长什么的时候，你们所说的那些事。说出其中的一些，帮助全班回想起来。你们怎样才能用这些才能来荣耀主耶稣？

例子唱歌：我们可以唱关于耶稣的歌，教别人认识祂。

讲故事：我们可以把在主日学听到的关于耶稣的故事，讲给我们的家人和朋友听。

我们不需要等到长大成人才为耶稣工作。我们现在就可以开始，并一直做下去，直到祂再来！

第 12 课：银子的比喻

经文阅读： 马太福音 25:14-30

1. 数一数，写下来

写出答案：

  • 主人给了第一个仆人五袋银子，他又赚了 ____ 袋。 __________ 👉 5
  • 第二个仆人得到了 ____ 袋银子。 __________ 👉 两
  • 第三个仆人得到了 ____ 袋银子。 __________ 👉 一

2. 选出正确的答案

圈出 甲）、乙）或 丙）：

  • 第三个仆人怎样处理他的银子？
    甲）好好运用 乙）埋了起来 丙）弄丢了 👉 乙）埋了起来
  • 主人对那两个好仆人说了什么？
    甲）“做得好！” 乙）“走开！” 丙）“闭嘴！” 👉 甲）“做得好！”
  • 我们的才能是什么？
    甲）神给我们的恩赐 乙）硬币 丙）房子 👉 甲）神给我们的恩赐

3. 运用还是藏起来？ 用/藏

运用写“用”，藏起来写“藏”：

  • 我唱关于耶稣的歌。( ___ ) 👉 用
  • 我很会画画，却从不与人分享。( ___ ) 👉 藏
  • 我给我的朋友们讲圣经故事。( ___ ) 👉 用

4. 讨论题

  • 你擅长什么？

参考答案：答案各不相同，例如唱歌或画画。

  • 你怎样用它来为耶稣做事？

参考答案：帮助别人，并把祂告诉他们。

  • 主人为什么对第三个仆人不高兴？

参考答案：他对所得到的什么也没做。

5. 背诵经文：

马太福音 25:21 ——“好，你这又良善又忠心的仆人，你在不多的事上有忠心……可以进来享受你主人的快乐！”

歌罗西书 3:23 ——“无论做什么，都要从心里做，像是给主做的。”

6. 给图画涂色：

手工 1：才能银币

材料： 金色纸、剪刀、线、蜡笔

步骤：

  • 剪出金色的纸圆片。
  • 在每一片上写上或画出你有的一种才能。
  • 把它们穿成一条链子。

课程重点： 神给我们每个人恩赐，让我们去运用。

手工 2：我的才能徽章

材料： 卡纸、安全别针或胶带、蜡笔

步骤：

  • 用卡纸剪一个圆形的徽章。
  • 画出你擅长的事。
  • 写上：“我要为耶稣运用它。”

课程重点： 我们应该把我们的恩赐用来服事神。

游戏 1：展示你的才能

玩法：

  • 每个孩子展示或说出一件他们擅长的事。
  • 全班欢呼，并说出一种为耶稣运用它的方法。
  • 每个人都轮流一次。

课程重点： 每个孩子都有神所赐的才能。

游戏 2：把它挖出来

玩法：

  • 把纸硬币藏在杯子底下。
  • 孩子们找到它们，并说说他们会怎样运用这份恩赐。
  • 不要让任何一枚硬币藏着！

课程重点： 我们应该运用我们的才能，而不是把它们埋起来。
