向神祷告

目标

向孩子们说明：耶稣怎样开始教导祂的门徒祷告。

经文阅读

马太福音 6:5-15；路加福音 11:1；尼希米记 1:1-11；2:1-9

背诵经文

马太福音 6:6

“你祷告的时候，要进你的内屋，关上门，祷告你在暗中的父；你父在暗中察看，必然报答你。”

讲授课程

起点

举一些人们为了吸引别人注意所做的事的例子。他们可以大喊、挥动手臂、敲鼓或吹号角。也让孩子们提出一些建议。每个人都会看这个做这类事的人，想知道发生了什么事。

课程重点

1. 出示图片 5。向全班就这幅图提问。右边的人在看谁？给孩子们时间回答。对，他们在看这个人，他穿着华丽的衣服，在街角大声祷告。耶稣看见宗教领袖们这样祷告，为的是让每个人都注意到他们，以为他们非常敬虔。耶稣说，别人的称赞，就是这种人祷告所得的全部报赏（马太福音 6:5）。

2. 耶稣说，我们要像图片 5 中的另一个人那样祷告。他在自己的房间里独自与神相处。他不是要用他的祷告给别人留下深刻印象（马太福音 6:6）。注：（甲）这幅图有一点误导。在圣经里，第二个人是在关着的门后面祷告（6:6）。在图里，门是开着的；而那个人跪在门后面，所以他不是在向邻居炫耀。

（乙）犹太男人习惯蒙着头祷告。

3. 讲尼希米的故事，作为耶稣教导人怎样祷告的一个例子。尼希米从耶路撒冷来的访客给他带来了非常悲伤的消息。他故乡的京城仍然是一片废墟。尼希米在他可以独处的地方祷告，向神述说这使他多么悲伤，并求问神他该怎么办（尼希米记 1:1-10）。他这样做了四个月！

4. 尼希米对神说话、也听神说话之后，才去见波斯王，他是波斯王的仆人。王问他为什么看起来这么悲伤，尼希米就把耶路撒冷的事告诉了他。王准他去访问那座城，还给了他建筑材料和路上的保护（2:1-9）。这远远超过了尼希米所祷告求的。

牢记背诵经文

我们对这个故事的回应

如果你这位老师能分享一个自己生活中蒙应允祷告的故事，这一课会有更大的影响。

第 5 课：向神祷告

经文阅读： 马太福音 6:5-15；路加福音 11:1；尼希米记 1:1-11；2:1-9

1. 连线配对

A

B

宗教领袖

大声祷告好让人看见

耶稣的方式

单独向你的父祷告

尼希米

答案：
宗教领袖 → 大声祷告好让人看见
耶稣的方式 → 单独向你的父祷告
尼希米 → 为耶路撒冷祷告
王 → 给了他帮助和木材

2. 数一数，写下来

写出答案：

  • 尼希米祷告了____个月。 __________ 👉 四
  • 耶稣说，祷告的时候要关上____________。 __________ 👉 门
  • 神是我们在天上的____________。 __________ 👉 父

3. 对的祷告还是错的祷告？ 对/错

对的写“对”，错的写“错”：

  • 安静地祷告，把一切都告诉神。( ___ ) 👉 对
  • 大声祷告，好让人们说：“多么好！”( ___ ) 👉 错
  • 祷告之后听神说话。( ___ ) 👉 对

4. 讨论题

  • 耶稣说我们可以在哪里祷告？

参考答案：在安静的地方，单独与神相处。

  • 什么使尼希米悲伤？

参考答案：耶路撒冷仍是一片废墟。

  • 你在祷告中可以为什么感谢神？

参考答案：答案各不相同，例如家人、食物和朋友。

5. 背诵经文：

马太福音 6:6 ——“你祷告的时候，要进你的内屋，关上门，祷告你在暗中的父；你父在暗中察看，必然报答你。”

帖撒罗尼迦前书 5:17 ——“要不住地祷告。”

手工 1：祷告的双手

材料： 纸、剪刀、蜡笔、胶水

步骤：

  • 把你的两只手并排描下来，手指并拢。
  • 把它们剪下来，在手腕处折起来。
  • 在里面写上：“感谢你，父。”

课程重点： 我们可以在任何地方、任何时候与神说话。

手工 2：祷告门牌

材料： 卡纸、剪刀、蜡笔、细绳

步骤：

  • 剪一张门形的卡纸，顶部打一个孔。
  • 涂上颜色，并写上：“与神的安静时间。”
  • 把它挂在家里的门上。

课程重点： 耶稣教导我们在暗中祷告。

游戏 1：安静的角落

玩法：

  • 一次一个人走到房间里安静的角落。
  • 每个孩子默默地说一句很短的祷告。
  • 不说话，回到圈里。

课程重点： 我们安静祷告时，神听我们。

游戏 2：传祷告

玩法：

  • 围坐成一圈，传递一个软球。
  • 拿到它的孩子说：“感谢你，神，为……”
  • 一直传下去，直到每个人都祷告过。

课程重点： 祷告就是简单地与神说话。
