又聋又哑的人听见了也说话了

目标

教导孩子们：耶稣运用祂对疾病和痛苦的权柄，向人们显明祂真的是神的儿子。

经文阅读

马可福音 7:31-37

背诵经文

马可福音 7:37

“[耶稣]所做的事都好，……连聋子也叫他们听见，哑巴也叫他们说话。”

讲授课程

起点

请班上几个孩子用手捂住耳朵。然后用你平常的声音，请他们做一件简单的事。例如：“到桌子上拿一本书来”或者“站起来。”他们不会听得很清楚，其他孩子可能会对他们大声喊这个要求，或者用手势把你的意思传达给他们。

这可能会造成一些混乱！不过，这正是你想要说明的重点。聋子的生活非常艰难，因为他们不能明白周围发生的事。失去听力已经够糟糕了，而生来就聋的人往往也是哑的，因为人是靠听周围的人说话、重复他们听到别人所用的声音和词语来学会说话的。

课程重点

1. 有一天，一个又聋又哑的人的朋友们把他带到耶稣面前。他们求耶稣帮助（7:32）。

2. 耶稣把那人带到一边，免得他被总是跟着耶稣的人群吓着。那人可能连耶稣是谁都不知道！因为他听不见祂的话，耶稣就用手势向他表明祂要做什么。把指头探进他的耳朵，是表示耶稣要医好他的耳聋。摸他的舌头，是表示耶稣要使他说话。向天举目，是祷告的表示（7:33-34上）。

3. 耶稣祷告，说：“开了吧”（7:34）。出示图片 22。

那人立刻就能听见，也能说话了（7:35）。

4. 每一个听见这个从前又聋又哑的人说话的人，都惊讶不已。他们不停地谈论耶稣所行的奇妙神迹。

牢记背诵经文

我们对这一课的回应

每一个看见这些神迹的人都惊讶不已。故事里的人说耶稣所做的事都好。他们说得对。

耶稣是完美的，因为祂是神。但是在祂住在世上的时候，很少有人信靠祂、爱祂。祂要我们信靠祂、爱祂，因为祂能完美地爱我们、帮助我们。

第 22 课：又聋又哑的人听见了也说话了

经文阅读： 马可福音 7:31-37

1. 连线配对

A

B

朋友们

把那人带到耶稣面前

耶稣

把他带到一边并医治了他

那个人

能听见也能说话了

人群

惊讶不已

答案：
朋友们 → 把那人带到耶稣面前
耶稣 → 把他带到一边并医治了他
那个人 → 能听见也能说话了
人群 → 惊讶不已

2. 缺失的字

填上缺少的字：

  • 听 _ __________ 👉 听见
  • 讲 _ __________ 👉 讲话
  • 惊 _ __________ 👉 惊奇

3. 对还是错

写“对”或“错”：

  • 耶稣把那人带离人群。( ___ ) 👉 对
  • 耶稣说：“开了吧！”( ___ ) 👉 对
  • 人们对这神迹保持沉默。( ___ ) 👉 错

4. 讨论题

  • 耶稣为什么把那人带到一边？

参考答案：免得他被人群吓着。

  • 人们对耶稣说了什么？

参考答案：祂所做的事都好。

  • 我们怎样把我们的耳朵和嘴用于耶稣？

参考答案：聆听祂的话，并把祂告诉别人。

5. 背诵经文：

马可福音 7:37 ——“祂所做的事都好，连聋子也叫他们听见，哑巴也叫他们说话。”

以赛亚书 35:5 ——“那时瞎子的眼必睁开，聋子的耳必开通。”

手工 1：听见的耳朵

材料： 卡纸、蜡笔、剪刀

步骤：

  • 用卡纸剪一个大大的耳朵形状。
  • 涂上颜色，并写上：“耶稣帮助我听见。”
  • 再装饰上一张微笑的小嘴。

课程重点： 耶稣关心那些不能听、不能说的人。

手工 2：手语卡片

材料： 卡纸、蜡笔

步骤：

  • 在卡片上画出表示“爱”的手势。
  • 把手涂上鲜艳的颜色。
  • 写上：“我爱耶稣。”

课程重点： 我们不用言语也能表达爱。

游戏 1：无声的信息

玩法：

  • 一个孩子默默地做出一个简单的动作，比如吃饭或睡觉。
  • 其他孩子猜是什么动作。
  • 谈谈聋人怎样使用手势。

课程重点： 耶稣用手势帮助聋子明白。

游戏 2：开了吧！

玩法：

  • 孩子们捂住耳朵，安静地站着。
  • 老师说“开了吧！”，他们就把耳朵放开。
  • 他们说：“感谢你，耶稣，赐给我们耳朵！”

课程重点： 耶稣有医治的能力。
