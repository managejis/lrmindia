死去的孩子又活了

目标

教导孩子们：耶稣对生死有权柄。跟从祂的人不必惧怕死亡。

经文阅读

马可福音 5:22-24, 35-43

背诵经文

马可福音 5:36

“不要怕，只要信。”

讲授课程

起点

你们当中有谁最近生过病？那是什么感觉？它使你感到害怕吗？人病得很重的时候，有时会非常害怕。他们害怕死亡。

课程重点

1. 一个小女孩病得很重。她的父亲睚鲁是个有地位的人，但他所有的财富对她都没有帮助。后来他听说，医治过那么多人的耶稣就在附近。睚鲁就出去找耶稣。

2. 睚鲁恳求耶稣到他家里去，帮助他的女儿。睚鲁是个有地位的人，但他在耶稣面前谦卑下来（可 5:22-23）。

3. 耶稣开始跟着睚鲁往他家去，但路上因为许多想见祂的人而耽搁了（5:24）。还没到睚鲁的家，就有消息传来，说他的女儿死了（5:35）。

4. 耶稣告诉睚鲁不要放弃希望，只要信靠祂（5:36）。

5. 耶稣到了睚鲁的家，那里已经开始预备丧事了。祂叫大家不要哭了，因为小女孩没有死，只是睡着了。大家都不信，嘲笑耶稣（5:38-40上）。

6. 在屋子里，只有女孩的父母和彼得、雅各、约翰在场，耶稣使小女孩复活了（5:37, 40-43）。出示图片 20。

耶稣对死亡有权柄，因为祂是神。祂能使人从死里复活。

牢记背诵经文

我们对这个故事的回应

了解一下孩子们害怕什么。可能是去诊所或医院，或者只是生病。耶稣告诉睚鲁要信祂，不要怕。我们害怕的时候，也可以信靠耶稣。

第 20 课：死去的孩子又活了

经文阅读： 马可福音 5:22-24, 35-43

1. 连线配对

A

B

睚鲁

求耶稣帮助他的女儿

小女孩

复活了

彼得、雅各和约翰

和耶稣一起进去了

耶稣

说：“不要怕”

答案：
睚鲁 → 求耶稣帮助他的女儿
小女孩 → 复活了
彼得、雅各和约翰 → 和耶稣一起进去了
耶稣 → 说：“不要怕”

2. 圈出正确的词

圈出正确的词：

  • 睚鲁的女儿（十二 / 一百）岁。 👉 十二
  • 耶稣说：“不要（怕 / 懒），只要信。” 👉 怕
  • 耶稣对（死亡 / 虚无）有权柄。 👉 死亡

3. 是或否

写上“是”或“否”：

  • 睚鲁是个有地位的人吗？( ___ ) 👉 是
  • 耶稣说她只是睡着了吗？( ___ ) 👉 是
  • 我们害怕或生病的时候，耶稣关心吗？( ___ ) 👉 是

4. 讨论题

  • 睚鲁的女儿病了的时候，他做了什么？

参考答案：他去找耶稣，恳求帮助。

  • 耶稣对睚鲁说了什么？

参考答案：不要怕，只要信。

  • 什么使你害怕？你可以做什么？

参考答案：答案各不相同；我们可以信靠耶稣，并祷告。

5. 背诵经文：

马可福音 5:36 ——“不要怕，只要信。”

约翰福音 11:25 ——“耶稣说：‘复活在我，生命也在我。’”

6. 给图画涂色：

手工 1：小床

材料： 一个小盒子、碎布、一个纸娃娃

步骤：

  • 用纸做一个娃娃。
  • 用布在盒子里做一张小床。
  • 把娃娃放在里面，并写上：“起来！”

课程重点： 耶稣对生死有权柄。

手工 2：赶走害怕卡片

材料： 卡纸、蜡笔

步骤：

  • 在一半上画一件使你害怕的东西。
  • 在另一半上画耶稣拉着你的手。
  • 写上：“不要怕。”

课程重点： 我们害怕的时候可以信靠耶稣。

游戏 1：醒来！

玩法：

  • 孩子们假装睡在地板上。
  • 老师说：“耶稣说，醒来！”他们就站起来欢呼。
  • 换另一个“耶稣”，再玩一次。

课程重点： 耶稣有赐生命的能力。

游戏 2：相信之路

玩法：

  • 沿着一条路放上卡片，上面写着“信靠”“相信”“爱”这样的词。
  • 孩子们一边走，一边念出每张卡片上的词。
  • 最后说背诵经文。

课程重点： 耶稣要我们信靠祂，不要害怕。
