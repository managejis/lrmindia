耶稣平息风暴

目标

教导孩子们：耶稣的能力胜过天上地下的任何其他能力。我们可以信靠祂与我们同在，保护我们。

经文阅读

马可福音 4:35-41

背诵经文

马太福音 28:18

耶稣进前来，对他们说：“天上地下所有的权柄都赐给我了。”

讲授课程

起点

讲一讲你曾经非常害怕的一次经历，因为有一件你完全无能为力的事正在发生。例如：1989 年 2 月和 1990 年，苏丹南部的朱巴遭到炮击的时候。

课程重点

1. 门徒们非常害怕。他们在船上，遇到了风暴。有几个门徒在成为耶稣的门徒之前是渔夫，但即使是他们也很害怕。描述海上的风暴；想一想它发出的声音。水直灌进船里（可 4:37）！

2. 耶稣和他们在一起，但祂正睡在船尾。门徒们把祂叫醒。他们对耶稣很生气。他们认为祂不在乎他们会怎么样（4:38）。

3. 耶稣起来，止住了风暴。描述所发生的事（4:39）。

出示图片 18。

4. 然后耶稣对祂的门徒说话。他们以前见过祂行许多神迹。如果有时间，请全班说说门徒们看见耶稣行过的一些神迹。

尽管和耶稣一起生活，看见、听见祂所做的和所教导的一切，门徒们还是不明白耶稣就是神自己。祂创造了存在的一切，祂甚至能控制大自然的力量，比如风暴。门徒们觉得这很难理解（4:40-41）。

牢记背诵经文

我们对这个故事的回应

有时候，当我们认为自己遇到危险的时候，我们的表现就和门徒们一模一样。他们指责耶稣不关心他们。我们有时候也这样做。然而，耶稣在危险之中与我们同在。没有任何能力比祂的能力更大，那是神的能力。我们需要信靠祂。给孩子们读罗马书 8:35, 37-39。

第 18 课：耶稣平息风暴

经文阅读： 马可福音 4:35-41

1. 我是谁？

写出答案：

  • 我睡在船尾。我是谁？ __________ 👉 耶稣
  • 我们在风暴中很害怕，就叫醒了耶稣。我们是谁？ __________ 👉 门徒
  • 耶稣说：“住了吧！静了吧！”我就停了。我是什么？ __________ 👉 风暴

2. 信靠还是忧虑？ 信/忧

信靠写“信”，忧虑写“忧”：

  • 在黑暗中，耶稣与我同在。( ___ ) 👉 信
  • 我确信没有人关心我。( ___ ) 👉 忧
  • 我害怕的时候就祷告。( ___ ) 👉 信

3. 连线配对

A

B

风暴

波浪涌进船里

门徒们

非常害怕

耶稣

止住了风

海

平静下来

答案：
风暴 → 波浪涌进船里
门徒 → 非常害怕
耶稣 → 止住了风
海 → 平静下来

4. 讨论题

  • 门徒们虽然是渔夫，为什么还是很害怕？

参考答案：风暴非常大，船里灌满了水。

  • 耶稣制伏风暴的能力显明了什么？

参考答案：祂是神，掌管一切。

  • 你害怕的时候可以做什么？

参考答案：信靠耶稣，向祂祷告。

5. 背诵经文：

马太福音 28:18 ——“耶稣进前来，对他们说：‘天上地下所有的权柄都赐给我了。’”

诗篇 56:3 — “我惧怕的时候要依靠你。”

6. 给图画涂色：

手工 1：风暴中的船

材料： 蓝纸做的波浪、棕色纸做的船、胶水、卡纸

步骤：

  • 把波浪形的蓝纸条粘在卡纸上。
  • 把一只棕色的船粘在波浪上。
  • 在船里画上耶稣，并写上：“住了吧！静了吧！”

课程重点： 无论遇到什么风暴，耶稣都与我们同在。

手工 2：平静的海面图画

材料： 浅蓝色纸、蜡笔、胶水

步骤：

  • 在一张纸上画出平直、光滑的蓝色线条。
  • 加上一只小船和一个微笑的太阳。
  • 写上：“耶稣更大。”

课程重点： 耶稣平息使我们害怕的事。

游戏 1：风暴与平静

玩法：

  • 孩子们用拍打和跺脚发出风暴的声音。
  • 老师说：“住了吧！静了吧！”大家就都一动不动。
  • 换另一个孩子扮演“耶稣”，再玩一次。

课程重点： 耶稣的声音带来平静。

游戏 2：划船

玩法：

  • 孩子们一排一排地坐着当作一条船，一起“划船”。
  • 老师喊“风暴！”，他们就更用力地划。
  • 一喊“耶稣！”，他们就停下来欢呼。

课程重点： 耶稣比任何风暴都强大。
