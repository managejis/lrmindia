ಇಸ್ರಾಯೇಲಿನ ನಾಯಕ ಯೆಹೋಶುವನ ವಿದಾಯ

Download Word

ಉದ್ದೇಶ: ದೇವರನ್ನು ನಂಬಿಗಸ್ತಿಕೆಯಿಂದ ಅನುಸರಿಸುವಂತೆ ಯೆಹೋಶುವ ಇಸ್ರಾಯೇಲ್ಯರನ್ನು ಹೇಗೆ ಪ್ರೋತ್ಸಾಹಿಸಿದನು, ಮತ್ತು ದೇವರು ಯಾವಾಗಲೂ ತನ್ನ ವಾಗ್ದಾನಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತಾನೆ ಎಂಬುದನ್ನು ಮಕ್ಕಳಿಗೆ ತೋರಿಸುವುದು.

ಬೈಬಲ್ ವಾಚನ: ಯೆಹೋಶುವ 23:1-16; 24:1-31

ಕಂಠಪಾಠ ವಚನ: ಯೆಹೋಶುವ 23:14 – “ನಿಮ್ಮ ದೇವರಾದ ಯೆಹೋವನು ನಿಮಗೆ ವಾಗ್ದಾನ ಮಾಡಿದ ಒಳ್ಳೆಯ ಮಾತುಗಳಲ್ಲಿ ಒಂದಾದರೂ ತಪ್ಪಿಹೋಗಲಿಲ್ಲವೆಂದು ನೀವು ಪೂರ್ಣ ಹೃದಯದಿಂದಲೂ ಪೂರ್ಣ ಪ್ರಾಣದಿಂದಲೂ ಬಲ್ಲಿರಿ.”

ಪಾಠವನ್ನು ಮಂಡಿಸುವುದು

ಆರಂಭದ ಬಿಂದು

ತಮ್ಮ ಸಮಾಜದಲ್ಲಿ ವೃದ್ಧರ ಸ್ಥಾನದ ಬಗ್ಗೆ ತರಗತಿಯನ್ನು ಕೇಳಿ. ಸಾಮಾನ್ಯವಾಗಿ ಅವರನ್ನು ಗೌರವಿಸಲಾಗುತ್ತದೆ. ವೃದ್ಧರೊಬ್ಬರು ಸಾಯುವ ಸಮಯದಲ್ಲಿ ಹೇಳುವ ಕೊನೆಯ ಮಾತುಗಳಿಗೂ ಸಲಹೆಗೂ ನಾವು ಬಹಳ ಮಹತ್ವ ಕೊಡುತ್ತೇವೆ.

ಇಂದಿನ ಬೋಧನೆಯ ಮುಖ್ಯ ಅಂಶಗಳು

1. ಈಗ ಯೆಹೋಶುವ ವೃದ್ಧನಾಗಿದ್ದನು. ಇಸ್ರಾಯೇಲ್ಯರು ಯೊರ್ದನ್ ನದಿಯನ್ನು ದಾಟಿ ವಾಗ್ದತ್ತ ದೇಶವಾದ ಕಾನಾನಿಗೆ ಬಂದು ಅನೇಕ ವರ್ಷಗಳು ಕಳೆದಿದ್ದವು. ಅವರು ಈಗ ದೇವರು ಕೊಟ್ಟ ದೇಶದಲ್ಲಿ ಹೆಚ್ಚು ಶಾಂತಿಯಿಂದ ವಾಸಿಸುತ್ತಿದ್ದರು. ತಾನು ಹೆಚ್ಚು ಕಾಲ ಬದುಕುವುದಿಲ್ಲ ಎಂದು ಯೆಹೋಶುವನಿಗೆ ತಿಳಿದಾಗ ಅವನು ಜನರನ್ನು ಒಟ್ಟಿಗೆ ಕರೆದು ವಿದಾಯ ಹೇಳಿದನು (23:1-3).

2. ದೇವರು ತನ್ನ ವಾಗ್ದಾನಗಳನ್ನು ಹೇಗೆ ಉಳಿಸಿಕೊಂಡನು ಎಂದು ಯೆಹೋಶುವ ಇಸ್ರಾಯೇಲ್ ಜನರಿಗೆ ನೆನಪಿಸಿದನು. ಆತನು ಅವರನ್ನು ಐಗುಪ್ತದಿಂದ ಸುರಕ್ಷಿತವಾಗಿ ವಾಗ್ದತ್ತ ದೇಶಕ್ಕೆ ತಂದನು. ಶತ್ರುಗಳ ಮೇಲೆ ಅವರಿಗೆ ಜಯಗಳನ್ನು ಕೊಟ್ಟನು. ಪಾಠ 1, 4 ಮತ್ತು 7ರ ಬಗ್ಗೆ ಪ್ರಶ್ನೆಗಳನ್ನು ಕೇಳುವ ಮೂಲಕ ಅವನ್ನು ಸಂಕ್ಷಿಪ್ತವಾಗಿ ಮೆಲುಕು ಹಾಕಿ, ಪ್ರತಿ ಬಾರಿ ದೇವರು ತನ್ನ ವಾಗ್ದಾನಗಳನ್ನು ಹೇಗೆ ಉಳಿಸಿಕೊಂಡನು ಎಂದು ತೋರಿಸಿ (24:6-8, 11-13).

3. ವಾಗ್ದತ್ತ ದೇಶದ ಕೆಲವು ಭಾಗಗಳನ್ನು ಇನ್ನೂ ವಶಪಡಿಸಿಕೊಳ್ಳಬೇಕಿದೆ ಎಂದು ಯೆಹೋಶುವ ಇಸ್ರಾಯೇಲ್ಯರಿಗೆ ನೆನಪಿಸಿದನು. ಬಲವಂತರಾಗಿದ್ದು ದೇವರ ಆಜ್ಞೆಗಳನ್ನು ಪಾಲಿಸಲು ಎಚ್ಚರದಿಂದಿರಿ ಎಂದು ಅವನು ಹೇಳಿದನು (23:4-6, 8-11). ಚಿತ್ರ 8 ತೋರಿಸಿ.

4. ತಾವು ಯಾರನ್ನು ಸೇವಿಸುವೆವು ಎಂದು ತೀರ್ಮಾನಿಸುವಂತೆ ಯೆಹೋಶುವ ಜನರಿಗೆ ಸವಾಲು ಹಾಕಿದನು. ಅವರು ನಂಬಿಗಸ್ತಿಕೆಯಿಂದ ದೇವರನ್ನು ಸೇವಿಸಿದರೆ ಆತನು ಅವರಿಗೆ ತನ್ನ ವಾಗ್ದಾನಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತಲೇ ಇರುವನು. ಅಖಾನನಂತೆ ಅವರು ಅವಿಧೇಯರಾಗಿ ದೇವರನ್ನೂ ಆತನ ಆಜ್ಞೆಗಳನ್ನೂ ಕಡೆಗಣಿಸಿದರೆ ವಾಗ್ದತ್ತ ದೇಶವನ್ನು ಕಳೆದುಕೊಳ್ಳುವರು (23:11, 14-16).

ಕಥೆಗೆ ನಮ್ಮ ಪ್ರತಿಕ್ರಿಯೆ

ದೇವರು ನಮಗೆ ಏನು ವಾಗ್ದಾನ ಮಾಡಿದ್ದಾನೆ ಎಂದು ಮಕ್ಕಳನ್ನು ಹೇಳಲು ಕೇಳಿ. ಅದನ್ನು ಸ್ವೀಕರಿಸುವ ಎಲ್ಲರಿಗೂ ದೇವರು ಅತ್ಯಂತ ಅದ್ಭುತ ಕೊಡುಗೆಯನ್ನು ನೀಡುತ್ತಾನೆ: ಯೇಸು ಕ್ರಿಸ್ತನನ್ನು ಅನುಸರಿಸಿ ದೇವರನ್ನು ಪೂರ್ಣಹೃದಯದಿಂದ ಸೇವಿಸುವವರಿಗೆ ಪಾಪಕ್ಷಮೆ ಮತ್ತು ನಿತ್ಯಜೀವ.

ಕಂಠಪಾಠ ವಚನವನ್ನು ಮನದಲ್ಲಿ ಅಚ್ಚೊತ್ತುವುದು

ಯೆಹೋಶುವ 23:14 – “ನಿಮ್ಮ ದೇವರಾದ ಯೆಹೋವನು ನಿಮಗೆ ವಾಗ್ದಾನ ಮಾಡಿದ ಒಳ್ಳೆಯ ಮಾತುಗಳಲ್ಲಿ ಒಂದಾದರೂ ತಪ್ಪಿಹೋಗಲಿಲ್ಲವೆಂದು ನೀವು ಪೂರ್ಣ ಹೃದಯದಿಂದಲೂ ಪೂರ್ಣ ಪ್ರಾಣದಿಂದಲೂ ಬಲ್ಲಿರಿ.”

ಪಾಠ - 8: ಇಸ್ರಾಯೇಲಿನ ನಾಯಕ ಯೆಹೋಶುವನ ವಿದಾಯ

ಬೈಬಲ್ ವಾಚನ: ಯೆಹೋಶುವ 23:1-16; 24:1-31

1. ನಾನು ಯಾರು?

ಆರಿಸಿ: ಯೆಹೋಶುವ, ದೇವರು, ಇಸ್ರಾಯೇಲ್ಯರು

  1. ನಾನು ವೃದ್ಧನಾಗಿ ನನ್ನ ಜನರಿಗೆ ವಿದಾಯ ಹೇಳಿದೆ. ನಾನು ಯಾರು? __________ 👉 ಯೆಹೋಶುವ

  2. ನಾನು ಯಾವಾಗಲೂ ನನ್ನ ವಾಗ್ದಾನಗಳನ್ನು ನೆರವೇರಿಸುತ್ತೇನೆ. ನಾನು ಯಾರು? __________ 👉 ದೇವರು

  3. ನಾವು ಯಾರನ್ನು ಸೇವಿಸುತ್ತೇವೆಂದು ಆರಿಸಿಕೊಳ್ಳಲು ನಮಗೆ ಹೇಳಲಾಯಿತು. ನಾವು ಯಾರು? __________ 👉 ಇಸ್ರಾಯೇಲ್ಯರು

2. ದೇವರು ತನ್ನ ಮಾತನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತಾನೆ: ಹೌದೋ ಇಲ್ಲವೋ? ಹೌ/ಇ

ಹೌದು ಎಂದರೆ ಹೌ, ಇಲ್ಲ ಎಂದರೆ ಇ ಎಂದು ಬರೆಯಿರಿ:

  1. ದೇವರು ಇಸ್ರಾಯೇಲ್ಯರನ್ನು ಐಗುಪ್ತದಿಂದ ಹೊರಗೆ ತಂದನೇ? ( ___ ) 👉 ಹೌ

  2. ದೇವರು ಇಸ್ರಾಯೇಲಿಗೆ ಜಯಗಳನ್ನು ಕೊಟ್ಟನೇ? ( ___ ) 👉 ಹೌ

  3. ದೇವರ ವಾಗ್ದಾನಗಳಲ್ಲಿ ಒಂದಾದರೂ ವಿಫಲವಾಯಿತೇ? ( ___ ) 👉 ಇ

3. ವಾಕ್ಯಗಳನ್ನು ಪೂರ್ಣಗೊಳಿಸಿ

ಪದಪೆಟ್ಟಿಗೆ: ಸೇವಿಸಿರಿ, ವಾಗ್ದಾನಗಳನ್ನು, ಬಲವಂತರಾಗಿರಿ

  1. ಯೆಹೋಶುವ, “____________, ದೇವರಿಗೆ ವಿಧೇಯರಾಗಿರಿ” ಎಂದನು. __________ 👉 ಬಲವಂತರಾಗಿರಿ

  2. ದೇವರು ತನ್ನ ಎಲ್ಲಾ ____________ ಉಳಿಸಿಕೊಳ್ಳುತ್ತಾನೆ. __________ 👉 ವಾಗ್ದಾನಗಳನ್ನು

  3. ಯಾರನ್ನು ____________ ಎಂದು ಆರಿಸಿಕೊಳ್ಳಿ. __________ 👉 ಸೇವಿಸಿರಿ

4. ಚರ್ಚೆಯ ಪ್ರಶ್ನೆಗಳು

  1. ಯೆಹೋಶುವನು ಜನರನ್ನು ಏಕೆ ಒಟ್ಟುಗೂಡಿಸಿದನು?

    ಮಾದರಿ ಉತ್ತರ: ಅವನು ವೃದ್ಧನಾಗಿದ್ದನು, ದೇವರ ವಾಗ್ದಾನಗಳನ್ನು ನೆನಪಿಸಲು ಬಯಸಿದನು.

  2. ದೇವರು ನಮಗೆ ಯಾವ ವಾಗ್ದಾನಗಳನ್ನು ಮಾಡಿದ್ದಾನೆ?

    ಮಾದರಿ ಉತ್ತರ: ಕ್ಷಮೆ ಮತ್ತು ಯೇಸುವಿನೊಂದಿಗೆ ಶಾಶ್ವತ ಜೀವ.

  3. ನಾವು ದೇವರನ್ನು ಹೇಗೆ ಸೇವಿಸಬಹುದು?

    ಮಾದರಿ ಉತ್ತರ: ಆತನಿಗೆ ವಿಧೇಯರಾಗಿ ಇತರರೊಡನೆ ದಯೆಯಿಂದ ನಡೆದುಕೊಳ್ಳುವ ಮೂಲಕ.

5. ಕಂಠಪಾಠ ವಚನ:

ಯೆಹೋಶುವ 23:14 — “ನಿಮ್ಮ ದೇವರಾದ ಯೆಹೋವನು ನಿಮಗೆ ವಾಗ್ದಾನ ಮಾಡಿದ ಒಳ್ಳೆಯ ಮಾತುಗಳಲ್ಲಿ ಒಂದಾದರೂ ತಪ್ಪಿಹೋಗಲಿಲ್ಲವೆಂದು ನೀವು ಪೂರ್ಣ ಹೃದಯದಿಂದಲೂ ಪೂರ್ಣ ಪ್ರಾಣದಿಂದಲೂ ಬಲ್ಲಿರಿ.”

ಯೆಹೋಶುವ 24:15 — “ನಾನೂ ನನ್ನ ಮನೆಯವರೂ ಯೆಹೋವನನ್ನೇ ಸೇವಿಸುವೆವು.”

ಕರಕುಶಲ 1: ವಾಗ್ದಾನದ ಸುರುಳಿ

ಬೇಕಾದ ಸಾಮಗ್ರಿಗಳು: ಕಾಗದ, ದಾರ, ಬಣ್ಣದ ಕಡ್ಡಿಗಳು

ವಿಧಾನ:

  1. ಬರೆಯಿರಿ: “ದೇವರು ತನ್ನ ವಾಗ್ದಾನಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತಾನೆ.”

  2. ಅಂಚುಗಳನ್ನು ಅಲಂಕರಿಸಿ.

  3. ಸುರುಳಿ ಸುತ್ತಿ ದಾರದಿಂದ ಕಟ್ಟಿ.

ಪಾಠದ ಮುಖ್ಯ ಅಂಶ: ದೇವರು ಎಂದಿಗೂ ವಾಗ್ದಾನವನ್ನು ಮುರಿಯುವುದಿಲ್ಲ.

ಕರಕುಶಲ 2: ನನ್ನ ಆಯ್ಕೆಯ ಕಾರ್ಡ್

ಬೇಕಾದ ಸಾಮಗ್ರಿಗಳು: ಮಡಚಿದ ಕಾರ್ಡ್, ಬಣ್ಣದ ಕಡ್ಡಿಗಳು

ವಿಧಾನ:

  1. ಮುಂಭಾಗದಲ್ಲಿ ನಿಮ್ಮ ಚಿತ್ರ ಬಿಡಿಸಿ.

  2. ಒಳಗೆ ಬರೆಯಿರಿ: “ನಾನು ಯೆಹೋವನನ್ನು ಸೇವಿಸುತ್ತೇನೆ.”

  3. ನಿಮ್ಮ ಹೆಸರು ಬರೆಯಿರಿ.

ಪಾಠದ ಮುಖ್ಯ ಅಂಶ: ನಾವು ದೇವರನ್ನು ಸೇವಿಸಲು ಆರಿಸಿಕೊಳ್ಳಬಹುದು.

ಆಟ 1: ಯಾವ ಕಡೆ?

ಆಡುವ ವಿಧಾನ:

  1. ಎರಡು ಫಲಕಗಳನ್ನು ಬರೆಯಿರಿ: “ದೇವರನ್ನು ಸೇವಿಸು” ಮತ್ತು “ಸೇವಿಸಬೇಡ”.

  2. ಒಂದು ಕ್ರಿಯೆಯನ್ನು ಓದಿ, ಮಕ್ಕಳು ಒಂದು ಫಲಕದ ಬಳಿ ಹೋಗಲಿ.

  3. “ದೇವರನ್ನು ಸೇವಿಸು” ಎನ್ನುವುದಕ್ಕೆ ಹರ್ಷೋದ್ಗಾರ ಮಾಡಿ.

ಪಾಠದ ಮುಖ್ಯ ಅಂಶ: ನಾವು ದೇವರನ್ನು ಸೇವಿಸಲು ಆರಿಸಿಕೊಳ್ಳುತ್ತೇವೆ.

ಆಟ 2: ವಾಗ್ದಾನವನ್ನು ನೆನಪಿಡಿ

ಆಡುವ ವಿಧಾನ:

  1. ಪಾಠದ ಒಂದು ವಾಗ್ದಾನವನ್ನು ಹೇಳಿ.

  2. ಮಕ್ಕಳು ಸರದಿಯಂತೆ ಅದನ್ನು ಪುನರಾವರ್ತಿಸಲಿ.

  3. ಪ್ರತಿ ಬಾರಿ ಚಪ್ಪಾಳೆ ತಟ್ಟಿ.
