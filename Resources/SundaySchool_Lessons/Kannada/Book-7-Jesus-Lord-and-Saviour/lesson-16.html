ಐಶ್ವರ್ಯವಂತ ಮೂರ್ಖನು ಮರೆತದ್ದು

Download Word

ಉದ್ದೇಶ: ಜೀವನದಲ್ಲಿ ಆಸ್ತಿಪಾಸ್ತಿಗಿಂತ ಹೆಚ್ಚು ಮುಖ್ಯವಾದ ಸಂಗತಿಗಳಿವೆ ಎಂದು ಮಕ್ಕಳಿಗೆ ಕಲಿಸುವುದು.

ಶಾಸ್ತ್ರ ಓದು: ಲೂಕ 12:15-21

ನೆನಪಿನ ವಚನ: ಯೋಹಾನ 1:12 – 15ನೇ ಪಾಠದ ನೆನಪಿನ ವಚನವನ್ನು ಪೂರ್ಣಗೊಳಿಸಿ. “ಆದರೆ ತನ್ನನ್ನು ಅಂಗೀಕರಿಸಿದವರೆಲ್ಲರಿಗೂ, ಅಂದರೆ ತನ್ನ ಹೆಸರಿನಲ್ಲಿ ನಂಬಿಕೆಯಿಟ್ಟವರಿಗೆ, ದೇವರ ಮಕ್ಕಳಾಗುವ ಅಧಿಕಾರವನ್ನು ಆತನು ಕೊಟ್ಟನು ...”

ಪಾಠವನ್ನು ಪ್ರಸ್ತುತಪಡಿಸುವುದು

ಆರಂಭದ ಹಂತ

ಬಹುತೇಕ ಎಲ್ಲರೂ ಶ್ರೀಮಂತರಾಗಲು ಬಯಸುತ್ತಾರೆ! ನೀವು ಶ್ರೀಮಂತರಾಗಿದ್ದರೆ ಯಾವುದನ್ನು ಹೊಂದಲು ಬಯಸುತ್ತೀರಿ?

ಇಂದಿನ ಪಾಠದ ಮುಖ್ಯ ಅಂಶಗಳು

1. ಹೆಚ್ಚಿನ ಜನರು ಮರೆಯುವ ಸಂಗತಿ ಏನೆಂದರೆ, ದೊಡ್ಡ ಸಂಪತ್ತಿನೊಂದಿಗೆ ದೊಡ್ಡ ಜವಾಬ್ದಾರಿಗಳೂ ಬರುತ್ತವೆ. ಯೇಸು ಒಬ್ಬ ಶ್ರೀಮಂತನ ಬಗ್ಗೆ ಕಥೆ ಹೇಳಿದನು. ಅವನು ತನ್ನ ಜವಾಬ್ದಾರಿಗಳನ್ನು ನೆನಪಿಟ್ಟುಕೊಂಡನೇ ಎಂದು ಕೇಳಿ ನೋಡಿ.

2. ಆ ಶ್ರೀಮಂತನಿಗೆ ಒಳ್ಳೆಯ ಬೆಳೆ ಕೊಡುವ ಫಲವತ್ತಾದ ಜಮೀನಿತ್ತು. ವಾಸ್ತವದಲ್ಲಿ ಅವನಿಗೆ ಧಾನ್ಯ ಇಡಲು ಜಾಗವೇ ಸಾಲದಾಯಿತು. ಚಿತ್ರ 16ನ್ನು ತೋರಿಸಿ. ದೊಡ್ಡ ಕಣಜಗಳನ್ನು ಕಟ್ಟುವುದೇ ಪರಿಹಾರ ಎಂದು ಅವನು ತೀರ್ಮಾನಿಸಿದನು (12:16-18).

3. ತನ್ನ ಸುತ್ತಲಿನ ಬಡವರೊಂದಿಗೆ ತನ್ನ ಸಂಪತ್ತನ್ನು ಹಂಚಿಕೊಳ್ಳುವ ಯೋಚನೆಯೇ ಆ ಶ್ರೀಮಂತನಿಗೆ ಬರಲಿಲ್ಲ. ತನ್ನ ಆಶೀರ್ವಾದಗಳು ದೇವರಿಂದ ಬಂದವು ಎಂಬುದೂ ಅವನಿಗೆ ಅರಿವಾಗಲಿಲ್ಲ. ಅವನು ಲಕ್ಷಿಸಿದ್ದು, ಮೆಚ್ಚಿಸಬೇಕೆಂದಿದ್ದದ್ದು ತನ್ನನ್ನೇ (12:19).

4. ಕೊನೆಗೆ ಆ ಶ್ರೀಮಂತನಿಗೆ ತಿಳಿದಂತೆ, ಹಣದಿಂದ ಎಲ್ಲವನ್ನೂ ಕೊಳ್ಳಲಾಗುವುದಿಲ್ಲ. ಆ ಶ್ರೀಮಂತನಿಗೆ ಫಲವತ್ತಾದ ಬೆಳೆಗಳನ್ನು ಕೊಟ್ಟ ದೇವರೇ ಅವನ ಪ್ರಾಣವನ್ನು ತೆಗೆದುಕೊಂಡನು. ಆಗ ಅವನ ಆಸ್ತಿಯಿಂದ ಅವನಿಗೆ ಏನೂ ಪ್ರಯೋಜನವಾಗಲಿಲ್ಲ. ದೇವರನ್ನು ಮರೆತು ಈ ಲೋಕದ ಐಶ್ವರ್ಯ ಮತ್ತು ಸುಖಗಳಿಗಾಗಿ ಬದುಕಿದ ಆ ಶ್ರೀಮಂತನು ಮೂರ್ಖನಾಗಿದ್ದನು (12:20-21).

ಕಥೆಗೆ ನಮ್ಮ ಪ್ರತಿಕ್ರಿಯೆ

ನಮ್ಮಲ್ಲಿರುವ ವಸ್ತುಗಳು ನಮ್ಮ ಜೀವನದಲ್ಲಿ ಎರಡನೆಯ ಸ್ಥಾನದಲ್ಲಿರಬೇಕೆಂದು ಯೇಸು ನಾವು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಬೇಕೆಂದು ಬಯಸುತ್ತಾನೆ. ನಮ್ಮಲ್ಲಿರುವ ಎಲ್ಲವನ್ನೂ ಕೊಡುವವನು ದೇವರು; ಆದ್ದರಿಂದ ಆತನಿಗೇ ಮೊದಲ ಸ್ಥಾನ ಇರಬೇಕು. ಮೊದಲು ನಾವು ಆತನನ್ನು ಮೆಚ್ಚಿಸುವುದರ ಬಗ್ಗೆ ಕಾಳಜಿ ವಹಿಸಬೇಕು.

ಅಂದರೆ ಈ ಕಥೆಯ ಪಾಠ ನಾವು ಶ್ರೀಮಂತರೆಂದು ಭಾವಿಸುವವರಿಗೆ ಮಾತ್ರವಲ್ಲ, ನಮ್ಮೆಲ್ಲರಿಗೂ ಅನ್ವಯಿಸುತ್ತದೆ. ಬಡವರೂ ಎಷ್ಟು ದುರಾಸೆಯವರೋ ಅಸೂಯೆಪಡುವವರೋ ಆಗಬಹುದೆಂದರೆ, ಆಸ್ತಿಪಾಸ್ತಿಯೇ ಅವರ ಜೀವನದಲ್ಲಿ ಅತಿ ಮುಖ್ಯವಾಗಿಬಿಡುತ್ತದೆ. ಕಥೆಯಲ್ಲಿ ಆ ಶ್ರೀಮಂತನ ಜೀವನದಲ್ಲಿಯೂ ಯೋಜನೆಗಳಲ್ಲಿಯೂ ದೇವರಿಗೆ ಸ್ಥಾನವೇ ಇರಲಿಲ್ಲ.

ದೇವರಿಂದ ನಾವು ಪಡೆದದ್ದನ್ನು ಹಂಚಿಕೊಂಡಾಗ ಆತನಿಗೆ ಮೆಚ್ಚಿಗೆಯಾಗುತ್ತದೆ. ಈ ಲೋಕದಲ್ಲಿ ನಮಗೆ ಬೇಕಾದದ್ದಕ್ಕಾಗಿ ಆತನಲ್ಲಿ ಭರವಸೆಯಿಡಬೇಕೆಂದು ದೇವರು ಕೇಳುತ್ತಾನೆ; ಕೆಲಸ ಮಾಡುವ ಶಕ್ತಿಯನ್ನು ಆತನೇ ನಮಗೆ ಕೊಡುತ್ತಾನೆ, ಪರಲೋಕದಲ್ಲಿ ಐಶ್ವರ್ಯವನ್ನು ಕೊಡುವನು (12:15, 21).

ನೆನಪಿನ ವಚನವನ್ನು ಮನಸ್ಸಿನಲ್ಲಿ ಇಡುವುದು

ಯೋಹಾನ 1:12 – “ಆದರೆ ತನ್ನನ್ನು ಅಂಗೀಕರಿಸಿದವರೆಲ್ಲರಿಗೂ, ಅಂದರೆ ತನ್ನ ಹೆಸರಿನಲ್ಲಿ ನಂಬಿಕೆಯಿಟ್ಟವರಿಗೆ, ದೇವರ ಮಕ್ಕಳಾಗುವ ಅಧಿಕಾರವನ್ನು ಆತನು ಕೊಟ್ಟನು ...”

ಪಾಠ - 16: ಐಶ್ವರ್ಯವಂತ ಮೂರ್ಖನು ಮರೆತದ್ದು

ಬೈಬಲ್ ವಾಚನ: ಲೂಕ 12:15-21

1. ಸರಿಯಾದ ಪದದ ಸುತ್ತ ವೃತ್ತ ಬರೆಯಿರಿ

ಸರಿಯಾದ ಪದದ ಸುತ್ತ ವೃತ್ತ ಬರೆಯಿರಿ:

  1. ಶ್ರೀಮಂತನ ಜಮೀನು (ದೊಡ್ಡ / ಚಿಕ್ಕ) ಸುಗ್ಗಿಯನ್ನು ಕೊಟ್ಟಿತು. 👉 ದೊಡ್ಡ

  2. ಅವನು (ದೊಡ್ಡ / ಚಿಕ್ಕ) ಕಣಜಗಳನ್ನು ಕಟ್ಟಲು ತೀರ್ಮಾನಿಸಿದನು. 👉 ದೊಡ್ಡ

  3. ಅವನು (ದೇವರನ್ನು / ವ್ಯವಸಾಯವನ್ನು) ಮರೆತನು. 👉 ದೇವರನ್ನು

2. ಹಂಚುವುದೋ ಇಟ್ಟುಕೊಳ್ಳುವುದೋ?

ಹಂಚಿದರೆ ಹಂ, ಮಾತ್ರ ಇಟ್ಟುಕೊಂಡರೆ ಇ ಎಂದು ಬರೆಯಿರಿ:

  1. ನಾನು ಹಸಿದ ಸ್ನೇಹಿತನಿಗೆ ನನ್ನ ಆಹಾರದ ಸ್ವಲ್ಪ ಭಾಗ ಕೊಡುತ್ತೇನೆ. ( ___ ) 👉 ಹಂ

  2. ಯಾರೂ ಬಳಸದಂತೆ ನಾನು ನನ್ನ ಆಟಿಕೆಗಳನ್ನು ಅಡಗಿಸುತ್ತೇನೆ. ( ___ ) 👉 ಇ

  3. ನನ್ನಲ್ಲಿರುವ ಎಲ್ಲದಕ್ಕಾಗಿ ನಾನು ದೇವರಿಗೆ ಉಪಕಾರ ಹೇಳುತ್ತೇನೆ. ( ___ ) 👉 ಹಂ

3. ಹೌದೋ ಇಲ್ಲವೋ?

ಹೌದು ಅಥವಾ ಇಲ್ಲ ಎಂದು ಬರೆಯಿರಿ:

  1. ಶ್ರೀಮಂತನು ಬಡವರ ಬಗ್ಗೆ ಯೋಚಿಸಿದನೇ? ( ______ ) 👉 ಇಲ್ಲ

  2. ನಮ್ಮಲ್ಲಿರುವ ಎಲ್ಲವೂ ದೇವರಿಂದ ಬಂದದ್ದೇ? ( ______ ) 👉 ಹೌದು

  3. ವಸ್ತುಗಳಿಗಿಂತ ದೇವರು ಹೆಚ್ಚು ಮುಖ್ಯನೇ? ( ______ ) 👉 ಹೌದು

4. ಚರ್ಚೆಯ ಪ್ರಶ್ನೆಗಳು

  1. ಶ್ರೀಮಂತನು ಏನನ್ನು ಮರೆತನು?

    ಮಾದರಿ ಉತ್ತರ: ದೇವರನ್ನು ಮತ್ತು ಇತರರೊಂದಿಗೆ ಹಂಚಿಕೊಳ್ಳುವುದನ್ನು.

  2. ಜೀವನದಲ್ಲಿ ಅತಿ ಮುಖ್ಯವಾದದ್ದು ಯಾವುದು?

    ಮಾದರಿ ಉತ್ತರ: ವಸ್ತುಗಳನ್ನು ಹೊಂದುವುದಕ್ಕಿಂತ ದೇವರನ್ನು ಪ್ರೀತಿಸಿ ಆತನನ್ನು ಮೆಚ್ಚಿಸುವುದು.

  3. ನೀನು ಏನನ್ನು ಹಂಚಿಕೊಳ್ಳಬಹುದು?

    ಮಾದರಿ ಉತ್ತರ: ಆಹಾರ, ಆಟಿಕೆ, ಸಮಯ ಮತ್ತು ಇತರರಿಗೆ ಸಹಾಯ.

5. ಕಂಠಪಾಠ ವಚನ:

ಯೋಹಾನ 1:12 — “ಆದರೆ ತನ್ನನ್ನು ಅಂಗೀಕರಿಸಿದವರೆಲ್ಲರಿಗೂ, ಅಂದರೆ ತನ್ನ ಹೆಸರಿನಲ್ಲಿ ನಂಬಿಕೆಯಿಟ್ಟವರಿಗೆ, ದೇವರ ಮಕ್ಕಳಾಗುವ ಅಧಿಕಾರವನ್ನು ಆತನು ಕೊಟ್ಟನು ...”

ಮತ್ತಾಯ 6:33 — “ಮೊದಲು ದೇವರ ರಾಜ್ಯವನ್ನೂ ಆತನ ನೀತಿಯನ್ನೂ ಹುಡುಕಿರಿ; ಆಗ ಇವುಗಳೆಲ್ಲಾ ನಿಮಗೆ ದೊರೆಯುವವು.”

ಕರಕುಶಲ 1: ಕಣಜದ ಚಿತ್ರ

ಬೇಕಾದ ಸಾಮಗ್ರಿಗಳು: ಕೆಂಪು ಕಾಗದ, ಹಳದಿ ಕ್ರೆಯಾನ್, ಅಂಟು

ವಿಧಾನ:

  1. ಕೆಂಪು ಕಾಗದದಿಂದ ಕಣಜವನ್ನು ಕತ್ತರಿಸಿ.

  2. ಚಿನ್ನದ ಬಣ್ಣದ ಧಾನ್ಯವನ್ನು ಬರೆಯಿರಿ.

  3. ಬರೆಯಿರಿ: “ದೇವರಿಗೆ ಮೊದಲ ಸ್ಥಾನ.”

ಪಾಠದ ಮುಖ್ಯ ಅಂಶ: ನಮ್ಮಲ್ಲಿರುವ ಎಲ್ಲವೂ ದೇವರಿಂದ ಬಂದದ್ದು.

ಕರಕುಶಲ 2: ಹಂಚಿಕೆಯ ಚೀಲ

ಬೇಕಾದ ಸಾಮಗ್ರಿಗಳು: ಕಾಗದದ ಚೀಲ, ಕ್ರೆಯಾನ್‌ಗಳು

ವಿಧಾನ:

  1. ಚೀಲವನ್ನು ಅಲಂಕರಿಸಿ.

  2. ಬರೆಯಿರಿ: “ನಾನು ಹಂಚಿಕೊಳ್ಳುವೆನು.”

  3. ಯಾರಿಗಾದರೂ ಒಂದು ಸಣ್ಣ ಉಡುಗೊರೆಯನ್ನು ಅದರಲ್ಲಿ ಇಡಿ.

ಪಾಠದ ಮುಖ್ಯ ಅಂಶ: ನಾವು ಹಂಚಿಕೊಂಡರೆ ದೇವರಿಗೆ ಮೆಚ್ಚಿಗೆ.

ಆಟ 1: ಕಣಜವನ್ನು ತುಂಬಿಸಿ

ಆಡುವ ವಿಧಾನ:

  1. ಮಕ್ಕಳು ಕಾಗದದ ಉಂಡೆಗಳನ್ನು “ಕಣಜ” ಎಂದು ಹೆಸರಿಸಿದ ಪೆಟ್ಟಿಗೆಗೆ ಹಾಕಲಿ.

  2. ನಂತರ ಅವುಗಳಲ್ಲಿ ಕೆಲವನ್ನು “ನೆರೆಯವ” ಪೆಟ್ಟಿಗೆಗೆ ಕೊಡಲಿ.

  3. ಹಂಚಿಕೊಳ್ಳುವ ಬಗ್ಗೆ ಮಾತನಾಡಿ.

ಪಾಠದ ಮುಖ್ಯ ಅಂಶ: ನಮ್ಮಲ್ಲಿರುವುದನ್ನು ಹಂಚಿಕೊಳ್ಳಬೇಕೆಂದು ದೇವರು ಬಯಸುತ್ತಾನೆ.

ಆಟ 2: ಹಂಚು ಅಥವಾ ಇಟ್ಟುಕೊ

ಆಡುವ ವಿಧಾನ:

  1. ಆಟಿಕೆ ಅಥವಾ ತಿಂಡಿಯ ಚಿತ್ರ ತೋರಿಸಿ.

  2. ಮಕ್ಕಳು “ಹಂಚೋಣ!” ಎಂದು ಹೇಳಿ ಹಂಚುವ ಅಭಿನಯ ಮಾಡಲಿ.

  3. ಚಿತ್ರಗಳನ್ನು ಬದಲಾಯಿಸಿ.
