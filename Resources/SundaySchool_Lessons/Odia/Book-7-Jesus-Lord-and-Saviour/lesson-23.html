ଘରମାଲିକ ଫେରନ୍ତି

Download Word

ଉଦ୍ଦେଶ୍ୟ

ପିଲାମାନଙ୍କୁ ଦେଖାଇବା ଯେ ଖ୍ରୀଷ୍ଟିୟାନମାନେ ପ୍ରଭୁ ଯୀଶୁଙ୍କ ଫେରିବା ପାଇଁ ଅପେକ୍ଷା କରୁଥିବା ବେଳେ ବିଶ୍ୱସ୍ତ ଭାବେ ତାଙ୍କ ସେବା କରିବା ଉଚିତ୍।

ଶାସ୍ତ୍ରପାଠ

ଲୂକ 12:35-48

ମୁଖସ୍ଥ ପଦ

ଯୋହନ 1:10-14

ଅଂଶ ପୁନରାଲୋଚନା କରନ୍ତୁ।

ପାଠ ଉପସ୍ଥାପନା

ଆରମ୍ଭ

ସ୍କୁଲରେ ଶିକ୍ଷକ ଡାକରା ପାଇ ଯାଇଥିଲେ ଶ୍ରେଣୀରେ କ'ଣ ହୁଏ? ପ୍ରଥମେ ସମସ୍ତେ ଚୁପଚାପ୍ କାମ କରନ୍ତି, କିନ୍ତୁ ଶିକ୍ଷକ ଅନୁପସ୍ଥିତ ରହିଲେ କେତେକ କଥା ହେବାକୁ ଲାଗନ୍ତି, ଯାହା ଅନ୍ୟମାନଙ୍କ ପାଇଁ ମନୋଯୋଗ ଦେବା କଷ୍ଟକର କରେ। ଶେଷରେ ଶିକ୍ଷକ ଆସିଲା ବେଳକୁ ସମଗ୍ର ଶ୍ରେଣୀ ସାଧାରଣତଃ କାମ ବନ୍ଦ କରି କଥା ହୁଏ ବା ଖେଳେ।

ପାଠର ମୁଖ୍ୟ ବିଷୟଗୁଡ଼ିକ

1. ପୃଥିବୀରେ ଥିବା ସମୟରେ ଯୀଶୁ ନିଜ ଶିଷ୍ୟମାନଙ୍କୁ ତାଙ୍କ ଦ୍ୱିତୀୟ ଆଗମନ ବିଷୟରେ କହିଲେ। ତାଙ୍କ ଫେରିବା ପାଇଁ ଅପେକ୍ଷା କରୁଥିବା ବେଳେ ତାଙ୍କ ଶିଷ୍ୟମାନେ କିପରି ବଞ୍ଚିବେ? ଯୀଶୁଙ୍କୁ ଅନୁସରଣ କରିବାକୁ ଚାହୁଁଥିବା ଲୋକଙ୍କୁ ସାହାଯ୍ୟ କରିବାକୁ ଯୀଶୁ ଏ ବିଷୟରେ ଅନେକ କାହାଣୀ କହିଲେ।

2. ଉଦାହରଣ ସ୍ୱରୂପ, ସେ ବିବାହକୁ ଯାଇଥିବା ଜଣେ ବ୍ୟକ୍ତିଙ୍କ ବିଷୟରେ ଏକ କାହାଣୀ କହିଲେ। ଏପରି ଉତ୍ସବ ବହୁତ ରାତି ପର୍ଯ୍ୟନ୍ତ ଚାଲିପାରେ। କିନ୍ତୁ ଏହି ବ୍ୟକ୍ତି ଘରକୁ ଫେରିଲା ବେଳେ ତାଙ୍କ ଚାକରମାନେ ତତ୍କ୍ଷଣାତ୍ କବାଟ ଖୋଲିଲେ। ମଧ୍ୟରାତ୍ରି ପରେ ହୋଇଥିଲେ ମଧ୍ୟ ଚାକରମାନେ ନିଜ ମାଲିକ ପାଇଁ ପ୍ରସ୍ତୁତ ଓ ଅପେକ୍ଷା କରୁଥିଲେ। ସେମାନେ ଆନନ୍ଦିତ ଥିଲେ ଯେ ସେମାନଙ୍କ ମାଲିକ ସେମାନଙ୍କ ପ୍ରତି ଏତେ ସନ୍ତୁଷ୍ଟ। ଚାକରମାନେ ତାଙ୍କ ସମ୍ପତ୍ତି ଏତେ ଭଲ ଭାବେ ଦେଖାଶୁଣା କରୁଥିବାରୁ ମାଲିକ ଏତେ ଖୁସି ହେଲେ ଯେ ସେ ସେମାନଙ୍କୁ ଖାଦ୍ୟ ପରଷିଲେ (ଲୂକ 12:35-38)!

3. ତା'ପରେ ଯୀଶୁ ବର୍ଣ୍ଣନା କଲେ ଜଣେ ଜ୍ଞାନୀ ବ୍ୟକ୍ତି ଚୋରଠାରୁ ନିଜ ଘର କିପରି ରକ୍ଷା କରନ୍ତି। ସେ ନିଶ୍ଚିତ କରନ୍ତି ଯେ ସେ ସବୁବେଳେ ପ୍ରସ୍ତୁତ, କାରଣ ଚୋରମାନେ ଆସିବା ବେଳେ ଆପଣଙ୍କୁ ସତର୍କ କରିବେ ନାହିଁ। ଏହି କାହାଣୀ ଆମକୁ ସତର୍କ କରେ ଯେ ଯୀଶୁ କେବେ ପୁଣି ଆସିବେ ଆମେ ମଧ୍ୟ ଜାଣୁ ନାହୁଁ, ତେଣୁ ଆମେ ସବୁବେଳେ ପ୍ରସ୍ତୁତ ରହିବା ଉଚିତ୍ (12:39-40)।

4. ଅନ୍ୟ କାହାଣୀରେ ଯୀଶୁ ନିଜ ବନ୍ଧୁମାନଙ୍କୁ ଦେଖାଇବାକୁ ଚାହିଁଲେ ଯେ ତାଙ୍କ ପାଇଁ ପ୍ରସ୍ତୁତ ହୋଇ ଅପେକ୍ଷା କରୁଥିବା ବେଳେ ସେମାନେ କ'ଣ କରିବା ଉଚିତ୍। ସେ ଜଣେ ବିଶ୍ୱସ୍ତ ପରିଚାଳକଙ୍କ ଆଚରଣ ବର୍ଣ୍ଣନା କଲେ। ଚିତ୍ର 23 ଦେଖାନ୍ତୁ। ମାଲିକ ଦେଖିଲେ ଯେ ତାଙ୍କ ଅନୁପସ୍ଥିତିରେ ତାଙ୍କ ଘର ଭଲ ଭାବେ ସଂଗଠିତ ଥିଲା, ଏବଂ ତେଣୁ ପରିଚାଳକ ନିଜ ବିଶ୍ୱସ୍ତ ଓ ଉତ୍କୃଷ୍ଟ ସେବା ପାଇଁ ପୁରସ୍କୃତ ହେଲେ (12:42-44)।

5. କିନ୍ତୁ ଯୀଶୁ ମଧ୍ୟ ବର୍ଣ୍ଣନା କଲେ ଯେ ଦାୟିତ୍ୱରେ ଥିବା ଲୋକମାନେ ମାତାଲ ହୋଇ ମାଲିକଙ୍କ ସମ୍ପତ୍ତି ନଷ୍ଟ କଲେ ଓ ଯେଉଁମାନଙ୍କ ପାଇଁ ସେମାନେ ଦାୟୀ ଥିଲେ ସେମାନଙ୍କ ପ୍ରତି ଦୁର୍ବ୍ୟବହାର କଲେ କ'ଣ ହେବ। ସେମାନଙ୍କ ଦଣ୍ଡ କଠୋର ହେବ (12:45-46)।

କାହାଣୀ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ଯୀଶୁ ଘର ଦେଖାଶୁଣା କରିବା ବିଷୟରେ କହିଲା ବେଳେ, ସେ ଏହାକୁ ଆମ ଜୀବନର ଏକ ଚିତ୍ର ଭାବେ ବ୍ୟବହାର କରୁଥିଲେ। ଏକ ଘରେ ଭିନ୍ନ ଭିନ୍ନ କୋଠରୀ ଥାଏ। ଉଦାହରଣ ସ୍ୱରୂପ, ବସିବା କୋଠରୀ, ଶୋଇବା କୋଠରୀ, ରୋଷେଇ ଘର, ଭଣ୍ଡାର ଘର – ଏସବୁ ପ୍ରତ୍ୟେକ ଆମ ଜୀବନର ଭିନ୍ନ ଭିନ୍ନ ଅଂଶ ପରି। ଉଦାହରଣ ସ୍ୱରୂପ, ରୋଷେଇ ଘରେ ବହୁତ କାମ ହୁଏ। ଆମେ କେତେ ଭଲ କାମ କରୁ? ଆମେ ନିଜ ଦୈନନ୍ଦିନ କାମ କରିବାର ଢଙ୍ଗ ଦ୍ୱାରା ଯୀଶୁଙ୍କୁ ସମ୍ମାନ ଦେଇପାରିବା। ଆମ ମନ ଭଣ୍ଡାର ଘର ପରି। ଆମେ କ'ଣ ବା କାହା ବିଷୟରେ ଭାବୁ? ଆପଣ ଅନ୍ୟ ବ୍ୟବହାରିକ ଉଦାହରଣ ଭାବିପାରିବେ କି ଦେଖନ୍ତୁ।

ପ୍ରଭୁ ଆମ ସମସ୍ତଙ୍କୁ ତାଙ୍କୁ ସମ୍ମାନ ଦେବାକୁ ସୃଷ୍ଟି କରିଛନ୍ତି, କିନ୍ତୁ ସେ ଆମକୁ ପରସ୍ପରଠାରୁ ଭିନ୍ନ କରି ସୃଷ୍ଟି କରିଛନ୍ତି। ସେ ଆମକୁ ଭିନ୍ନ ଭିନ୍ନ ଦାୟିତ୍ୱ ଓ କ୍ଷମତା ଦେଇଛନ୍ତି। ଆମେ ତାଙ୍କ ଫେରିବା ଆଶାରେ ରହିବାକୁ ଓ ସେ ଆମକୁ ଯାହା ଦେଇଛନ୍ତି ତାହା ଦ୍ୱାରା ଆମେ କ'ଣ କରିଛୁ ତାଙ୍କୁ ଦେଖାଇବାକୁ ପ୍ରସ୍ତୁତ ରହିବାକୁ ଚାହୁଁ।

ମୁଖସ୍ଥ ପଦ ମନେ ରଖାନ୍ତୁ

ପାଠ - 23: ଘରମାଲିକ ଫେରନ୍ତି

ଶାସ୍ତ୍ରପାଠ: ଲୂକ 12:35-48

1. ବାକ୍ୟ ସମ୍ପୂର୍ଣ୍ଣ କର

ଶବ୍ଦ ବାକ୍ସ: ପ୍ରସ୍ତୁତ, ମାଲିକ, ଫେରିବେ

  • ଚାକରମାନେ ନିଜ ____________ ପାଇଁ ଅପେକ୍ଷା କଲେ। __________ 👉 ମାଲିକ
  • ସେମାନେ ସାରା ରାତି ____________ ରହିଲେ। __________ 👉 ପ୍ରସ୍ତୁତ
  • ଯୀଶୁ ଦିନେ ____________। __________ 👉 ଫେରିବେ

2. ସତ୍ୟ ନା ମିଥ୍ୟା?

ଠିକ୍ ହେଲେ ଠି ଏବଂ ଭୁଲ ହେଲେ ଭୁ ଲେଖ:

  • ଚାକରମାନେ ପ୍ରସ୍ତୁତ ରହିବା ପାଇଁ ପୁରସ୍କୃତ ହେଲେ। ( ___ ) 👉 ସ
  • ଯୀଶୁ କେବେ ଫେରିବେ ଆମେ ଜାଣୁ। ( ___ ) 👉 ମି
  • ଆମେ ଅପେକ୍ଷା କରୁଥିବା ବେଳେ ଈଶ୍ୱରଙ୍କ ସେବା କରିବା ଉଚିତ୍। ( ___ ) 👉 ସ

3. ପ୍ରସ୍ତୁତ ନା ଅପ୍ରସ୍ତୁତ? ପ୍ର/ଅ

ପ୍ରସ୍ତୁତ ହେଲେ ପ୍ର ଓ ଅପ୍ରସ୍ତୁତ ହେଲେ ଅ ଲେଖନ୍ତୁ:

  • ମୁଁ ମୋ କାମ ଭଲ ଭାବେ କରେ। ( ___ ) 👉 ପ୍ର
  • ମୁଁ ମୋ ସମୟ ନଷ୍ଟ କରେ। ( ___ ) 👉 ଅ
  • ମୁଁ ପ୍ରାର୍ଥନା କରେ ଓ ବାଇବଲ ପଢ଼େ। ( ___ ) 👉 ପ୍ର

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ଯୀଶୁଙ୍କ ପାଇଁ ଆମେ କାହିଁକି ପ୍ରସ୍ତୁତ ରହିବା ଉଚିତ୍?

ନମୁନା ଉତ୍ତର: ସେ କେବେ ଆସିବେ ଆମେ ଜାଣୁ ନାହୁଁ।

  • ଜଣେ ବିଶ୍ୱସ୍ତ ଚାକର କ'ଣ କରେ?

ନମୁନା ଉତ୍ତର: ମାଲିକ ନ ଥିଲେ ମଧ୍ୟ ନିଜ କାମ ଭଲ ଭାବେ କରେ।

  • ଆମେ ପ୍ରସ୍ତୁତ ବୋଲି କିପରି ଦେଖାଇପାରିବା?

ନମୁନା ଉତ୍ତର: ପ୍ରତିଦିନ ଈଶ୍ୱରଙ୍କ ବାଧ୍ୟ ହୋଇ ଓ ସେବା କରି।

5. ମୁଖସ୍ଥ ପଦ:

ଯୋହନ 1:10-11 — “ସେ ଜଗତରେ ଥିଲେ, ଆଉ ଜଗତ ତାଙ୍କ ଦ୍ୱାରା ସୃଷ୍ଟ ହୋଇଥିଲେ ହେଁ ଜଗତ ତାଙ୍କୁ ଚିହ୍ନିଲା ନାହିଁ।”
