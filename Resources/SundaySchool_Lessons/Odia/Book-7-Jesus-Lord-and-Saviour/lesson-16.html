ପିଲାମାନଙ୍କୁ ଶିଖାଇବା ଯେ ଜୀବନରେ ସମ୍ପତ୍ତି ଠାରୁ ଅଧିକ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଜିନିଷ ଅଛି।

ପାଠ ଉପସ୍ଥାପନା

ଆରମ୍ଭ

ପ୍ରାୟ ସମସ୍ତେ ଧନୀ ହେବାକୁ ଚାହାନ୍ତି! ଆପଣ ଧନୀ ହେଲେ କ'ଣ ମାଲିକାନା ପାଇବାକୁ ଚାହିଁବେ?

ପାଠର ମୁଖ୍ୟ ବିଷୟଗୁଡ଼ିକ

1. ଅଧିକାଂଶ ଲୋକ ଯାହା ଭୁଲିଯାଆନ୍ତି ତାହା ହେଲା ଯେ ବଡ଼ ଧନ ସହ ବଡ଼ ଦାୟିତ୍ୱ ଆସେ। ଯୀଶୁ ଜଣେ ଧନୀ ବ୍ୟକ୍ତିଙ୍କ ବିଷୟରେ ଏକ କାହାଣୀ କହିଲେ। ଶୁଣନ୍ତୁ ଓ ଦେଖନ୍ତୁ ସେ ନିଜ ଦାୟିତ୍ୱ ମନେ ରଖିଥିଲେ ବୋଲି ଆପଣ ଭାବୁଛନ୍ତି କି।

2. ଧନୀ ବ୍ୟକ୍ତିଙ୍କର ଉର୍ବର ଜମି ଥିଲା ଯାହା ଭଲ ଫସଲ ଦେଉଥିଲା। ବାସ୍ତବରେ, ଶୀଘ୍ର ତାଙ୍କ ଗଚ୍ଛିତ କରିବା ସ୍ଥାନ ଶେଷ ହୋଇଗଲା। ଚିତ୍ର 16 ଦେଖାନ୍ତୁ। ସେ ସ୍ଥିର କଲେ ଯେ ସମାଧାନ ହେଲା ବଡ଼ ଗୋଲାା ତିଆରି କରିବା (12:16-18)।

3. ଧନୀ ବ୍ୟକ୍ତି ନିଜ ଚାରିପାଖରେ ଥିବା ଗରିବଙ୍କ ସହ ନିଜ ଧନ ବାଣ୍ଟିବାକୁ ଭାବିଲେ ନାହିଁ। ତାଙ୍କ ଆଶୀର୍ବାଦ ଈଶ୍ୱରଙ୍କଠାରୁ ଆସିଛି ବୋଲି ସେ ମଧ୍ୟ ବୁଝିଲେ ନାହିଁ। ସେ ଯାହାଙ୍କୁ ଚିନ୍ତା କଲେ ଓ ସନ୍ତୁଷ୍ଟ କରିବାକୁ ଚାହିଁଲେ ସେ କେବଳ ନିଜେ (12:19)।

4. ଧନୀ ବ୍ୟକ୍ତି ଶେଷରେ ଜାଣିଲେ ଯେ ଟଙ୍କାରେ ସବୁକିଛି କିଣିହୁଏ ନାହିଁ। ଯେଉଁ ଈଶ୍ୱର ଧନୀ ବ୍ୟକ୍ତିଙ୍କୁ ଉର୍ବର ଫସଲ ଦେଇଥିଲେ, ସେ ତାଙ୍କ ପ୍ରାଣ ନେଇଗଲେ। ସେତେବେଳେ ତାଙ୍କ ସମ୍ପତ୍ତି ତାଙ୍କ କୌଣସି କାମରେ ଆସିଲା ନାହିଁ। ଈଶ୍ୱରଙ୍କୁ ଭୁଲି ଏହି ଜଗତର ଧନ ଓ ସୁଖ ପାଇଁ ବଞ୍ଚିବାରେ ଧନୀ ବ୍ୟକ୍ତି ମୂର୍ଖ ଥିଲେ (12:20-21)।

କାହାଣୀ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ଯୀଶୁ ଚାହାନ୍ତି ଆମେ ବୁଝିବା ଯେ ଆମ ମାଲିକାନାରେ ଥିବା ଜିନିଷଗୁଡ଼ିକ ଆମ ଜୀବନରେ ଦ୍ୱିତୀୟ ସ୍ଥାନ ନେବା ଉଚିତ୍। ଆମ ପାଖରେ ଥିବା ସବୁକିଛି ଈଶ୍ୱର ଦିଅନ୍ତି, ତେଣୁ ପ୍ରଥମ ସ୍ଥାନ ତାଙ୍କର। ଆମେ ପ୍ରଥମେ ତାଙ୍କୁ ସନ୍ତୁଷ୍ଟ କରିବା ବିଷୟରେ ଚିନ୍ତା କରିବା ଉଚିତ୍।

ଏହାର ଅର୍ଥ ଏହି କାହାଣୀର ଶିକ୍ଷା ଆମ ସମସ୍ତଙ୍କ ପାଇଁ, କେବଳ ଆମେ ଧନୀ ବୋଲି ଭାବୁଥିବା ଲୋକଙ୍କ ପାଇଁ ନୁହେଁ। ଗରିବ ଲୋକ ମଧ୍ୟ ଏତେ ଲୋଭୀ ବା ଈର୍ଷାଳୁ ହୋଇପାରନ୍ତି ଯେ ସମ୍ପତ୍ତି ସେମାନଙ୍କ ଜୀବନର ସବୁଠୁ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଜିନିଷ ହୋଇଯାଏ। କାହାଣୀରେ ଧନୀ ବ୍ୟକ୍ତିଙ୍କ ଜୀବନ ବା ଯୋଜନାରେ ଈଶ୍ୱରଙ୍କ ସ୍ଥାନ ନ ଥିଲା। ଆମେ ତାଙ୍କଠାରୁ ପାଇଥିବା ଜିନିଷ ବାଣ୍ଟିଲେ ଈଶ୍ୱର ସନ୍ତୁଷ୍ଟ ହୁଅନ୍ତି। ଈଶ୍ୱର ଆମକୁ ଏହି ଜଗତରେ ଯାହା ଦରକାର ତାହା ପାଇଁ ତାଙ୍କୁ ଭରସା କରିବାକୁ କହନ୍ତି, କାରଣ ସେ ଆମକୁ କାମ କରିବାର ଶକ୍ତି ଦିଅନ୍ତି, ଏବଂ ସେ ଆମକୁ ସ୍ୱର୍ଗରେ ଧନ ଦେବେ (12:15, 21)।

ପାଠ - 16: ଧନୀ ମୂର୍ଖ କ'ଣ ଭୁଲିଗଲା

ଶାସ୍ତ୍ରପାଠ: ଲୂକ 12:15-21

1. ଠିକ୍ ଶବ୍ଦକୁ ଗୋଲ ଘେରନ୍ତୁ

ଠିକ୍ ଶବ୍ଦକୁ ଗୋଲ ଚିହ୍ନ ଦିଅନ୍ତୁ:

  • ଧନୀ ବ୍ୟକ୍ତିଙ୍କ ଜମି (ବଡ଼ / ଛୋଟ) ଫସଲ ଦେଲା। 👉 ବଡ଼
  • ସେ (ବଡ଼ / ଛୋଟ) ଗୋଲା ତିଆରି କରିବାକୁ ସ୍ଥିର କଲେ। 👉 ବଡ଼
  • ସେ (ଈଶ୍ୱର / ଚାଷ) ବିଷୟରେ ଭୁଲିଗଲେ। 👉 ଈଶ୍ୱର

2. ବାଣ୍ଟିବା ନା ରଖିବା? ବା/ର

ଆମେ ବାଣ୍ଟିଲେ ବା ଏବଂ କେବଳ ରଖିଲେ ର ଲେଖନ୍ତୁ:

  • ମୁଁ ମୋ ଖାଦ୍ୟର କିଛି ଅଂଶ ଭୋକିଲା ବନ୍ଧୁକୁ ଦିଏ। ( ___ ) 👉 ବା
  • ମୁଁ ମୋ ଖେଳନା ଲୁଚାଏ ଯେପରି କେହି ବ୍ୟବହାର କରିପାରିବେ ନାହିଁ। ( ___ ) 👉 ର
  • ମୋ ପାଖରେ ଥିବା ସବୁ ପାଇଁ ମୁଁ ଈଶ୍ୱରଙ୍କୁ ଧନ୍ୟବାଦ ଦିଏ। ( ___ ) 👉 ବା

3. ହଁ ନା ନା?

ହଁ ପାଇଁ ‘ହ’ ଏବଂ ନା ପାଇଁ ‘ନା’ ଲେଖନ୍ତୁ:

  • ଧନୀ ବ୍ୟକ୍ତି କ'ଣ ଗରିବଙ୍କ ବିଷୟରେ ଭାବିଲେ? ( ___ ) 👉 ନା
  • ଆମ ପାଖରେ ଥିବା ସବୁକିଛି କ'ଣ ଈଶ୍ୱରଙ୍କଠାରୁ ଆସେ? ( ___ ) 👉 ହଁ
  • ଜିନିଷ ଠାରୁ ଈଶ୍ୱର କ'ଣ ଅଧିକ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ? ( ___ ) 👉 ହଁ

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ଧନୀ ବ୍ୟକ୍ତି କ'ଣ ଭୁଲିଗଲେ?

ନମୁନା ଉତ୍ତର: ଈଶ୍ୱର, ଏବଂ ଅନ୍ୟମାନଙ୍କ ସହ ବାଣ୍ଟିବା।

  • ଜୀବନରେ ସବୁଠୁ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ କ'ଣ?

ନମୁନା ଉତ୍ତର: ଜିନିଷ ମାଲିକାନା ପାଇବା ଠାରୁ ଅଧିକ, ଈଶ୍ୱରଙ୍କୁ ପ୍ରେମ କରିବା ଓ ତାଙ୍କୁ ସନ୍ତୁଷ୍ଟ କରିବା।

  • ଆପଣ କ'ଣ ବାଣ୍ଟିପାରିବେ?

ନମୁନା ଉତ୍ତର: ଖାଦ୍ୟ, ଖେଳନା, ସମୟ ଓ ଅନ୍ୟମାନଙ୍କ ପାଇଁ ସାହାଯ୍ୟ।

5. ମୁଖସ୍ଥ ପଦ:

ଯୋହନ 1:12 — “ତଥାପି ଯେଉଁମାନେ ତାଙ୍କୁ ଗ୍ରହଣ କଲେ, ଯେଉଁମାନେ ତାଙ୍କ ନାମରେ ବିଶ୍ୱାସ କଲେ, ସେ ସେମାନଙ୍କୁ ଈଶ୍ୱରଙ୍କ ସନ୍ତାନ ହେବାର ଅଧିକାର ଦେଲେ ...”

ମାଥିଉ 6:33 — “ପ୍ରଥମେ ତାଙ୍କ ରାଜ୍ୟ ଓ ଧାର୍ମିକତା ଖୋଜ, ତାହା ହେଲେ ଏହି ସବୁ ମଧ୍ୟ ତୁମକୁ ଦିଆଯିବ।”

ହସ୍ତକଳା 1: ଗୋଲା ଚିତ୍ର

ସାମଗ୍ରୀ: ଲାଲ୍ କାଗଜ, ହଳଦିଆ କ୍ରେୟନ, ଗମ୍

ନିର୍ଦ୍ଦେଶ:

  • ଲାଲ୍ କାଗଜରୁ ଏକ ଗୋଲା କାଟନ୍ତୁ।
  • ସୁନେଲି ଶସ୍ୟ ଆଙ୍କନ୍ତୁ।
  • ଲେଖନ୍ତୁ: “ଈଶ୍ୱର ପ୍ରଥମ।”

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଆମ ପାଖରେ ଥିବା ସବୁକିଛି ଈଶ୍ୱରଙ୍କଠାରୁ ଆସେ।

ହସ୍ତକଳା 2: ବାଣ୍ଟିବା ଥଳି

ସାମଗ୍ରୀ: କାଗଜ ଥଳି, କ୍ରେୟନ

ନିର୍ଦ୍ଦେଶ:

  • ବ୍ୟାଗ୍‌କୁ ସଜାନ୍ତୁ।
  • ଲେଖନ୍ତୁ: “ମୁଁ ବାଣ୍ଟିବି।”
  • କାହା ପାଇଁ ଏକ ଛୋଟ ଉପହାର ରଖନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଆମେ ବାଣ୍ଟିଲେ ଈଶ୍ୱର ସନ୍ତୁଷ୍ଟ ହୁଅନ୍ତି।

ଖେଳ 1: ଗୋଲା ଭରନ୍ତୁ

ଖେଳିବା ପଦ୍ଧତି:

  • ପିଲାମାନେ “ଗୋଲା” ଲେଖା ବାକ୍ସରେ କାଗଜ ଗୋଲା ରଖନ୍ତି।
  • ତା'ପରେ ସେମାନେ କିଛି “ପଡ଼ୋଶୀ” ବାକ୍ସକୁ ଦିଅନ୍ତି।
  • ବାଣ୍ଟିବା ବିଷୟରେ କଥା ହୁଅନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଆମ ପାଖରେ ଥିବା ଜିନିଷ ବାଣ୍ଟିବାକୁ ଈଶ୍ୱର ଚାହାନ୍ତି।

ଖେଳ 2: ବାଣ୍ଟ ନା ରଖ

ଖେଳିବା ପଦ୍ଧତି:

  • ଏକ ଖେଳନା ବା ଖାଦ୍ୟର ଚିତ୍ର ଉଠାନ୍ତୁ।
  • ପିଲାମାନେ “ବାଣ୍ଟ!” କହନ୍ତି ଓ ବାଣ୍ଟିବାର କାମ ଦେଖାନ୍ତି।
  • ଚିତ୍ର ବଦଳାନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ସବୁକିଛି ରଖିବା ଠାରୁ ବାଣ୍ଟିବା ଭଲ।
