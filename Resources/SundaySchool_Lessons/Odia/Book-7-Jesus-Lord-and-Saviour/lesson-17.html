ଭିକାରୀ ଓ ଧନୀ ବ୍ୟକ୍ତି

Download Word

ଉଦ୍ଦେଶ୍ୟ

ପିଲାମାନଙ୍କୁ ଶିଖାଇବା ଯେ ଏହି ଜୀବନରେ ଆମେ କରୁଥିବା ବାଛିବା ପରବର୍ତ୍ତୀ ଜଗତରେ ଆମ ସ୍ଥାନ ନିର୍ଣ୍ଣୟ କରେ।

ଶାସ୍ତ୍ରପାଠ

ଲୂକ 16:19-31

ମୁଖସ୍ଥ ପଦ

ଯୋହନ 1:13

[ଈଶ୍ୱରଙ୍କ] ସନ୍ତାନମାନେ ସ୍ୱାଭାବିକ ବଂଶ ଦ୍ୱାରା ନୁହେଁ, ମନୁଷ୍ୟର ଇଚ୍ଛା ବା ସ୍ୱାମୀର ଇଚ୍ଛା ଦ୍ୱାରା ନୁହେଁ, କିନ୍ତୁ ଈଶ୍ୱରଙ୍କ ଦ୍ୱାରା ଜାତ।

ଧ୍ୟାନ ଦିଅନ୍ତୁ: ଏହା ଏକ ଲମ୍ବା ପଦ, କିନ୍ତୁ ଭାଗ କରିବା କଷ୍ଟକର, ତେଣୁ ଶ୍ରେଣୀକୁ ଏହା ଶିଖିବାକୁ ଦୁଇଟି ଅଧିବେଶନ ଦିଅନ୍ତୁ।

ପାଠ ଉପସ୍ଥାପନା

ଆରମ୍ଭ

ଆପଣ ବାଛିବାକୁ ମୁକ୍ତ ଥିଲେ କେଉଁ ପ୍ରକାର ଜୀବନ ପାଇବାକୁ ଚାହିଁବେ?

ପାଠର ମୁଖ୍ୟ ବିଷୟଗୁଡ଼ିକ

1. ଯୀଶୁ ଆଉ ଜଣେ ଧନୀ ବ୍ୟକ୍ତିଙ୍କ ବିଷୟରେ ଏକ କାହାଣୀ କହିଲେ ଯେ ସେ କିପରି ବଞ୍ଚିବାକୁ ଚାହୁଁଥିଲେ ତାହା ଠିକ୍ ବାଛିଥିଲେ। ସେ ବାଛିଥିବା ପ୍ରକାରର ଜୀବନ ବର୍ଣ୍ଣନା କରନ୍ତୁ (ଲୂକ 16:19)।

2. ଲାଜାର ଜଣେ ଅତି ଗରିବ ବ୍ୟକ୍ତି ଥିଲେ ଯାହାଙ୍କୁ ଧନୀ ବ୍ୟକ୍ତିଙ୍କ ସମ୍ପତ୍ତିର ପ୍ରବେଶ ଦ୍ୱାରରେ ଭିକ ମାଗି ଜୀବନ ଚଳାଇବାକୁ ପଡ଼ୁଥିଲା। ତାଙ୍କ ଜୀବନ ଭୟଙ୍କର ଥିଲା (16:20-21)। ଚିତ୍ର 17 ଦେଖାନ୍ତୁ। ବାଣ୍ଟିବାକୁ ବହୁତ ଥିଲେ ମଧ୍ୟ ଧନୀ ବ୍ୟକ୍ତି ଗରିବ ଲାଜାରକୁ କିଛି ଗ୍ରାହ୍ୟ କଲେ ନାହିଁ।

3. ଲାଜାର ମରିବା ପରେ ତାଙ୍କ ପାଇଁ ସବୁକିଛି ବଦଳିଗଲା। ପରବର୍ତ୍ତୀ ଜଗତରେ ତାଙ୍କ ଜୀବନ ଚମତ୍କାର ଥିଲା; ସ୍ୱର୍ଗରେ ଅବ୍ରାହାମଙ୍କ ପାଖରେ ତାଙ୍କୁ ସମ୍ମାନର ସ୍ଥାନ ଦିଆଗଲା। ପିଲାମାନଙ୍କୁ ମନେ ପକାଇ ଦିଅନ୍ତୁ ଅବ୍ରାହାମ କିଏ ଥିଲେ। ସେ ଯିହୂଦୀ ଲୋକମାନଙ୍କ ପିତା (ଆଦି 12:2) ଥିଲେ ଓ ବାଇବଲ ତାଙ୍କୁ ଈଶ୍ୱରଙ୍କ ବନ୍ଧୁ କହେ (ଯାକୁବ 2:23)। ଧନୀ ବ୍ୟକ୍ତି ମଧ୍ୟ ମରିଲେ ଏବଂ ତାଙ୍କ ପରିସ୍ଥିତି ସେତିକି ନାଟକୀୟ ଭାବେ ବଦଳିଗଲା। ସେ ନିଜକୁ ନର୍କରେ ପାଇଲେ, ଯେଉଁଠାରେ ସେ ଭୟଙ୍କର କଷ୍ଟ ପାଇଲେ (16:22-23)।

4. ଧନୀ ବ୍ୟକ୍ତି ସାହାଯ୍ୟ ପାଇଁ କିପରି ଡାକିଲେ ଓ ସେ ପାଇଥିବା ଉତ୍ତର ବର୍ଣ୍ଣନା କରନ୍ତୁ (16:23-26)। ପୃଥିବୀରେ ତାଙ୍କ ଜୀବନରେ ସେ କାହାକୁ ସାହାଯ୍ୟ କରିବାକୁ ଇଚ୍ଛୁକ ନ ଥିଲେ ଏବଂ ବର୍ତ୍ତମାନ କେହି ତାଙ୍କୁ ସାହାଯ୍ୟ କରିପାରିଲେ ନାହିଁ। ସେ ସମସ୍ତ ଦୟା ଓ ଯତ୍ନରୁ ବିଚ୍ଛିନ୍ନ ହୋଇଗଲେ।

5. ସେତେବେଳେ ଯାଇ ଧନୀ ବ୍ୟକ୍ତି ଅନ୍ୟ ଲୋକଙ୍କ ବିଷୟରେ ଭାବିବାକୁ ଲାଗିଲେ। ସେ ନିଜ ଭାଇମାନଙ୍କୁ ସତର୍କ କରିବାକୁ ଆକୁଳ ଭାବେ ଚାହିଁଲେ, ଯେଉଁମାନେ ହୁଏତ ତାଙ୍କ ପରି ଅସାବଧାନ ଭାବେ ବଞ୍ଚୁଥିଲେ (16:27-28)। ଯୀଶୁ ଚାହାନ୍ତି ଆମେ ଏହି କାହାଣୀରୁ ଶିଖିବା ଯେ ଈଶ୍ୱରଙ୍କ ବାର୍ତ୍ତା ସ୍ପଷ୍ଟ ଓ ଶୁଣିବାକୁ ଇଚ୍ଛୁକ ସମସ୍ତଙ୍କ ପାଇଁ ଉପଲବ୍ଧ। ଯେଉଁମାନେ ଈଶ୍ୱରଙ୍କ ପ୍ରତି ନିଜ ମନ ବନ୍ଦ କରିଦେଇଛନ୍ତି, କବରର ଅପର ପାଖରୁ ଆସିଥିବା ଏକ ବାର୍ତ୍ତାବହ ମଧ୍ୟ ସେମାନଙ୍କୁ ଶୁଣାଇପାରିବେ ନାହିଁ (16:29-31)।

କାହାଣୀ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ପିତାମାତା ଓ ଅନ୍ୟ ବୟସ୍କମାନେ ପ୍ରାୟତଃ ପିଲାମାନଙ୍କୁ ବିପଜ୍ଜନକ ଜିନିଷ ବିଷୟରେ ସତର୍କ କରନ୍ତି, ଯେପରି: “ସେହି ହାଣ୍ଡି ଛୁଅଁ ନାହିଁ! ଏହା ଏବେ ନିଆଁରୁ ଓହ୍ଲାଇଛି ଓ ଏବେ ବି ବହୁତ ଗରମ।” ଶିକ୍ଷକ ଭାବେ ଆପଣ ଆହୁରି ଅନେକ ଉଦାହରଣ ଦେଇପାରିବେ। କେତେବେଳେ ଆମେ ସେମାନଙ୍କ ସତର୍କତା ପ୍ରତି ମନ ବନ୍ଦ କରିଦେଉ ଓ ତା'ପରେ ଅନାବଶ୍ୟକ ଭାବେ କଷ୍ଟ ପାଉ।

ଏହି କାହାଣୀ ଦ୍ୱାରା ଯୀଶୁ ଆମକୁ ସତର୍କ କରିବାକୁ ଚାହାନ୍ତି ଯେ ଏହି ଜଗତରେ ଆମେ ନିଜ ଜୀବନ କିପରି ବଞ୍ଚିବାକୁ ବାଛୁ ତାହା ପରବର୍ତ୍ତୀ ଜଗତରେ ଆମ ସ୍ଥାନକୁ ପ୍ରଭାବିତ କରେ। ଆମେ ଈଶ୍ୱରଙ୍କ ସୃଷ୍ଟି ପ୍ରତି ପ୍ରେମ ଓ ଦୟା ଦେଖାଇବାରେ ବିଫଳ ହେଲେ, ଆମ ସୃଷ୍ଟିକର୍ତ୍ତାଙ୍କଠାରୁ ପ୍ରେମ ଓ ଦୟା ଆଶା କରିବା କିପରି? ତେଣୁ ଆମେ କେବଳ ଯେଉଁଠାରେ ପାରୁ ଭଲ କରିବା ନୁହେଁ; ଆମେ ଲୋକଙ୍କ ନିଷ୍ଠୁରତା ବା ଅଦୟାର ପ୍ରତିଶୋଧ କେବେ ବି ଦେବା ଉଚିତ୍ ନୁହେଁ।

ଈଶ୍ୱର ଆମକୁ ପୁରସ୍କୃତ କରିବାକୁ ଇଚ୍ଛା କରନ୍ତି, କାରଣ ସେ ଆମକୁ ପ୍ରେମ କରନ୍ତି ଏବଂ ଆମ ପାଇଁ କେବଳ ଯାହା ଭଲ ତାହା ଚାହାନ୍ତି। ଈଶ୍ୱରଙ୍କୁ ପ୍ରେମ କରିବା ଓ ସେ ଆମକୁ ଯାହା ଦେଇଛନ୍ତି ତାହା ବାଣ୍ଟିବା ହିଁ ଆମେ ବଞ୍ଚିବାକୁ ସେ ଚାହୁଁଥିବା ପଥ। ଏହା ହିଁ ସବୁଠୁ ଭଲ ବାଛିବା।

ମୁଖସ୍ଥ ପଦ ମନେ ରଖାନ୍ତୁ

ପାଠ - 17: ଭିକାରୀ ଓ ଧନୀ ବ୍ୟକ୍ତି

ଶାସ୍ତ୍ରପାଠ: ଲୂକ 16:19-31

1. ସତ ନା ମିଛ?

ଠିକ୍ ହେଲେ ଠି ଏବଂ ଭୁଲ ହେଲେ ଭୁ ଲେଖ:

  • ଲାଜାର ଜଣେ ଗରିବ ଭିକାରୀ ଥିଲେ। ( ___ ) 👉 ସ
  • ଧନୀ ବ୍ୟକ୍ତି ନିଜ ଖାଦ୍ୟ ଲାଜାରଙ୍କ ସହ ବାଣ୍ଟିଲେ। ( ___ ) 👉 ମି
  • ଲାଜାର ସ୍ୱର୍ଗରେ ଅବ୍ରାହାମଙ୍କ ସହ ରହିବାକୁ ଗଲେ। ( ___ ) 👉 ସ

2. ମିଳାଅ

କ

ଖ

ଧନୀ ବ୍ୟକ୍ତି

କେବଳ ନିଜ ପାଇଁ ବଞ୍ଚିଲେ

ଲାଜାର

ଗରିବ ଓ ଅସୁସ୍ଥ ଥିଲେ

ଅବ୍ରହାମ

ଈଶ୍ୱରଙ୍କ ବନ୍ଧୁ ଥିଲେ

ଭାଇମାନେ

ଈଶ୍ୱରଙ୍କ ବାକ୍ୟ ଶୁଣିବା ଦରକାର ଥିଲା

ଉତ୍ତର:
ଧନୀ ବ୍ୟକ୍ତି → କେବଳ ନିଜ ପାଇଁ ବଞ୍ଚିଲେ
ଲାଜାର → ଗରିବ ଓ ଅସୁସ୍ଥ ଥିଲେ
ଅବ୍ରାହାମ → ଈଶ୍ୱରଙ୍କ ବନ୍ଧୁ ଥିଲେ
ଭାଇମାନେ → ଈଶ୍ୱରଙ୍କ ବାକ୍ୟ ଶୁଣିବା ଦରକାର ଥିଲା

3. ଦୟାଳୁ ନା ନିର୍ଦ୍ଦୟ? ଦ/ନି

ଦୟାଳୁ ପାଇଁ ଦ ଏବଂ ନିର୍ଦ୍ଦୟ ପାଇଁ ନି ଲେଖନ୍ତୁ:

  • ମୁଁ ଏକ ଗରିବ ପଡ଼ୋଶୀକୁ ସାହାଯ୍ୟ କରେ। ( ___ ) 👉 ଦ
  • ମୁଁ ଭୋକିଲା ଜଣଙ୍କୁ ଅଣଦେଖା କରେ। ( ___ ) 👉 ନି
  • ମୁଁ ମୋ ଖାଦ୍ୟ ବାଣ୍ଟେ। ( ___ ) 👉 ଦ

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ଧନୀ ବ୍ୟକ୍ତି ଲାଜାରଙ୍କ ସହ କିପରି ବ୍ୟବହାର କଲେ?

ନମୁନା ଉତ୍ତର: ସେ ତାଙ୍କୁ ଆଦୌ ସାହାଯ୍ୟ କଲେ ନାହିଁ।

  • ଏହି କାହାଣୀ ଆମକୁ କେଉଁ ବିଷୟରେ ସତର୍କ କରେ?

ନମୁନା ଉତ୍ତର: ଆମେ ବର୍ତ୍ତମାନ କିପରି ବଞ୍ଚୁ ତାହା ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ, ତେଣୁ ଆମେ ଦୟାଳୁ ହେବା ଓ ଈଶ୍ୱରଙ୍କ କଥା ଶୁଣିବା ଉଚିତ୍।

  • ଆମେ ଅଭାବରେ ଥିବା କାହାକୁ କିପରି ସାହାଯ୍ୟ କରିପାରିବା?

ନମୁନା ଉତ୍ତର: ଖାଦ୍ୟ, ଲୁଗାପଟା ଓ ବନ୍ଧୁତା ବାଣ୍ଟନ୍ତୁ।

5. ମୁଖସ୍ଥ ପଦ:

ଯୋହନ 1:13 — “... ସନ୍ତାନମାନେ ସ୍ୱାଭାବିକ ବଂଶ ଦ୍ୱାରା ନୁହେଁ, ମନୁଷ୍ୟର ଇଚ୍ଛା ବା ସ୍ୱାମୀର ଇଚ୍ଛା ଦ୍ୱାରା ନୁହେଁ, କିନ୍ତୁ ଈଶ୍ୱରଙ୍କ ଦ୍ୱାରା ଜାତ।”

ଖେଳ 1: ଦୟା ନା ଅଦୟା?

ଖେଳିବା ପଦ୍ଧତି:

  • ଶିକ୍ଷକ ଏକ କାମ କୁହନ୍ତି; ଦୟାଳୁ ହେଲେ ପିଲାମାନେ ଠିଆ ହୁଅନ୍ତି, ଅଦୟାଳୁ ହେଲେ ବସନ୍ତି।
  • କେତେକ ବିଷୟରେ ଆଲୋଚନା କରନ୍ତୁ।
  • ଦୟାଳୁ ବାଛିବାର ପ୍ରଶଂସା କରନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଆମେ ପ୍ରତିଦିନ ଦୟା ବାଛିବା ଉଚିତ୍।

ଖେଳ 2: ଦାନ କରିଦିଅ

ଖେଳିବା ପଦ୍ଧତି:

  • ପ୍ରତ୍ୟେକ ପିଲା ପାଖରେ ଏକ କାଗଜର “ମୁଦ୍ରା” ଥାଏ।
  • ସେମାନେ ଯାହା ପାଖରେ ନାହିଁ ତାକୁ ଦିଅନ୍ତି।
  • ସମସ୍ତଙ୍କ ପାଖରେ କିଛି ନ ହେବା ପର୍ଯ୍ୟନ୍ତ ଗଣନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ବାଣ୍ଟିବା ସମସ୍ତଙ୍କୁ ସାହାଯ୍ୟ କରେ।
