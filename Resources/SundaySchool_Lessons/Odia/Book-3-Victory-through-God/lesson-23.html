ପାଠ ଉପସ୍ଥାପନା

ଆରମ୍ଭ

ଶ୍ରେଣୀକୁ ପଚାରନ୍ତୁ ଯେ ଏକ ଗୋଷ୍ଠୀ, ପ୍ରଦେଶ ବା ଦେଶର ନେତାଙ୍କୁ ଆମେ କ'ଣ କହୁ। ସେମାନେ ଏହି ଲୋକଙ୍କର ପ୍ରକୃତ ନାମ କହିବା ଆବଶ୍ୟକ ନୁହେଁ, କେବଳ ସେମାନଙ୍କର ପଦ (ଉଦାହରଣ: ମୁଖିଆ, ରାଜ୍ୟପାଳ, ରାଷ୍ଟ୍ରପତି)।

ପାଠର ମୁଖ୍ୟ ବିଷୟଗୁଡ଼ିକ

1. ଈଶ୍ୱର ଯୀଶୁଙ୍କୁ ମଣ୍ଡଳୀର ମସ୍ତକ ରୂପେ ନିଯୁକ୍ତ କରିଛନ୍ତି। ମୁଖସ୍ଥ ପଦ ଆବୃତ୍ତି କରନ୍ତୁ। ଈଶ୍ୱର ଏହା କାହିଁକି କରିଛନ୍ତି? ଆଜିର ଚିତ୍ର ଆମକୁ ବୁଝିବାରେ ସାହାଯ୍ୟ କରିବ।

2. ଚିତ୍ର 23 ଦେଖାନ୍ତୁ। ଏଠାରେ ଯୀଶୁ ଯିରୂଶାଲମ ବାହାରେ ଏକ ପାହାଡ଼ ଉପରେ ନିଜ ଅନୁଗାମୀମାନଙ୍କ ସହ କଥା ହେଉଥିବା ଦେଖାଯାଉଛନ୍ତି। ଚିତ୍ରରେ ଯିରୂଶାଲମକୁ ଦେଖାନ୍ତୁ। ଯୀଶୁ କୌଣସି ଭୁଲ ନ କରିଥିଲେ ମଧ୍ୟ ତାଙ୍କୁ ମୃତ୍ୟୁଦଣ୍ଡ ଦିଆଯାଇଥିଲା। ସେ ଦୁଇ ଅପରାଧୀଙ୍କ ମଝିରେ କ୍ରୁଶରେ ମୃତ୍ୟୁବରଣ କଲେ। ଚିତ୍ରରେ କ୍ରୁଶଗୁଡ଼ିକୁ ଦେଖାନ୍ତୁ। ଈଶ୍ୱରଙ୍କ ପୁତ୍ର ଯୀଶୁ ନିଜକୁ ମୃତ୍ୟୁଦଣ୍ଡ ପାଇଁ ସମର୍ପଣ କଲେ (ମାଥି 27:33-44)।

3. କିନ୍ତୁ ମୃତ୍ୟୁ ଜୀବିତ ଈଶ୍ୱରଙ୍କ ପୁତ୍ରଙ୍କୁ ଧରି ରଖିପାରିଲା ନାହିଁ। ଯୀଶୁ ମୃତ୍ୟୁରୁ ପୁନରୁତ୍ଥାନ କଲେ। ସେ ମୃତ୍ୟୁକୁ ପରାସ୍ତ କଲେ। ସେ ଆଉ କେବେ ମରିପାରିବେ ନାହିଁ। ଚିତ୍ରରେ ଖାଲି କବର ଓ ତା' ପାଖରେ ଥିବା ବଡ଼ ପଥରକୁ ଦେଖାନ୍ତୁ।

4. ଯୀଶୁ ନିଜ ଶିଷ୍ୟମାନଙ୍କୁ ଏକାଠି ଡାକି କହିଲେ, “ସ୍ୱର୍ଗ ଓ ପୃଥିବୀରେ ମୋତେ ସମସ୍ତ କର୍ତ୍ତୃତ୍ୱ ଦିଆଯାଇଅଛି।” ସେ ଶିଷ୍ୟମାନଙ୍କୁ ଆଜ୍ଞା ଦେଲେ ଯେ ସେମାନେ ବାହାରକୁ ଯାଇ ଜୀବିତ ଯୀଶୁ ଖ୍ରୀଷ୍ଟଙ୍କ ବିଷୟରେ ସମସ୍ତ ଲୋକଙ୍କୁ କହନ୍ତୁ, ଯେପରି ସେମାନେ ମଧ୍ୟ ତାଙ୍କୁ ଅନୁସରଣ ଓ ଉପାସନା କରିବେ। ଯୀଶୁ ସେମାନଙ୍କ ସହିତ ସର୍ବଦା ରହିବେ ବୋଲି ପ୍ରତିଜ୍ଞା କଲେ। ସେ ସେମାନଙ୍କୁ ପାପ ଓ ମନ୍ଦ ଶକ୍ତି ଉପରେ ବିଜୟର ପ୍ରତିଜ୍ଞା କଲେ। ଯୀଶୁଙ୍କ ଏହି ବାକ୍ୟ ଆମ ପାଇଁ ମଧ୍ୟ!

କାହାଣୀ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ଜାୟର ଏକ ସ୍ୱାଧୀନ ଦେଶ ହେବା ପୂର୍ବରୁ ଔପନିବେଶିକ ସରକାରର କେତେକ ସଦସ୍ୟ ପ୍ରୋଟେଷ୍ଟାଣ୍ଟ ମଣ୍ଡଳୀର ବିସ୍ତାରକୁ ସୀମିତ କରିବାକୁ ଚେଷ୍ଟା କଲେ। ସେହି ସମୟରେ ଯୋଆନେ ଅକୁଦ୍ରି ଜଣେ ପ୍ରତିଭାଶାଳୀ ଓ ସୁପରିଚିତ ମଣ୍ଡଳୀ ନେତା ଥିଲେ। ସରକାର ତାଙ୍କୁ ଗିରଫ କଲେ, ଯେପରି ତାଙ୍କୁ ଅନ୍ୟ କେଉଁଠାକୁ ପଠାଇପାରିବେ ଯେଉଁଠାରେ ସେ ସେମାନଙ୍କୁ କମ୍ ଅସୁବିଧା ଦେବେ। “ମୋ ପାଇଁ ତାହା ଠିକ୍ ଅଛି,” ଯୋଆନେ ସେମାନଙ୍କୁ କହିଲେ। “ଏହି ସୁସମାଚାର କେବଳ କାକ୍ୱାମାନଙ୍କ ପାଇଁ ନୁହେଁ, ଆମ ସାରା ଦେଶର ଲୋକଙ୍କ ପାଇଁ!” ଯେଉଁ ସରକାରୀ ଅଧିକାରୀ ଏହି ମାମଲା ସମ୍ଭାଳୁଥିଲେ ସେ ଯୋଆନେଙ୍କ ସାକ୍ଷ୍ୟରେ ଏତେ ପ୍ରଭାବିତ ହେଲେ ଯେ ସେ ତାଙ୍କୁ ମୁକ୍ତ କରିଦେଲେ।

ଏଥିରୁ ଅକୁଦ୍ରି ପିଟର ବ୍ରାଶଲର୍ ଦ୍ୱାରା

ଶାସ୍ତ୍ରପାଠ: ମାଥିଉ 28:16-20

1. ମୁଁ କିଏ?

ବାଛନ୍ତୁ: ଯୀଶୁ, ଶିଷ୍ୟମାନେ, ପଥର

  • ମୁଁ କବରରୁ ଗଡ଼ିଗଲି। ମୁଁ କିଏ? __________ 👉 ପଥର
  • ମୁଁ ମୃତ୍ୟୁରୁ ପୁନରୁତ୍ଥାନ କଲି। ମୁଁ କିଏ? __________ 👉 ଯୀଶୁ
  • ଆମକୁ ଯାଇ ସମସ୍ତଙ୍କୁ କହିବାକୁ କୁହାଗଲା। ଆମେ କିଏ? __________ 👉 ଶିଷ୍ୟମାନେ

2. ସତ୍ୟ ନା ମିଥ୍ୟା? ସ/ମି

ଠିକ୍ ହେଲେ ଠି ଏବଂ ଭୁଲ ହେଲେ ଭୁ ଲେଖ:

  • ଯୀଶୁ ଆଜି ଜୀବିତ। ( ___ ) 👉 ସ
  • ମୃତ୍ୟୁ ଯୀଶୁଙ୍କୁ ଚିରକାଳ ଧରି ରଖିପାରିଲା। ( ___ ) 👉 ମି
  • ଯୀଶୁ ସର୍ବଦା ଆମ ସହ ରହିବେ ବୋଲି ପ୍ରତିଜ୍ଞା କଲେ। ( ___ ) 👉 ସ

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ଖାଲି କବର ଆମକୁ କ'ଣ କହେ?

ନମୁନା ଉତ୍ତର: ଯୀଶୁ ପୁନରୁତ୍ଥାନ କରି ମୃତ୍ୟୁକୁ ପରାସ୍ତ କଲେ।

  • ମଣ୍ଡଳୀର ମସ୍ତକ କିଏ?

ନମୁନା ଉତ୍ତର: ଯୀଶୁ ଖ୍ରୀଷ୍ଟ।

  • ଯୀଶୁ ନିଜ ଅନୁଗାମୀମାନଙ୍କୁ କ'ଣ କରିବାକୁ କହିଲେ?

ନମୁନା ଉତ୍ତର: ଯାଅ ଓ ସମସ୍ତ ଲୋକଙ୍କୁ ତାଙ୍କ ବିଷୟରେ କୁହ।

5. ମୁଖସ୍ଥ ପଦ:

ଏଫିସୀୟ 1:22 — “ଆଉ ଈଶ୍ୱର ତାଙ୍କ ପାଦ ତଳେ ସମସ୍ତ ବିଷୟ ରଖିଲେ ଏବଂ ମଣ୍ଡଳୀ ପାଇଁ ତାଙ୍କୁ ସମସ୍ତଙ୍କର ମସ୍ତକ ରୂପେ ନିଯୁକ୍ତ କଲେ।”

ମାଥିଉ 28:20 — “ଆଉ ଦେଖ, ଯୁଗର ଶେଷ ପର୍ଯ୍ୟନ୍ତ ମୁଁ ସର୍ବଦା ତୁମ୍ଭମାନଙ୍କ ସହିତ ଅଛି।”

  • ଆପଣ “ଯୀଶୁ ଜୀବିତ!” କହିଲେ ସେମାନେ ଡେଇଁ ଉଠି ଜୟଧ୍ୱନି କରନ୍ତି।
  • ଅନେକ ଥର ପୁନରାବୃତ୍ତି କରନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଯୀଶୁ ଜୀବିତ।

ଖେଳ 2: ଯାଅ ଓ କୁହ

ଖେଳିବା ପଦ୍ଧତି:

  • ପ୍ରତ୍ୟେକ ପିଲାକୁ ଏକ ବାର୍ତ୍ତା କାର୍ଡ ଦିଅନ୍ତୁ।
  • ସେମାନେ ଜଣେ ବନ୍ଧୁ ପାଖକୁ ଯାଇ କୁହନ୍ତି: “ଯୀଶୁ ଜୀବିତ।”
  • କାର୍ଡ ବଦଳାନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଆମେ ଅନ୍ୟମାନଙ୍କୁ ଯୀଶୁଙ୍କ ବିଷୟରେ କହୁ।
