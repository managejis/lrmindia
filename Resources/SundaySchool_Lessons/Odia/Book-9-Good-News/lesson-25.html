ଈଶ୍ୱରଙ୍କର ଦୁଷ୍ଟ ଆତ୍ମାମାନଙ୍କ ଉପରେ ଶକ୍ତି ଅଛି

ଚିତ୍ର

31

ଉଦ୍ଦେଶ୍ୟ

ପ୍ରଭୁ ଯୀଶୁ ଖ୍ରୀଷ୍ଟଙ୍କର ଦୁଷ୍ଟ ଆତ୍ମାମାନଙ୍କ ଉପରେ ଶକ୍ତି ଅଛି ବୋଲି ଶିଖାଇବା।

ଶିକ୍ଷକଙ୍କ ପ୍ରସ୍ତୁତି

ଏହି ପାଠ ପ୍ରସ୍ତୁତ କରିବା ବେଳେ ଯୀଶୁ ଶୟତାନ ଓ ମନ୍ଦକୁ ଜୟ କରିଥିବାରୁ ଈଶ୍ୱରଙ୍କୁ ପ୍ରଶଂସା କରନ୍ତୁ ଓ ଆପଣ, ଆପଣଙ୍କ ଛାତ୍ରଛାତ୍ରୀମାନେ ଓ ଖ୍ରୀଷ୍ଟିୟାନ ବିଶ୍ୱାସୀମାନଙ୍କୁ ଦୁଷ୍ଟ ଆତ୍ମାମାନଙ୍କୁ ଭୟ କରିବାକୁ ପଡ଼ୁନାହିଁ କାରଣ ସେମାନେ ପ୍ରଭୁ ଯୀଶୁ ଖ୍ରୀଷ୍ଟଙ୍କ ଶକ୍ତି ଓ ଅଧିକାରର ଅଧୀନ ବୋଲି ତାଙ୍କୁ ଧନ୍ୟବାଦ ଦିଅନ୍ତୁ। ତା'ପରେ ଲୂକ 8:26-39 ଓ ପାଠ ଯୋଜନା ପଢ଼ନ୍ତୁ ଓ ଅଧ୍ୟୟନ କରନ୍ତୁ।

ମୁଖସ୍ଥ ପଦ

1 ଯୋହନ 4:4

ତୁମଠାରେ ଥିବା ଆତ୍ମା ଜଗତର ଲୋକମାନଙ୍କଠାରେ ଥିବା ଆତ୍ମାଠାରୁ ଅଧିକ ଶକ୍ତିଶାଳୀ।

ପାଠ ଯୋଜନା

ଭୂମିକା

ରବିବାର ବିଦ୍ୟାଳୟ ଆରମ୍ଭ ହେବା ପୂର୍ବରୁ ପ୍ରାୟ 6 କି 8 ଜଣ ବଡ଼ ପିଲାଙ୍କୁ ପଚାରନ୍ତୁ ପାଠ ଆରମ୍ଭରେ ସେମାନେ ଆପଣଙ୍କୁ ସାହାଯ୍ୟ କରିବେ କି। ସେମାନଙ୍କ ସଂଖ୍ୟା ଯୁଗ୍ମ ହେବା ଉଚିତ ଏବଂ ବାଳିକାମାନଙ୍କ ଅପେକ୍ଷା ବାଳକମାନେ ଏହା ଅଧିକ ଉପଭୋଗ କରିପାରନ୍ତି। ପାଠ ଆରମ୍ଭରେ ଆପଣଙ୍କ ସହାୟକମାନଙ୍କୁ ସମାନ ସଂଖ୍ୟାର ଦୁଇଟି ଦଳରେ ବିଭକ୍ତ କରି ଦଉଡ଼ି ଟାଣାଟାଣି ନାମକ ଏକ ଖେଳ ଖେଳନ୍ତୁ। ଜଣେ ଶିକ୍ଷକ ପ୍ରତ୍ୟେକ ଦଳର ନେତା ହେବାକୁ ଚାହିଁପାରନ୍ତି।

ପ୍ରତ୍ୟେକ ଦଳ ସଦସ୍ୟ ସାମ୍ନାରେ ଥିବା ବ୍ୟକ୍ତିଙ୍କ କଟିକୁ ଧରନ୍ତି। ନେତାମାନେ ହାତ ଧରନ୍ତି। ଦୁଇ ନେତାଙ୍କ ମଝିରେ ଚଟାଣରେ ଏକ ଚିହ୍ନ ଦିଆଯାଏ। “ଯାଅ” କହିଲେ ପ୍ରତ୍ୟେକ ଦଳ ଅନ୍ୟକୁ ଚିହ୍ନର ଅନ୍ୟ ପାର୍ଶ୍ୱକୁ ଟାଣିବାକୁ ଚେଷ୍ଟା କରେ। ଦଳ ସଦସ୍ୟମାନେ ପରସ୍ପରକୁ ଛାଡ଼ିବେ ନାହିଁ। ଏହି ଖେଳ ଥରେ ଖେଳନ୍ତୁ ଓ ତା'ପରେ ପିଲାମାନଙ୍କୁ ନିଜ ନିଜ ସ୍ଥାନକୁ ପଠାନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ

1. ସେହି ଖେଳ ମଜାଦାର ଥିଲା କିନ୍ତୁ ଧରନ୍ତୁ ଏହା ଆପଣଙ୍କ ମୁଣ୍ଡରେ ଚାଲିଥିବା ଏକ ଟଣାଟଣି ପରି ହୁଅନ୍ତା। ଆପଣ ପାଗଳ ହୋଇଯିବେ। ଦିନେ ଯୀଶୁ ଏପରି ଜଣେ ଲୋକଙ୍କୁ ଭେଟିଲେ। ଚିତ୍ର 31 ଦେଖାନ୍ତୁ. ଏହି ଲୋକ ନିଜ ସୁସ୍ଥ ବୁଦ୍ଧିରେ ନାହିଁ। ସେ କିପରି ବାସ କରୁଥିଲେ ଓ ତାଙ୍କ ସମସ୍ୟା କ'ଣ ଥିଲା ବର୍ଣ୍ଣନା କରନ୍ତୁ। ତାଙ୍କ ଶରୀର ଅନେକ ଦୁଷ୍ଟ ଆତ୍ମାଙ୍କ ଦ୍ୱାରା ଅଧିକୃତ (ଅଧୀନ) ଥିଲା, ଲୂକ 8:27,29-30।

2. ଦିନେ ଯୀଶୁ ତାଙ୍କୁ କିପରି ଭେଟିଲେ ତାହା ବର୍ଣ୍ଣନା କରନ୍ତୁ। ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଜାଣିଲେ ଯୀଶୁ କିଏ ଓ ସେମାନଙ୍କ ଉପରେ ତାଙ୍କ ଶକ୍ତି ଚିହ୍ନିଲେ, ଲୂକ 8:28।

3. ଯୀଶୁ ଦୁଷ୍ଟ ଆତ୍ମାମାନଙ୍କୁ ଲୋକଟିଠାରୁ ବାହାରିବାକୁ ଆଜ୍ଞା ଦେଲେ ଓ ସେମାନଙ୍କୁ ଘୁଷୁରୀମାନଙ୍କ ଭିତରକୁ ଯିବାକୁ ଦେଲେ। ଯୀଶୁଙ୍କର ସମସ୍ତ ଦୁଷ୍ଟ ଆତ୍ମା ଉପରେ ଶକ୍ତି ଅଛି। ଯୀଶୁ ଯେକୌଣସି ଭୂତଠାରୁ ବହୁତ ଅଧିକ ଶକ୍ତିଶାଳୀ ବୋଲି ଲେଜିୟନ (ଭିଡ଼) ନାମକ ଲୋକଟିଠାରୁ ଭୂତମାନଙ୍କୁ ବାହାରିବାକୁ ବାଧ୍ୟ କରାଗଲା, ଲୂକ 8:32-33। ଭୂତ ବା ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଯୀଶୁଙ୍କୁ ଭୟ କରନ୍ତି। ଯୀଶୁଙ୍କ ଶକ୍ତି ଦୁଷ୍ଟ ଆତ୍ମା ପ୍ରତି ଆମ ଭୟ ଦୂର କରିପାରେ।

4. ଲେଜିୟନ (ଭିଡ଼) ନାମକ ଲୋକଟି ଜଣେ ନୂତନ ବ୍ୟକ୍ତି ପରି ଥିଲେ, ଲୂକ 8:35। ସେ ଯୀଶୁଙ୍କ ସହ ରହିପାରିବେ କି ପଚାରିଲେ କିନ୍ତୁ ଯୀଶୁ ତାଙ୍କୁ କରିବା ପାଇଁ ଏକ ନୂତନ କାମ ଦେଲେ, ଲୂକ 8:39। ସେ ଜଣେ ପରିବର୍ତ୍ତିତ ବ୍ୟକ୍ତି ଥିଲେ।

ପୁନରାବଲୋକନ

ଅନ୍ୟ ଲୋକମାନେ ଦୁଷ୍ଟ, ପାଗଳ, ବିପଜ୍ଜନକ ଓ ଉଦ୍ଧାର କରିହେବ ନାହିଁ ବୋଲି ଭାବୁଥିବା ଏକ ଲୋକଙ୍କୁ ଯୀଶୁ ନିଜ ଅଧିକାର ଓ ଶକ୍ତି ଯୋଗୁଁ ସାହାଯ୍ୟ କରିପାରିଲେ ବୋଲି ଗୁରୁତ୍ୱ ଦେଇ ପାଠକୁ ସଂକ୍ଷେପରେ ଦୁହରାନ୍ତୁ। ଈଶ୍ୱରଙ୍କ ପାଇଁ କିଛି ବି ବହୁତ କଠିନ ନୁହେଁ।

ପାଠ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ମୁଖସ୍ଥ ପଦ ଶିଖାନ୍ତୁ

ଏହା ଶିଖାଇବା ବେଳେ ବୁଝାନ୍ତୁ ଯେ ଖ୍ରୀଷ୍ଟିୟାନଙ୍କଠାରେ ଥିବା ଈଶ୍ୱରଙ୍କ ପବିତ୍ର ଆତ୍ମା ଜଗତର ଯେକୌଣସି ଆତ୍ମାଠାରୁ ଅଧିକ ଶକ୍ତିଶାଳୀ। ଆମେ ଯୀଶୁଙ୍କ ସାହାଯ୍ୟ ମାଗିଲେ ସେ ଆମକୁ ସୁରକ୍ଷା ଦେଉଥିବାରୁ ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଆମକୁ କ୍ଷତି କରିପାରନ୍ତି ନାହିଁ।

ପାଠ - 25: ଈଶ୍ୱରଙ୍କର ଦୁଷ୍ଟ ଆତ୍ମାମାନଙ୍କ ଉପରେ ଶକ୍ତି ଅଛି

ଶାସ୍ତ୍ରପାଠ: ଲୂକ 8:26-39

1. ମୁଁ କିଏ?

ବାଛନ୍ତୁ: ଯୀଶୁ, ଲୋକଟି, ଘୁଷୁରୀ ପାଳକମାନେ

  • ମୋର ସମସ୍ତ ଦୁଷ୍ଟ ଆତ୍ମା ଉପରେ ଶକ୍ତି ଅଛି। ମୁଁ କିଏ? __________ 👉 ଯୀଶୁ
  • ମୋତେ ସାହାଯ୍ୟ କରାଗଲା ଓ ମୁଁ ନୂତନ ହେଲି। ମୁଁ କିଏ? __________ 👉 ଲୋକଟି
  • ଯାହା ଘଟିଲା ତାହା ଦେଖି ଆମେ ଆଶ୍ଚର୍ଯ୍ୟ ହେଲୁ। ଆମେ କିଏ? __________ 👉 ଘୁଷୁରୀ ପାଳକମାନେ

2. ଠିକ୍ ନା ଭୁଲ

ଠିକ୍ ହେଲେ ଠି ଏବଂ ଭୁଲ ହେଲେ ଭୁ ଲେଖ:

  • ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଜାଣିଲେ ଯୀଶୁ କିଏ। ( ___ ) 👉 ଠି
  • ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଯୀଶୁଙ୍କଠାରୁ ଅଧିକ ଶକ୍ତିଶାଳୀ। ( ___ ) 👉 ଭୁ
  • ଯୀଶୁ ଲୋକଟିକୁ କରିବା ପାଇଁ ଏକ ନୂତନ କାମ ଦେଲେ। ( ___ ) 👉 ଠି

3. ଭରସା ନା ଭୟ? (ଭ/ଭୀ)

ଭରସା ପାଇଁ ଭ ବା ଭୟ ପାଇଁ ଭୀ ଲେଖନ୍ତୁ:

  • ମୁଁ ଯୀଶୁଙ୍କୁ ସାହାଯ୍ୟ ମାଗେ। ( ___ ) 👉 ଭ
  • ମୁଁ ବିଶ୍ୱାସ କରେ ଈଶ୍ୱରଙ୍କ ପାଇଁ କିଛି ବି କଠିନ ନୁହେଁ। ( ___ ) 👉 ଭ
  • ମୁଁ ଭାବେ ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଯୀଶୁଙ୍କୁ ହରାଇପାରିବେ। ( ___ ) 👉 ଭୀ

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ଦୁଷ୍ଟ ଆତ୍ମାମାନେ ଲୋକଟିଠାରୁ କାହିଁକି ବାହାରିଗଲେ?

ନମୁନା ଉତ୍ତର: ଯୀଶୁ ବହୁତ ଅଧିକ ଶକ୍ତିଶାଳୀ।

  • ଯୀଶୁ ଲୋକଟିକୁ କ'ଣ କରିବାକୁ କହିଲେ?

ନମୁନା ଉତ୍ତର: ଘରକୁ ଯାଇ ଈଶ୍ୱର ଯାହା କରିଛନ୍ତି ତାହା ଅନ୍ୟମାନଙ୍କୁ କୁହ।

  • ଆମେ ଭୟଭୀତ ହେଲେ କ'ଣ କରିବା ଉଚିତ?

ନମୁନା ଉତ୍ତର: ଯୀଶୁଙ୍କୁ ସାହାଯ୍ୟ ମାଗ।

5. ମୁଖସ୍ଥ ପଦ:

1 ଯୋହନ 4:4 — “ତୁମଠାରେ ଥିବା ଆତ୍ମା ଜଗତର ଲୋକମାନଙ୍କଠାରେ ଥିବା ଆତ୍ମାଠାରୁ ଅଧିକ ଶକ୍ତିଶାଳୀ।”
