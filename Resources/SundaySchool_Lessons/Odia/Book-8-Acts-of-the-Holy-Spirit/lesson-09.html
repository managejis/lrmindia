ପିତରଙ୍କ ମିଶନାରୀ ଦର୍ଶନ

Download Word

ଉଦ୍ଦେଶ୍ୟ

ପିଲାମାନଙ୍କୁ ଶିଖାଇବା ଯେ ସୁସମାଚାର ପ୍ରତ୍ୟେକ ଜନଜାତି ଓ ଜାତିର ସମସ୍ତ ଲୋକଙ୍କ ପାଇଁ।

ଶାସ୍ତ୍ରପାଠ

ପ୍ରେରିତ 10:1-48,

ମୁଖସ୍ଥ ପଦ

ପ୍ରେରିତ 10:35

[ଈଶ୍ୱର] ପ୍ରତ୍ୟେକ ଜାତିର ସେହି ଲୋକମାନଙ୍କୁ ଗ୍ରହଣ କରନ୍ତି ଯେଉଁମାନେ ତାଙ୍କୁ ଭୟ କରନ୍ତି ଓ ଠିକ୍ କାମ କରନ୍ତି।

ଧ୍ୟାନ ଦିଅନ୍ତୁ: ବିଶେଷତଃ 9-16 ପଦ

ପାଠ ଉପସ୍ଥାପନା

ଆରମ୍ଭ

ଆସନ୍ତୁ ସ୍ୱପ୍ନ ବିଷୟରେ କଥା ହେଉ। ଆପଣ କେବେ ସ୍ୱପ୍ନ ଦେଖନ୍ତି କି? ଆପଣ ଦେଖିଥିବା ଏକ ସ୍ୱପ୍ନ ବର୍ଣ୍ଣନା କରନ୍ତୁ। ସ୍ୱପ୍ନ ପ୍ରାୟତଃ ଅର୍ଥହୀନ ଲାଗେ। କିନ୍ତୁ ବେଳେବେଳେ ଈଶ୍ୱର ଆମକୁ କୌଣସି ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ କଥା କହିବା ପାଇଁ ଦର୍ଶନ ନାମକ ଏକ ବିଶେଷ ପ୍ରକାରର ସ୍ୱପ୍ନ ବ୍ୟବହାର କରନ୍ତି।

ପାଠର ମୁଖ୍ୟ ବିଷୟଗୁଡ଼ିକ

1. ଈଶ୍ୱର ପିତରଙ୍କୁ ଏକ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ସତ୍ୟ ଶିଖାଇବା ପାଇଁ ଏକ ଦର୍ଶନ ପଠାଇଲେ। (ପିତର ଯୀଶୁଙ୍କ ପ୍ରଥମ ଶିଷ୍ୟମାନଙ୍କ ମଧ୍ୟରୁ ଜଣେ ଥିଲେ।) ପବିତ୍ର ଆତ୍ମା ଢଳାଯିବା ପରେ ସେ କ୍ରମଶଃ ପ୍ରାରମ୍ଭିକ ମଣ୍ଡଳୀର ନେତା ହେଲେ। ପରିସ୍ଥିତି ବର୍ଣ୍ଣନା କରନ୍ତୁ। ପିତରଙ୍କୁ ଭୋକ ଲାଗିଥିଲା। ମଧ୍ୟାହ୍ନ ଭୋଜନର ସମୟ ଥିଲା ଓ ଖାଦ୍ୟ ପ୍ରସ୍ତୁତ ହେଉଥିବା ବେଳେ ସେ ପ୍ରାର୍ଥନା କରିବାକୁ ଗଲେ। ହୁଏତ ଗରମ ଥିଲା, ତେଣୁ ପିତର ଘରର ସମତଳ ଛାତ ଉପରକୁ ଗଲେ, ଯେଉଁଠି ଥଣ୍ଡା ଥିଲା। ପିତର ସେଠାରେ ଏକୁଟିଆ ଥିବା ବେଳେ ଈଶ୍ୱର ତାଙ୍କୁ ଏକ ଦର୍ଶନ ପଠାଇଲେ (10:9-10)।

2. ଚିତ୍ର 9 ଦେଖାନ୍ତୁ। ଚିତ୍ର ବ୍ୟବହାର କରି 11-14 ପଦରେ ଯାହା ଘଟିଲା ତାହା ନିଜ ଭାଷାରେ କୁହନ୍ତୁ। ପିତର ସେହି ପଶୁମାନଙ୍କୁ ଖାଇବାକୁ ମନା କଲେ କାରଣ ଈଶ୍ୱରଙ୍କ ବ୍ୟବସ୍ଥା ଯିହୂଦୀମାନଙ୍କୁ ତାହା କରିବାକୁ ନିଷେଧ କରିଥିଲା।

3. ପିତରଙ୍କୁ ଆହୁରି ଦୁଇ ଥର କୁହାଗଲା ଯେ ବ୍ୟବସ୍ଥା ଯେଉଁ ପଶୁମାନଙ୍କୁ ଅଶୁଚି ବା ଅପବିତ୍ର କହିଥିଲା ସେଗୁଡ଼ିକୁ ଉଠି ଖାଆନ୍ତୁ (10:15-16)। ପ୍ରତ୍ୟେକ ଥର କ'ଣ ଘଟିଲା କୁହନ୍ତୁ। ପିଲାମାନେ କାହାଣୀରେ କିଛି ପୁନରାବୃତ୍ତି ପସନ୍ଦ କରନ୍ତି ଓ ତାହାରୁ ଶିଖନ୍ତି।

4. ତୃତୀୟ ଥର ପରେ ପିତର ଉଠିଲେ ଓ ସ୍ୱପ୍ନର ଅର୍ଥ କ'ଣ ବୋଲି ଭାବିଲେ। ଠିକ୍ ସେତିକିବେଳେ ସେ କାହାକୁ ଦ୍ୱାର ବାଡ଼ାଉଥିବା ଓ ତାଙ୍କ ନାମ ଡାକୁଥିବା ଶୁଣିଲେ। ପରେ କ'ଣ ଘଟିଲା ବର୍ଣ୍ଣନା କରନ୍ତୁ (10:17-18)। ହୁଏତ ପିତର ଭାବିଲେ ଯେ ତାଙ୍କୁ ବନ୍ଦୀ କରାଯିବ, କାରଣ ଜଣେ ଆଗନ୍ତୁକ ସୈନିକ ଥିଲେ!

5. ଈଶ୍ୱରଙ୍କ ପବିତ୍ର ଆତ୍ମା ପିତରଙ୍କୁ ସେମାନଙ୍କ ସହ ଯିବାକୁ କହିଲେ; ସେମାନଙ୍କୁ ଯୀଶୁ ଖ୍ରୀଷ୍ଟଙ୍କ ବିଷୟରେ ଶୁଣିବା ଆବଶ୍ୟକ ଥିଲା (10:19-20)। କିନ୍ତୁ ସେମାନେ ଅଣଯିହୂଦୀ ଥିଲେ। ଯିହୂଦୀମାନେ କେବେ ଅଣଯିହୂଦୀମାନଙ୍କ ସହ କିଛି ସମ୍ପର୍କ ରଖୁନଥିଲେ। ସେମାନେ ଈଶ୍ୱରଙ୍କ ପାଇଁ ପବିତ୍ରୀକୃତ ନଥିବାରୁ ସେମାନଙ୍କୁ ଅଶୁଚି ଗଣାଯାଉଥିଲା। ତା'ପରେ ପିତର ଦେଖିଲେ ଯେ ଈଶ୍ୱର କାହିଁକି ତାଙ୍କୁ ସେହି ଦର୍ଶନ ପଠାଇଥିଲେ। ଈଶ୍ୱରଙ୍କ ଦୃଷ୍ଟିରେ କୌଣସି ବସ୍ତୁ ବା କେହି ଅଶୁଚି ନୁହେଁ। ସୁସମାଚାର ସମଗ୍ର ମାନବଜାତି ପାଇଁ।

କାହାଣୀ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ଆପଣଙ୍କ ସମାଜରେ ଅଲୋକପ୍ରିୟ ବା ସମାଜରୁ ବାହାର ହୋଇଥିବା କେତେକ ପ୍ରକାରର ଲୋକଙ୍କୁ ଉଲ୍ଲେଖ କରନ୍ତୁ। ଆମେ ସେମାନଙ୍କ ପାଖକୁ ସୁସମାଚାର କିପରି ନେଇପାରିବା?

ମୁଖସ୍ଥ ପଦ ମନେ ରଖାନ୍ତୁ

ପାଠ - 9: ପିତରଙ୍କ ମିଶନାରୀ ଦର୍ଶନ

ଶାସ୍ତ୍ରପାଠ: ପ୍ରେରିତ 10:1-48, ବିଶେଷତଃ 9-16 ପଦ

1. ଗଣ ଓ ଲେଖ

ଉତ୍ତର ଲେଖନ୍ତୁ:

  • ଈଶ୍ୱର ପିତରଙ୍କୁ ପଶୁମାନଙ୍କ ସହ ଚାଦର ____ ଥର ଦେଖାଇଲେ। __________ 👉 3
  • ପିତର ____________ କରିବାକୁ ଛାତ ଉପରକୁ ଗଲେ। __________ 👉 ପ୍ରାର୍ଥନା
  • କର୍ଣ୍ଣିଲିୟଙ୍କ ପାଖରୁ କେତେ ଜଣ ଆଗନ୍ତୁକ ଦ୍ୱାର ପାଖକୁ ଆସିଲେ? (ପ୍ରାୟ) __________ 👉 3

2. ହଁ ନା ନା

ହଁ କିମ୍ବା ନା ଲେଖ:

  • ଦର୍ଶନ ଦେଖିବା ବେଳେ ପିତର କ'ଣ ଛାତ ଉପରେ ଥିଲେ? ( ___ ) 👉 ହଁ
  • ପିତର କ'ଣ ପ୍ରଥମ ଥର ସେହି ପଶୁମାନଙ୍କୁ ଖାଇଲେ? ( ___ ) 👉 ନା
  • ଈଶ୍ୱରଙ୍କ ସୁସମାଚାର କ'ଣ ପ୍ରତ୍ୟେକ ଜାତିର ଲୋକଙ୍କ ପାଇଁ? ( ___ ) 👉 ହଁ

ପବିତ୍ର ଆତ୍ମା

ସୁସମାଚାର → ସମସ୍ତ ଲୋକଙ୍କ ପାଇଁ

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ଈଶ୍ୱର ପିତରଙ୍କୁ କ'ଣ ଶିଖାଇଲେ?

ନମୁନା ଉତ୍ତର: କୌଣସି ବ୍ୟକ୍ତି “ଅଶୁଚି” ନୁହେଁ; ସୁସମାଚାର ସମସ୍ତଙ୍କ ପାଇଁ।

  • ପିତରଙ୍କ ପାଇଁ ମାନିବା କାହିଁକି କଷ୍ଟକର ଥିଲା?

ନମୁନା ଉତ୍ତର: ସେ ଆଗରୁ ଏପରି କାମ କେବେ କରିନଥିଲେ।

  • ଆମ ସହରରେ କିଏ ଅବହେଳିତ ଅନୁଭବ କରିପାରେ?

ନମୁନା ଉତ୍ତର: ଉତ୍ତର ଭିନ୍ନ ହୋଇପାରେ, ଯେପରି ଗରିବ ବା ଅଜଣା ଲୋକ।

5. ମୁଖସ୍ଥ ପଦ:

ପ୍ରେରିତ 10:35 — “ବରଂ ପ୍ରତ୍ୟେକ ଜାତିରେ ଯେଉଁ ଲୋକ ତାଙ୍କୁ ଭୟ କରେ ଓ ଠିକ୍ କାମ କରେ, ତାକୁ ସେ ଗ୍ରହଣ କରନ୍ତି।”

ପ୍ରେରିତ 10:34 — “ମୁଁ ବର୍ତ୍ତମାନ ବୁଝିଲି ଯେ ଈଶ୍ୱର ପକ୍ଷପାତୀ ନୁହନ୍ତି, ଏହା କେତେ ସତ୍ୟ।”

ହସ୍ତକଳା 1: ପିତରଙ୍କ ଦର୍ଶନର ଚାଦର

ସାମଗ୍ରୀ: କାଗଜ, କ୍ରେୟନ, ଦଉଡ଼ି

ନିର୍ଦ୍ଦେଶ:

  • ଏକ ବଡ଼ ଚାଦର ଆଙ୍କନ୍ତୁ, ପ୍ରତ୍ୟେକ କୋଣରେ ଗୋଟିଏ ଦଉଡ଼ି ସହ।
  • ଭିତରେ ବିଭିନ୍ନ ପଶୁ ଆଙ୍କନ୍ତୁ।
  • ଲେଖନ୍ତୁ: “ଈଶ୍ୱରଙ୍କ ସୁସମାଚାର ସମସ୍ତଙ୍କ ପାଇଁ।”

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଈଶ୍ୱରଙ୍କ ବାର୍ତ୍ତା ସମସ୍ତ ଲୋକଙ୍କ ପାଇଁ।

ହସ୍ତକଳା 2: ପ୍ରତ୍ୟେକ ଜାତିର ଲୋକ

ସାମଗ୍ରୀ: କାଗଜ, କ୍ରେୟନ, କଞ୍ଚି, ଗଂ

ନିର୍ଦ୍ଦେଶ:

  • ବିଭିନ୍ନ ରଙ୍ଗର ଲୁଗା ପିନ୍ଧିଥିବା ଲୋକଙ୍କୁ ଆଙ୍କନ୍ତୁ।
  • ସେମାନଙ୍କୁ କାଟି ଏକ ବୃତ୍ତରେ ଲଗାନ୍ତୁ।
  • ଲେଖନ୍ତୁ: “ଯୀଶୁ ସମସ୍ତଙ୍କୁ ଭଲପାଆନ୍ତି।”

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଯୀଶୁ ପ୍ରତ୍ୟେକ ଜନଜାତି ଓ ଜାତିକୁ ଭଲପାଆନ୍ତି।

ଖେଳ 1: ସମସ୍ତେ ସ୍ୱାଗତ

ଖେଳିବା ପଦ୍ଧତି:

  • ପିଲାମାନେ ଏକ ବୃତ୍ତରେ ଠିଆ ହୁଅନ୍ତି।
  • ପ୍ରତ୍ୟେକ ପିଲାର ନାମ କହି ତାଙ୍କୁ ମଝିକୁ ଆସିବାକୁ ନିମନ୍ତ୍ରଣ କରନ୍ତୁ।
  • ପ୍ରତ୍ୟେକ ଥର ଶ୍ରେଣୀ “ସ୍ୱାଗତ!” କୁହେ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଈଶ୍ୱର ସମସ୍ତଙ୍କୁ ସ୍ୱାଗତ କରନ୍ତି।

ଖେଳ 2: ସ୍ୱପ୍ନ ଦେଖ ଓ କୁହ

ଖେଳିବା ପଦ୍ଧତି:

  • ପିଲାମାନେ ଏକ ସ୍ୱପ୍ନ ବା ଦର୍ଶନର ଚିତ୍ର ଆଙ୍କନ୍ତି।
  • ପିତରଙ୍କ ଦର୍ଶନକୁ ସରଳ ଶବ୍ଦରେ ପୁନର୍ବାର କୁହାଯାଏ।
  • ପିଲାମାନେ ନିଜ ଚିତ୍ର ବାଣ୍ଟନ୍ତି।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଈଶ୍ୱର ଆମକୁ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ କଥା ଦେଖାଇପାରନ୍ତି।
