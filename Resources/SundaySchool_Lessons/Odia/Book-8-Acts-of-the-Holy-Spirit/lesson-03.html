ପିତର ପ୍ରଚାର ଆରମ୍ଭ କରନ୍ତି

Download Word

ଉଦ୍ଦେଶ୍ୟ

ପିଲାମାନଙ୍କୁ ଦେଖାଇବା ଯେ ପବିତ୍ର ଆତ୍ମାଙ୍କ ଶକ୍ତି ପିତରଙ୍କଠାରେ କିପରି କାମ କଲା।

ଶାସ୍ତ୍ରପାଠ

ମାର୍କ 14:66-72; ପ୍ରେରିତ 2:14-41

ମୁଖସ୍ଥ ପଦ

ପ୍ରେରିତ 2:38

“ମନ ପରିବର୍ତ୍ତନ କର ଏବଂ ତୁମ ପାପର କ୍ଷମା ପାଇଁ ଯୀଶୁ ଖ୍ରୀଷ୍ଟଙ୍କ ନାମରେ ବାପ୍ତିସ୍ମ ନିଅ … ତାହା ହେଲେ ତୁମେ ପବିତ୍ର ଆତ୍ମାଙ୍କ ଦାନ ପାଇବ।”

ପାଠ ଉପସ୍ଥାପନା

ଆରମ୍ଭ

ଆପଣ କେବେ ଭୁବନେଶ୍ୱର ଭଳି ବଡ଼ ସହରରେ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ ଘୋଷଣା କରିବାକୁ ଛାତ ଉପରେ ଲାଉଡସ୍ପିକର୍ ଥିବା ଏକ ଗାଡ଼ି ବୁଲୁଥିବା ଦେଖିଛନ୍ତି କି? ଲୋକମାନେ ଶୁଣିବାକୁ ଘରୁ ବାହାରକୁ ଆସନ୍ତି। ପିଲାମାନେ ଗାଡ଼ି ପଛେ ପଛେ ଯାଆନ୍ତି ଓ ଭିଡ଼ ଜମେ। ଆପଣଙ୍କ ସହରରେ ଭିଡ଼ କିପରି ଜମେ ତାହାର ଅନ୍ୟ ଉଦାହରଣ ଦିଅନ୍ତୁ। ଲୋକମାନେ ସବୁବେଳେ ଏହିପରି; ସେମାନେ ଖବର ଶୁଣିବାକୁ, ସମସ୍ତେ କ'ଣ କଥା ହେଉଛନ୍ତି ଜାଣିବାକୁ ଚାହାନ୍ତି।

ପାଠର ମୁଖ୍ୟ ବିଷୟଗୁଡ଼ିକ

1. ଈଶ୍ୱରଙ୍କ କାମ ଜାରି ରଖିବାକୁ ପ୍ରେରିତମାନଙ୍କୁ ସାହାଯ୍ୟ କରିବାକୁ ଯୀଶୁ କାହାକୁ ପଠାଇଲେ ଆପଣ ମନେ ପକାଇପାରିବେ କି? ଠିକ୍: ପବିତ୍ର ଆତ୍ମା। ତାଙ୍କ ଶକ୍ତି ପ୍ରେରିତମାନଙ୍କୁ ଯିରୁଶାଲମର ସମସ୍ତଙ୍କୁ ଯୀଶୁଙ୍କ ବିଷୟରେ କହିବାରେ ସାହାଯ୍ୟ କରିବ। ପାଠ 2 ର ମୁଖସ୍ଥ ପଦ, ଯୋହନ 14:26, ଏକାଠି କୁହନ୍ତୁ।

2. ପ୍ରେରିତମାନେ ଯୀଶୁ ଯାହା କହିଥିଲେ ସେପରି କଲେ। ସେମାନେ ତାଙ୍କ ବିଷୟରେ କହିବାକୁ ରାସ୍ତାକୁ ବାହାରିଲେ। ବର୍ଷର ସେହି ସମୟରେ ଯିରୁଶାଲମରେ ଅନେକ ଅତିଥି ଥିଲେ, ଏବଂ ସେମାନେ ଅନେକ ଭିନ୍ନ ଭିନ୍ନ ଦେଶରୁ ଆସିଥିଲେ। ଚିତ୍ର 3 ଦେଖାନ୍ତୁ, ଭିନ୍ନ ଭିନ୍ନ ଦେଶର ଲୋକଙ୍କୁ ଦେଖାଇ। ସେମାନେ ଭିନ୍ନ ଭିନ୍ନ ଭାଷା କହୁଥିଲେ ମଧ୍ୟ, ସମସ୍ତେ ପ୍ରେରିତମାନଙ୍କୁ ନିଜ ଭାଷାରେ କହୁଥିବା ଶୁଣିପାରିଲେ। ସେମାନେ ଏହା ବୁଝାଇପାରିଲେ ନାହିଁ। କେତେକ ଭାବିଲେ ପ୍ରେରିତମାନେ ମାତାଲ (ପ୍ରେରିତ 2:12-13)। ତା'ପରେ ପିତର ଠିଆ ହୋଇ ସେମାନଙ୍କ ସହ କଥା ହେଲେ (2:14)। ଚିତ୍ରରେ ପିତରଙ୍କୁ ଦେଖାନ୍ତୁ।

3. ଚିତ୍ର ରଖିଦିଅନ୍ତୁ ଓ ଯୀଶୁଙ୍କ ବିଚାର ସମୟରେ ପିତର କେତେ ଭୟଭୀତ ଥିଲେ ପିଲାମାନଙ୍କୁ ମନେ ପକାଇ ଦିଅନ୍ତୁ। ସେ ଯୀଶୁଙ୍କୁ ଜାଣନ୍ତି ନାହିଁ ବୋଲି ମଧ୍ୟ କହିଲେ – ତିନିଥର! ମାର୍କ 14:66-72 ର କାହାଣୀ ସଂକ୍ଷେପରେ କୁହନ୍ତୁ। ପିତରଙ୍କଠାରେ ଏହି ପରିବର୍ତ୍ତନ କାହାଦ୍ୱାରା ଆସିଲା? ସେ ବର୍ତ୍ତମାନ ଏକ ବଡ଼ ଭିଡ଼ ସାମ୍ନାରେ ଠିଆ ହୋଇ ଯୀଶୁଙ୍କ ବିଷୟରେ କିପରି କହିପାରିଲେ? ଉତ୍ତର ହେଲା: ସେ ପବିତ୍ର ଆତ୍ମାଙ୍କ ଦାନ ପାଇଥିଲେ! ଚିତ୍ର 3 ପୁଣି ଦେଖାନ୍ତୁ।

4. ପିତର ବୁଝାଇଲେ ଯେ ସେମାନେ ମାତାଲ ନୁହନ୍ତି। ଈଶ୍ୱର ସେମାନଙ୍କୁ ନିଜ ପବିତ୍ର ଆତ୍ମା ଦେଇଥିଲେ ଯେପରି ସେମାନେ ସମସ୍ତ ମାନବଜାତିର ତ୍ରାଣକର୍ତ୍ତା ଯୀଶୁଙ୍କ ବିଷୟରେ ସମସ୍ତଙ୍କୁ କହିପାରିବେ (2:15-17କ, 21)। ପିତର ଭିଡ଼କୁ ଯୀଶୁ କିଏ ତାହା କହିଲେ। ଯୀଶୁ ଈଶ୍ୱରଙ୍କ ପୁତ୍ର ବୋଲି ଦେଖାଇବାର ଗୋଟିଏ ଉପାୟ ଥିଲା ତାଙ୍କ ଚମତ୍କାର (2:22)। ଶ୍ରେଣୀକୁ କେତେକ ଉଦାହରଣ ଦେବାକୁ କୁହନ୍ତୁ। ଯୀଶୁ ମାତ୍ର ମନୁଷ୍ୟମାନଙ୍କୁ ତାଙ୍କୁ ମାରିବାକୁ ଦେଲେ ଯେପରି ସେ ସେମାନଙ୍କୁ ପାପ ଓ ମୃତ୍ୟୁରୁ ଉଦ୍ଧାର କରିପାରିବେ। ତିନି ଦିନ ପରେ ଈଶ୍ୱର ଯୀଶୁଙ୍କୁ ପୁନରୁତ୍ଥାନ କରାଇଲେ (ପ୍ରେରିତ 2:23-24)।

5. ମୁଖସ୍ଥ ପଦ ଆମକୁ କହେ ଆମେ ଏହି ବାର୍ତ୍ତା ପ୍ରତି କିପରି ପ୍ରତିକ୍ରିୟା କରିବା ଉଚିତ୍। ସେହି ଦିନ ପିତର ଲୋକମାନଙ୍କୁ ଏହା କହିଲେ, ଏବଂ 3 000 ଲୋକ ଯୀଶୁଙ୍କୁ ନିଜ ତ୍ରାଣକର୍ତ୍ତା ଭାବେ ଗ୍ରହଣ କଲେ (ପ୍ରେରିତ 2:38, 41)।

କାହାଣୀ ପ୍ରତି ଆମର ପ୍ରତିକ୍ରିୟା

ପିତର ଈଶ୍ୱରଙ୍କ ପବିତ୍ର ଆତ୍ମା ପାଇଲେ ଓ ନିର୍ଭୟରେ ଯୀଶୁଙ୍କ ବିଷୟରେ ସାକ୍ଷ୍ୟ ଦେଲେ। ଯୀଶୁଙ୍କୁ ବିଶ୍ୱାସ କରୁଥିବା ଆମ ସମସ୍ତେ ପବିତ୍ର ଆତ୍ମା ପାଇଛୁ (2:17କ)। ତେଣୁ ଆମେ ସମସ୍ତେ ଯୀଶୁଙ୍କ ବିଷୟରେ ସାକ୍ଷ୍ୟ ଦେଇପାରିବା। ଏହା ନିଜ ଜୀବନର ଏକ ଉଦାହରଣ ଦ୍ୱାରା ନିଶ୍ଚିତ କରିବାକୁ ଚେଷ୍ଟା କରନ୍ତୁ।

ପବିତ୍ର ଆତ୍ମାଙ୍କ ଦାନ ପାଇଁ ଏକ ଧନ୍ୟବାଦ ପ୍ରାର୍ଥନା ସହ ଶେଷ କରନ୍ତୁ।

ମୁଖସ୍ଥ ପଦ ମନେ ରଖାନ୍ତୁ

ପାଠ - 3: ପିତର ପ୍ରଚାର ଆରମ୍ଭ କରନ୍ତି

ଶାସ୍ତ୍ରପାଠ: ମାର୍କ 14:66-72; ପ୍ରେରିତ 2:14-41

1. ପିତର ନା ଭିଡ଼? ପି/ଭି

ପିତର କଲେ ପି, ଭିଡ଼ କଲେ ଭି ଲେଖନ୍ତୁ:

  • ଠିଆ ହୋଇ ସାହସ ସହ ଯୀଶୁଙ୍କ ବିଷୟରେ କହିଲେ। ( ___ ) 👉 ପି
  • ପ୍ରେରିତମାନଙ୍କୁ ନିଜ ଭାଷାରେ କହୁଥିବା ଶୁଣିଲେ। ( ___ ) 👉 ଭି
  • ଥରେ ତିନିଥର କହିଲେ, “ମୁଁ ତାଙ୍କୁ ଜାଣେ ନାହିଁ।” ( ___ ) 👉 ପି

2. ଠିକ୍ ଶବ୍ଦକୁ ଗୋଲ କରନ୍ତୁ

ଠିକ୍ ଶବ୍ଦକୁ ଗୋଲ କରନ୍ତୁ:

  • ପଞ୍ଚାଶତମୀରେ ପ୍ରଚାର କରିବା ବେଳେ ପିତର (ଭୟଭୀତ / ନିର୍ଭୟ) ଥିଲେ। ଠିକ୍ ଶବ୍ଦ: 👉 ନିର୍ଭୟ
  • ସେହି ଦିନ ପ୍ରାୟ (30 / 3000) ଲୋକ ବିଶ୍ୱାସ କଲେ। ଠିକ୍ ଶବ୍ଦ: 👉 3000
  • ପିତର ସେମାନଙ୍କୁ (ମନ ପରିବର୍ତ୍ତନ କରିବାକୁ / ଦଉଡ଼ିବାକୁ) ଓ ବାପ୍ତିସ୍ମ ନେବାକୁ କହିଲେ। ଠିକ୍ ଶବ୍ଦ: 👉 ମନ ପରିବର୍ତ୍ତନ କରିବାକୁ

4. ଆଲୋଚନା ପ୍ରଶ୍ନ

  • ପିତର କାହିଁକି ଏତେ ସାହସୀ ଥିଲେ?

ନମୁନା ଉତ୍ତର: ପବିତ୍ର ଆତ୍ମା ତାଙ୍କୁ ସାହସ ଓ ଶକ୍ତି ଦେଲେ।

  • ପିତର ଲୋକମାନଙ୍କୁ ଯୀଶୁଙ୍କ ବିଷୟରେ କ'ଣ କହିଲେ?

ନମୁନା ଉତ୍ତର: ଯୀଶୁ ତ୍ରାଣକର୍ତ୍ତା ଯିଏ ମରିଲେ ଓ ପୁଣି ଉଠିଲେ।

  • ଆପଣ ଯୀଶୁଙ୍କ ପାଇଁ କିପରି ସାହସୀ ହୋଇପାରିବେ?

ହସ୍ତକଳା 1: କଥା ବବୁଲ୍ ସହ ପିତର

ସାମଗ୍ରୀ: କାଗଜ, କ୍ରେୟନ, କଞ୍ଚି, ଗଂ

ନିର୍ଦ୍ଦେଶ:

  • ସିଧା ଠିଆ ହୋଇଥିବା ପିତରଙ୍କୁ ଆଙ୍କନ୍ତୁ।
  • ଏକ ବଡ଼ କଥା ବବୁଲ୍ କାଟନ୍ତୁ।
  • ଏଥିରେ ଲେଖନ୍ତୁ: “ଯୀଶୁ ପ୍ରଭୁ!” ଏବଂ ତାଙ୍କ ପାଖରେ ଲଗାନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ପବିତ୍ର ଆତ୍ମା ପିତରଙ୍କୁ ସାହସୀ କଲେ।

ହସ୍ତକଳା 2: ଭିଡ଼ର କାଗଜ ଶୃଙ୍ଖଳା

  • ପଟିଗୁଡ଼ିକୁ ଲୋକଙ୍କ ଏକ ଶୃଙ୍ଖଳାରେ ଲଗାନ୍ତୁ।
  • ପ୍ରଥମଟିରେ ଲେଖନ୍ତୁ: 3000 ଜଣ ବିଶ୍ୱାସ କଲେ।

ଖେଳ 1: ଭିଡ଼ ଜମାଅ

ଖେଳିବା ପଦ୍ଧତି:

  • ପିଲାମାନେ କୋଠରୀରେ ଚାଲନ୍ତି।
  • ଶିକ୍ଷକ “ଶୁଣ!” କହିଲେ, ସମସ୍ତେ ଜଣେ ପିଲାଙ୍କ ଚାରିପାଖରେ ଏକତ୍ର ହୁଅନ୍ତି।
  • ସେହି ପିଲା ମୁଖସ୍ଥ ପଦ କହେ ଓ ଭିଡ଼ ହାତତାଳି ଦିଏ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଲୋକମାନେ ସୁସମାଚାର ଶୁଣିବାକୁ ଏକତ୍ର ହୁଅନ୍ତି।

ଖେଳ 2: ସାହସୀ ସ୍ୱର

ଖେଳିବା ପଦ୍ଧତି:

  • ପିଲାମାନେ “ଯୀଶୁ ପ୍ରଭୁ” ଫୁସଫୁସ୍ କରି କହନ୍ତି।
  • ତା'ପରେ ଟିକିଏ ଜୋରରେ, ତା'ପରେ ଉଚ୍ଚ ଓ ସ୍ପଷ୍ଟ ଭାବେ କୁହନ୍ତୁ।
  • ଯୀଶୁଙ୍କ ବିଷୟରେ ବାଣ୍ଟିବାକୁ ସାହସୀ ହେବା ବିଷୟରେ କଥା ହୁଅନ୍ତୁ।

ପାଠର ମୁଖ୍ୟ ବିଷୟ: ଆତ୍ମା ଆମକୁ ସାହସୀ ହେବାକୁ ସାହାଯ୍ୟ କରନ୍ତି।
